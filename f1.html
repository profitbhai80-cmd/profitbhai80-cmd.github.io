Haier Refrigerator Error Code F1

Quick answer

Error codeF1 — Haier Refrigerator
What it meansF1 means the refrigerator (R1) sensor has a malfunction — the R1 sensor has a short circuit or an open/broken circuit. Both Haier service manuals agree on this meaning; what differs by family is how the code is displayed and retrieved, not what it means.
Most common causeA failed or disconnected refrigerator-compartment sensor (R1 SNR), or a wiring/connector fault between the sensor and the main board.
Safe to check yourself?Only partly. You can safely retrieve the code and check connectors with the power off. Sensor resistance testing and replacement are technician work — a hard sensor fault cannot be fixed by any reset.
Checked againstHaier HB21FWRSS Refrigerator Service Manual (EDITION 2008-03-24); Haier HRF-663ISB2 Service Manual (Issue 20090416, Ref0904S016V0); Haier HRF-6631RG user manual (code list); Haier HB21FGRAA user manual

Applies to — read this first

Haier uses F1 consistently for the refrigerator sensor across the families we checked — but the families differ in how the code appears. On HB21F-family models the code is recalled with a button sequence; on HRF-663-family models the display shows the fault mode directly. Check your model family on the rating label before you start — see how to find your model number.

ManualExact wording for F1
HB21FWRSS service manual (EDITION 2008-03-24)"Refrigerator sensor malfunction — R1 SNR short circuit or open circuit" (Malfunction Codes Table, No. 4).
HRF-663ISB2 service manual (Issue 20090416, Ref0904S016V0)"R1 SNR is defective — R1 SNR short circuit or broken circuit." The display indicates fault mode as "Refrigerator setting 1 glitters"; R1 SNR controls the start/stop of the refrigerator-compartment air damper.

Neighbouring codes from the HB21F table for orientation: F2 = freezer sensor malfunction, F3 = environment temperature sensor, F5 = defrost sensor, F6 = icemaker sensor. Do not confuse with Haier AIR CONDITIONER F1 — that is the indoor-unit heat-exchanger temperature sensor fault: a different appliance, a different code map.

What the machine does when F1 fires

On HB21F models the codes are not shown automatically. You recall them by pressing the freezer temperature control button (>) and the fridge temperature control buttons (<) and (>) at the same time for 3 seconds; the code appears on the cabinet display panel, and pressing the same buttons for 3 seconds again exits the mode. On HRF-663-family models the refrigerator setting indicator enters fault mode (setting 1 glitters) and F1 is shown among the display codes E0, E1, E2, F1, F2, F3. The HRF-663 manual's user-facing guidance is: if a code appears, contact customer service.

Common causes

  1. The R1 (refrigerator compartment) sensor has failed — short circuit or open circuit. Both Haier service manuals list this as the definition of F1.
  2. The sensor's wiring or connector to the main board is loose, corroded, or damaged — the HRF-663 manual names a "broken circuit" as a fault mode.
  3. A main-board fault misreading the sensor circuit — the HB21F manual gives the sensor resistance values the board expects, so a wrong reading can point at either side.

Safe checks, in order

  1. Retrieve the code properly: on HB21F models press the freezer temperature control (>) and the fridge temperature controls (<) + (>) together for 3 seconds and read the cabinet display. Confirm it really is F1 and note it down.
  2. Switch the refrigerator off at the wall and unplug it. Leave it a few minutes, then plug it back in and recall the code once — a transient display glitch is rare, but ruling it out costs nothing.
  3. With the power OFF and the machine unplugged, visually inspect the visible sensor connector and harness near the refrigerator compartment for looseness or corrosion. Do not cut, splice, or probe any wires.
  4. If F1 returns immediately, stop: the manual's next step is measuring the sensor resistance at the main-board connector CN1 pins 1–2 (the manual expects about 6.35–3.88 kΩ at 0–10 °C and 2.45–1.58 kΩ at 20–30 °C) — a test that needs the back panel off and a multimeter, which the manual reserves for service staff.

Work through the checks in order and stop as soon as the code clears. A hard sensor fault (short or open circuit) cannot be cleared by any reset — the power-cycle step above only rules out a display glitch. If a check needs a panel removed, a connector probed, or a part tested, it is no longer a safe home check — skip to the technician section.

When to call a technician

  • F1 returns after every power cycle — the R1 sensor is almost certainly failed or its circuit is broken.
  • The CN1 resistance measurement is needed to confirm the fault — that is service-staff work.
  • Visible wire damage or a burnt connector anywhere near the sensor — do not attempt to repair wiring yourself.
  • The refrigerator compartment is not cooling correctly, or the compressor runs non-stop or never runs — the failed sensor is disrupting temperature control.

Safety first

Always unplug the refrigerator before touching any connector or wiring, and let it sit a few minutes. A failed sensor means temperature control may misbehave — check stored food for spoilage if the compartment has been warm. Never probe a live control board, and never attempt sealed-system (refrigerant) work: sensor faults are electrical and refrigerant is not involved here, but the boundary still stands.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does F1 mean on a Haier refrigerator?

F1 means the refrigerator (R1) sensor has a malfunction — a short circuit or an open/broken circuit. Both Haier service manuals we checked (HB21FWRSS, edition 2008-03-24, and HRF-663ISB2, issue 20090416) give this meaning, and both families agree on it.

Why don't I see F1 on my Haier fridge display?

On HB21F-family models the codes are not shown automatically. Press the freezer temperature control (>) and the fridge temperature controls (<) and (>) together for 3 seconds; the code appears on the cabinet display. Press the same buttons for 3 seconds again to exit.

Can I reset Haier refrigerator F1 by unplugging it?

A power cycle rules out a display glitch, but a genuine F1 is a hard sensor fault — a shorted or open R1 sensor circuit — and no reset repairs that. If F1 comes back after the power cycle, the sensor or its wiring needs a technician.

Some websites say Haier F1 means fan failure. Is that right?

No — that is the Daewoo refrigerator meaning, not Haier's. One ranking page mislabels Daewoo content as Haier and claims F1 = fan failure; both Haier service manuals define F1 as the refrigerator sensor fault. Replacing a fan for an F1 code would fix nothing on a Haier.

Is Haier fridge F1 the same as Haier air conditioner F1?

No. Haier air conditioner F1 is the indoor-unit heat-exchanger temperature sensor fault — a different appliance with a different code map. Make sure any guide you read is about Haier refrigerators, not air conditioners.
