Hisense Refrigerator Error Code C1, C2, C3

Quick answer

Error codeC1, C2, C3 — Hisense Refrigerator
What it meansC1 = freezer door open more than 10 minutes (else freezer door sensor failure); C2 = refrigerator door open more than 10 minutes (else refrigerator door sensor failure); C3 = both doors open more than 10 minutes (else door sensor failure). Close the door to clear the code; if it stays displayed with the door closed, the door sensor has failed - call a service centre.
Most common causeA door left open for more than 10 minutes - or, if the code stays on with the door closed, a door sensor failure. The manuals name no other cause.
Safe to check yourself?Yes - for the door-open case only: close the door and the code clears. If the code stays displayed with the door closed, the door sensor has failed and it is a service-centre job.
Checked againstHisense RB5P410SACCUK user manual (pp.33-34) + Hisense doc 962974en-a2, INSTRUCTIONS FOR USE OF A REFRIGERATOR WITH FREEZER (troubleshooting section 28)

Applies to — read this first

Read this first, because Hisense C1, C2 and C3 are one combined page for a reason: they are door-OPEN indicators with a built-in sensor-failure fallback - NOT door-switch faults. C1 names the freezer door, C2 the refrigerator door, C3 both doors - each after more than 10 minutes open. The two Hisense documents give identical rows for all three. Do not confuse them with dr (HRF266 service manual: 'Closed Freezer/Refrigerator doors or the door switch malfunctions' - the door switch on the service platform; dr stays HOLD, one family only) or with E9 (door open too long / door sensor failure on the fan platform, already published). C1/C2/C3 name WHICH door; E9 and dr do not.

What the machine does when C1, C2, C3 fires

The display shows C1, C2 or C3 after the named door has been open for more than 10 minutes. Close the door and the code clears. If the code stays displayed with the door closed, a door sensor has failed.

Common causes

  1. Freezer compartment door open for more than 10 minutes (C1) - the manuals' own row.
  2. Refrigerator compartment door open for more than 10 minutes (C2) - the manuals' own row.
  3. Refrigerator and freezer compartment doors open for more than 10 minutes (C3) - the manuals' own row.
  4. Door sensor failure - if the code stays displayed despite the door being closed, a door sensor failure has occurred (the manuals' own fallback).

Safe checks, in order

  1. Close the door - the manuals' ONLY homeowner step, quoted verbatim: 'To eliminate the error, close the door.' (C1: freezer door; C2: refrigerator door; C3: both doors.)
  2. If the code stays displayed with the door closed, a door sensor has failed - call a service centre to fix the problem.
  3. Do not invent seal-cleaning, hinge, or sensor-replacement steps - none exist in the manuals.

The steps above are the manuals' full remedy, printed exactly. This page does not invent seal-cleaning, hinge, or sensor-replacement steps - none exist in the manuals for C1/C2/C3.

When to call a technician

  • C1, C2 or C3 stays displayed with the door closed - the door sensor has failed; call a service centre.
  • Any other fault code alongside C1/C2/C3 - switch off and call a qualified technician.

More guidance: when an appliance error requires professional service.

Safety first

C1/C2/C3 are door indicators in a mains-powered refrigerator: the only homeowner action is closing the door. Never open panels or probe the door sensor wiring yourself - sensor replacement is technician work.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does C1 mean on a Hisense refrigerator?

The freezer compartment door has been open for more than 10 minutes. Close the door to clear it. If C1 stays displayed with the door closed, the freezer door sensor has failed - call a service centre.

What is the difference between C1, C2, and C3?

Which door: C1 is the freezer door, C2 is the refrigerator door, C3 is both doors - each after more than 10 minutes open. All three carry the same fallback: if the code stays on with the door(s) closed, a door sensor has failed.

Is C1 the same as E9 or dr?

No. E9 (fan platform) is also a door-open/door-sensor code but does not say which door; dr (service platform) is the door switch malfunctioning. C1/C2/C3 are specific to the RB5P410 platform and name the door. See the E9 page; dr is not yet published (only one manual names it).

My fridge beeps after 2 minutes with the door open - is that C1?

No. That is the door-open alarm on other Hisense families (e.g. HR6CDFF512GB: alarm after 2 minutes). C1 appears only after 10 minutes, on RB5P410-type models. Different behaviour, different code.

What should I do if C1 stays on with the door closed?

The door sensor has failed - the manuals say 'If, despite the door being closed, the error C1 is still displayed, a door sensor failure has occurred. Call a service centre to fix the problem.' Do not try to replace the sensor yourself.
