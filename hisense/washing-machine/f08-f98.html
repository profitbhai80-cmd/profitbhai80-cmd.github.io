Hisense Washing Machine Error Code F08–F98

Quick answer

Error codeF08–F98 — Hisense Washing Machine
What it meansF08–F98 = electronic module fault. On the verified Hisense families, any F-code other than F01, F03, F13, F14 or F24 falls under one catch-all row in the manuals: else fault code, F04–F98, electronic module fault. F17 is EXCLUDED from this page (see below).
Most common causeThe manuals give no user-diagnosable cause and no per-code cause tree for these codes. The control electronics have detected an internal fault; the manuals offer no per-code diagnosis.
Safe to check yourself?Yes - only the manual's 3-step reset: turn the knob to Off for 3 seconds (WDQR: press On/off for 2 seconds), press Start/Pause after the fault clears, and if the fault occurs again, disconnect the power supply and contact aftersale service. There is no other manual remedy.
Checked againstHisense WFQP8014EVM / WFQP9014EVM / WFMP8014EVM / WFMP9014EVM User Manual, Fault Code List p.16 + section C + Hisense HWFL1014V User Manual + Hisense WDQR1014EVAJM User Manual (doc X08060925, p.12)

Applies to — read this first

Read this first, because no Hisense manual defines F08, F09, F10, F11, F12, F15, F16, F18, F19, F20, F21, F22 or any F25+ code individually. Every manual names only F01, F03, F13, F14, F24 (and F04–F07/F23) - everything else is one catch-all row meaning electronic module fault. F04–F07/F23 are the same fault under their own grouped row (see the published F04–F07/F23 page); this page covers the rest of the catch-all range. F17 is NOT covered by this page: on washer-dryers WDQY9014EVJM and WDBL1014V, owner and technician reports consistently describe F17 as a drying-cycle fault (no water coming into the condensing chamber during drying), which conflicts with the catch-all meaning, and no Hisense manual for those models has been verified yet, so F17 is still under research. Do not tell WDQY/WDBL owners F17 is an electronic-module fault, and do not publish it as a condensing fault either. Scope caveat: the catch-all is NOT verified for the WFQY / WDQY / WDBL families - their full user manuals were not found in readable form. If your manual defines the code individually, that manual wins.

What the machine does when F08–F98 fires

The washer stops when the program is running and the display window shows the fault code.

Common causes

  1. Electronic module fault - the control electronics detected an internal fault. That is the manuals' whole definition; they give no per-code cause.
  2. No user-diagnosable cause is given in any manual for these codes - there is no manual cause tree for F08, F09, F10, F11, F12, F15, F16, F18-F22 or F25-F98.
  3. Wrong-code reading - door lock is F13/F14 in the manuals, not F08/F09. Heater, motor-tachometer, low-water-pressure, pump-circuit, user-interface and worn-brushes meanings on ranking pages are competitor inventions, not manual causes.
  4. F17 is a different question - on WDQY9014EVJM and WDBL1014V washer-dryers, field reports describe F17 as a drying-cycle fault (no water reaching the condensing chamber), which conflicts with the catch-all meaning. F17 is excluded from this page and still under research.

Safe checks, in order

  1. Turn the knob to Off for 3 seconds to turn off the machine (WDQR1014EVAJM variant: press the On/off button for 2 seconds to turn off the machine).
  2. After the fault is removed, press the Start/Pause key.
  3. If the fault occurs again, disconnect the power supply and contact aftersale service.
  4. Do not follow forum remedies as manual steps: the 30-60-minute unplug, heater replacement, tachometer checks and condenser cleaning prescribed in JustAnswer threads are forum advice, not manual steps, and must not be presented as manual remedies.

The steps above are the manuals' full remedy, quoted from the WFQP8014EVM manual section C (all catch-all families equivalent). No heater/thermostat replacement, multimeter, tachometer, pressure-switch, condenser-cleaning, or drain-pump steps exist in the manuals for these codes.

When to call a technician

  • The fault occurs again after the 3-step reset - disconnect the power supply and contact aftersale service.
  • Your model is a WFQY, WDQY or WDBL machine - the catch-all is not verified for those families, so check your model's own manual first; if it defines the code individually, that manual wins.
  • Your washer-dryer shows F17 - do not follow the electronic-module reset as a fix for a drying fault; F17 is excluded from this page and still under research.

More guidance: when an appliance error requires professional service.

Safety first

If the fault occurs again, disconnect the power supply and contact aftersale service. The manuals offer no user-serviceable repair for an electronic-module fault - do not open the machine or attempt a module repair yourself.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

My washer shows F10 (or F08, F11, F12...). What does it mean?

On WFQP, WFMP, HWFL and WDQR families it means the same thing as F04-F07: an electronic-module fault. The manuals do not define F08-F12, F15, F16, F18-F22 or F25-F98 individually - any F-code other than F01, F03, F13, F14 or F24 falls under the catch-all row "else fault code, F04-F98: electronic module fault". Same 3-step reset, then a service call if it reoccurs.

A website says F08 is a door-lock fault / F10 is a heater fault. Is that right?

No Hisense manual says that. The manuals put the door lock at F13/F14, and put F08/F09/F10 under the electronic-module catch-all. The door-lock, heater, motor-tachometer and low-water-pressure meanings on ranking pages contradict each other (four different F08 meanings, three different F10 meanings) and none cites a manual.

What does "electronic module fault" actually mean?

The control electronics detected an internal fault. The manuals give no user-diagnosable cause and no per-code diagnosis; the only sanctioned steps are the 3-step reset (off 2-3 seconds, then Start/Pause, then service if it reoccurs).

My washer-dryer shows F17. Is it the same fault?

Not necessarily - F17 is excluded from this page. On WDQY9014EVJM and WDBL1014V washer-dryers, owner and technician reports consistently describe F17 as a drying-cycle fault (no water reaching the condensing chamber), which conflicts with the catch-all meaning. No Hisense manual for those models has been verified yet, so F17 is still under research - do not follow the electronic-module reset as a fix for a drying fault; check your model's own manual.

My display shows F25 / F30 / F54 - what is that?

Same catch-all: on the verified families, any F-code from F04 to F98 that is not F01/F03/F13/F14/F24 is an electronic-module fault. Note the trap: dishwasher F-codes (F10 overfilling, F54, F67) are a different system - if your appliance is a dishwasher, see the Hisense dishwasher pages, not this one.
