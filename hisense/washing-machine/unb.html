Hisense Washing Machine Error Code UNB

Quick answer

Error codeUNB — Hisense Washing Machine
What it meansUNB = unbalance alarm — the load is unevenly distributed, so the machine paused (usually before/during spin) to protect itself. UNB is an ALARM, not a component fault: the manuals give no internal-failure diagnosis for UNB, and this page invents no bearing/suspension/motor diagnostics beyond the manuals' "if it reoccurs, call service." The manuals' two named triggers: "Laundry winding" (tangled/balled load) and "Too light-weighted laundry" (single heavy item or tiny load — add one or two towels). Display-case note: manuals print UNB, Unb and "Unb" interchangeably. Scope: UNB appears in BOTH the F-series tables and the top-load E-series tables — do not present it as F-series-only.
Most common causeAn unbalanced load — the manuals' two named triggers: "Laundry winding" (tangled/balled load) and "Too light-weighted laundry" (a single heavy item or a tiny load).
Safe to check yourself?Yes — the manuals' own procedure: press the Power key for 3 sec to turn the machine off; open the door and re-tidy the clothes; rotate the program knob to single dehydration mode; spin the clothes to dry again.

What the machine does when UNB fires

The display shows UNB (or Unb / "Unb") and the machine pauses — usually before or during spin — because the load is unbalanced.

Common causes

  1. Laundry winding — the tangled/balled load trigger, verbatim from the manuals.
  2. Too light-weighted laundry — the single-heavy-item or tiny-load trigger, verbatim from the manuals.

Safe checks, in order

  1. Press 'Power Supply' key for 3 sec to turn off the machine (WFPV7012MT: "Turn the nub to Off for 3 seconds").
  2. Open the door and re-tidy the clothes — for a tangled/winding load: shake the clothes out and put them back in; for a too-lightweight load: add one or two towels (the manuals' own remedies).
  3. Rotate the program knob to single dehydration mode (WF5S1045BB: "select the single dewatering program").
  4. Spin the clothes to dry again.
  5. If the fault occurs again, disconnect power supply and contact with after-sale service.

The steps above are the manuals' own UNB procedure, in order — the two named triggers and their remedies included. Nothing added, nothing invented.

When to call a technician

  • UNB reoccurs with balanced loads after re-tidying and a retry — disconnect power and call service (the manuals stop there; do not invent suspension/bearing diagnostics).

More guidance: when an appliance error requires professional service.

Safety first

UNB is a load-balance alarm: the home scope is redistributing the laundry and running a single dehydration programme. Never open the machine's panels to reach suspension components yourself — that is service work.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does UNB mean on a Hisense washing machine?

UNB means the washing machine has detected an unbalanced load — an unbalance alarm, not a part failure. It is verified verbatim in 10+ Hisense manuals (WFN9012, WF5S1045BB, WFPV7012MT, WFQP8014EVM and others).

Is UNB a fault or just a warning?

An alarm, not a component fault: the machine paused itself because the load is unbalanced. 10+ manuals list it as "Unbalance alarm" with a user procedure — no part diagnosis.

It shows UNB with just one heavy item (duvet/towel).

The manuals' named trigger: too-lightweight/single-heavy laundry. Add one or two towels to balance, then run the single dehydration programme.

UNB keeps coming back with normal loads.

Re-tidy and retry once per the manuals; check the machine stands level and firm. If it reoccurs with balanced loads, disconnect power and call service — the manuals stop there; this page does not invent suspension/bearing diagnostics.

Does UNB appear as 'Unb' or 'UNB'?

Both: manuals print UNB, Unb, "Unb" interchangeably.
