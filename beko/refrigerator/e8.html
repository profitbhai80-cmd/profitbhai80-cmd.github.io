Beko Refrigerator Error Code E8

Quick answer

Error codeE8 — Beko Refrigerator
What it meansE8 = icematic air sensor error - the ice-maker (icematic) air sensor circuit has failed. On Cosmos SBS models (G91631NE-G91634NE) and FOUREVER 3-door models (G91629NWU). CAVEAT, stated honestly: both manuals are U4-platform documents with the same section structure and the same KN4/KN6/KN10 sockets - two product families, one control platform. Same caveat class as the published Hisense refrigerator F2 page.
Most common causeThe icematic air sensor circuit has failed. The handbooks name no sub-cause beyond the sensor circuit itself. "Ice buildup around sensor" as a cause is invented - neither handbook mentions it.
Safe to check yourself?No - the handbooks give no user reset for E8. The flowchart check (KN4 pins 14-15, then a multimeter resistance measurement) is a service procedure - if you are not comfortable opening the control area, call a service centre.
Checked againstArcelik BEKO COSMOS Service Handbook, section 13.6 (p.107) + Arcelik BEKO G91629NWU Service Manual, section 9.6 (p.40)

Applies to — read this first

Read this first, because Beko refrigerator E8 carries a platform caveat this page states honestly and prominently: both documents are U4-platform documents with the same section 13 / section 9 structure and the same KN4/KN6/KN10 sockets - two product families (SBS Cosmos vs FOUREVER 3-door wardrobe), one control platform. Same caveat class as the published Hisense refrigerator F2 page. E8 in this meaning exists only on the Cosmos/American U4 platform - not on bottom-mount models (where E08 is a low-voltage warning, power supply below 170 V), not on Beko washing machines (WM E8 is not taking in water), not on Beko tumble dryers (dryer E08 is a door NTC fault), and not on Beko dishwashers (DW E08). E8 is NOT a drainage problem.

What the machine does when E8 fires

The ice maker will not operate while this fault is present (ukwhitegoods ASD V0 transcription: "Ice maker will not operate" - a transcription, not a manual quote). The handbooks give no further user-facing behaviour for E8.

Common causes

  1. Icematic air sensor circuit failed - the handbooks' own fault definition.
  2. Disconnected sensor cables at the control board sensor socket (KN4) pins 14 and 15 - the flowchart's first check.
  3. Wrong-code reading - E08 (bottom-mount low-voltage warning), Beko WM E8 (not taking in water), Beko dryer E08 (door NTC) and Beko DW E08 are different codes on different systems. E8 is NOT a drainage problem.

Safe checks, in order

  1. Check the cables connected to the control board sensor socket (KN4) pins 14 and 15; if disconnected, re-connect them, turn the refrigerator on and check whether the error is still displayed (Cosmos handbook flowchart, p.245).
  2. Measure the sensor resistance with a multimeter at the KN4 pins - the flowchart's next step. The text layer is truncated at the end; this page does not invent the continuation.
  3. Do NOT use the JustAnswer expert's ~8 kOhm figure (at room temperature) as a manual value - no resistance value exists in either handbook's visible text. Do NOT publish "ice buildup around sensor" as a cause. Do NOT publish the JustAnswer AI summary's drainage steps.

The steps above are the handbook flowchart's steps, printed exactly as far as the text layer goes. The ukwhitegoods ASD V0 transcription adds: "Icemaker or ice thermistor sensor error. Displayed if measured sensor value is open circuit or short circuit. Resets if the sensor value is correct (not open or short) error is omitted. Check wiring. Replace sensor. Ice maker will not operate." - a transcription, not a manual, cited as such. All cable and multimeter work is a service procedure.

When to call a technician

  • E8 is displayed at all - the flowchart check is a service procedure; there is no homeowner fix.
  • E8 returns after the KN4 pins 14-15 cable check - the sensor or the control board needs a technician.
  • Any burning smell, visibly damaged wiring, or other fault codes alongside E8 - switch off and call a qualified technician.

More guidance: when an appliance error requires professional service.

Safety first

E8 is a sensor-circuit fault in a mains-powered refrigerator: never open the control area or probe the control board yourself. The KN4 socket and multimeter checks are service work.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does E8 mean on a Beko refrigerator?

The ice-maker (icematic) air sensor has failed. Verified in two Arcelik service manuals: the COSMOS handbook (section 13.6, models G91631NE-G91634NE) and the G91629NWU service manual (section 9.6). The ice maker will not operate while this fault is present.

Is E8 a drainage problem?

No. One JustAnswer AI summary says to check the drain pump and drain hose for E8 - that is the washing-machine E8 meaning leaking into a fridge result. On a Beko refrigerator, E8 is the icematic air sensor. The thread's own expert says the same.

Is E8 the same as E9?

No. E8 = icematic air SENSOR error; E9 = icematic MOTOR error. Two JustAnswer experts say E9 is a sensor error - that is E8's meaning, not E9's. See the E9 page.

How do I check it?

Per the Cosmos handbook flowchart: check the cables on the control board sensor socket (KN4) pins 14 and 15; if disconnected, re-connect them, turn the refrigerator on and check whether the error is still displayed. Then measure the sensor resistance with a multimeter at the KN4 pins. This is a service procedure - if you are not comfortable opening the control area, call a service centre.

Is E8 the same as the dryer E08 or washing machine E08?

No. Beko reuses code strings across appliances: dryer E08 is a door NTC fault (already live on our site), WM E08 is "not taking in water", and the fridge warning-table E08 is a low-voltage warning. This page covers the refrigerator E8 (icematic air sensor) only.
