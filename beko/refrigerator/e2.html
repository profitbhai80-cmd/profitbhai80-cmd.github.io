Beko Refrigerator Error Code E2

Quick answer

Error codeE2 — Beko Refrigerator
What it meansE2 = fridge evaporator sensor error - the refrigerator (fresh-food) compartment evaporator sensor circuit has failed. On Cosmos SBS models (G91631NE-G91634NE) and FOUREVER 3-door models (G91629NWU). CAVEAT, stated honestly: both manuals are U4-platform documents with the same section structure and the same KN6 sockets - two product families, one control platform. Same caveat class as the published Hisense refrigerator F2 page.
Most common causeThe fridge evaporator sensor circuit has failed. The handbooks name no sub-cause beyond the sensor circuit itself.
Safe to check yourself?No - the handbooks give no user reset for E2. The flowchart check (KN6 pins 3-4, then a multimeter measurement) is a service procedure - if you are not comfortable opening the control area, call a service centre.
Checked againstArcelik BEKO COSMOS Service Handbook, section 13.3 (p.104) + Arcelik BEKO G91629NWU Service Manual, section 9.3 (p.37)

Applies to — read this first

Read this first, because Beko refrigerator E2 carries a platform caveat this page states honestly and prominently: both documents are U4-platform documents with the same section 13 / section 9 structure and the same KN6 sockets - two product families (SBS Cosmos vs FOUREVER 3-door wardrobe), one control platform. Same caveat class as the published Hisense refrigerator F2 page. E2 in this meaning exists only on the Cosmos/American U4 platform - not on bottom-mount models (where E02 is a generic sensor warning), not on Beko washing machines (WM E2/E02 is a heating fault) or air conditioners (AC E2 is an evaporator temperature sensor fault) or dishwashers (DW E02 is a water shortage fault).

What the machine does when E2 fires

The handbooks give no user-facing behaviour for E2 - no "cannot operate normally" language and no user reset; the fault is a sensor circuit fault, not a user setting.

Common causes

  1. Fridge evaporator sensor circuit failed - the handbooks' own fault definition.
  2. Disconnected sensor cables at the control card sensor socket (KN6) pins 3 and 4 - the flowchart's first check.
  3. Wrong-code reading - E02 (bottom-mount warning table), Beko WM E2/E02 (heating), Beko AC E2 (evaporator temperature sensor) and Beko DW E02 (water shortage) are different codes on different systems.

Safe checks, in order

  1. Check the cables connected to the control card sensor socket (KN6) pins 3 and 4. If cables are disconnected, re-connect them, turn the refrigerator on and check whether the error is still displayed (Cosmos handbook flowchart, pp.240-241).
  2. Measure the sensor with a multimeter - the flowchart's next step. The text layer is truncated after "measure sensor"; this page does not invent the continuation.
  3. Do NOT use appliancemode's 25.3 kOhm figure (5C ~25.3 kOhm) as a manual value - neither handbook's visible text layer gives a resistance table.

The steps above are the handbook flowchart's steps, printed exactly as far as the text layer goes. The ukwhitegoods ASD V0 transcription adds: "Fridge compartment evaporator or defrost sensor / thermistor error. Check wiring. Replace sensor. Check control module." - a transcription, not a manual, cited as such. All cable and multimeter work is a service procedure.

When to call a technician

  • E2 is displayed at all - the flowchart check is a service procedure; there is no homeowner fix.
  • E2 returns after the KN6 pins 3-4 cable check - the sensor or the control module needs a technician.
  • Any burning smell, visibly damaged wiring, or other fault codes alongside E2 - switch off and call a qualified technician.

Safety first

E2 is a sensor-circuit fault in a mains-powered refrigerator: never open the control area or probe the control card yourself. The KN6 socket and multimeter checks are service work.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does E2 mean on a Beko refrigerator?

The fridge (fresh-food) evaporator sensor has failed. Verified in two Arcelik service manuals: the COSMOS handbook (section 13.3, models G91631NE-G91634NE) and the G91629NWU service manual (section 9.3). It is the sensor on the fridge evaporator coil - not the fridge air sensor (that is E3).

Is E2 the same as E02?

No. E2 (no leading zero) is a Cosmos/American SxS service code: fridge evaporator sensor error. E02 is a bottom-mount warning-table code that means a generic "sensor warning" - and no Beko manual defines its meaning. Different systems, different pages.

How do I check it?

Per the Cosmos handbook flowchart: check the cables on the control card sensor socket (KN6) pins 3 and 4; if disconnected, re-connect them, turn the refrigerator on and check whether the error is still displayed. Then measure the sensor with a multimeter. This is a service procedure - if you are not comfortable opening the control area, call a service centre.

Why does one Beko page have no E2 at all?

The ukwhitegoods "American" page covers an older (GNE-type) code set with no E2 row, while the same site's ASD V0/V3 pages list E2. The code exists on the Cosmos/American U4 platform; the older set is a different control version. Check your model number against the Cosmos (G91631NE-G91634NE) or FOUREVER (G91629NWU) families.

Is E2 the same as the washing machine E2 or air conditioner E2?

No. Beko reuses code strings across appliances: WM E2 is a heating fault, AC E2 is an evaporator temperature sensor fault on the air conditioner. This page covers the refrigerator E2 only.
