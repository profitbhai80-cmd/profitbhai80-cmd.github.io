Beko Refrigerator Error Code E15

Quick answer

Error codeE15 — Beko Refrigerator
What it meansE15 = cyclic condenser fan error - the condenser fan speed is wrong or the fan has failed. On Cosmos SBS models (G91631NE-G91634NE) and FOUREVER 3-door models (G91629NWU). CAVEAT, stated honestly: both manuals are U4-platform documents with the same section structure and the same KN10 socket - two product families, one control platform. Same caveat class as the published Hisense refrigerator F2 page.
Most common causeThe condenser fan speed is wrong or the fan has failed. The handbooks name no sub-cause beyond the fan itself. "Dust/debris buildup" as a cause is invented - neither handbook mentions it.
Safe to check yourself?No - the handbooks give no user reset for E15. The flowchart check (KN10 pins 4-6, then the "Replace Condenser Fan" branch) is a service procedure - if you are not comfortable opening the control area, call a service centre.
Checked againstArcelik BEKO COSMOS Service Handbook, section 13.9 (p.110) + Arcelik BEKO G91629NWU Service Manual, section 9.9 (p.43)

Applies to — read this first

Read this first, because Beko refrigerator E15 carries a platform caveat this page states honestly and prominently: both documents are U4-platform documents with the same section 13 / section 9 structure and the same KN10 socket - two product families (SBS Cosmos vs FOUREVER 3-door wardrobe), one control platform. Same caveat class as the published Hisense refrigerator F2 page. E15 in this meaning exists only on the Cosmos/American U4 platform. There is no E15 on the bottom-mount warning table (the table stops at E11). Beko WM E15 is a flowmeter error (still on HOLD) and Beko DW E15 is a different code - different appliances, different systems. Note the G91629NWU section 9.8 heading mislabels E13 as "Condenser Fan" - see the E13 spec; the E15 meaning itself is consistent across both manuals.

What the machine does when E15 fires

The handbooks give no user-facing behaviour for E15 beyond the fault itself. The ukwhitegoods transcription adds: "Condenser fan will not run" - a transcription, not a manual quote.

Common causes

  1. Condenser fan speed error or failure - the handbooks' own fault definition.
  2. Disconnected cables at the control card DC Input-Output socket (KN10) pins 4, 5 and 6 - the flowchart's first check.
  3. Wrong-code reading - E15 is NOT the freezer fan (that is E13); Beko WM E15 (flowmeter error) and Beko DW E15 are different codes on different appliances.

Safe checks, in order

  1. Check the cables connected to the control card DC Input-Output socket (KN10) pins 4, 5 and 6. If cables are disconnected, re-connect them, turn the refrigerator on and check whether the error is still displayed (Cosmos handbook flowchart, p.248).
  2. If the fault persists, the flowchart's branch is "Replace Condenser Fan" - a service procedure, not a homeowner step.
  3. Do NOT use appliancemode's 12 VDC figure as a manual value - no voltage figures exist in either handbook's visible text (and the E15 "verify feedback signal" step has no number at all). Do NOT publish "dust/debris buildup" as a cause.

The steps above are the handbook flowchart's steps, printed exactly. The ukwhitegoods ASD V0 transcription adds: "Condenser fan speed error or failure. Condenser fan will not run. Check wiring. Replace fan. Check control module." - a transcription, not a manual, cited as such. All cable and fan-replacement work is a service procedure.

When to call a technician

  • E15 is displayed at all - the flowchart check is a service procedure; there is no homeowner fix.
  • E15 returns after the KN10 pins 4-6 cable check - the condenser fan or the control module needs a technician.
  • Any burning smell, visibly damaged wiring, or other fault codes alongside E15 - switch off and call a qualified technician.

More guidance: when an appliance error requires professional service.

Safety first

E15 is a fan fault in a mains-powered refrigerator: never open the control area or probe the condenser fan wiring yourself. The KN10 socket and fan-replacement work is service work.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does E15 mean on a Beko refrigerator?

The condenser fan has failed or is running at the wrong speed ("cyclic condenser fan error"). Verified in two Arcelik service manuals: the COSMOS handbook (section 13.9, models G91631NE-G91634NE) and the G91629NWU service manual (section 9.9). It is the fan by the condenser at the back/bottom - not the freezer fan (that is E13).

Is E15 the same as E13?

No. E13 = freezer fan (KN10 pins 1-3); E15 = condenser fan (KN10 pins 4-6). Same socket, different pins, different fans. The pin split is the fastest way to tell them apart - and no competitor page gives it.

How do I check it?

Per the Cosmos handbook flowchart: check the cables on the control card DC Input-Output socket (KN10) pins 4, 5 and 6; if disconnected, re-connect them, turn the refrigerator on and check whether the error is still displayed. If the fault persists, the flowchart's branch is "Replace Condenser Fan". This is a service procedure - if you are not comfortable opening the control area, call a service centre.

Is E15 a flowmeter fault?

No. One page ranking on the fridge E15 query (appliancemode's washing-machine guide) says E15 is a flowmeter error - that is the washing-machine E15, a different appliance. Fridge E15 is the condenser fan.

Why does one Beko page have no E15 at all?

The ukwhitegoods "American" page covers an older (GNE-type) code set with no E15 row, while the same site's ASD V0/V3 pages list E15. The code exists on the Cosmos/American U4 platform; the older set is a different control version. Check your model number against the Cosmos (G91631NE-G91634NE) or FOUREVER (G91629NWU) families.
