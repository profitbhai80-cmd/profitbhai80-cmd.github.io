Beko Tumble Dryer Error Code E11

Quick answer

Error codeE11 — Beko Tumble Dryer
What it meansE11 = Compressor NTC: Overheat — the heat-pump compressor temperature sensor is reading an over-temperature condition. BX B7S / BLED heat-pump tumble dryer platform only. FAMILY-COUNT CAVEAT, stated honestly: verified in ONE genuine Arcelik/Beko service handbook covering TWO named platforms (BX B7S and BLED) — the code-to-meaning row is stated once in a table that applies to both named platforms. No second standalone dryer handbook was found publicly.
Most common causeRestricted airflow is the only user-addressable overheat contributor the handbook supports (its own E13 is 'Filter Blocked'). The handbook gives no overheat threshold for E11 and no resistance values — this page invents none.
Safe to check yourself?Partly — clean the lint filter and the vents, then switch the dryer off and on once. If E11 returns, it is a technician job: the handbook gives no E11-specific home procedure, and the service-test program is technician work.

Applies to — read this first

Read this first, because Beko dryer E11 carries a family-count caveat this page states honestly and prominently: E11's meaning is verified in ONE genuine manufacturer document — the Beko/Arcelik service handbook below — which covers TWO named platforms (BX B7S and BLED) with separate service-test programs for each. That is the basis for the 2-family count: the code-to-meaning row is stated once in a table that applies to both named platforms. No second standalone dryer handbook was found publicly. The meaning itself ('Compressor NTC: Overheat') is not in doubt — it is verbatim from the handbook. Scope: E11 here is the BX B7S/BLED heat-pump dryer platform only. The compressor NTC is the heat-pump compressor temperature sensor — there is NO 'heater NTC' on this platform. Do NOT merge E11 with washer E11 (motor / unbalanced / water inlet — contested) or with dryer E08 (Door NTC: Overheat — the OTHER overheat code, a different sensor).

What the machine does when E11 fires

The display shows E11 and the dryer stops — the compressor temperature sensor is reading an over-temperature condition. Overheat has no 'h:xx' live display in the service test — it is a stored error code recalled at Steps 7/17; only open/short have live test displays ('h:OC' / 'h:SC').

Common causes

  1. Restricted airflow — a blocked filter or vent (the handbook's own E13 is 'Filter Blocked'); the only user-addressable overheat contributor the document supports.
  2. Compressor NTC fault — the compressor temperature sensor itself is reading an over-temperature condition (E09 open circuit / E10 short circuit are the same sensor's other faults).
  3. Wrong-appliance reading — Beko washer E11 is a motor fault, an unbalanced load, or a water-inlet fault depending on the source; none of those is the dryer meaning.
  4. Wrong-sensor reading — E08 is also 'overheat', but on the door NTC, a different sensor.

Safe checks, in order

  1. Clean the lint filter and the vents — restricted airflow is the only user-addressable overheat contributor the handbook supports.
  2. Switch the dryer off and on once; if E11 returns, stop — the handbook gives no further home procedure.
  3. A service technician runs the handbook's service-test program: Step 15 runs the compressor ('Crn' appears on display, the compressor starts to work, the compressor NTC value appears and starts to increase, and when it reaches 50–55 °C, 'C on' appears and the 'Sound Warning Led' starts to blink); E11 is a stored code recalled at Steps 7/17.
  4. Do NOT use the figures from other sites (15.2–19.5 kΩ; heater coils 32.3 Ω / 73.6 Ω): they are unsourced, absent from the handbook, and for the wrong part — and do NOT present Step 15's 50–55 °C as the overheat threshold; it is a service-test checkpoint, not the threshold.

The handbook gives NO E11-specific home procedure, NO overheat threshold, and NO resistance values. Overheat has no 'h:xx' display code in the service test — it is a stored error code recalled at Steps 7/17; only open/short have live test displays. Anything beyond cleaning the filters and vents is a technician job.

When to call a technician

  • E11 returns after the filters and vents are clean — the compressor NTC and its circuit need a technician with the service-test program.
  • The service test blocks progress on NTC or voltage errors (Step 8: 'If NTC and voltage error occurs, it is not allowed to pass to the next step') — that is a technician diagnosis.
  • Any burning smell, damaged wiring, or other fault codes alongside E11 — switch off and call a qualified technician.

Safety first

E11 is an overheat fault in a mains-powered heat-pump dryer: never open the machine or probe the NTC wiring yourself. The service-test program is technician work. Clean only the user-accessible filters and vents, with the machine switched off.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does E11 mean on a Beko tumble dryer?

Compressor NTC: Overheat. The heat-pump compressor temperature sensor is reading an over-temperature condition.

What is the difference between E08 and E11?

Both are 'overheat', different sensors: E08 is the DOOR sensor overheating, E11 is the COMPRESSOR sensor overheating. Never merge them.

Why do other sites say E11 is a heater fault?

The leading dryer guide renames the compressor NTC as a 'heater NTC'. The handbook says 'Compressor NTC'.

Can I fix E11 myself?

The handbook gives no home fix and no overheat threshold. Clean the filters and vents (the only user-addressable overheat contributor the handbook supports), then a technician runs the service-test program.

Is dryer E11 the same as washer E11?

No. Washer E11 is a motor fault, an unbalanced load, or a water-inlet fault depending on the source. Same token, different appliance, different meaning.
