Beko Tumble Dryer Error Code E08

Quick answer

Error codeE08 — Beko Tumble Dryer
What it meansE08 = Door NTC: Overheat - the door temperature sensor (NTC thermistor near the door) is reading an over-temperature condition. BX B7S / BLED heat-pump tumble dryer platform only. FAMILY-COUNT CAVEAT, stated honestly: verified in ONE genuine Arcelik/Beko service handbook covering TWO named platforms (BX B7S and BLED) - the code-to-meaning row is stated once in a table that applies to both named platforms. No second standalone dryer handbook was found publicly.
Most common causeRestricted airflow is the only user-addressable overheat contributor the handbook supports (its own E13 is 'Filter Blocked'). The handbook gives no temperature threshold for 'overheat' and no resistance values - this page invents none.
Safe to check yourself?Partly - clean the lint filter and the vents, then switch the dryer off and on once. If E08 returns, it is a technician job: the handbook gives no E08-specific home procedure, and the service-test program is technician work.

Door-NTC triple - E06 / E07 / E08E06 = Door NTC: Open Circuit; E07 = Door NTC: Short Circuit; E08 = Door NTC: Overheat. Three faults on the SAME sensor (the door NTC) - do not confuse them.
Compressor-NTC triple - E09 / E10 / E11E09 = Compressor NTC: Open Circuit; E10 = Compressor NTC: Short Circuit; E11 = Compressor NTC: Overheat. A different sensor (the compressor NTC) with the same three fault types - do not confuse the door NTC with the compressor NTC.
Voltage faults - E16 / E17, NOT E08E16 = Low Voltage (Lower than 165V); E17 = High Voltage (Higher than 265V). On this Beko dryer platform voltage faults are E16/E17 - never E08.

What the machine does when E08 fires

The display shows E08 and the dryer stops - the door NTC is reading an over-temperature condition. Overheat has no 'd:xx' live display in the service test - it is a stored error code recalled at Steps 7/17; only open/short have live test displays ('d:OC' / 'd:SC').

Common causes

  1. Restricted airflow - a blocked filter or vent (the handbook's own E13 is 'Filter Blocked'); the only user-addressable overheat contributor the document supports.
  2. Door NTC fault - the door temperature sensor itself is reading an over-temperature condition (E06 open circuit / E07 short circuit are the same sensor's other faults).
  3. Wrong-appliance reading - Beko washer E08 is a water inlet valve error; Vestel/Daewoo dryer E08 is mains voltage fluctuation; on this Beko dryer platform voltage faults are E16/E17, not E08.

Safe checks, in order

  1. Clean the lint filter and the vents - restricted airflow is the only user-addressable overheat contributor the handbook supports.
  2. Switch the dryer off and on once; if E08 returns, stop - the handbook gives no further home procedure.
  3. A service technician runs the handbook's service-test program: Step 7 shows the last stored error codes (a technician can delete them by turning the On/Off Program Selection Knob 180 degrees); Step 8 checks the door and compressor NTCs ('d:OC'/'d:SC' for the door NTC); Step 17 shows the last error codes again, and codes cannot be deleted in this step.
  4. Do not use the unsourced 'door NTC approx. 12 k-ohm at 25 C' figure - it appears nowhere in the handbook excerpt.

The handbook gives NO E08-specific home procedure, NO temperature threshold for 'overheat', and NO resistance values. Overheat has no 'd:xx' display code in the service test - it is a stored error code recalled at Steps 7/17; only open/short have live test displays. Anything beyond cleaning the filters and vents is a technician job.

When to call a technician

  • E08 returns after the filters and vents are clean - the door NTC and its circuit need a technician with the service-test program.
  • The service test blocks progress on NTC or voltage errors (Step 8: 'If NTC and voltage error occurs, it is not allowed to pass to the next step') - that is a technician diagnosis.
  • Any burning smell, damaged wiring, or other fault codes alongside E08 - switch off and call a qualified technician.

Safety first

E08 is an overheat fault in a mains-powered heat-pump dryer: never open the machine or probe the NTC wiring yourself. The service-test program is technician work. Clean only the user-accessible filters and vents, with the machine switched off.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does E08 mean on a Beko tumble dryer?

Door NTC: Overheat - the door temperature sensor (NTC thermistor near the door) is reading an over-temperature condition. Verified verbatim in the BX B7S / BLED Heat Pump Tumble Dryer Service Handbook (Beko 2013), Error Codes table p.29.

What is the door NTC - and what are E06 and E07?

The door NTC is the temperature sensor near the door. E06, E07 and E08 are three faults on that one sensor: E06 = open circuit, E07 = short circuit, E08 = overheat. The compressor has its own NTC with the same three fault types (E09/E10/E11) - do not confuse the two sensors.

Can I fix Beko dryer E08 myself?

Only the filter and vent cleaning: restricted airflow is the only user-addressable overheat contributor the handbook supports (its own E13 is 'Filter Blocked'). The handbook gives no E08-specific home procedure, no temperature threshold, and no resistance values - if E08 returns after cleaning, a service technician runs the service-test program (Steps 7/8/17).

What does the service test show for E08?

E08 is a stored error code, recalled at Step 7 (where a technician can delete stored codes by turning the On/Off Program Selection Knob 180 degrees) and Step 17 (where codes cannot be deleted). Step 8 checks the door and compressor NTCs live - but only open/short have live displays ('d:OC' / 'd:SC'); overheat has no 'd:xx' display.

Is dryer E08 the same as Beko washer E08?

No. Beko washer E08 is a water inlet valve error - a different appliance, a different meaning (see our washer E08 page). Other brands' dryer E08s differ too: Vestel/Daewoo = mains voltage fluctuation, Indesit/Hoover = overheat thermostat tripped, Bosch = internal power/electronics fault. On this Beko dryer platform, voltage faults are E16/E17, not E08.
