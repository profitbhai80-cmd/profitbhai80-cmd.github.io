Beko Tumble Dryer Error Code E04

Quick answer

What the machine does when E04 fires

The display shows E04 and the programme will not start - it was started while the door was open. E04 is a stored error code, recalled at Steps 7/17 of the service-test program.

Common causes

  1. A programme was started while the door was open - a start-condition event, not a component fault.
  2. The door was not fully closed or latched before Start was pressed.
  3. If E04 returns with the door closed and latched, the door switch / latch is the technician's check.
  4. Wrong-appliance reading: washer E04 is an overfill / fill fault; cookupexperts' "heating element fault" contradicts the handbook.

Safe checks, in order

  1. Close the door firmly until it latches, then press Start - E04 is a start-condition event, not a component fault.
  2. If E04 returns with the door closed and latched, stop - the door switch / latch is the technician's check.
  3. A service technician recalls stored codes in the service-test program: Step 7 shows the last error codes (a technician can delete them by turning the On/Off Program Selection Knob 180 degrees); Step 17 shows the last error codes again, and codes cannot be deleted in this step.
  4. Do NOT present a heating-element fix for E04 - the handbook says "Start While Door Open".

The handbook gives NO E04-specific home procedure and NO test values. E04 is a one-line definition: a start-condition event. Anything beyond closing the door and restarting is a technician job.

When to call a technician

  • E04 returns with the door closed and latched - the door switch needs a technician with the service-test program.
  • The door will not latch or stay closed.
  • Any burning smell, damaged wiring, or other fault codes alongside E04 - switch off and call a qualified technician.

Safety first

E04 is a door event in a mains-powered heat-pump dryer: never open the machine or probe the door-switch wiring yourself. The service-test program is technician work. Close the door firmly and press Start only.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does E04 mean on a Beko tumble dryer?

Start While Door Open: a programme was started while the door was open.

Is E04 a heating-element fault?

No. One list says so - the handbook says "Start While Door Open". There is no heating meaning for dryer E04.

What is the difference between E01 and E04?

E01: the door was opened during a running programme. E04: a programme was started while the door was open.

How do I clear E04?

Close the door firmly until it latches, then press Start. If it returns with the door latched, the door switch is a technician's check.

Is dryer E04 the same as washer E04?

No. Washer E04 is an overfill / fill fault. Same token, different appliance, different meaning.
