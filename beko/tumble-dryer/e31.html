Beko Tumble Dryer Error Code E31

Quick answer

Error codeE31 — Beko Tumble Dryer
What it meansE31 = Combined Filter Not Mounted — the combined filter is not fitted (or not fitted correctly). Combined-filter models only. BX B7S / BLED heat-pump tumble dryer platform only. FAMILY-COUNT CAVEAT, stated honestly: verified in ONE genuine Arcelik/Beko service handbook covering TWO named platforms (BX B7S and BLED) — the code-to-meaning row is stated once in a table that applies to both named platforms. No second standalone dryer handbook was found publicly.
Most common causeThe combined filter is not fitted, or not seated correctly in its housing. If your dryer has separate lint + condenser filters, E31 cannot occur on it.
Safe to check yourself?Yes — remove the combined filter, check it is undamaged, and refit it firmly until it seats. If E31 returns with the filter fitted and seated, it is a technician's check.
Checked againstBX B7S / BLED Heat Pump Tumble Dryer Service Handbook (Beko 2013; doc 2977720092_BX_BLED-B7S_HP_Service_Handbook, Sept '17), Error Codes table p.29

Applies to — read this first

Read this first, because Beko dryer E31 carries a family-count caveat this page states honestly and prominently: E31's meaning is verified in ONE genuine manufacturer document — the Beko/Arcelik service handbook below — which covers TWO named platforms (BX B7S and BLED) with separate service-test programs for each. That is the basis for the 2-family count: the code-to-meaning row is stated once in a table that applies to both named platforms. No second standalone dryer handbook was found publicly. The meaning itself ('Combined Filter Not Mounted (for combined filter models)') is not in doubt — it is verbatim from the handbook. Scope: E31 exists ONLY on combined-filter models. If your dryer has separate lint + condenser filters, E31 cannot occur on it. Do NOT merge E31 with washer-dryer E31 (dryer NTC sensor error) or with dryer E13 (Filter Blocked).

What the machine does when E31 fires

The display shows E31 and the dryer will not run properly — the combined filter is not mounted, so the machine detects the filter as missing.

Common causes

  1. The combined filter is not fitted at all — removed for cleaning and not put back, or never fitted.
  2. The combined filter is fitted but not seated correctly — the filter sensor / switch does not register it as mounted.
  3. A damaged combined filter that will not seat — check it for damage before refitting.
  4. Wrong-appliance reading — washer-dryer E31 is a dryer NTC sensor error (~840 Ω at 70 °C), not a filter fault.

Safe checks, in order

  1. Open the filter housing, remove the combined filter, check it is undamaged, and refit it firmly until it seats correctly (the user-manual filter-fitting procedure for these models).
  2. Switch the dryer off and on once and try again.
  3. If E31 returns with the filter fitted and seated, the filter sensor / switch or the main board are the technician's checks.
  4. Do NOT present an NTC-sensor test for E31 — the washer-dryer E31 is a sensor code; the tumble-dryer E31 is a filter-fitting code.

The handbook gives NO E31-specific home procedure beyond the table row. The fitting check is the procedure the row itself implies (the user-manual filter-fitting procedure for these models). The handbook gives no sensor test values for E31 — this page invents none, and it does not import the washer-dryer E31's ~840 Ω at 70 °C figure, which belongs to a different appliance.

When to call a technician

  • E31 returns with the filter fitted and seated — the filter sensor / switch needs a technician's check.
  • The filter housing or sensor/switch is damaged, or the filter will not seat at all — call a qualified technician.
  • Any burning smell, damaged wiring, or other fault codes alongside E31 — switch off and call a qualified technician.

Safety first

E31 is a filter-fitting fault: handle only the user-accessible filter, with the machine switched off. Never open the machine or probe the sensor/switch wiring yourself.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does E31 mean on a Beko tumble dryer?

Combined Filter Not Mounted: the combined filter is not fitted (or not fitted correctly).

Does every Beko dryer show E31?

No. Only combined-filter models. If your dryer has separate lint + condenser filters, E31 cannot occur on it.

How do I clear E31?

Remove the combined filter, check it is undamaged, and refit it firmly until it seats. If it returns with the filter seated, the filter sensor/switch is a technician's check.

What is the difference between E13 and E31?

E13: the filter is fitted but BLOCKED (clean it). E31: the combined filter is NOT FITTED (fit it).

Is dryer E31 the same as washer-dryer E31?

No. Washer-dryer E31 is a dryer NTC sensor error (~840 Ω at 70 °C). Tumble-dryer E31 is a filter-fitting code. Same token, different appliance, different meaning.
