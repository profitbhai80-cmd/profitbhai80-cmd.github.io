Beko Washing Machine Error Code E05

Quick answer

Error codeE05 — Beko Washing Machine
What it meansE05 means a drainage fault: the pump filter is likely clogged and the machine could not empty in time. The Beko manuals' own fix order is: clean the pump filter, then try a spin cycle — and only then call service. Five Beko manuals use identical wording. Do not confuse with E08, which is the inlet-side code ("the machine may not be taking in water").
Most common causeA clogged pump filter — coins, buttons, lint, or a sock blocking the drain pump filter.
Safe to check yourself?Yes — cleaning the pump filter is the manual's own first step and is designed for the user. Have towels ready; some water will come out.

Applies to — read this first

E05 is one of Beko's most consistent codes — B5WFU, BMGWU, BM3WFU, BM1WFSU, and BMW digital-display families all print the identical error table row. The single most useful fact on this page is the manual's own fix order, which no competitor quotes first: clean the pump filter, try a spin cycle, then call service.

From the SAME manual tables: E8 = "The machine may not be taking in water" (inlet side). One table proves E05 is the drain code and E08 is the inlet code — directly rebutting a JustAnswer 'expert' claim that E08 means the drain pump runs continuously. On LED-display Beko models the code is stored in diagnostic mode and decoded via BCD (no spin=1, 600rpm=2, 800rpm=4, 1000rpm=8, 1200rpm=16 — 1+4 = E05); on some models the alternates EH20/EH21/C2 cover the same drain timeout.

What the machine does when E05 fires

The machine stops with water still in the drum and will not spin — E05 is the drain-stage timeout ("the machine couldn't spin or empty in the allocated time"). The door may stay locked while water remains inside.

Common causes

  1. A clogged pump filter — coins, buttons, lint, or a sock blocking the drain pump filter (the manual's first suspect).
  2. A kinked or blocked drain hose.
  3. A drain hose installed too high or pushed too far down the standpipe.
  4. A failed drain pump.
  5. A blocked standpipe or household drain.

Safe checks, in order

  1. Switch off and unplug the machine.
  2. Open the pump filter cover (bottom front), place towels and a shallow tray underneath — water will come out.
  3. Unscrew the filter, remove debris (coins, buttons, lint, socks), rinse it, and check the pump impeller behind it turns freely.
  4. Refit the filter firmly.
  5. Run a spin-only cycle, as the manual instructs ("Try in spin cycle").
  6. Check the drain hose for kinks and that it is not pushed too far down the standpipe or above the manual's height limit.
  7. If E05 returns with a clean filter and clear hose, the pump or its wiring needs a technician.

Work through the checks in order and stop as soon as the code clears. The manual's fix order — filter first, spin retry second, service third — exists because the filter is the cause in the great majority of cases; do not jump to pump replacement before the filter is clean. If a check needs the machine opened or the pump tested electrically, it is no longer a safe home check — skip to the technician section.

When to call a technician

  • E05 returns with a clean filter and a clear, correctly routed drain hose.
  • The pump makes no sound at all (or a loud humming) during drain.
  • The impeller behind the filter is jammed or broken.
  • Water will not leave the drum by gravity when the filter is opened — a deeper standpipe blockage may need a plumber.

Safety first

Always unplug the machine before opening the pump filter, and expect a litre or more of water — towels and a shallow tray are mandatory, and the water may be hot after a hot wash. Never reach into the pump housing while the machine is connected to power. Pump electrical tests are service-staff work.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does E05 mean on a Beko washing machine?

E05 is a drainage fault — the pump filter is likely clogged and the machine could not empty in the allocated time. Five Beko manuals print the identical row: "E5 Pump filter may be clogged. Clean the pump filter... Try in spin cycle."

How do I clear Beko E05?

The manual's own order: clean the pump filter (unplug first, towels ready), then run a spin-only cycle. Only if the issue is not resolved should you call service. Check the drain hose for kinks as well.

Is Beko E05 the same as E08?

No — and the same manual table proves it. E05 = drain side (pump filter clogged); E08 = inlet side ("the machine may not be taking in water"). A JustAnswer 'expert' once claimed E08 means the drain pump runs continuously — the manuals say the opposite.

My Beko has no display — how do I read E05?

On LED-only models the fault is stored in diagnostic mode and decoded in BCD: no-spin=1, 600rpm=2, 800rpm=4, 1000rpm=8, 1200rpm=16 — a reading of 1+4 means E05. The cleaning steps are the same once you know the code.
