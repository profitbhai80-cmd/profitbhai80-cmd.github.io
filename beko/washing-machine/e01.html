Beko Washing Machine Error Code E01

Quick answer

Error codeE01 — Beko Washing Machine
What it meansE01 means the board has detected an NTC (water temperature sensor) open circuit or short circuit: it is not getting a plausible water-temperature reading. Both Arçelik service manuals we checked — the MLCD platform manual (WMB series) and the BX B7S service manual (WTK series) — define it identically. The manuals print the code as E1; newer displays show E01.
Most common causeThe NTC (water temperature sensor) circuit is open or shorted, or its connection to the control board is faulty.
Safe to check yourself?You can safely do one power-cycle reset and observe/document the symptoms (when the code appears, whether the water heats). Everything else — opening the machine, touching the NTC, its socket, or its wiring — is technician work.
Checked againstArçelik MLCD_BLDC-BL Fault Diagrams (Rev 01, 08.10.2009, prepared by Engin BAYATLI, Recep SERÇE) — manufacturer service document for the MLCD BLDC platform (Beko WMB series); Arçelik BX B7S BXBLED BL Washing Machine Service Manual No:1 (WTK92151W) — manufacturer service handbook with failure flow diagrams

Applies to — read this first

Naming first: the Arçelik service documents print this code as E1; current Beko displays show it as E01. Same code, same fault — the same convention our E08 page uses (display shows E08, manuals print E8). Both Arçelik platforms we checked define E01 identically: an NTC (water temperature sensor) open circuit or short circuit. What you must NOT do is borrow meanings from other Beko appliances: Beko dishwasher E01 is a flood-switch/overflow fault, which has nothing to do with this page.

ManualExact wording for E01
Arçelik MLCD_BLDC-BL Fault Diagrams (Rev 01, 08.10.2009)"E1 – * NTC short circuit or * NTC open circuit error." E.g., shows 9500 Ohm resistance under 10 C, and 1700 Ohm resistance under 50 C." Arçelik BX B7S BXBLED BL Washing Machine Service Manual No:1 (WTK92151W)E1 flow identical: "* NTC short circuit or * NTC open circuit error"; KN2 socket check; "Does it show approx. 4700 OHM under 25°C temperature?"; same 9500Ω @ 10°C / 1700Ω @ 50°C reference; same cold-washing protective note for E1/E2/E3.

Newer Beko front-load user manuals (e.g. B3WFU4741WBG, BM1WFSU37233WPBB) only list E5/E8/E17/E29 in the user troubleshooting table — E01 lives in the service documentation, which is why this page cites the service manuals directly. Older non-display models show the same fault as LED light codes rather than digits.

What the machine does when E01 fires

The manuals describe a protective response: when the board logs an E1/E2/E3 fault, the machine does cold washing and ends the program before the heater is activated. In practice you may see the cycle run unusually long, the water never heat, and E01 displayed — or the code may appear as soon as the heating stage should start.

Common causes

  1. The NTC temperature sensor itself has failed open or shorted — the manual's primary definition of E01.
  2. A loose or poorly seated NTC socket: the MLCD manual's first check is whether the KN2 (K2) socket on the control board is attached; the BX B7S manual gives the same KN2 check for its platform.
  3. Damaged, loose, or corroded cabling between the NTC sensor and the control board — both manuals say to verify cabling before replacing any part.
  4. The control board misreading a good sensor — the manuals' last step, reached only after the NTC and its cabling check out.

Safe checks, in order

  1. Switch the machine off, unplug it from the wall, wait about a minute, then plug it back in. A single reset clears a transient control glitch — if E01 returns, the fault is real and resetting again will not fix it.
  2. Run a hot wash and observe: does E01 appear when heating should start? Does the water stay cold and the cycle run long? Note the exact display (E01 or E1) and copy the full model number from the rating label (usually around the door opening) — a technician needs both.
  3. Stop there. The manuals' next steps — checking the KN2 socket and measuring the NTC (their reference: approximately 4700 ohms at 25°C, about 9500 ohms at 10°C, 1700 ohms at 50°C) — require opening the machine and working around mains-voltage wiring. That is technician work, not a home check.

Work through the checks in order and stop as soon as the code clears. If a check needs a panel removed, a connector touched, or a resistance measured, it is no longer a safe home check — skip to the technician section.

When to call a technician

  • E01 returns immediately after the power-cycle reset — the NTC circuit fault is genuine.
  • The machine completes cycles but the water never heats, or E01 appears at the start of the heating stage.
  • A technician's NTC measurement is far from the manual's ~4700Ω at 25°C reference, or shows open/short circuit.
  • Any burning smell, scorch marks, or tripped household electrics — switch off and unplug, then call a qualified technician.

Safety first

The NTC sits on the heater assembly inside the machine, surrounded by mains-voltage wiring and water connections. Never remove the top, rear, or side panels yourself. The manuals' own safety sections stand: if the product is faulty, it must be repaired by authorized service — risk of electric shock. If you smell burning or see scorch marks, switch off, unplug, and call a qualified technician.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does E01 mean on a Beko washing machine?

E01 means the control system has detected an NTC (water temperature sensor) open circuit or short circuit — the board is not getting a plausible temperature reading. Both Arçelik service manuals we checked define it this way, identically, on the WMB and WTK platforms.

Is E01 the same as E1?

Yes. The Arçelik service documents print the code as E1 while newer displays show E01. It is the same NTC fault — the same naming convention as our E08 page (manuals print E8, displays show E08).

Some websites say Beko E01 is a door-lock or water-supply problem. Is that right?

No. The two Arçelik service manuals define E01 strictly as the NTC temperature-sensor circuit (open or short). Pages mapping E01 to door lock or water supply contradict the manufacturer's own service documentation.

Is E01 the same as Beko dishwasher E01?

No. Beko dishwasher E01 is a flood-switch/overflow fault — a completely different meaning on a different appliance. Never borrow error-code meanings across appliances.

Will unplugging the machine fix E01?

A single power-cycle reset can clear a transient glitch. If E01 comes back, the fault is real — the sensor, its socket, its wiring, or the board — and needs a technician. Do not keep resetting it.
