Beko Washing Machine Error Code E18

Quick answer

Error codeE18 — Beko Washing Machine
What it meansE18 is a warning, not an error: unbalanced load — the spin cycle is not initiated, or the programme ends without spinning. Sort the laundry by hand, distribute it evenly inside the appliance (too little laundry can also trigger it), and retry the spin cycle. User-fixable.
Most common causeUnevenly distributed laundry — overloaded, clumped to one side, a single heavy item, or too little laundry to balance.
Safe to check yourself?Yes — E18 is fully user-fixable. Open, redistribute, retry the spin cycle. No tools or technician needed.
Checked againstArçelik Beko B13 Service Handbook §11 (unbalanced load ended the programme without spinning — warning, not error); Beko user manual BM3WFSU48415WPBB2 (E18: spin not initiated, amount may not be sufficient); ukwhitegoods WMA table E18 row

Applies to — read this first

Like E17, E18 is marked in the B13 service handbook as 'not error, but a warning.' The spin cycle is not initiated due to an imbalance of the machine. The underload case is the differentiator competitors miss: the BM3WFSU48415WPBB2 manual says the amount of laundry may simply not be sufficient — try increasing it. One competitor blames weak shock absorbers, which appears in no manufacturer source for E18; the manuals blame load distribution, including too little laundry.

Competitors get the theme (unbalanced, redistribute) but miss or bury the underload case: too little laundry triggers E18 too, and the manual's fix for that is to ADD laundry. One repair list blames shock absorbers — not in any manufacturer source for E18, so this page does not.

What the machine does when E18 fires

The machine will not start the spin, or the programme ends without spinning (sometimes with an extended time as the machine keeps trying to redistribute). Clothes come out soaking wet. This is a protection behaviour: spinning an unbalanced drum at high speed would hammer the machine.

Common causes

  1. Laundry clumped on one side of the drum.
  2. Too little laundry — a single heavy item or a very small load cannot balance.
  3. Overloading, so the load cannot redistribute.
  4. Laundry tangled together so it spins as one lump.

Safe checks, in order

  1. Stop the cycle and open the door.
  2. Check the laundry amount: if there is very little in the drum, add more items — the manual says the amount may not be sufficient.
  3. Sort the laundry by hand and distribute it evenly inside the appliance.
  4. Close the door and retry in the spin cycle.
  5. If it still will not spin with a balanced load, try a slightly lower spin speed; a recurring imbalance with correct loading deserves a technician check of the machine's levelling and suspension.

Work through the steps in order and stop as soon as the spin runs. E18 is a protection behaviour, not a fault — the machine is telling you the load, not itself, is the problem.

When to call a technician

  • E18 recurs with every load even when loading is balanced and correct — levelling feet or internal suspension may need checking.

Safety first

E18 is a load warning, not an electrical fault. Never try to hold the drum still or reach in while it is attempting to spin — let the machine stop completely before opening the door.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

Is Beko E18 an error?

No — the B13 handbook marks E18 as 'not error, but a warning.' It means the load is unbalanced and the spin cycle was not initiated (or the programme ended without spinning).

Can too little laundry cause Beko E18?

Yes — and this is the case competitors miss. The user manual says the amount of laundry may not be sufficient and tells you to increase it. A single heavy item alone can trigger E18.

How do I clear Beko E18?

The manual's sequence: check the laundry, add more if there is too little, sort it by hand and distribute evenly, then retry the spin cycle.

Is Beko E18 a shock absorber problem?

Not according to any manufacturer source: the B13 handbook and the user manual blame load distribution only. If E18 recurs with correct loading, suspension wear is a technician's diagnosis, not the manual's E18 meaning.
