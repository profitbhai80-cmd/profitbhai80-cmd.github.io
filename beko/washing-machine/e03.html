Beko Washing Machine Error Code E03

Quick answer

Error codeE03 — Beko Washing Machine
What it meansE03 means the board has detected the heater as continuously active — heating when it should not be. The Arçelik manuals' customer complaint is unmistakable: 'Machine is boiling the water. Laundry comes out very hot; they are worn.' Both service manuals we checked define it identically. The manuals print the code as E3; newer displays show E03.
Most common causeThe heater is staying on when it should not — a heater-control fault (wiring short, sensor misread, or control board).
Safe to check yourself?The only safe home action for E03 is switching the machine off and unplugging it, then leaving it alone until a technician checks it. Do not open the machine, do not run test cycles, do not touch anything inside.
Checked againstArçelik MLCD_BLDC-BL Fault Diagrams (Rev 01, 08.10.2009, prepared by Engin BAYATLI, Recep SERÇE) — manufacturer service document for the MLCD BLDC platform (Beko WMB series); Arçelik BX B7S BXBLED BL Washing Machine Service Manual No:1 (WTK92151W) — manufacturer service handbook with failure flow diagrams

Applies to — read this first

Naming first: the Arçelik service documents print this code as E3; current Beko displays show it as E03. Same code, same fault. Both Arçelik platforms we checked define E03 identically: a heater-always-active fault — the board detects the heater running when it should not be. E03 is the opposite fault to E02: E02 means the heater will not heat; E03 means the heater will not stop. Because uncontrolled heating is a scald and fire risk, this is the one code of the three where the first home step is safety, not diagnosis.

Newer Beko front-load user manuals only list E5/E8/E17/E29 in the user troubleshooting table — E03 lives in the service documentation, which is why this page cites the service manuals directly. The manuals' cold-washing note also covers E3: once the board has logged the fault it locks the heater out — but the fault itself is uncontrolled heating, which is why you unplug first.

What the machine does when E03 fires

The manuals' customer complaint says it plainly: the machine boils the water and laundry comes out very hot and worn. The display shows E03 and the cycle cannot be trusted to control temperature. Once the board has logged the fault, the manuals note the machine will make cold washing and end the program without the heater being activated — but that lockout is the board's emergency response, not a safe mode to keep using.

Common causes

  1. A short circuit between the first pins of the heater and tacho connectors (KN8/KN4 on the MLCD platform; KN8/KN5 on the BX B7S platform) — the manual's first electrical check.
  2. The water-level sensor misreading — the manual branches to a sensor-frequency check (around 25560 Hz) because a false low-water reading can keep the heater driven.
  3. A stuck or failed heater relay / faulty control board — the manual's last step after connectors and sensor check out.
  4. The heater itself — checked via the manual's 25-ohm resistance measurement.

Safe checks, in order

  1. Switch the machine off and UNPLUG it from the wall immediately. A heater that stays on is a scald and fire risk — this is the one code of the three where unplugging comes before any observation.
  2. Let the machine cool completely. Do not open the door to feel the water, do not run another cycle to 'see if it still happens', and do not remove any panel.
  3. Call a qualified technician. The manuals' checks for E03 — the connector short-circuit test, the water-level sensor frequency check (25560 Hz), the 25-ohm heater measurement, and the control-board assessment — are all internal electrical work.

For E03 there is no safe home diagnosis beyond unplugging. Every check the manuals describe needs the machine opened and live electrical parts tested — that is technician work by definition.

When to call a technician

  • Laundry comes out very hot or visibly worn, or the water is boiling — the manual's own complaint wording.
  • E03 appears during or after the heating stage, even once.
  • Any burning smell, scorch marks, smoke, or tripped electrics — keep clear and call a qualified technician immediately.
  • The machine otherwise behaves normally on non-heating stages — the fault is isolated to heater control, which still needs professional repair.

Safety first

Uncontrolled heating is a scald and fire risk. Unplug the machine immediately — do not leave it running or unattended with E03 showing. Let it cool fully before anyone touches it. Never remove panels: the heater circuit runs at mains voltage. If you see smoke, scorch marks, or smell burning, keep clear and call a qualified technician (or emergency services if there is an immediate danger).

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does E03 mean on a Beko washing machine?

E03 means the board has detected the heater as continuously active — heating when it should not be. The manuals' own customer complaint: 'Machine is boiling the water. Laundry comes out very hot; they are worn.' Both Arçelik service manuals define it this way on the WMB and WTK platforms.

Is E03 dangerous?

Treat it as urgent: uncontrolled heating can scald and, in the worst case, damage the machine. Switch the machine off and unplug it immediately, let it cool, and do not run more cycles to 'test' it. Call a qualified technician.

What is the difference between E02 and E03?

They are opposite faults. E02 = heater open circuit: the heater will not heat (cold washes). E03 = heater always active: the heater will not stop (boiling water, very hot laundry). The manuals give them separate diagnostic flows.

Can I keep using cold-only cycles while E03 shows?

No. The manuals give no safe workaround for a heater-control fault — the fault is in the heating control itself, not in the temperature selection. Unplug the machine and leave it out of use until a technician has checked it.

Will a reset fix E03?

Do not rely on a reset for this code. Even if the display clears, a heater that has stayed on once has a control fault that can return mid-cycle. Unplug and call a technician.
