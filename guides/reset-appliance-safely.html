How to Reset an Appliance Safely

“Turn it off and on again” is real advice for appliances — control boards do occasionally glitch — but a reset is a diagnostic step, not a repair. Used well, it tells you something: if the code never returns, it may have been a one-off glitch; if it returns immediately, the fault is real and still there.

How to reset safely

  1. Switch the appliance off at its control and at the wall socket.
  2. Unplug it (or switch off the circuit breaker for hard-wired appliances). With dry hands, on a dry floor.
  3. Wait at least one minute — this lets the control board fully discharge. Some manufacturers specify longer; your manual wins.
  4. Reconnect power and switch on. For a washing machine or dishwasher, start a fresh, short programme rather than resuming the old one.
  5. Watch the first full cycle (or the stage where the code appeared) to see whether the code returns.

When a reset is reasonable

After a power cut or surge; after you have fixed an obvious external cause (a closed tap, a blocked filter, a door left open); for input errors such as a button held too long, where the manual itself describes the reset; and once — only once — as a test for a code with no clear external cause.

When a reset will not help

A reset cannot clean a filter, unkink a hose, seal a leak or revive a failed sensor, motor or heating element. Codes naming those systems will return, and each return mid-cycle usually means another drum or tub of water to deal with.

Never reset and ignore these

  • Leak / overflow codes: the water that triggered them is still somewhere. Find it first.
  • Refrigerant codes (AC/fridges): switch off and call a technician; running low on refrigerant can destroy the compressor.
  • Any code accompanied by burning smell, smoke, or breaker trips: leave the machine off.
  • Gas ignition faults: do not keep cycling the ignition. Ventilate and call a professional.

And one hard rule: never bypass, tape down or short out a safety device — a door lock, a float switch, a thermal cut-out — to make a code go away. The code is the machine protecting itself, and you.
