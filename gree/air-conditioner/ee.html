Gree Air Conditioner Error Code EE

Quick answer

Error codeEE — Gree Air Conditioner
What it meansEE on a Gree air conditioner means the main control board's memory chip has failed — loading EEPROM malfunction / outdoor main-control memory-chip malfunction. Case split, and it matters: uppercase EE = the main-control board's memory chip; lowercase ee = the outdoor DRIVE board's memory chip, a different board. Power-cycle first; if EE persists the main control board needs a technician — this is not a sensor you can replace.
Most common causeThe main control board's EEPROM / memory chip has failed or lost its data — a board-level fault, not a sensor, wiring or refrigerant issue.
Safe to check yourself?Barely. A power-cycle is the only safe home action. Beyond that the manuals' verdict is a board replacement by a technician.
Checked againstGREE R32 Slim Duct Mini Split System Owner's Manual, error table row 18; Gree One-Way Cassette Owner's Manual, error table row 16; Gree Vireo diagnostic list (EE, outdoor yellow 11 flashes + 1 sec off); Gree 1309378 Owner's Manual, error table (EE, main control; ee, drive)

Applies to — read this first

Gree EE is a board fault wearing a code that looks like a sensor fault. The manuals are consistent: EE = the memory chip on the main control board has failed. The detail the blogs erase is the case split from the Gree 1309378 owner's manual — uppercase EE is the outdoor main-control memory chip, lowercase ee is the outdoor drive board's memory chip, and they are different boards. Getting the case right tells the technician which board to look at.

ManualExact wording for EE
GREE R32 Slim Duct Mini Split System Owner's Manual, error table row 18EE = Loading EEPROM malfunction, in the shared duct-family error table.
Gree One-Way Cassette Owner's Manual, error table row 16EE = Loading EEPROM malfunction, same wording in the cassette table.
Gree Vireo diagnostic listEE = 'EEPROM Memory Malfunction — Control board malfunction', outdoor yellow indicator 11 flashes + 1 sec off.
Gree 1309378 Owner's Manual, error tableEE = 'Outdoor Main Control Memory Chip Malfunction'; ee = 'Outdoor Drive Memory Chip Malfunction' — the case split that decides which board is at fault.

The blogs merge EE and ee into one row and then tell you to 'replace the EEPROM chip' — neither is what the manuals say. The manuals point to the control board, and the 1309378 manual splits the two boards by case. Read the display carefully: EE and ee are not the same fault.

What the machine does when EE fires

The display shows EE (or ee) and the system does not run normally; on Vireo diagnostics the outdoor yellow indicator flashes 11 times, pauses 1 second, and repeats while the memory-chip fault stands.

Common causes

  1. The main control board's EEPROM / memory chip has failed (uppercase EE).
  2. The outdoor drive board's memory chip has failed (lowercase ee) — a different board from the main control board.

Safe checks, in order

  1. Power the unit off at the isolator or breaker, wait several minutes, and power it back on.
  2. Repeat the power-cycle a couple of times — this is the manuals' first and only home step.
  3. If EE persists, stop: the manuals' verdict is the main control board, diagnosed and replaced by a technician. Do not buy a sensor for this code.

Power-cycling is the entire home procedure. EE is a memory-chip/board fault — there is no safe home repair beyond the restart, and sensor checks are the wrong tree entirely.

When to call a technician

  • EE (or ee) persists after repeated power-cycles.
  • Any board-level work — board replacement is technician work with proper qualifications.
  • You are unsure whether the display shows EE or ee — note the case and tell the technician, since it decides which board is suspect.

More guidance: when an appliance error requires professional service.

Safety first

A control-board fault means opening the electrical enclosure — do not do it. Switch power off at the breaker before any inspection, and leave board diagnosis and replacement to a qualified technician.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does EE mean on a Gree air conditioner?

EE means loading EEPROM malfunction / outdoor main-control memory-chip malfunction: the main control board's memory chip has failed. The Vireo diagnostic list ties it to the outdoor yellow indicator flashing 11 times with a 1-second pause.

Is lowercase ee the same as uppercase EE?

No. The Gree 1309378 owner's manual splits them: EE = outdoor main-control memory-chip malfunction, ee = outdoor drive-board memory-chip malfunction. Different boards, so read the display's case carefully and report it to the technician.

Can I fix Gree EE by replacing a sensor?

No. EE is a board/memory-chip fault, not a sensor fault. The manuals' home step is power-cycling; if it persists, the main control board (or drive board for lowercase ee) needs a technician.

How many times should I try power-cycling?

Try it a couple of times with a few minutes off between attempts. If the code is still there, stop — repeated power-cycling will not fix a failed memory chip.

Why do blogs say 'replace the EEPROM chip'?

That advice is not what the Gree manuals say. The manuals point to the control board as the failed part — blogs invented the chip-swap advice, and this page does not repeat it.
