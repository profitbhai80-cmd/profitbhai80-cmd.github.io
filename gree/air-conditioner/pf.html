Gree Air Conditioner Error Code PF

Quick answer

Error codePF — Gree Air Conditioner
What it meansOn U-Match units, PF means electric box sensor error: the outdoor unit's electric-box sensor reading has been out of range for 5 seconds continuously. PF is a U-Match-only code — it does not appear on wall-split Gree units.
Most common causePoor contact of the electric box sensor; the electric box sensor is abnormal; the detecting circuit of the electric box sensor is abnormal (U-Match R32 §3.4.16).
Safe to check yourself?Only the checks on this page: switch the unit off and re-energize once. The electric-box sensor and its detecting circuit are inside the outdoor electric box — technician work.
Checked againstGree U-Match R32 Service Manual §3.3 row 16 + §3.4.16 (GUD125W/NhB-S, GUD140W/NhB-S); GREE Mini After-sale Service Manual, U-Match appendix; Gree UMA30HP230V1ACS Installation Manual Table 6.1 row 17

Applies to — read this first

PF is a U-Match-only code — frame it that way, like PA/PC. It is NOT in the Soyal §9.1 list (rows 1-53 read in full), not in the Livo Gen4/Livo+ §9.1 tables as recorded, not in the evo/Change tables, and not in the U-Match R410A §1.1/§1.2 tables as read. Do not present PF as a universal wall-split code. Three different PFs exist, and this page is only the first.

No competitor page defines the U-Match PF at all — luce and aysonline have no PF row, and the top search results for 'Gree PF error code' are VRF manuals. The three PFs: (1) U-Match PF (this page): electric box sensor error — §3.4.16, AD value out of range for 5 seconds. (2) Rooftop GK-H / Xe7120 PF: 'Drive Board Ambient Temperature Sensor Error' / 'Drive board temperature sensor error' — the same concept in different words (a drive-board/electric-box temperature sensor) on different platforms; a wording variant of the same sensor class, not a different fault — but do not present the Rooftop meaning as the U-Match meaning. (3) GMV VRF PF (excluded): 'Charging loop of driven compressor' — a wholly different fault on the VRF platform; never borrow it.

What the machine does when PF fires

The error displays on the outdoor mainboard, the indoor wired controller and the indoor receive light board (U-Match R32 §3.4.16). No blink count exists for PF: U-Match codes display on the wired controller / outdoor main board / indoor receive light board, not as indoor lamp flashes. This page assigns none.

Common causes

  1. Poor contact of electric box sensor (U-Match R32 §3.4.16).
  2. Electric box sensor is abnormal (U-Match R32 §3.4.16).
  3. Detecting circuit of electric box sensor is abnormal (U-Match R32 §3.4.16).

Safe checks, in order

  1. Switch the unit off and re-energize once. If PF clears, the sensor reading has come back into range.
  2. If PF returns, stop: the electric-box sensor contact, the sensor itself, and its detecting circuit are all technician checks inside the outdoor electric box.
  3. Do not open the outdoor electric box yourself, and do not order a sensor on the strength of a listicle — the manual names three possible causes, and only a technician can tell which one it is.

No manual gives a PF-specific owner reset or a step-by-step sensor test. No owner-level sensor check, no resistance value, and no board-replacement step exists in the manuals for PF — do not invent one.

When to call a technician

  • PF returns after one off-and-re-energize.
  • PF appears together with other electric-box or drive faults.
  • Any burning smell, damaged wiring, or scorch marks near the outdoor unit — switch off and call a qualified technician immediately.

More guidance: when an appliance error requires professional service.

Safety first

PF involves the outdoor unit's electric box — mains-powered electronics. Never open the outdoor electric box or touch sensor terminals while investigating it.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does PF mean on a Gree air conditioner?

On U-Match units, PF is the electric box sensor error: the outdoor unit's electric-box sensor reading has been out of range for 5 seconds continuously. Verified in the U-Match R32 manual (§3.4.16).

What causes PF?

The manual names three causes: poor contact of the electric box sensor; the electric box sensor is abnormal; the detecting circuit of the electric box sensor is abnormal. All three are technician checks inside the outdoor electric box.

Will PF clear itself?

No manual gives an auto-clear rule for PF. Switch the unit off and re-energize once; if PF returns, call a technician.

Is PF the same as the VRF PF?

No. On GMV VRF units PF is the charging loop of the driven compressor — a completely different fault. This page is the U-Match PF only.

Does PF appear on wall-split Gree units?

No. PF is not in the Soyal, Livo Gen4, Livo+, evo, or Change wall-split tables. If a wall-split shows a code that looks like PF, check the code again — it may be a different code (or a U-Match indoor unit).
