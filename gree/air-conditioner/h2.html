Gree Air Conditioner Error Code H2

Quick answer

Error codeH2 — Gree Air Conditioner
What it meansH2 = static dedusting / static clearing dust protection - a STATUS display, not a fault, like H1 (defrosting). The unit shows H2 while the static dedusting function runs. Blink pattern: OFF 3S and blink twice. Turn it off with the HEALTH button on the remote. R410A-era only. This OVERTURNS the 2026-10-24 REJECT - H2 is now verified in two named wall-split manuals (Change 18/24 section 9.3 row 22 + evo Malfunction Tab).
Most common causeThere is no fault cause - H2 is the static dedusting function running. Do not clean or replace a filter for H2 (hundred-worries / accio / old becool) - no manual ties H2 to a filter.
Safe to check yourself?Yes - turn static dedusting OFF with the HEALTH button on the remote while the unit is operating (the function only works while the indoor fan is operating). H2 clears when the function is off.

Applies to — read this first

Read this first, because H2 is NOT a fault: it is a status display, like H1 (defrosting) - the unit shows H2 while the static dedusting function runs. There is nothing broken and nothing to fix, and the manuals give no cause column and no diagnosis for H2. Generation split: H2 is present in R410A-era evo/Change tables and ABSENT from the R32-era tables checked (Livo Gen4 section 9.1, GWH18QD section 9.1, Amber 18-24, GWH09YC, Livo+ section 9.1) - none lists H2. What the machine does when H2 fires

The display shows H2 while the static dedusting function runs - the unit is operating normally, not faulting. Blink pattern: OFF 3 seconds, then blink twice.

Common causes

  1. Static dedusting function is turned ON - the unit shows H2 as a status display while the function runs. There is no fault cause.
  2. Wrong framing - H2 is not a dirty electrostatic filter, not an arcing risk, and not an automatic-shutdown trigger; no manual ties H2 to a filter.

Safe checks, in order

  1. If H2 is showing and you do not want the function, turn static dedusting OFF with the HEALTH button on the remote while the unit is operating (the function only works while the indoor fan is operating). H2 clears when the function is off.
  2. Do not invent a duration, a fault cause, or a reset ritual for H2 - no manual gives one. H2 is not a fault: there is nothing to fix, reset, or replace.
  3. Do not clean or replace a filter for H2 - no manual ties H2 to a filter. If H2 stays on after turning the function off, or the unit misbehaves, check your own model's manual - it may use a different code for the fault you actually have.

The steps above are the manuals' own function control. This page does not invent a filter-cleaning or reset step - no manual documents one for H2.

When to call a technician

  • H2 stays on after turning static dedusting OFF with the HEALTH button - check your own model's manual; it may use a different code for the fault you actually have.
  • The unit misbehaves (not cooling/heating, strange noises, other codes) - H2 itself is not the fault; call a qualified technician for the real problem.

Safety first

H2 is a status display, not a fault: there is no repair to attempt and no panel to open. Work only from the remote control; if the unit misbehaves, switch it off and call a qualified technician.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does H2 mean on a Gree air conditioner?

Static dedusting (static clearing dust) protection - the unit is running its static dedusting function. Verified in the Change 18/24 service manual (section 9.3 row 22) and the evo owner's manual (Malfunction Tab).

Is H2 a fault?

No. H2 is a status display, not a fault - like H1 (defrosting). There is nothing broken and nothing to fix. The manuals give no cause column and no diagnosis for H2.

How do I turn H2 off?

Turn static dedusting OFF with the HEALTH button on the remote while the unit is operating (GWH18TC service manual: the function only works while the indoor fan is operating). H2 clears when the function is off.

Why does my Gree manual not list H2?

H2 is R410A-era only. The newer R32 ranges (Livo Gen4, GWH18QD, Amber, Livo+) do not list H2 in their error tables. Check your own model's manual - a newer unit showing a similar code may mean something else.

Is H2 the same on VRF systems?

No. On GMV VRF systems H2 means "Voltage protection of driving board of fan" - a different fault. Do not use VRF meanings for a wall-split unit, or the other way around.
