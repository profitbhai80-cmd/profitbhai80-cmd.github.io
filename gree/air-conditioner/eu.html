Gree Air Conditioner Error Code EU

Quick answer

Error codeEU — Gree Air Conditioner
What it meansEU means limit/decrease frequency due to high temperature of the module: the IPM module is running hot, so the compressor keeps running at a decreased frequency. The loads operate normally — the unit does not stop. No blink count is verified for EU.
Most common causeIPM module running hot — the manual's remedy is to de-energize for 20 minutes, check/replace the thermal grease on the IPM module radiator, and if that does not help replace the outdoor control panel AP1.
Safe to check yourself?Yes, for the 20-minute de-energize and restart. The thermal-grease check and AP1 replacement are technician work (the outdoor unit must be opened).

Applies to — read this first

EU is the third, distinct IPM-temperature behaviour — and the page's core distinction is a table, not a sentence. EU is a frequency LIMIT: the compressor keeps running at decreased frequency. H5 is IPM protection: the module trips and the unit STOPS. P8 is IPM high-temperature protection: the module overheats and the unit STOPS. Same module, three different behaviours — do not merge them.

The ranking pages merge all three. Aysonline gives one row — 'EU | IPM overheating | Reduce load, replace IPM if faulty' — but no manual says that: the Soyal fix is to de-energize for 20 minutes, check/replace the thermal grease on the IPM module radiator, and if that does not help replace control panel AP1. 'Reduce load' is meaningless advice for a wall-split, and 'replace IPM' is not the manual's remedy. Luce gives one correct row ('IPM over temperature limit / drop frequency') with no source, no fix and no H5/P8 distinction. Arlington has no EU section at all in its 48-code decoder. The official greecomfort H5 guide ranks for EU queries — a trap: H5 is a stop fault, EU is a frequency limit.

What the machine does when EU fires

During cooling and drying operation the compressor operates at decreased frequency to improve the system overload situation, and all loads operate normally. The unit does not stop. No blink count is verified for EU: the Soyal table has a dual-8 blinking column but the extracted text does not preserve the EU count, and the GWH-UB table's name for code 8 is not recoverable. This page assigns none.

Common causes

  1. High temperature of the IPM module — the Soyal row names the module temperature as the trigger and the remedy as a thermal-grease check on the IPM module radiator.
  2. Thermal grease on the IPM module radiator dried out or not making contact (the Soyal fix checks whether it 'needs to be replaced' / is 'inserted tightly').
  3. Outdoor control panel AP1 failing, if the thermal-grease check does not help (the Soyal fix: replace control panel AP1).

Safe checks, in order

  1. Switch the unit off and leave it de-energized for 20 minutes — the manual's own figure — then re-energize.
  2. If EU clears, the module temperature has come back down. Watch whether it returns on the next hot run.
  3. If EU returns, call a technician: the thermal grease on the IPM module radiator needs checking, and if that does not help the outdoor control panel AP1 is replaced. Both are technician work inside the outdoor unit.

Do not apply thermal grease yourself, do not take a temperature reading of the module, and do not replace a board — no manual gives an owner-level step for any of those. Aysonline's 'reduce load / replace IPM' is invented and is not the manual's remedy.

When to call a technician

  • EU returns after a 20-minute de-energize and restart.
  • EU appears together with a stop fault (H5 or P8) — the module temperature has gone from a limit to a trip.
  • Any burning smell, damaged wiring, or scorch marks near the outdoor unit — switch off and call a qualified technician immediately.

Safety first

EU involves the outdoor unit's IPM module and control panel — mains-powered electronics. Never open the outdoor unit's covers, never apply thermal grease yourself, and never touch board terminals while investigating it.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does EU mean on a Gree air conditioner?

Limit/decrease frequency due to high temperature of the module: the IPM module is running hot, so the compressor keeps running at a decreased frequency. Verified in five Gree manuals. The loads operate normally — the unit does not stop.

Is EU the same as H5?

No. H5 is IPM protection — the module trips and the unit stops. EU is a frequency limit — the unit keeps running, just slower. Same module, different behaviour.

Is EU the same as P8?

No. P8 is IPM high-temperature protection — the module overheats and the unit stops. EU limits frequency; P8 stops the unit.

How do I clear EU?

Switch the unit off and leave it de-energized for 20 minutes (the manual's own figure), then re-energize. If EU returns, a technician checks the thermal grease on the IPM module radiator and, if that does not help, replaces the outdoor control panel AP1.

Can I keep running the AC with EU showing?

The manuals describe the loads operating normally at decreased frequency, so the unit keeps cooling while EU is active. But EU means the IPM module is running hot — if it keeps appearing, get the thermal grease and the outdoor control panel checked before it becomes a stop fault.
