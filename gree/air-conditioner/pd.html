Gree Air Conditioner Error Code Pd

Quick answer

Error codePd — Gree Air Conditioner
What it meansOn U-Match units, Pd means sensor connection protection: the discharge sensor's AD value has been out of range for 5 seconds continuously. Pd is a U-Match-only code — it does not appear on wall-split Gree units.
Most common causeDischarge sensor in poor contact or damaged; discharge sensor terminal not connected; main board damaged (U-Match R32 §3.4.33).
Safe to check yourself?No — the discharge sensor, its needle-stand contact, its resistance and the outdoor main board are all technician work inside the outdoor unit. Switch off and re-energize once, then call a technician.
Checked againstGree U-Match R32 Service Manual §3.3 row 35 + §3.4.33 (GUD125W/NhB-S, GUD140W/NhB-S); Gree XK19 wired-controller generic error table (corroboration only); Gree U-Match 5 Series Service Manual §3.4.33 (corroboration; may be the same document as the R32 manual under a different host)

Applies to — read this first

Pd is a U-Match-only code — frame it that way, like PA/PC. It is NOT in the Soyal §9.1 list (rows 1-53 read in full), not in the Livo Gen4/Livo+ §9.1 tables as recorded, not in the evo/Change tables, and not in the U-Match R410A §1.1/§1.2 tables as read. This is the thinnest page of the batch: the meaning and one full troubleshooting section are verified first-hand, but no competitor defines Pd at all, so the page is won on manual depth alone.

Pd must not be merged with its neighbours: F5 is the discharge sensor's own error, E4 is high discharge temperature protection, and PF is the electric-box sensor error — Pd is specifically the discharge-sensor CONNECTION protection.

What the machine does when Pd fires

The error displays on the outdoor mainboard, the indoor wired controller and the indoor receive light board (U-Match R32 §3.4.33). The manual's judgment method is: the AD value of the discharge sensor is out of range for 5 seconds continuously. No blink count exists for Pd: U-Match codes display on the wired controller / outdoor main board / indoor receive light board, not as indoor lamp flashes. This page assigns none.

Common causes

  1. Discharge sensor is in poor contact or the sensor is damaged (U-Match R32 §3.4.33).
  2. Discharge sensor terminal is not connected (U-Match R32 §3.4.33).
  3. Main board is damaged (U-Match R32 §3.4.33).

Safe checks, in order

  1. Switch the unit off and re-energize once. If Pd clears, the sensor reading has come back into range.
  2. If Pd returns, call a technician. The manual's flow is: check the discharge sensor's contact with the needle stand on the main board, measure the sensor's resistance, replace the sensor if the resistance is abnormal, and if the sensor is normal replace the outdoor main board.
  3. Do not check the sensor contact, measure resistance, or replace a board yourself — every step of the manual's flow is technician work inside the outdoor unit.

No owner-level step exists in the manual for Pd. No owner-level sensor check, no resistance value, and no board-replacement procedure exists in the manuals for Pd — do not invent one.

When to call a technician

  • Pd returns after one off-and-re-energize.
  • Pd appears together with other discharge-sensor or main-board faults.
  • Any burning smell, damaged wiring, or scorch marks near the outdoor unit — switch off and call a qualified technician immediately.

Safety first

Pd involves the discharge sensor and the outdoor main board — mains-powered parts inside the outdoor unit. Never open the outdoor unit's covers or touch sensor terminals while investigating it, and never measure a sensor's resistance yourself.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does Pd mean on a Gree air conditioner?

On U-Match units, Pd is sensor connection protection: the discharge sensor's AD value has been out of range for 5 seconds continuously. Verified in the U-Match R32 manual (§3.4.33).

What causes Pd?

The manual names three causes: the discharge sensor is in poor contact or damaged; the discharge sensor terminal is not connected; the main board is damaged.

How is Pd fixed?

The manual's flow: check the discharge sensor's contact with the needle stand on the main board, measure the sensor's resistance, replace the sensor if the resistance is abnormal, and if the sensor is normal replace the outdoor main board. All technician work inside the outdoor unit.

Is Pd the same as F5 or E4?

No. F5 is the discharge sensor's own error; E4 is high discharge temperature protection. Pd is the sensor CONNECTION protection — poor contact, a disconnected terminal, or a damaged main board.

Does Pd appear on wall-split Gree units?

No. Pd is not in the Soyal, Livo Gen4, Livo+, evo, or Change wall-split tables, nor in the U-Match R410A tables. If a wall-split shows a code that looks like Pd, check the code again — it may be a different code (or a U-Match indoor unit).
