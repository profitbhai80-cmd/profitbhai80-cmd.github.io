Gree Air Conditioner Error Code PA

Quick answer

Error codePA — Gree Air Conditioner
What it meansPA = AC current protection (input side) - the AC input current has exceeded the set protection value, so the system shuts down for protection. U-Match (duct/cassette) and rooftop packaged units ONLY - PA is absent from every wall-split manual checked, so a wall-split owner will never see PA.
Most common causeSystem heavy-loaded with compressor current too large; abnormal grid voltage; a damaged PFC module; or a damaged drive-board PFC current sampling circuit (U-Match R32 service manual, section 3.4.31).
Safe to check yourself?No - no manual gives a user reset for PA. Restart the unit once; if PA comes back, it is a technician job (grid voltage, PFC module, drive-board sampling circuit, or mainboard).
Checked againstGree U-Match Series DC Inverter Service Manual, R410A (GC201602-I), section 1.2 + section 2.2 + Gree DC Inverter U-Match Series Service Manual, R32 (2019), section 3.3 row 33 + section 3.4.31 + Gree Mini After-sales Service Manual, U-Match appendix (p.35) + Gree ME33-42/G Owner's Manual

Applies to — read this first

Read this first, because Gree PA is a U-Match / rooftop packaged code ONLY - never a general wall-split code. PA is verified in two Gree U-Match service manuals (R410A and R32) plus the Mini U-Match appendix and the ME33-42/G adaptor manual (which states the adaptor is 'applicable for the Gree rooftop packaged unit, and U-Match unit'). It is ABSENT from every wall-split manual checked first-hand: Change 18/24 section 9.3, Viola GWH09/12RB section 9.1, Soyal GWH09/12/18AKC section 9.1, the G-TECH user manual, Livo Gen4/Livo+ section 9.1, the Mini split-type flash table, Flexx A-coil, and Xe71 Table 4. If you have a wall-split unit, PA is not your code - check your own model's manual.

What the machine does when PA fires

The ODU mainboard, the IDU wired controller and the IDU receiver light board display PA, and the system shuts down for protection. PA is not a flash-count code like the wall-split P5-P8: U-Match shows the code on the wired controller / dual-8 display.

Common causes

  1. System heavy-loaded and compressor current too large - the R32 manual's first possible reason.
  2. Grid voltage abnormal - the R32 manual's second possible reason.
  3. PFC module damaged - the R32 manual's third possible reason.
  4. Drive board PFC current sampling circuit element damaged, or drive chip PFC current sampling AD terminal abnormal - the R32 manual's fourth possible reason.
  5. Wrong-platform reading - VRF PA (drive storage chip malfunction) is a different fault that shares the code letters.

Safe checks, in order

  1. Restart the unit once: switch it off, wait a few minutes, switch it back on. If PA clears, the trip may have been a transient overload.
  2. If PA comes back, do not keep restarting - the manual's causes are a heavy load, abnormal grid voltage, a damaged PFC module, or a faulty drive-board PFC current sampling circuit. That is technician work.
  3. The R410A section 2.2 flowchart fix for the P0/P7/PA/HC/PC drive-malfunction group is to 'Replace the mainboard' - a board fix, not a wiring or sensor fix.
  4. Do not follow generic 'check wiring and components' advice (no manual lists wiring checks for PA), do not invent a breaker-reset ritual or a compressor-replacement step, and do not use VRF PA diagnosis for a U-Match PA.

The R32 section 3.4.31 troubleshooting flowchart is an image in the PDF and its text is not extractable - this page does not invent its steps. No manual gives a user reset for PA beyond one restart.

When to call a technician

  • PA returns after one restart - the grid voltage, PFC module, drive-board sampling circuit, or mainboard needs a technician.
  • Any burning smell, visibly damaged wiring, or other fault codes alongside PA - switch off and call a qualified technician.
  • Your unit is a wall-split showing PA - PA is not a wall-split code, so what you are seeing needs professional diagnosis of the real fault.

More guidance: when an appliance error requires professional service.

Safety first

PA involves mains-powered drive electronics (PFC module, drive board): never open the outdoor unit or probe the drive board yourself. Work only from the outside of the unit, and switch it off at the isolator before any visible check.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does PA mean on a Gree air conditioner?

AC current protection from the input side - the AC input current exceeded the set protection value, so the system shut down. Verified in two Gree U-Match service manuals (R410A section 1.2, R32 section 3.3 row 33 + section 3.4.31).

Does every Gree AC use PA?

No - and this matters. PA is listed in the U-Match (duct/cassette) and rooftop packaged manuals, but NOT in Change 18/24, Viola, Soyal, G-TECH, Livo Gen4 or Livo+. If you have a wall-split unit, PA is not your code - check your own model's manual.

How do I reset a Gree PA error?

Restart the unit once. If PA comes back, do not keep restarting - the manual's causes are a heavy load, abnormal grid voltage, a damaged PFC module, or a faulty drive-board PFC current sampling circuit, and the R410A flowchart fix is to replace the mainboard. That is technician work.

Is PA the same as P5 or E5?

No. PA is the AC INPUT current tripping (grid side / PFC sampling). P5 is compressor PHASE current overcurrent. E5 is general AC overcurrent protection. They are different faults with different diagnoses.

Is VRF PA the same fault?

No. On GMV VRF units PA means 'Malfunction of drive storage chip of compressor' - a different fault that happens to share the code letters. Do not use VRF diagnosis for a U-Match PA, or vice versa.
