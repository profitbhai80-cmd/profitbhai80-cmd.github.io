Beko Washing Machine Error Code E08

Quick answer

Error codeE08 — Beko Washing Machine (your Beko manual lists it as E8)
What it meansThe machine may not be taking in water — it is not filling (or not filling fast enough) when it should.
Most common causeA water tap not fully open, a folded/kinked inlet hose, a water outage, or a clogged filter — check the manual's steps below before anything else.
Safe to check yourself?Yes — for the basic external checks below. Do not open the machine's body.

Applies to — read this first

Before anything else: if your display shows E08 but your Beko manual only lists E8, you have the right code. Beko's user manuals print this fault as E8; the display shows it as E08. Same fault, same meaning, same steps — no manual splits the two.

Where you see itWhat it means there
Your machine's display: E08The machine may not be taking in water.
Your Beko manual: E8The machine may not be taking in water.

No series split was found: every Beko washing machine manual checked uses identical wording for this fault. One important exception: this page covers washing machines only. Beko tumble dryers have a separate E08 code that is not documented in the washer manuals — do not use this page for a dryer.

Find your model number on the rating label if you are not sure — see how to find your model number.

Common causes

  1. The water tap feeding the machine is closed or only partly open.
  2. A water outage or interrupted supply to the home.
  3. The water inlet hose is folded or kinked, or its connection is restricted.
  4. The inlet hose mesh filters are clogged with grit, rust or limescale.
  5. The pump filter is clogged (Beko's own troubleshooting list for this code includes it).
  6. The front cover of the machine is not closed or not locked.
  7. If all of the above are fine: a faulty inlet valve, wiring, or the control board — technician territory.

Safe checks, in order

  1. Turn the water taps fully on.
  2. Make sure there is no water outage — check another tap in the house.
  3. Check the water inlet hose connection; if there is any folding on the hose, straighten it.
  4. Turn the taps off again and clean the small mesh filters at the inlet hose connections (brush off grit and limescale, rinse, refit firmly), then reopen the taps.
  5. Clean the pump filter: open the filter cover at the front base, have a towel ready for residual water, turn the filter anti-clockwise, remove debris, rinse, refit firmly.
  6. Close the front cover of the machine and make sure that it is locked.
  7. Run the machine one more time and watch whether it fills normally and the code stays away.

Work through the checks in order and stop as soon as the code clears. If a check needs a panel removed, a part tested, or a wire touched, it is no longer a safe home check — skip to the technician section.

When to call a technician

  • The code returns immediately even with a known-good water supply and clean filters.
  • No water enters at all, or you never hear the inlet valve click open.
  • There is any sign of leaking under or behind the machine, or any burning smell.

Safety first

Always switch off and unplug the washing machine before moving it or disconnecting hoses, and close the water tap first. Water and electricity are a dangerous mix — never work on a machine that is connected to power with wet hands or a wet floor.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

Is E08 the same as E8 on a Beko washing machine?

Yes. Your display shows E08, but Beko's user manuals list the same fault as E8: "The machine may not be taking in water." It is the same water-intake fault with the same steps, so if you search your manual for E08 you will not find it — look up E8 instead.

What does E08 mean on a Beko washing machine?

In Beko's own wording: "The machine may not be taking in water." The machine is not filling (or not filling fast enough) at the start of the cycle or before a rinse, so it stops and shows the code.

How do I clear E08 on my Beko washing machine?

Work through the manual's steps: turn the water taps fully on, check there is no water outage, straighten any folding in the inlet hose, clean the pump filter, close the front cover of the machine and make sure it is locked, then run the machine one more time. There is no special button reset sequence in the manuals.

Why do some websites say E08 means the drain pump is running continuously?

That claim is wrong. It comes from forum answers that mixed up the codes. Every Beko user manual describes E8 (displayed as E08) as a water-intake fault: "The machine may not be taking in water." The drain fault is E05 on Beko washers.
