Sharp Washing Machine Error Codes

E1

Sharp Washing Machine Error E1

Sharp WM E1 (top-load): water inlet fault — set water level not reached in 15 minutes. Faucet, flow, inlet filter net.

 E01

Sharp Washing Machine Error E01

Sharp WM E01 (front-load): door not shut properly — shut it until it clicks. Not the same as top-load E1.

 E02

Sharp Washing Machine Error E02

Sharp WM E02 (front-load): water pressure or water level may be low — check the tap is fully on.

 E03

Sharp Washing Machine Error E03

Sharp WM E03 (front-load): pump faulty / pump filter clogged — clean the pump filter.

 E04

Sharp Washing Machine Error E04

Sharp WM E04 (front-load): excessive amount of water — the machine discharges it by itself.

 E2

Sharp Washing Machine Error E2

Sharp WM E2 (top-load): top lid open when spinning — close the lid and clear the alarm. Not front-load E02.

 E3

Sharp Washing Machine Error E3

Sharp WM E3 (top-load): spin imbalance (HK/F/G) or drain-hose fault (W/M) — check the model first.

 E4

Sharp Washing Machine Error E4

Sharp WM E4 (top-load): 20-min filling timeout (HK/F/G) or imbalance (W/M) — opposite faults.

 F1

Sharp Washing Machine Error F1

Sharp WM F1 (top-load): water level sensor is wrong — power off 1 minute, then on again.
