Sharp Washing Machine Error Code E2

Quick answer

Error codeE2 — Sharp Washing Machine
What it meansE2 means the top lid is open when spinning. The manuals' only owner action is to close the top lid and clear up the alarm. On the ES-W95TWXT / ES-W85TWXT and ES-M1108T family there is a second trigger: the lid opened when the reservation course starts.
Most common causeThe top lid is open during spin drying — or, on the W/M family, opened when the reservation course starts.
Safe to check yourself?Yes — close the top lid and clear up the alarm. If E2 persists with the lid closed, the lid switch or sensor needs a technician.
Checked againstSharp ES-HK800G Operation Manual §1 (Abnormal display); Sharp ES-F120G / ES-F100G Operation Manual §1 (Abnormal display); Sharp ES-G80G Operation Manual §1 (Abnormal display); Sharp ES-W95TWXT / ES-W85TWXT Operation Manual, Abnormal display (printed p.17); Sharp ES-M1108T Operation Manual, Abnormal display (printed p.6)

Applies to — read this first

E2 is a TOP-LOAD code only, and it is not the same code as front-load E02. On Sharp top-load washers E2 means the top lid is open when spinning. On Sharp front-load washers there is no E2 at all: the front-load code is E02, and it means the water pressure or the water level inside the machine may be low. Check the model number and the platform first, not just the letters. On the same top-load platform, E0 is the lid opened when the preset is started, and E5 (HK/F/G) / U9 (W/M) is the lid opened after setting child-lock. Front-load door is E01, never E2.

The ranking pages get E2 wrong or hedge it. knowledgebase.bison.co.in (ranks #1) says E2 is the lid but hedges a second meaning — "On other documented Sharp platforms, E2 represents an abnormal or excessive water level" — which is unsupported by every manual read: all five say lid, and no platform, model or manual is named for the water-level half. Its "If E2 Appears During Filling" branch (pressure hose, sensor, inlet valve, PCB checks) is invented; the manuals' only settlement is closing the lid. Its "one top-load family" list (E2 abnormal water level, E3 lid, E4 imbalance, E5 drainage) matches NO single manual. theblackurbantimes.com (ranks #2) says E2 is a door problem — WRONG on both platforms (top-load E2 is the lid; front-load door is E01) — and its "open and close the door six times within 12 seconds" reset is not a Sharp manual instruction. primerepair.co.uk covers E01–E04 only and has NO E2 section at all. manuals.plus's own ES-G80G FAQ block garbles E2/E3/E4 together ("E2: … If spinning does not balance after 20 minutes of water filling time…") — a manuals.plus FAQ error, not the manual text; never quote it as the manual. webtech360's LE ("washer lid may not be covered") is a Vietnamese digit/letter code — a different code format, never import it onto E2.

What the machine does when E2 fires

When E2 fires, the machine stops because the top lid is open during spin drying. On the ES-W95TWXT / ES-W85TWXT and ES-M1108T family the same code appears if the lid is opened when the reservation course starts. Close the lid and clear up the alarm to resume.

Common causes

  1. The top lid is open during spin drying (all five manual families).
  2. The top lid was opened when the reservation course starts (ES-W95TWXT / ES-W85TWXT and ES-M1108T).
  3. The lid was not fully closed before the spin started.

Safe checks, in order

  1. Close the top lid fully.
  2. Clear up the alarm as the manual instructs.
  3. If the reservation course was starting, close the lid before the reserved start time, then restart the course.
  4. If E2 stays on with the lid properly closed, stop — the lid switch or sensor needs a technician.

The manuals name no other owner step: no lid-switch test, no safety-switch replacement, no pressure-tube or sensor check, no inlet-valve or PCB step exists in any E2 manual row. Do not replace parts on the code alone.

When to call a technician

  • E2 persists with the lid properly closed.
  • The lid switch feels loose or the lid does not stay shut.
  • E2 appears together with other fault codes.

Safety first

E2 is a lid-safety fault, not an electrical fault, but never reach into the machine while the tub is spinning and never open the machine while it is connected to power. If the lid switch is faulty, the machine needs a technician — do not bypass the lid switch.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does E2 mean on a Sharp washing machine?

On Sharp top-load washers, E2 means the top lid is open when spinning. Close the top lid and clear up the alarm.

Is Sharp E2 the same as E02?

No. E2 on top-load machines is the lid open when spinning; E02 on front-load machines means the water pressure or water level inside the machine may be low. Different code, different platform.

Why does E2 appear when I start a delayed (reservation) wash?

On the ES-W95TWXT / ES-W85TWXT and ES-M1108T family the manual lists a second E2 trigger: the top lid opened when the reservation course starts. Close the lid before the reserved start time.

Does E2 mean a water-level problem?

No. Some guides say E2 can mean abnormal water level on some platforms, but every Sharp top-load manual read defines E2 as the lid — the water-level fault on these machines is E1 (inlet) or, on the M1108T family, C2 (sensor).

What if E2 stays on with the lid closed?

The manuals give no owner step beyond closing the lid. If E2 persists with the lid properly closed, the lid switch or sensor needs a technician — do not replace parts on the code alone.
