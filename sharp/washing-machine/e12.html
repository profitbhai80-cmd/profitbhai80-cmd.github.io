Sharp Washing Machine Error Code E12

Quick answer

Error codeE12 — Sharp Washing Machine
What it meansE12 means undrained — the machine has not drained. Check the drain pipe's position, height and length, and that it is not blocked, then press START/PAUSE.
Most common causeThe drain pipe is in the wrong place, too high, too long, or blocked — or hot water was used.
Safe to check yourself?Yes — the manual's own inspection points only, then press START/PAUSE. If E12 persists with the drain clear, the machine needs a technician.
Checked againstSharp ES-FH10AT-W Manual, Troubleshooting Guide; Sharp ES-FH105BV-B Operation Manual, Troubleshooting Guide

Applies to — read this first

E12 is a FRONT-LOAD code only, on the FH family (ES-FH10AT-W, ES-FH105BV-B). On these machines E12 means undrained — the machine has not drained. E12 is not the same code as top-load E2 (a lid/water-level code by family), front-load E02 (low water, on the E01–E04 family), or Haier WM E12 (a different brand's code and a different fault). Grundig's E12 (leak / float switch) and Bosch's E12 (washer-dryer lock fault) are other brands' codes — never import them.

What the machine does when E12 fires

When E12 fires, the machine has not drained. The manuals list eight inspection points — drain pipe in the right place, drain height not too high, drain pipe not blocked, drain-pipe length, do not use hot water, water temperature high when washing, suspension of drying, washer in the right place and steady — and the settlement is to press START/PAUSE.

Common causes

  1. The drain pipe is not in the right place.
  2. The drain height is too high.
  3. The drain pipe is blocked.
  4. The drain-pipe length is wrong.
  5. Hot water was used, or the water temperature is high when washing.
  6. The washer is not in the right place or not steady.

Safe checks, in order

  1. Ensure the drain pipe is in the right place.
  2. Check the drain height is not too high.
  3. Ensure the drain pipe has not been blocked.
  4. Ensure the drain-pipe length is right.
  5. Make sure not to use hot water.
  6. Ensure the washer is in the right place and steady.
  7. Press the START/PAUSE button.

The manuals name no other owner step: no drain-pump impeller check, no pump-winding test, no "tilt the unit forward 45°" float-switch step (that is Grundig), and no "replace the main control board" step exists in any E12 manual row. Do not replace parts on the code alone.

When to call a technician

  • E12 persists with the drain pipe clear.
  • E12 appears together with other fault codes.
  • Water is leaking from the drain hose or around the machine — turn off the tap and unplug the machine first.

Safety first

E12 is a drainage fault, not an electrical fault, but never open the machine while it is connected to power, and if water is leaking around the machine, turn off the tap and unplug the machine before touching anything wet.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does E12 mean on a Sharp washing machine?

On Sharp front-load washers ES-FH10AT-W and ES-FH105BV-B, E12 means undrained — the machine has not drained. Check the drain pipe's position, height and length, and that it is not blocked, then press START/PAUSE.

Is Sharp E12 the same as E2?

No. E2 is a top-load code (lid or water level, depending on family). E12 is a front-load FH-family code for drainage. Different code, different platform.

Is Sharp E12 the same as Haier E12?

No. Haier WM E12 is a different brand's code with a different fault. The letters match; the meaning does not. Check the brand and model number first.

Why does the manual mention hot water for a drainage code?

Because the FH105BV-B table lists it as an inspection point: "Make sure not to use hot water. The water temperature is high when washing." The manual's list also covers suspension of drying and machine placement.

What if E12 stays on with the drain clear?

The manuals give no further owner step beyond the inspection points and pressing START/PAUSE. If E12 persists with the drain pipe clear, the drain pump needs a technician — do not replace parts on the code alone.
