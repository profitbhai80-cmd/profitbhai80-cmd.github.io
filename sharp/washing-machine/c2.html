Sharp Washing Machine Error Code C2

Quick answer

Error codeC2 — Sharp Washing Machine
What it meansC2 means the water level sensor shows an abnormal level. The manual's settlement is to pull out the plug and entrust the maintenance department — a service code, not an owner-fix code.
Most common causeThe water level sensor shows an abnormal level — the manuals name no owner check for C2 at all.

Checked againstSharp ES-M1108T Operation Manual, Abnormal display (printed p.6); Sharp ES-W110DS-S / ES-W100DS Operation Manual, Abnormal display (p.9); Sharp ES-W95TWXT / ES-W85TWXT Operation Manual, Abnormal display (printed p.17)

Applies to — read this first

C2 is a TOP-LOAD code only, on the M series and W (DS) series (ES-M1108T, ES-W110DS-S / ES-W100DS). On these machines C2 means the water level sensor shows an abnormal level. C2 is a service code: the manuals give no owner diagnostic for it. C2 is not the same code as F1 (the same sensor fault on the HK/F/G family) or E02 (a front-load low-water code). C1, C3, C4 and C5 have no verified individual meanings in any Sharp manual read — the ES-W95TWXT manual only prints a generic C* wildcard ("There is a possibility of malfunction").

Its meaning ("abnormal water-level sensor reading") is correct, but it gives no named manual, no model, no verbatim row, no actual settlement, no failure-cause list from the manuals, and no C2-vs-F1 split. Its seven-cause list ("Defective water-level sensor / Pressure tube disconnected / Pressure tube leaking / Tube blocked with detergent residue / Wiring disconnected / Connector corrosion / PCB input circuit failure") is invented as C2 causes, and its "Technician Diagnosis" (inspect the pressure hose for cracks, water inside, detergent deposits, pinching, loose connections; electrically test the sensor) is invented — no such procedure exists in either manual. Its quick-table "first things to check: Pressure sensor and pressure tube" is not in any C2 manual row.

What the machine does when C2 fires

When C2 fires, the machine has detected that the water level sensor shows an abnormal level. The manuals' settlement is to pull out the plug and entrust the maintenance department.

Common causes

  1. The water level sensor shows an abnormal level (ES-M1108T / ES-W110DS-S manuals).
  2. On the sibling ES-W95TWXT, any C-number is a generic malfunction code (C* wildcard) — but it does not name C2's sensor meaning.

Safe checks, in order

  1. Pull out the plug from the plug seat.
  2. Entrust the maintenance department — C2 is a service code with no owner diagnostic.
  3. Do not open the machine to test the sensor or inspect a pressure hose on the code alone.

The manuals name no owner diagnostic for C2. The service-side list printed under the table in both manuals is a general "List of failure cause" for the whole abnormal-display table, not a C2-specific cause list: "Get water in tube of water level sensor; Circuit failure; Failure of water inlet valve; Wiring disconnection; Connector contact failure; Failure of water level sensor; Failure of safety switch; Failure of drain valve; Failure of drain valve motor; Connect failure on drain valve motor." It contains no "pressure tube leaking", no "detergent residue", no "connector corrosion" and no "PCB input circuit failure" — those are bison's invention, not the manuals'.

When to call a technician

  • C2 appears at all — the manuals' own settlement is to entrust the maintenance department.
  • C2 appears together with other fault codes.
  • Water is leaking around the machine — turn off the tap and unplug the machine first.

Safety first

C2 is a sensor fault. Pull out the plug and call the maintenance department.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does C2 mean on a Sharp washing machine?

On Sharp top-load washers ES-M1108T and ES-W110DS-S / ES-W100DS, C2 means the water level sensor shows an abnormal level. The manual says to pull out the plug and entrust the maintenance department.

Can I fix Sharp C2 myself?

The manuals give no owner fix for C2. Unlike the lid codes, C2 is a service code: pull out the plug and call the maintenance department. Do not open the machine to test the sensor.

Is Sharp C2 the same as F1?

Same fault, different code on a different family. F1 is the water-level-sensor fault on the ES-HK800G / ES-F120G / ES-G80G family; C2 is the same fault on the ES-M1108T / ES-W110DS-S family.

What do Sharp C1, C3, C4 and C5 mean?

No Sharp manual read gives them individual meanings. The ES-W95TWXT manual only prints a generic C* wildcard ("There is a possibility of malfunction"). Treat them as model-specific codes until a manual confirms otherwise.

Is Sharp C2 the same as E02?

No. E02 is a front-load code for low water (tap, fill-hose kink, filter). C2 is a top-load code for a sensor fault. Different code, different platform, different fault.
