Sharp Washing Machine Error Codes

E1

Sharp Washing Machine Error E1

Sharp WM E1 (top-load): water inlet fault — set water level not reached in 15 minutes. Faucet, flow, inlet filter net.

 E01

Sharp Washing Machine Error E01

Sharp WM E01 (front-load): door not shut properly — shut it until it clicks. Not the same as top-load E1.

 E02

Sharp Washing Machine Error E02

Sharp WM E02 (front-load): water pressure or water level may be low — check the tap is fully on.

 E03

Sharp Washing Machine Error E03

Sharp WM E03 (front-load): pump faulty / pump filter clogged — clean the pump filter.

 E04

Sharp Washing Machine Error E04

Sharp WM E04 (front-load): excessive amount of water — the machine discharges it by itself.

 E2

Sharp Washing Machine Error E2

Sharp WM E2 (top-load): top lid open when spinning — close the lid and clear the alarm. Not front-load E02. X series: abnormal water level instead.

 E3

Sharp Washing Machine Error E3

Sharp WM E3 (top-load): spin imbalance (HK/F/G) or drain-hose fault (W/M) — check the model first. X series: lid instead.

 E4

Sharp Washing Machine Error E4

Sharp WM E4 (top-load): 20-min filling timeout (HK/F/G) or imbalance (W/M and X) — opposite faults.

 F1

Sharp Washing Machine Error F1

Sharp WM F1 (top-load): water level sensor is wrong — power off 1 minute, then on again.

 E0

Sharp Washing Machine Error E0

Sharp WM E0 (top-load): top lid open at preset start — close the lid and clear the alarm. Not front-load E01.

 E5

Sharp Washing Machine Error E5

Sharp WM E5 (top-load): child-lock lid (HK/F/G) or drainage (X series) — check the model first.

 U9

Sharp Washing Machine Error U9

Sharp WM U9 (top-load): lid opened during child lock — turn power off, reset manually.

 C2

Sharp Washing Machine Error C2

Sharp WM C2 (top-load): water level sensor abnormal — pull the plug, call service.

 E7

Sharp Washing Machine Error E7

Sharp WM E7 (X series): lid not closed when child lock is on — close within 10 seconds.

 E11

Sharp Washing Machine Error E11

Sharp WM E11 (front-load FH): no water — check tap, frozen pipe, blocked filter.

 E12

Sharp Washing Machine Error E12

Sharp WM E12 (front-load FH): undrained — check drain pipe position, height, blockage.

 H

Sharp Washing Machine Error H

Sharp WM H (front-load FH): door can't be opened — unlocks automatically as temperature drops.

 U3

Sharp Washing Machine Error U3

Sharp WM U3 (front-load FH): no dehydration — add 2 pieces of cloth, press START/PAUSE.

 U4

Sharp Washing Machine Error U4

Sharp WM U4 (front-load FH): door not closed — close until the 'locked' light is on.
