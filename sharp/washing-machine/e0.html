Sharp Washing Machine Error Code E0

Quick answer

Error codeE0 — Sharp Washing Machine
What it meansE0 means the top lid is open when the preset (delayed-start) program is started. The manuals' only owner action is to close the top lid and clear up the alarm.
Most common causeThe top lid was left open when the preset (delayed-start) program was started.
Safe to check yourself?Yes — close the top lid and clear up the alarm. If E0 persists with the lid closed, the machine needs a technician.
Checked againstSharp ES-HK800G Operation Manual §1 (Abnormal display); Sharp ES-F120G / ES-F100G Operation Manual §1 (Abnormal display); Sharp ES-G80G Operation Manual §1 (Abnormal display)

Applies to — read this first

E0 is a TOP-LOAD code only, and it is not the same code as front-load E01. On Sharp top-load washers (ES-HK800G, ES-F120G / ES-F100G, ES-G80G), E0 means the top lid is open when the preset (delayed-start) program is started. E0 is a start-condition code, not a fault in a component: the machine refuses to start the preset countdown with the lid open. On Sharp front-load washers there is no E0 at all: the front-load code is E01, and it means the door is not shut properly. Check the model number and the platform first, not just the letters. On the same top-load platform, E2 is the lid open when spinning and E5 is the lid opened after setting child-lock — same lid, different triggers.

The ranking pages do not state Sharp washer E0 at all. knowledgebase.bison.co.in (ranks #3) never mentions E0 — no quick-table row, no section, no FAQ — and its "one top-load family" list (E1 water supply, E2 abnormal water level, E3 lid, E4 imbalance, E5 drainage) is the ES-X155 table reproduced without the model name, not the HK/F/G table where E0 lives. webtech360.com (ranks #2) lists Vietnamese digit-first codes 1E/0E/LE — a different code format; its 0E ("cannot drain") must never be imported onto E0. The front-load manuals (ranks #4–#10) cover E01–E04, and a searcher landing on an E01 FAQ can mistake E01 for E0. usro.net's J-Tech E0 ("communication error between PCB boards") belongs to Sharp inverter refrigerators/air conditioners, never to washers.

What the machine does when E0 fires

When E0 fires, the machine refuses to start the preset countdown with the lid open. Close the top lid and clear up the alarm to let the preset start.

Common causes

  1. The top lid was left open when the preset (delayed-start) program was started.
  2. The lid was opened just as the preset was started.
  3. The lid was not fully closed before the preset was started.

Safe checks, in order

  1. Close the top lid fully.
  2. Clear up the alarm as the manual instructs.
  3. If E0 stays on with the lid properly closed, stop — the lid switch or sensor needs a technician.

The manuals name no other owner step: no lid-switch test, no safety-switch replacement, no preset-timer or control-board step exists in any E0 manual row. Do not replace parts on the code alone.

When to call a technician

  • E0 persists with the lid properly closed.
  • The lid switch feels loose or the lid does not stay shut.
  • E0 appears together with other fault codes.

Safety first

E0 is a start-condition fault, not an electrical fault, but never reach into the machine while the tub is spinning and never open the machine while it is connected to power. If the lid switch is faulty, the machine needs a technician — do not bypass the lid switch.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does E0 mean on a Sharp washing machine?

On Sharp top-load washers (ES-HK800G, ES-F120G/F100G, ES-G80G), E0 means the top lid is open when the preset (delayed-start) program is started. Close the top lid and clear up the alarm.

Is Sharp E0 the same as E01?

No. E0 on top-load machines is the lid open at preset start; E01 on front-load machines means the door is not shut properly. Different code, different platform — check the model number, not just the letters.

What is the difference between E0 and E2?

Same lid, different trigger. E0 appears when the preset is started with the lid open; E2 appears when the lid is open while spinning. Close the lid for either.

My Sharp washer has no E0 — is that normal?

Yes, on some families. The ES-W95TWXT / ES-M1108T / ES-W110DS-S family folds the preset-start lid trigger into E2, and the ES-X155 / ES-X751 / ES-X851 family calls it E3. E0 exists only on the HK/F/G family.

What if E0 stays on with the lid closed?

The manuals give no owner step beyond closing the lid. If E0 persists with the lid properly closed, the lid switch or sensor needs a technician — do not replace parts on the code alone.
