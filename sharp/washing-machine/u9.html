Sharp Washing Machine Error Code U9

Quick answer

Error codeU9 — Sharp Washing Machine
What it meansU9 means the top lid was opened during child lock. The manual's settlement is to turn the power off and check inside the tub — and the child lock must be reset manually, it does not release on its own.
Most common causeThe top lid was opened after the water supply started while child lock was set.
Safe to check yourself?Yes — turn the power off, check inside the tub, and reset the child lock manually (hold COURSE 3 seconds on W95TWXT, FRAGRANCE 3 seconds on W110DS-S). If U9 persists, the machine needs a technician.
Checked againstSharp ES-W95TWXT / ES-W85TWXT Operation Manual, Abnormal display (printed p.17); Sharp ES-M1108T Operation Manual, Abnormal display (printed p.6); Sharp ES-W110DS-S / ES-W100DS Operation Manual, Abnormal display (p.9)

Applies to — read this first

U9 is a TOP-LOAD code only, on the W/M family (ES-W95TWXT / ES-W85TWXT, ES-M1108T, ES-W110DS-S / ES-W100DS). On these machines U9 means the top lid was opened during child lock. The child lock must be reset manually — the manuals print the caution "CHILD LOCK is not released, unless you reset it manually." U9 is not the same code as E5 (the HK/F/G family's child-lock lid code) or E7 (the X family's child-lock lid code), and it is not the same code as front-load "CL", which is a child-lock indicator, not a fault code.

Its meaning ("lid opened while Child Lock is active") is correct, but it gives no named manual, no model, no verbatim row, no exact settlement, no reset method (COURSE 3 sec / FRAGRANCE 3 sec), no 30-second auto-drain rule, and no U9-vs-E5 split. Its "Close the lid correctly. Restart the washer" is generic filler; the manuals say nothing about restarting after U9 beyond the reset caution.

What the machine does when U9 fires

When U9 fires, the error tone sounds if the top lid is opened after the water supply starts. If the top lid stays open for 30 seconds, the error tone sounds again and the water is drained automatically. Only the POWER key is operable in this mode.

Common causes

  1. The top lid was opened after the water supply started while child lock was set.
  2. The top lid was left open for 30 seconds during child lock, so the machine drained automatically.
  3. The child lock was not reset manually after the lid was opened.

Safe checks, in order

  1. Turn the power off, and check inside the tub.
  2. Reset the child lock manually — hold the COURSE key for 3 seconds (ES-W95TWXT) or the FRAGRANCE key for 3 seconds (ES-W110DS-S). The reset method varies by model.
  3. If U9 stays on with the lid properly closed, stop — the lid switch or sensor needs a technician.

The manuals name no other owner step: no lid-switch test, no lid-magnet check, no safety-switch, lock-mechanism, wiring or control-board step exists in any U9 manual row. Bison's six-component inspection list (lid switch / lid magnet / safety switch / lock mechanism / wiring / control board) is invented — do not use it. Do not replace parts on the code alone.

When to call a technician

  • U9 persists with the lid properly closed.
  • The lid switch feels loose or the lid does not stay shut.
  • U9 appears together with other fault codes.

Safety first

U9 is a lid-safety fault, not an electrical fault, but never reach into the machine while the tub is spinning and never open the machine while it is connected to power. If the lid switch is faulty, the machine needs a technician — do not bypass the lid switch.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does U9 mean on a Sharp washing machine?

On Sharp top-load washers ES-W95TWXT / ES-W85TWXT, ES-M1108T and ES-W110DS-S / ES-W100DS, U9 means the top lid was opened during child lock. Turn the power off and check inside the tub.

How do I clear Sharp U9?

Turn the power off and check inside the tub, then reset the child lock manually — hold the COURSE key for 3 seconds (W95TWXT) or the FRAGRANCE key for 3 seconds (W110DS-S). Child lock is not released unless you reset it manually.

Is Sharp U9 the same as E5?

Same trigger, different code on a different family. E5 is the child-lock lid code on the ES-HK800G / ES-F120G / ES-G80G family; U9 is the child-lock lid code on the W/M family. Their settlements differ too.

Why does the washer drain by itself after U9?

Because the manual says so: if the lid stays open for 30 seconds during child lock, the error tone sounds again and the water is drained automatically. Only the POWER key works in that mode.

What if U9 stays on with the lid closed?

The manuals give no owner step beyond turning the power off and checking inside the tub. If U9 persists with the lid properly closed, the lid switch or sensor needs a technician — do not replace parts on the code alone.
