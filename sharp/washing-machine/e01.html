Sharp Washing Machine Error Code E01

Quick answer

Error codeE01 — Sharp Washing Machine
What it meansE01 means the door of the machine is not shut properly. The manual's only owner action is to shut the door properly until a click is heard; if the fault persists, turn the machine off, unplug it, and contact the nearest authorised service agent.
Most common causeThe door is not shut properly — shut it until you hear a click.
Safe to check yourself?Yes — shut the door properly until you hear a click. If E01 persists, turn the machine off, unplug it, and contact the nearest authorised service agent.
Checked againstSharp ES-NFA814BW1NA-DE User Manual §10 (EN p.28); Sharp ES-NFB914AWC User Manual §10 (EN p.28); Sharp ES-HFB8143WD-DE User Manual §10 (EN p.27)

Applies to — read this first

E01 is a FRONT-LOAD code only, and it is not the same code as top-load E1. On Sharp front-load washers E01 means the door of the machine is not shut properly. On Sharp top-load washers there is no E01 at all: the top-load code is E1, and it means the water level was not reached (a water-inlet fault). Check the model number and the platform first, not just the letters. Top-load washers use E0/E2 for the top lid, never E01.

What the machine does when E01 fires

The machine will not start the cycle: it checks the door before starting, and if the door is not shut properly it shows E01 instead of starting. The manual's only owner action is to shut the door until it clicks; if the fault persists, turn the machine off, unplug it, and contact the nearest authorised service agent.

Common causes

  1. The door is not shut properly (ES-NFA814BW1NA-DE User Manual §10).
  2. The door lock has not engaged, so the machine will not start the cycle.

Safe checks, in order

  1. Shut the door properly until you hear a click (ES-NFA814BW1NA-DE User Manual §10).
  2. If E01 persists, turn off your machine, unplug it, and contact the nearest authorised service agent immediately.

The manuals name no other owner step: no door-interlock position ("right side"), no interlock/PCB replacement step, and no "use a bit of force" instruction exists in them. The page's only owner action is the manual's own: shut the door until it clicks; if E01 persists, turn off, unplug, and call the nearest authorised service agent.

When to call a technician

  • E01 persists after the door is shut properly until it clicks.
  • The door will not stay shut or the lock will not engage at all.
  • Any sign of damage to the door, hinge or lock — do not force it.

Safety first

Never force the door: forcing it can damage the interlock. Never open the machine while it is connected to power, and never attempt to bypass the door lock — it is a safety device.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does E01 mean on a Sharp washing machine?

On Sharp front-load washers, E01 means the door of the machine is not shut properly. Shut the door properly until you hear a click.

Is Sharp E01 the same as E1?

No. E01 on front-load machines is a door fault; E1 on top-load machines is a water-inlet fault. Same brand, different platform, different fault — check the model number.

How do I fix Sharp E01?

Shut the door firmly until you hear the click. If E01 persists, turn the machine off, unplug it, and contact the nearest authorised service agent — that is the manual's instruction.

Why does E01 appear right after I select a cycle?

The machine checks the door before starting; if the door is not shut properly (or the lock has not engaged), it shows E01 instead of starting. (A repair guide notes this timing; the manual itself does not state it.)

Can I force the door shut if E01 keeps showing?

No. Forcing the door can damage the interlock. Shut it normally until it clicks; if it still will not register, the machine needs an authorised service agent.
