Sharp Washing Machine Error Code E7

Quick answer

Error codeE7 — Sharp Washing Machine
What it meansE7 means the lid is not closed when child lock is on. Close the lid within 10 seconds and the program resumes itself; if the lid is still open after 10 seconds, the machine starts draining — to resume, deselect child-lock mode.
Most common causeThe lid was not closed within 10 seconds while child lock was on.
Safe to check yourself?Yes — close the lid within 10 seconds, or deactivate child lock to resume. If E7 persists with the lid closed, the machine needs a technician.
Checked againstSharp ES-X155 Operation Manual, Troubleshooting; Sharp ES-X751 / ES-X851 Operation Manual, Error Codes

Applies to — read this first

E7 is a TOP-LOAD code only, on the X series (ES-X155, ES-X751 / ES-X851). On these machines E7 means the lid is not closed when child lock is on. E7 exists only on the X series, and the X series reassigns E2 (water level), E3 (lid) and E5 (drainage) — never import the HK/F/G or W/M meanings onto an X-series code. E7 is not the same code as E5 (the HK/F/G child-lock lid code, 5-second rule) or U9 (the W/M child-lock lid code, power-off settlement).

No ranking page states Sharp washer E7 at all. knowledgebase.bison.co.in (ranks #2) never mentions E7 — no quick-table row, no section, no FAQ, no mention in its model-difference lists — and its U9 section never mentions that the X series calls the same condition E7. webtech360.com (ranks #5) lists Vietnamese digit-first codes 1E/0E/LE — a different code format; its LE ("lid may not be covered") must never be imported onto E7.

What the machine does when E7 fires

When E7 fires, the program waits for the lid: close the lid within 10 seconds and the program resumes itself. If the lid is still open after 10 seconds, the machine starts draining. To resume, deselect (deactivate) child-lock mode.

Common causes

  1. The lid was not closed when child lock was on.
  2. The lid was left open for more than 10 seconds during child lock, so the machine started draining.
  3. Child lock was set (press Preset + Add together, or press and hold PRESET and ADD for 3 seconds on X751/X851) and the lid was then opened.

Safe checks, in order

  1. Close the lid within 10 seconds — the program resumes itself.
  2. If the lid is still open after 10 seconds, the machine starts draining; to resume, deselect (deactivate) child-lock mode.
  3. If E7 stays on with the lid properly closed, stop — the lid switch or sensor needs a technician.

The manuals name no other owner step: no lid-switch test, no safety-switch replacement and no lid-magnet check exists in any E7 manual row. Do not replace parts on the code alone.

When to call a technician

  • E7 persists with the lid properly closed.
  • The lid switch feels loose or the lid does not stay shut.
  • E7 appears together with other fault codes.

Safety first

E7 is a lid-safety fault, not an electrical fault, but never reach into the machine while the tub is spinning and never open the machine while it is connected to power. If the lid switch is faulty, the machine needs a technician — do not bypass the lid switch.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does E7 mean on a Sharp washing machine?

On Sharp top-load washers ES-X155, ES-X751 and ES-X851, E7 means the lid is not closed when child lock is on. Close the lid within 10 seconds and the program resumes itself.

What happens if I don't close the lid within 10 seconds?

The manual says the machine will start draining. To resume, deselect (deactivate) child-lock mode.

Is Sharp E7 the same as E5?

Same trigger, different code on a different family. E5 is the child-lock lid code on the ES-HK800G / ES-F120G / ES-G80G family (5-second rule); E7 is the child-lock lid code on the X family (10-second rule). On the X family, E5 means drainage instead.

How do I turn child lock on or off on an X-series Sharp washer?

Press Preset + Add together until the CHILD LOCK lights up (X155), or press and hold PRESET and ADD for 3 seconds (X751/X851). Deactivate the same way.

Why do some guides say E5 means the child-lock lid code and others say drainage?

Because E5 splits by family. On HK/F/G it is the child-lock lid code; on the X family it is drainage, and the X family's child-lock lid code is E7. Check the model number first.
