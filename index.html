Find Your Appliance Error Code & Fix the Problem

Understand appliance error codes, explore possible causes, and follow practical troubleshooting steps. Every meaning on this site is checked against the manufacturer manual for the model family — we never guess.

Codes appear in many formats — for example E1, F21 or LE. The same code can mean different things on different brands and even different models of the same brand, so always check the brand and model family, not just the code.

Recently Added Guides

Each guide below was checked against the manufacturer manual named on its page.

F1

Midea Air Conditioner Error F1

F1 = outdoor room temperature sensor (T4) open/short circuit: timer lamp ON, running lamp 2 flashes. Power-cycle; if it returns, the T4 sensor, its wiring, or the outdoor PCB needs a technician.

 F2

Midea Air Conditioner Error F2

F2 = outdoor condenser-pipe sensor (T3) open/short circuit: timer lamp ON, running lamp 3 flashes. Power-cycle; if it returns, the T3 sensor, its wiring, or the outdoor PCB needs a technician.

 F3

Midea Air Conditioner Error F3

F3 = compressor discharge sensor (T5) open/short circuit: timer lamp ON, running lamp 4 flashes. Power-cycle; if it returns, the T5 sensor, its wiring, or the outdoor PCB needs a technician — do not confuse it with P2 overheating protection.

 F1

Gree Air Conditioner Error F1

F1 (wall-split) = indoor ambient temperature sensor open/short circuit: cool indicator flashes once every 3s. Power-cycle; if it returns, the room sensor, its connection, or the mainboard needs a technician. U-Match/FCU owners: your F1 is the evaporator sensor, not this one.
