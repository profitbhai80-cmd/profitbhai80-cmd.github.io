Refrigerators & Freezers Error Codes

Fridge and freezer codes most often concern temperature sensors, fans, defrost systems and door alarms. This category is still being built: each code is added only after its meaning is verified against the manufacturer's manual for that model family, so nothing is published here yet rather than guessing.

Guides in this category

  • Haier Refrigerator — Error Code F1 Verified
    F1 = refrigerator (R1) sensor malfunction: short circuit or open/broken circuit. Codes are recalled with a 3-button sequence on HB21F models; shown directly on HRF-663 models.
  • Haier Refrigerator — Error Code F2 Verified
    F2 = freezer sensor malfunction (F SNR short or open circuit) on the HB21F family. On HRF-663/664 and HRF-628 families Haier's manuals list F2 with no defined meaning — the family split matters.

    F8 means the R2 sensor — the second refrigerator-compartment sensor, on the side wall of the refrigerator — has a short or open circuit, per the Haier HRF-628AF6/IF6 service manual. It is an HRF-628-family-only code.
  • Haier Refrigerator — Error Code F5 Verified
    F5 = defrost sensor malfunction: D SNR short circuit or open circuit. HB21F family only (HB21FWRSS, HB21FNN); HRF-628 defrost = F6, HRF-663 has no F5.
  • Midea Refrigerator — Error Code E1 Verified
    E1 = temperature sensor failure of the refrigerating (fresh-food) chamber (loose/contaminated connection, faulty sensor, or faulty main PCB).
  • Midea Refrigerator — Error Code E2 Verified
    E2 = temperature sensor failure of the freezing (freezer) chamber; wording varies by family (freezer drawer, freezing chamber, freezer room) but the sensor zone is identical, and it is not the fresh-food sensor (E1) or the ambient sensor (E7).
  • Midea Refrigerator — Error Code E5 Verified
    E5 = failure of the defrost sensor (defrost sensor detection circuit) of the freezing (freezer) chamber; it is a defrost fault, not the freezer temperature sensor (E2), and on four-door models it pairs with E4 (fresh-food defrost sensor) while on combi models it is the only defrost code.
  • Midea Refrigerator — Error Code E6 Verified
    E6 = communication error between the main control board and the display board; it is universal across checked refrigerator families with no scope split, and it is not CA (main board to ice-making board communication, French-door ice-maker models only).
  • Daewoo Refrigerator — Error Code F1 Verified
    F1 = freezer (F) sensor disconnection or short circuit, shown as Lo for disconnection and Hi for short circuit; while faulty, the compressor and freezer fan cycle 25 minutes ON / 25 minutes OFF, and the code clears automatically once the sensor reads normal.
  • Daewoo Refrigerator — Error Code r1 Verified
    r1 = refrigerator-compartment (R) sensor disconnection or short circuit, shown as Lo for disconnection and Hi for short circuit; while faulty, control falls back to the ambient-temperature work-rate table, and the code clears automatically once the sensor reads normal.
  • Midea Refrigerator — Error Code E3 Verified
    E3 = temperature sensor failure of the meat & fish zone (variable-temperature drawer). SCOPED: E3 exists only on models with a meat & fish zone or variable-temperature drawer; French-door MRF29D3 and four-door MDRF648FG manuals list no E3, so owners of those models must not use this page.
  • Midea Refrigerator — Error Code E4 Verified
    E4 = failure of the defrosting sensor in the refrigerating (fresh-food) chamber. SCOPED: E4 exists only on four-door / variable-temperature-chamber families, paired with E5 (freezing defrost sensor); the common combi families (MERB345MG, MDRB470MG, MDRB521MGA, MDRB521MIE02, MDRB593FGE) have no E4 at all.
  • Midea Refrigerator — Error Code F4 Verified
    F4 = the sensor at the bottom of the refrigerating (fresh-food) ice maker fails. SCOPED: F4 exists only on French-door models with a refrigerating-chamber ice maker; it is a sensor fault, distinct from F5 (ice maker fails to turn over ice), F6 (initialization failure), and EE (freezer ice-maker bottom sensor).
  • Midea Refrigerator — Error Code F5 Verified
    F5 = the refrigerating (fresh-food) ice maker fails to turn over (release) ice. SCOPED: F5 exists only on French-door models with a refrigerating-chamber ice maker; it is a mechanical harvest failure, distinct from F4 (bottom sensor), F6 (initialization failure), and EP (freezer ice-maker turn-over failure).
  • Daewoo Refrigerator — Error Code F3 Verified
    F3 = defrosting return happened by time limit instead of by the D (defrost) sensor, so the defrost cycle timed out and Pre-cool mode in defrosting mode is deleted. Series split: 80-minute limit on FRS-2011/2031, FRS20 and FR-530NT/590NT; 50-minute limit on FRSU21DFV.
  • Daewoo Refrigerator — Error Code rt Verified
    rt = room/ambient-temperature (RT) sensor disconnection or short circuit, shown as Lo for disconnection and Hi for short; the sensor sits on the main PCB, checked by voltage at point 'A' (0.5V–4.5V normal, 0V short, 5V disconnected), and the code clears automatically once the sensor reads normal.
  • Daewoo Refrigerator — Error Code d1 Verified
    d1 = defrost (D) sensor — the evaporator sensor — disconnection or short circuit (Lo/Hi); while faulty, defrost return is governed by a time limit (30 min most families, 40 min FR-530NT/590NT) instead of the sensor, and the code clears automatically once the sensor reads normal.
  • Daewoo Refrigerator — Error Code C1 Verified
    C1 = abnormal refrigeration cycle: compressor works for over 3 hours while the D-sensor temperature stays above -5°C; the manuals' check point is refrigerant leakage, control is normal running, and the code terminates when the D-sensor falls below -5°C while the compressor is off.
  • Daewoo Refrigerator — Error Code dr Verified
    dr = refrigerator (R) door sensed open for more than 1 hour; check first whether the door is actually open, ajar, or blocked, then whether the R-door switch is stuck reporting open; door-switch sensing is suspended while active and the code terminates automatically once an open-and-close is sensed.
  • Daewoo Refrigerator — Error Code dF Verified
    dF = freezer (F) door sensed open for more than 1 hour; check first whether the door is actually open, ajar, or blocked by food or ice, then whether the F-door switch is stuck reporting open; door-switch sensing is suspended while active and the code terminates automatically once an open-and-close is sensed.
