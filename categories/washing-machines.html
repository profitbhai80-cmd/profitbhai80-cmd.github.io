Washing Machines Error Codes

Washing machine error codes usually point at one of five systems: water filling, draining, the door lock, the motor, or a sensor. The same code can mean different things on different models of the same brand, so every guide here is tied to the model family and manual it was checked against.

Guides in this category

  • Hisense Washing Machine — Error Code E3 Verified
    Series-dependent: on top-load HW-K60B/HWT3K8065B models it is a drainage error (water not drained after about 15 minutes); a front-load error table lists it as a water filling error.
  • Hisense Washing Machine — Error Code F03 Verified
    Draining fault: waste water is not being pumped out. A second documented meaning (overflow / high water level) exists in some Hisense documentation.
  • Daewoo Washing Machine — Error Code IE Verified
    Water fill problem: the water level sensor frequency is not changing, or the machine does not fill within the set time.
  • Daewoo Washing Machine — Error Code E8 Verified
    Initial-operation error: the Hall IC / motor connection signal is abnormal and the motor stops.
  • Daewoo Washing Machine — Error Code H2 Verified
    Wash water temperature sensor fault: the sensor circuit is open or short-circuited.
  • Daewoo Washing Machine — Error Code OE Verified
    Drain fault: the water level did not reach the reset point after drainage started. (Some Daewoo families show QE for the same fault.)
  • Daewoo Washing Machine — Error Code UE Verified
    Unbalance error: the load is unevenly distributed; the machine tried to rebalance itself twice during spin and gave up.
  • Haier Washing Machine — Error Code E2 Verified
    Series-dependent: on the HW80-B14979 front-load model it is a door lock error; on the HWM90DD top-load model the top lid is not closed during the wash.
  • Haier Washing Machine — Error Code E1 Verified
    Drainage failure: blocked drain hose on top-load families, or a clogged pump filter on front-load families. Some Haier families do not use E1 at all.
  • Beko Washing Machine — Error Code E08 Verified
    The machine may not be taking in water. Beko's manuals call this fault E8 — your display shows E08.
  • Daewoo Washing Machine — Error Code E9 Verified
    E9 = water-level sensor fault: sensor frequency above 30 kHz or below 15 kHz, a sudden >1.44 kHz jump after filling, or the sensor hose disconnected. Daewoo manuals route E9 to the service center.
  • Hisense Washing Machine — Error Code E4 Verified
    Series split: on top-loaders (HW-K60B, HWT3K8065B) E4 = too-long-to-fill water supply fault (check tap, hose, and drain-hose height ≥90 cm); on front-load E-series (WFQY9014EVJM) E4 = motor error. F-code front-loads have no E4.
  • Beko Washing Machine — Error Code E05 Verified
    E05 = drainage fault: the pump filter is likely clogged. The manual's fix order: clean the pump filter, retry in a spin cycle, then call service. E08 is the inlet-side code.
  • Daewoo Washing Machine — Error Code LE Verified
    LE = the door was opened while the machine was running (front-loader DWD families). Close the door and the course continues by itself. Not the same as DE (door-lock solenoid fault); top-loaders use E2, not LE.
  • Haier Washing Machine — Error Code E3 Verified
    E3 = safety switch acted: the machine cannot spin (imbalance fault after two automatic rebalancing attempts). Top-load families only — B14979 front-loads use 'Unb'. Manual fix: redistribute load, open/close lid once, level the machine.
  • Haier Washing Machine — Error Code E4 Verified
    E4 = water level not reached in time (fill timeout: 12 min B14979 front-load, ~15 min top-loads). Manual checklist: tap, pressure, inlet hose/filter. Distinct from FA (sensor) and E8 (self-syphoning).
  • Hisense Washing Machine — Error Code E1 Verified
    Series split: on top-loaders (HWT3K8065B, HW-K60B) E1 = lid not closed (open/close lid + Start/Pause); on front-load E-series (WFQY9014EVJM) E1 = temperature sensor error. F-code front-loads have no E1.
  • Hisense Washing Machine — Error Code E2 Verified
    E2 = door lock error on front-load families (WFQY9014EVJM, WFGE90141VM): close the door, unplug/replug, restart. E2 does not exist on Hisense top-loaders. The manual also defines E22 (cannot lock) and E23 (cannot unlock).

    E7 = Direction error: the Hall signal IC differs from the predicted signal for the direction of rotation. The motor stops and E7 is displayed; the alarm sounds for 10 seconds every 10 minutes and the display clears when the power is turned off and on.
  • Daewoo Washing Machine — Error Code H1 Verified
    H1 = Thermistor Dry OPEN/SHORT: the drying temperature sensor has failed. DWC-ED1213 causes: sensor temp. broken (change the sensor temp.) or connector problem (check the contact of the connector). Washer-dryer combos only.
  • Daewoo Washing Machine — Error Code H4 Verified
    H4 = Wash Overheating: the wash temperature sensor reading is over 95 °C. DWC-ED1213 causes: wash heater working with no water supply (check water level) or wash sensor temp. broken (change the sensor temp.). Alarm 10 seconds every 10 minutes; display clears on power off/on.
  • Haier Washing Machine — Error Code E5 Verified
    E5 = water level sensor fault (HLT364XXQ, GWT900AW/GWT700AW/GWT800AW — call service) OR water temperature too high, over 60°C (HWM70-A — cool, then Start/Pause).
  • Haier Washing Machine — Error Code E6 Verified
    E6 = the water level sensor is bad. Template top-load families only (7 manuals, identical wording). Same fault = E5 on HLT/GWT, FA on B14979.
  • Haier Washing Machine — Error Code E7 Verified
    E7 = communication fault: 'The communication is bad.' Four Haier washer manuals agree; remedy is after-sales service. Not Err7 (motor).
  • Beko Washing Machine — Error Code E04 Verified
    E04 = continuous-fill fault: the machine keeps taking in water (inlet valve stuck open, valve triac short circuit, or control board fault). Turn the taps off first; if water still enters with the machine unplugged, the valve is mechanically faulty; if it stops, the triac/board is at fault.
  • Beko Washing Machine — Error Code E07 Verified
    E07 = water level sensor (pressure sensor) error: the machine discharges every time it is turned on, or the programme does not start. Service checks: level-sensor socket and control-card KN2 socket fitted and secure, else repair sockets/cables, else replace the level sensor.
  • Beko Washing Machine — Error Code E06 Verified
    E06 = the machine cannot start — the door is not closed or the lock hasn't engaged. Close firmly and retry.
  • Beko Washing Machine — Error Code E09 Verified
    E09 = water intake problem — fill time exceeded. Check the water tap is fully open, the inlet hose isn't kinked, and the inlet filter isn't blocked.
  • Beko Washing Machine — Error Code E10 Verified
    E10 = pressure switch (water level sensor) error. Call a service technician — no user repair step.
  • Beko Washing Machine — Error Code E11 Verified
    E11 = drain pump fault — water won't drain or drain time exceeded. Clean the drain pump filter, check the drain hose.
  • Beko Washing Machine — Error Code E12 Verified
    E12 = unbalanced load at spin — the machine reduces or skips spin. Redistribute the load evenly and retry.
  • Beko Washing Machine — Error Code E17 Verified
    E17 is a warning, not an error: excessive foam detected — programme may end without spinning. Reduce detergent, run rinse-only cycles.
  • Beko Washing Machine — Error Code E18 Verified
    E18 is a warning, not an error: unbalanced load — spin not initiated. Redistribute laundry evenly and retry.
  • Beko Washing Machine — Error Code E29 Verified
    E29 = the machine has too little water — intake fault. Check the water tap, inlet hose, and inlet filter.
  • Haier Washing Machine — Error Code E8 Verified
    E8 = the water level is not reached within 8 minutes (top-loaders). Check the tap is fully open, hose isn't kinked, inlet valve filter isn't blocked.
  • Haier Washing Machine — Error Code F3 Verified
    F3 = temperature sensor error. The manuals prescribe no user step — contact after-sales service.
  • Haier Washing Machine — Error Code F4 Verified
    F4 = heater error. The manuals prescribe no user step — contact after-sales service.
  • Haier Washing Machine — Error Code F7 Verified
    F7 = motor error. The manuals prescribe no user step — contact after-sales service.
  • Haier Washing Machine — Error Code FA Verified
    FA = water level sensor error. The manuals prescribe no user step — contact after-sales service.
  • Haier Washing Machine — Error Code FC Verified
    FC = communication error between boards (top-loaders). Power off/on once; if it returns, contact service.
  • Haier Washing Machine — Error Code Unb Verified
    Unb = unbalanced load — the machine tried to rebalance and the spin didn't reach full speed. Redistribute laundry and retry.
  • Hisense Washing Machine — Error Code E5 Verified
    E5 = motor error (front-load E-series). Restart the programme; if it reoccurs, call a service technician.
  • Hisense Washing Machine — Error Code E6 Verified
    E6 = heating error (front-load E-series). Restart the programme; if it reoccurs, call a service technician.
  • Hisense Washing Machine — Error Code E7 Verified
    E7 = temperature sensor error (front-load E-series). Restart the programme; if it reoccurs, call a service technician.
  • Hisense Washing Machine — Error Code E8 Verified
    E8 = 3D sensor error (front-load E-series). Restart the programme; if it reoccurs, call a service technician.
  • Hisense Washing Machine — Error Code E9 Verified
    E9 = water at the bottom of the machine (Total Aqua Stop). Switch off and on; if it reoccurs, call a service technician.
  • Hisense Washing Machine — Error Code E10 Verified
    E10 = water level sensor error (front-load E-series). Restart the programme; if it reoccurs, call a service technician.
  • Hisense Washing Machine — Error Code E11 Verified
    E11 = water overflow: programme interrupted, water pumped out. Restart — but if it keeps filling, close the tap and call a technician.
  • Hisense Washing Machine — Error Code E12 Verified
    E12 = motor control error (front-load E-series) — the motor's control, not the motor. Restart; if it reoccurs, call a technician.
  • Hisense Washing Machine — Error Code E22 Verified
    E22 = error while locking the door — closed but cannot lock. Off/on, restart programme; if it reoccurs, call a technician.
  • Hisense Washing Machine — Error Code E23 Verified
    E23 = error while unlocking the door — closed but cannot unlock. Turn off/on; if it reoccurs, call a technician.
  • Daewoo Washing Machine — Error Code H5 Verified
    H5 = water temperature error in wool/delicate course — 45 °C or higher. Alarm 10 s per 10 min; clears on power off/on. Thermistor wash: technician.
  • Daewoo Washing Machine — Error Code H6 Verified
    H6 = heater wash error — temperature fails the 15-minute rise test (2 °C at ≤42 °C standard, 1 °C above). Alarm 10 s per 10 min; clears on power off/on.
  • Daewoo Washing Machine — Error Code H8 Verified
    H8 = heater wash overheating — heater rises 5 °C+ in 30 s with no water in tank. Do not run heated washes; call a technician.
  • Daewoo Washing Machine — Error Code PFE Verified
    PFE = pump filter error — clogged drain pump filter, pump fault, too much/unsuitable detergent, or hose above 1 m. Reset: Power → SPIN → Start/Pause.
