Air Conditioners Error Codes

Air conditioner codes cover sensors, communication between units, and the sealed refrigerant system. Anything refrigerant-related is technician-only territory — the Midea EL OC guide here explains why, and what to do instead of a reset.

Guides in this category

  • Midea Air Conditioner — Error Code EL OC Verified
    Refrigerant leakage detection on Midea U-shaped window air conditioners (displayed EL OC / EL0C). Refrigerant work is technician-only.
  • Midea Air Conditioner — Error Code E1 Verified
    E1 = communication malfunction between the indoor and outdoor units (no feedback for 110 seconds, happening 4 times). Check wiring first; the S-to-N voltage test is technician work.
  • Midea Air Conditioner — Error Code EC Verified
    EC = refrigerant leak detection: the T2 coil temperature fails to drop after the compressor starts (8-minute/3-times trigger logic). Power-cycle only; pressure, leak and recharge work is technician-only.
  • Gree Air Conditioner — Error Code H3 Verified
    H3 = compressor overload protection on mini-split families (low charge, blocked capillary, compressor motor, loose OVC-COMP terminal; outdoor unit flashes 8×). On GMV VRF platforms H3 = fan drive module reset protection instead.
  • Midea Air Conditioner — Error Code F0 Verified
    F0 = overcurrent protection: an abnormal current rise detected in the current detection circuit. F0 is NOT the refrigerant-leak code (that is EC) — the 'F0 = leak' claim is Gree-family contamination. F0 straight after power-up on standby points to the outdoor PCB.
  • Midea Air Conditioner — Error Code P1 Verified
    P1 = over-voltage or under-voltage protection (abnormal voltage rise/drop in the detection circuit). Check the mains supply first; if good, the rectifier or outdoor ebox/PCB is faulty. Not the portable-AC 'tray full' code.
  • Midea Air Conditioner — Error Code P4 Verified
    P4 = inverter compressor drive error (abnormal drive signal). Causes: wiring mistakes, IPM fault, outdoor fan motor, compressor, outdoor PCB, surge — or bad commissioning (no vacuum drying) on new installs. Indoor display P4; outdoor display maps it to inverter module protection.
  • Midea Air Conditioner — Error Code P5 Verified
    P5 means an indoor-units mode conflict: on a multi-zone system, the indoor units are set to incompatible modes — one in HEATING while another is in COOLING — and the system refuses to run both at once. Every Midea mini-s
  • Gree Air Conditioner — Error Code C5 Verified

    E1 means compressor high pressure protection: the refrigerant pressure on the high side of the system has risen past the safe limit and the unit has shut itself down to protect the compressor. The Gree Vireo manual names
  • Midea Air Conditioner — Error Code E2 Verified
    E2 = zero-crossing signal detection error: the system cannot detect the correct zero-crossing signal time interval (bad power-cable connection, faulty power supply, or faulty indoor PCB).
  • Midea Air Conditioner — Error Code E3 Verified
    E3 = indoor fan speed out of control: fan speed keeps too low (300 RPM) for a set time, then the unit stops and displays E3 (wiring, fan wheel/bearing, fan motor, PCB, or surge).
  • Midea Air Conditioner — Error Code P0 Verified
    P0 = IPM malfunction / IGBT over-strong current protection: the voltage signal the IPM sends to the compressor drive chip is abnormal, so the display shows P0 and the AC turns off (wiring, IPM, outdoor fan motor, compressor, outdoor PCB, or surge).
  • Midea Air Conditioner — Error Code P2 Verified
    P2 = high temperature protection of compressor top: protection trips at ≥120°C (248°F) and resumes at 105°C (221°F) (outdoor airflow, refrigerant system, blockage, protector, or outdoor PCB).
  • Gree Air Conditioner — Error Code E2 Verified
    E2 = indoor anti-freeze protection: the indoor coil dropped too cold in cooling or dry mode and the unit paused the compressor to stop it freezing. Restore return airflow and clean the coil; persistent E2 needs a technician.
  • Gree Air Conditioner — Error Code E4 Verified
    E4 = compressor high discharge temperature protection: discharge temperature exceeded the safe limit (over 118°C) and the unit stopped to protect the compressor. Check airflow, then call a technician if it returns.
  • Gree Air Conditioner — Error Code E5 Verified
    E5 = AC over-current protection: current exceeded the safe limit and the unit stopped. Causes are unstable supply voltage, low supply voltage under high load, or a blocked/dirty indoor coil. Restart once; persistent E5 is electrician/technician work.
  • Gree Air Conditioner — Error Code H1 Verified
    H1 = defrosting status: in heating mode the unit detected frost on the outdoor coil and paused heating to clear it. Fans stop during defrost, then the display returns to the setpoint and heating resumes. No action needed.
  • Gree Air Conditioner — Error Code H6 Verified
    H6 = no feedback of the indoor fan motor: the control board is not receiving the fan's feedback signal, so the unit stops. Check for a blocked fan and restart once; persistent H6 needs a technician for the motor, connector, or board.
  • Midea Air Conditioner — Error Code E4 Verified
    E4 = indoor room temperature sensor (T1) open circuit or short circuit: sampling voltage below 0.06V or above 4.94V (wiring mistake, faulty sensor, or faulty indoor PCB).
  • Midea Air Conditioner — Error Code F1 Verified
    F1 = outdoor room (ambient) temperature sensor T4 open circuit or short circuit: sampling voltage below 0.06V or above 4.94V (wiring mistake, faulty sensor, or faulty outdoor PCB).
  • Midea Air Conditioner — Error Code F2 Verified
    F2 = outdoor condenser pipe (coil) temperature sensor T3 open circuit or short circuit: sampling voltage below 0.06V or above 4.94V (wiring mistake, faulty sensor, or faulty outdoor PCB).
  • Midea Air Conditioner — Error Code F3 Verified
    F3 = discharging air / compressor discharge temperature sensor T5 open circuit or short circuit: sampling voltage below 0.06V or above 4.94V (wiring mistake, faulty sensor, or faulty outdoor PCB).
  • Gree Air Conditioner — Error Code F1 Verified
    F1 (Gree wall-split) = indoor ambient (room) temperature sensor open circuit or short circuit (bad connection, faulty sensor, short from tripped parts, or faulty mainboard).
  • Hisense Air Conditioner — Error Code E5 Verified
    E5 (Hisense portable) = unit full of water: the internal water container/tank has reached its limit and must be drained before the unit will run again.
  • Gree Air Conditioner — Error Code E3 Verified
    E3 = compressor low-pressure protection, including refrigerant-lacking protection and refrigerant-collecting (recovery) mode; the system stops when suction pressure falls below the protection value (floor-standing service manual: below -41C equivalent), and E3 during refrigerant recovery is a normal mode, not a fault.
  • Gree Air Conditioner — Error Code F3 Verified
    F3 = outdoor ambient temperature sensor open circuit or short circuit; unusually, wall-split and U-Match numbering agree on F3, so there is no platform split for this code.
  • Gree Air Conditioner — Error Code F2 Verified
    F2 (wall-split) = indoor evaporator (indoor coil/tube) temperature sensor open circuit or short circuit. Series split: on U-Match / fan-coil families F2 instead means the outdoor condenser temperature sensor.
  • Gree Air Conditioner — Error Code F4 Verified
    F4 (wall-split) = outdoor condenser (outdoor coil/tube) temperature sensor open circuit or short circuit. Series split: on U-Match families F4 instead means the compressor discharge temperature sensor.
  • Gree Air Conditioner — Error Code F5 Verified
    F5 (wall-split) = compressor discharge (exhaust) temperature sensor open circuit or short circuit, not to be confused with E4 (high discharge temperature protection trip). Series split: on U-Match families F5 instead means the wired-controller temperature sensor.
  • Gree Air Conditioner — Error Code F6 Verified
    F6 (wall-split) = limit / decrease frequency due to overload (overload, high-temperature resistance): all loads keep operating normally while the compressor's operating frequency is decreased; not a sensor fault, not a stop fault; U-Match has no F6, GMV VRF F6 is a compressor-2 discharge-sensor fault.
  • Gree Air Conditioner — Error Code F8 Verified
    F8 (wall-split) = decrease frequency due to overcurrent: all loads keep operating normally while the compressor's operating frequency is decreased, because the input supply voltage is too low or the system pressure is too high and the system is overloaded; not a sensor fault, not a stop; U-Match has no F8, GMV VRF F8 is a discharge-sensor fault.
  • Gree Air Conditioner — Error Code F9 Verified
    F9 (wall-split) = decrease frequency due to high air discharge (high exhaust/discharge temperature limit): all loads keep operating normally while the compressor's operating frequency is decreased, because of overload or temperature too high, insufficient refrigerant, or a malfunctioning electric expansion valve (EKV); not F5 (sensor) and not E4 (protection trip); U-Match has no F9, GMV VRF F9 is a compressor-5 discharge-sensor fault.
  • Gree Air Conditioner — Error Code H4 Verified
    H4 = system overload protection (system abnormal, overload / high-temperature resistance): when the tube temperature gets too high — outdoor heat-exchanger temperature in cooling, indoor heat-exchanger temperature in heating — the protection activates; in cooling/drying the compressor stops while the indoor fan keeps running, and in heating the whole unit stops; manual causes: outdoor temperature too high when cooling, insufficient outdoor air circulation, refrigerant flow malfunction; GMV VRF H4 is fan drive PFC protection.
  • Gree Air Conditioner — Error Code FH Verified
    FH (wall-split) = limit/decrease frequency due to antifreezing; keeps running slower.
  • Midea Air Conditioner — Error Code P3 Verified
    P3 (indoor display) = outdoor temperature too low protection; thresholds split by family.
  • Gree Air Conditioner — Error Code E7 Verified
    E7 on a Gree air conditioner means MODE CONFLICT — two or more indoor units on the same outdoor unit are set to incompatible modes (one heating while another cools).
  • Gree Air Conditioner — Error Code E8 Verified
    E8 on a Gree air conditioner (duct / cassette / slim-duct families) means ANTI-HIGH TEMPERATURE PROTECTION — the system has tripped on high temperature, and the cassette diagnostic shows the outdoor yellow indicator flashing 6 times with a 1-second pause.
  • Gree Air Conditioner — Error Code E9 Verified
    E9 on a Gree air conditioner (duct / cassette families) means FULL WATER PROTECTION — the indoor unit's condensate level has reached the full-water state (drain tray / water-level device).
  • Gree Air Conditioner — Error Code EE Verified
    EE on a Gree air conditioner means the main control board's memory chip has failed — loading EEPROM malfunction / outdoor main-control memory-chip malfunction.
  • Midea Air Conditioner — Error Code E0 Verified
    E0 on a Midea air conditioner (indoor display, timer OFF, running lamp 1 flash) means indoor unit EEPROM parameter error — the indoor PCB main chip does not receive feedback from the EEPROM chip.
  • Midea Air Conditioner — Error Code E5 Verified
    E5 on a Midea air conditioner (current-generation indoor display, timer OFF, running lamp 6 flashes) means the evaporator coil temperature sensor (T2) is open circuit or short circuit.
  • Midea Air Conditioner — Error Code E8 Verified
    E8 on a Midea air conditioner (indoor display, timer OFF, running lamp 9 flashes) means communication malfunction between two indoor units — and it is TWINS-MODEL ONLY.
  • Midea Air Conditioner — Error Code E9 Verified
    E9 on a Midea air conditioner (indoor display, timer OFF, running lamp 10 flashes) means 'other malfunction of twins model' — and it is TWINS-MODEL ONLY, the residual twins code next to E8.
  • Midea Air Conditioner — Error Code EE Verified
    EE on a Midea air conditioner (indoor display, timer OFF, running lamp 8 flashes) means water-level alarm malfunction — the indoor unit's water-level device has alarmed (drain tray / float / pump circuit on duct/cassette units fitted with one).
  • Midea Air Conditioner — Error Code F6 Verified
    F6 on a Midea air conditioner (indoor display, timer ON, running lamp 7 flashes) means T2b sensor error.
