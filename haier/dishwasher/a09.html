Haier Dishwasher Error Code A09

Quick answer

Error codeA09 — Haier Dishwasher
What it meansA09 = sanitise cycle failed - the sanitise wash did not reach the temperature needed to sanitise the dishes. It is a cycle-outcome fault, not a broken component: the dishes were washed but not sanitised. Neither document states the target temperature - do NOT invent a number (no 65 C / 70 C claim appears in either source).
Most common causeThe sanitise cycle did not reach sanitising temperature. Per the F&P manual, this can happen simply because the water supply was turned off or the program was interrupted. A09 is not diagnosed as a heater fault in either document (the heater fault is A60/E60).
Safe to check yourself?Yes - check the water supply was not turned off and the program was not interrupted, clear the fault, and run the sanitise cycle again. If it faults again, book a service.
Checked againstHaier official support article "Haier Dishwasher Fault Codes" (support.haier.com.au, AU/NZ) + Fisher & Paykel DishDrawer DD24SCTB9-N User Guide (p.49)

Applies to — read this first

Read this first, because A09 carries a THIN / PLATFORM flag: the two named families agree word-for-word, but the second family is a DishDrawer, not a freestanding HDW manual - the F&P DishDrawer DD24SCTB9-N User Guide lists A09 as "(DD*C models only)". The Haier official article itself lists A09 in the HDW fault-code table, which is what makes this an HDW code. The page states plainly that the corroborating manual is the drawer platform (DD*C only) and that no freestanding HDW user manual lists A09. Do NOT claim a freestanding HDW manual documents A09.

What the machine does when A09 fires

The display shows A09 after a sanitise cycle that did not reach the temperature needed to sanitise the dishes. The dishes were washed but not sanitised - do not assume a failed sanitise cycle sanitised anything.

Common causes

  1. Sanitise cycle did not reach sanitising temperature - the manuals' own fault definition; neither document states a target temperature.
  2. Water supply turned off or wash program interrupted (F&P manual) - a cycle-outcome cause, not a broken component.

Safe checks, in order

  1. Check if the water supply has been turned off or the wash program interrupted (F&P DishDrawer DD24SCTB9-N, p.49).
  2. Press the button once to stop the beeping, and then again to clear the fault (F&P). General HDW fault-clear procedure (Haier HDW15U3B1 user manual - the U3B1 manual does not list A09 itself): press and hold 'CANCEL' to stop the beeping, then again to clear the fault code; turn the dishwasher off, then on again.
  3. Run the sanitise cycle again. If it faults again, please book a service (Haier article).
  4. Do not invent temperature checks, heater tests, or thermostat steps. A09 is not diagnosed as a heater fault in either document (the heater fault is A60/E60).

The steps above are the manuals' own procedures, in order. This page does not invent temperature checks, heater tests, or thermostat steps - no manual documents them for A09.

When to call a technician

  • A09 faults again after re-running the sanitise cycle - book a service.
  • Any other fault code alongside A09 - switch off and call a qualified technician.

More guidance: when an appliance error requires professional service.

Safety first

A09 is a cycle-outcome fault in a mains-powered dishwasher: work only from the controls (clear the fault, re-run the cycle). Never open the machine or test the heater or thermostat yourself - that is qualified-technician work.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What temperature must the sanitise cycle reach?

Neither the Haier article nor the F&P manual states a number, so this guide does not give one. Both documents define A09 only as "hasn't met [the] temp needed to sanitise dishes" - the fix is to re-run the cycle, not to chase a temperature reading.

Are my dishes safe to use after A09?

Neither document says the dishes are safe - it says the sanitise cycle did not meet the temperature needed to sanitise them. Re-run the sanitise cycle; if it faults again, book a service. Do not assume a failed sanitise cycle sanitised anything.

A09 vs A60 - what's the difference?

A60 is the heating fault (the heater/water-temperature system itself is faulty). A09 is a cycle-outcome fault: the sanitise cycle ran but did not reach sanitising temperature - which the F&P manual says can happen simply because the water supply was turned off or the program was interrupted.

A09 vs A70 - what's the difference?

A70 is a temperature-sensing fault (the sensor that measures water temperature is faulty). A09 is about the sanitise cycle's result, not the sensor. A faulty sensor could in principle cause a failed sanitise, but neither document links the two - do not conflate them.

Is A09 the same as Bosch E09?

No. Bosch E09 is a different brand's code (heating-system fault on Bosch dishwashers). Haier has no E09 on the HDW platform, and Haier A09 is a sanitise-temperature outcome, not a heater fault.
