Haier Split Air Conditioner Error Code F17

Quick answer

Error codeF17 — Haier Split Air Conditioner
What it meansF17 = liquid pipe circuit 'C' temperature probe failure — the liquid-pipe temperature sensor for indoor unit / circuit C is disconnected, broken, or poorly positioned. The indoor display shows F17; the outdoor error number is 30. The '30' is the outdoor error/LED code, NOT an LED1 flash count — M2, which supplies flash counts, does not list F17. Multi-split ONLY, and sharpest of the three circuit codes: circuit C exists only where a multi-split outdoor unit serves a third indoor unit (3U/4U/5U). A single-split system has no circuit C; a 2-indoor multi-split has no circuit C either. If a smaller system shows F17, the board/display is at fault, not a circuit-C sensor.
Most common causeSensor disconnected, broken, or poorly positioned (M3 Table A cause).
Safe to check yourself?No — no fix step exists in any manual. Switch the unit off and call a technician; checking or replacing the circuit-C liquid-pipe sensor is technician work on the outdoor/multi-split piping.
Checked againstHaier European HVAC Technical Book 2024-25, DIAGNOSTIC Table A (Mono Residential and Multi Units), pp.30–31; Haier FlexFit 3U24MS2VHB Service Manual, Error Codes table (p.112); Haier 4U36MS2VHB Service Manual, Error Codes table (p.92); haier-ac.pt ducted/cassette troubleshooting table (Cod.-Erros-Condutas-Alta-Pest.pdf)

Applies to — read this first

Read this first, because F17 is a split-wall/ductless Table A code — it means the liquid pipe circuit 'C' temperature probe has failed on the EU mono residential/multi range, the US FlexFit multi-zone/console and mid-static ducted ranges, and the EU cassette/convertible/duct ranges on 3U/4U/5U outdoor units (M3/FlexFit/haier-ac.pt, all agreeing on outdoor error 30 and circuit C). F17 is NOT in M2 (US ductless split, p.43) and NOT in M7 (1U26MADFRA, p.25) — do not claim M2/M7 corroboration. The same book's Commercial and Cabinet tables call F17 a DIFFERENT fault — the 4-way valve switching failure — while in Table A that fault is F14. Check the model and series, not just the letters.

What the machine does when F17 fires

The indoor display shows F17 in place of the set temperature, and the outdoor error number is 30. The liquid-pipe temperature sensor for indoor unit / circuit C has failed — disconnected, broken, or poorly positioned — so the outdoor unit cannot read that circuit's liquid-pipe temperature.

Common causes

  1. Sensor disconnected, broken, or poorly positioned (M3 Table A cause).

Safe checks, in order

  1. Switch the unit off.
  2. Call a technician to check or replace the circuit-C liquid-pipe sensor — there is no owner fix step in any manual.
  3. If the system has fewer than three indoor units, tell the technician: there is no circuit C, so the board or display is at fault.
  4. Do not replace or check the 4-way valve for F17 — that fault is F14 in Table A.

No power-cycle reset time, resistance value, 'check the plug' step, sensor-replacement procedure or 'clean the sensor' step exists in any manual for F17. Do not claim the 60-second short/open detection window for F17 — M3 gives that window verbatim only for the single-sensor rows (F6/F7/F11/F12/F13/F21/F25), not for the circuit A–E rows. Do not present E1's indoor-sensor steps, F14's 4-way-valve steps, or any expansion-valve steps (Panasonic F17) as F17 steps.

When to call a technician

  • F17 returns after a restart — the circuit-C liquid-pipe sensor needs diagnosis.
  • Outdoor error 30 — liquid pipe circuit C (F10 is circuit A, 28; F16 is circuit B, 29; F18 is circuit D, 31).
  • A single-split or 2-indoor multi-split shows F17 — there is no circuit C, so the board or display is at fault.
  • Any burning smell or visible damage — switch off and call a qualified technician.

Safety first

No owner repair exists in any manual for this code. Never open the indoor or outdoor unit while it is connected to power, and never attempt refrigerant, gas or high-voltage work without the proper qualifications.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does F17 mean on a Haier split air conditioner?

F17 means the liquid pipe circuit 'C' temperature probe has failed — the liquid-pipe temperature sensor for indoor unit / circuit C is disconnected, broken, or poorly positioned (M3 Table A; FlexFit 3U24MS2VHB p.112; 4U36MS2VHB p.92; haier-ac.pt ducted PDF). Outdoor error number 30.

Can F17 appear on a single-split air conditioner?

No — not as a real sensor fault. Circuit C exists only on a multi-split outdoor unit serving at least three indoor units (3U/4U/5U). A single-split unit has no circuit C, and neither does a 2-indoor multi-split. If a smaller system shows F17, the board or display is at fault. Tell the technician how many indoor units share the outdoor unit.

Is F17 a 4-way valve fault?

No — not in Table A. The 4-way valve switching failure is F14 in Table A. The same book's Commercial and Cabinet tables call F17 the 4-way valve failure — that is the other numbering system, not Table A. On a mono-residential/multi unit, use the Table A meaning above; do not replace or check the 4-way valve for F17.

Can I fix Haier F17 myself?

No fix step exists in any manual read. The manuals give only the table row plus M3's cause ('Sensor disconnected, broken, or poorly positioned'). Switch the unit off and call a technician to check or replace the circuit-C liquid-pipe sensor.

How is F17 different from F10 and F16?

Same sensor type (liquid-pipe temperature probe), different circuits: F10 = circuit A (outdoor 28), F16 = circuit B (outdoor 29), F17 = circuit C (outdoor 30). The gas-pipe counterparts are F29 (A), F30 (B) and F31 (C). Each circuit has its own code — never merge them.
