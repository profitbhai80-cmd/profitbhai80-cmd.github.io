Haier Split Air Conditioner Error Code F33

Quick answer

Error codeF33 — Haier Split Air Conditioner
What it meansF33 = liquid pipe circuit "E" temperature probe (sensor) failure — the liquid-pipe temperature sensor on refrigerant circuit E (the fifth circuit) of the multi-split outdoor unit is faulty: sensor disconnected, broken, or poorly positioned. The indoor display shows F33 and the outdoor PCB LED1 flashes 40 times (two-LED boards: LED1 6 + LED2 0 = code 60). All three F-label manuals agree on code, meaning, circuit letter and flash count. F33 is the highest LED flash count in this batch (F29: 32, F30: 33, F31: 34, F32: 35, F33: 40) — but do NOT claim 40 is the highest in the full M3 table (F43 = 46). This is the AIR CONDITIONER meaning only — the Haier INTELIUS 50 tumble dryer uses the same label F33 for a condenser thermal sensor fault, a different appliance.
Most common causeLiquid pipe circuit E temperature probe faulty — sensor disconnected, broken, or poorly positioned (M3 Table A p.31).
Safe to check yourself?No — no fix step exists in any manual read. Switch the unit off, note which indoor unit / circuit E is affected, and call a technician; checking or replacing the outdoor liquid-pipe-E probe is technician work on the outdoor unit.
Checked againstHaier European HVAC Technical Book 2024-25, DIAGNOSTIC Table A (Mono Residential and Multi Units) (Table A p.31); Haier FlexFit Series Multi Zone Split System Heat Pump Service Manual, 3U24MS2VHB (outdoor units 2U18/3U24/4U36MS2VHB, R410A, US), Error Codes (p.112 + p.35); Haier haier-ac.pt Cod.-Erros-Condutas-Alta-Pest.pdf (Round way cassette / cassette / convertible / duct unit troubleshooting, outdoor units 3U/4U/5U) (p.428); Haier 4U36MS2VHB Service Manual, MID-STATIC DUCTED TECHNICAL OVERVIEW, Error Codes (p.92) - numeric corroboration only

Applies to — read this first

Read this first, because F33 is a split-wall/ductless Table A code — it means the liquid pipe circuit E temperature sensor on multi-split outdoor units (3U/4U/5U). Circuit E exists only on 5-circuit multi-split outdoor units (5U); a single-split (mono) unit has only circuit A, but its single-split manuals (M2, M7) do not list F33 at all, so a reader with a single-split unit will never see it in their manual either. If your unit shows F33, it is a multi-split outdoor unit fault on circuit E. F33 sits at row 40, AFTER F36 (row 39), in M3's table — the table is not in F-number order. Cabinet Table B has NO F33 at all, and the old fixed-speed lamp table has no F33. Check the model and series, not just the letters.

F26 INTRA-BOOK COLLISION — the E-circuit family is where it lives: F33's gas-pipe sibling is F26 = "Gas pipe circuit "E" temperature probe faulty" (M3 Table A row 36; M8 p.112 "F26 36 Gas pipe sensor failure: Circuit E"; M9 p.428 row 36 "Malfunction of gas pipe temp. sensor for indoor unit E"). But the SAME book's Table B (MONO CABINET UNIT 14kW, p.33) uses F26 for "Lack of a phase in the power module — System reset / compressor phase check / power module failure" (LED 46), and the haier-ac.pt ducted 1U105S2SS1FA troubleshooting PDF independently confirms the cabinet-side meaning: error 26 = "Lack phase of the drive module". So F26 has two manufacturer-printed meanings depending on the table/series — gas-pipe-E sensor (Table A / multi-split) vs lack of phase (Table B / cabinet / ducted). F33 itself has no such collision, but any reader working on the E-circuit pair (F26 + F33) must check the series first. F26 has no standalone page and is not presented here as resolved. TUMBLE-DRYER collision: the same labels F31/F32/F33 mean something completely different on a Haier INTELIUS 50 tumble dryer — "F31, F32, F33 | The condenser thermal sensor is open-circuited or short-circuited | Contact the customer service" (notice-facile user manual, SERP snippet-level, 2026-11-18). That is a dryer fault, not an air-conditioner fault. No ranking competitor page covers F33 in prose at all: Arlington has no F33 section (its per-code sections stop at F28); acerrorcode has no F33 row (its main table ends at F28, then jumps to F66) and gets the neighbouring sensor family wrong — F10 "No AC power supply" (wrong: F10 = liquid pipe circuit A sensor) and F16 "Running state-detecting circuit failure" (wrong: F16 = liquid pipe circuit B sensor); decorexpro has no F33 (its F-codes stop at F12) and claims LED blinks run "1 to 25 times" (wrong: F33 = 40, F43 = 46); lioncityaircon.sg uses a different Haier system (E01-E124) with no F-codes. The gas family runs F29 A (32) / F30 B (33) / F31 C (34) / F32 D (35) / F26 E (36); the liquid family runs F10 A (28) / F16 B (29) / F17 C (30) / F18 D (31) / F33 E (40). F36 (LED 39) sits next to F33 in the table but is a different sensor — piping/condenser temperature probe "TC" — not a circuit sensor.

What the machine does when F33 fires

The indoor display shows F33 in place of the set temperature, and the outdoor PCB LED1 flashes 40 times (two-LED boards: LED1 6 + LED2 0 = code 60). The outdoor board cannot read the liquid-pipe-E probe, so it cannot run the multi-split outdoor unit correctly.

Common causes

  1. Sensor disconnected (M3 Table A p.31).
  2. Sensor broken (M3 Table A p.31).
  3. Sensor poorly positioned (M3 Table A p.31).

Safe checks, in order

  1. Switch the unit off.
  2. Note which indoor unit / circuit E is affected, then call a technician — checking or replacing the outdoor liquid-pipe-E probe is technician work on the outdoor unit. No manual gives a procedure, a resistance value, or a plug check for F33, so this page does not invent one.

There is NO F33 flowchart and NO fix step in any manual: the full extent of the manual evidence is the M3 Table A row-40 cause ("Sensor disconnected, broken, or poorly positioned"), the M8 p.112/p.35 table rows and the M9 p.428 table row. No lockout rule ("3 times in an hour") is stated for the F33 row in any manual — do not claim one. No detection window is stated for F33 — the 60-second short/open-circuit window is verified only for F6/F7/F21/F25 (M3 rows 10-13); do not claim it for F33. Do NOT present other sensors' steps (e.g. E1 indoor-sensor steps, or F6 ambient-sensor steps) as F33 steps. Do NOT present the dryer F33 (condenser thermal sensor) as the air-conditioner F33. F33 is a one-row code in every manual: keep it short, do not pad with invented diagnostics.

When to call a technician

  • F33 returns after a restart — the outdoor liquid-pipe-E probe needs checking or replacing.
  • The outdoor LED1 flashes 40 times — liquid pipe circuit E (F26, the gas pipe sensor on the same circuit, is 36).
  • Any burning smell or visible damage — switch off and call a qualified technician.

More guidance: when an appliance error requires professional service.

Safety first

The outdoor liquid-pipe-E probe is on the outdoor unit: checking or replacing it is qualified-technician work. Never open the outdoor unit while it is connected to power.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does F33 mean on a Haier split air conditioner?

F33 means the liquid pipe circuit "E" temperature probe (sensor) has failed — the liquid-pipe temperature sensor on refrigerant circuit E (the fifth circuit) of the multi-split outdoor unit is disconnected, broken, or poorly positioned. The indoor display shows F33 and the outdoor PCB LED1 flashes 40 times (M3 Table A p.31; M8 FlexFit p.112; M9 haier-ac.pt p.428).

I found "F33 = condenser thermal sensor" — is that the same code?

No. That meaning belongs to the Haier INTELIUS 50 tumble dryer, whose manual groups F31/F32/F33 as "condenser thermal sensor open-circuited or short-circuited". It is a dryer fault, not an air-conditioner fault. On a Haier air conditioner, F33 is the liquid pipe circuit E temperature sensor. Check which appliance you have before using any F33 meaning.

What is F26, and why does it matter for F33?

F26 is F33's gas-pipe sibling: Table A F26 = "Gas pipe circuit "E" temperature probe faulty" (LED 36). But the same book's cabinet table uses F26 for "Lack of a phase in the power module" — so F26 has two manufacturer-printed meanings depending on the series. F33 itself has no such collision, but if you are diagnosing the E-circuit pair, check the series first: multi-split Table A (sensor) vs cabinet Table B (phase fault).

Can a single-split Haier show F33?

Not in any manual read. Circuit E exists only on 5-circuit multi-split outdoor units (5U), and the single-split manuals (M2, M7) do not list F33 at all. If your unit shows F33, it is a multi-split outdoor unit fault on circuit E.

Can I fix Haier F33 myself?

No fix step exists in any manual read. The manuals give only the table row plus M3's cause ("Sensor disconnected, broken, or poorly positioned"). Switch the unit off, note that it is circuit E, and call a technician to check or replace the outdoor liquid-pipe-E probe. Do not follow guides that tell you to use another sensor's fix for F33.
