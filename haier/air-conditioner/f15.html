Haier Split Air Conditioner Error Code F15

Quick answer

Error codeF15 — Haier Split Air Conditioner
What it meansF15 = board / terminal overheating — the outdoor terminal block (board/terminal) has overheated; the cause is short circuit / overheating on components. The outdoor PCB LED1 flashes 20 times (M3 + M7 only — FlexFit gives NO LED number for F15). M7 words it "Outdoor terminal block temperature protection"; FlexFit says "Terminal block temp too high". Same fault family, three phrasings. Not a compressor fault.
Most common causeShort circuit / overheating on components at the outdoor terminal block (M3 Table A p.30).
Safe to check yourself?No — there is no owner fix in any manual. Switch the unit off and call a technician; the fault is a short circuit / overheating on components at the outdoor terminal block — live electrical work.
Checked againstHaier European HVAC Technical Book 2024-25 (haierhvac.eu), DIAGNOSTIC Table A p.30; Haier 1U26MADFRA Room Air Conditioner Installation Manual (Sept 2024, R32, AU/NZ), Outdoor Unit Troubleshooting p.25; Haier FlexFit Series Multi Zone Split System Heat Pump Service Manual (3U24MS2VHB), Console Technical Overview p.112 (no LED number given for F15)

Applies to — read this first

Read this first, because F15 is a split-wall/ductless Table A code — it means board / terminal overheating on the EU mono residential / multi range, the AU/NZ R32 split families and the US FlexFit multi-zone consoles (M3/M7/FlexFit). The LED1 20 count rests on M3 + M7 only: FlexFit gives no LED number for F15 ("/"), unlike F5/F13/F14/F9 which all carry numbers in the same table. The US ductless split manual (M2) does NOT list F15. The cabinet 14kW table (M3 Table B) uses F15 for a different fault — "Communication error between indoor and outdoor units" — the same wording as split-wall E7. The old fixed-speed lamp table has no F15 at all. Check the model and series, not just the letters.

The ranking pages get F15 wrong. acerrorcode, the #1 list page, says F15 is "Compressor running faulty — resumable" — wrong, no manual supports it; M3 says board/terminal overheating (short circuit / overheating on components), M7 says outdoor terminal block temperature protection, FlexFit says terminal block temp too high. Arlington has no F15 section at all, and decorexpro has no F15 content. F5 is SPDU/ISPM power module temperature protection (LED1 23) — the power module overheating, a different part from the terminal block/board (F15); F35 is power module temperature sensor failure (LED1 38) — a sensor fault, not an overheating protection trip.

What the machine does when F15 fires

The outdoor terminal block / board has overheated, and the outdoor PCB LED1 flashes 20 times. M7 marks F15 "Trouble record" — logged in the unit's trouble history rather than shown straight on the indoor panel.

Common causes

  1. Short circuit on components at the outdoor terminal block (M3 Table A p.30).
  2. Overheating on components at the outdoor terminal block (M3 Table A p.30).

Safe checks, in order

  1. Switch the unit off.
  2. Call a technician — there is no fix step in any manual for F15. Do not open the outdoor unit or touch the terminal block; the manual cause is a short circuit / overheating on components — live electrical work.

No power-cycle reset time, no "tighten the terminal screws" step, no resistance value, no "check the wiring" step and no board-replacement procedure exists in any manual for F15. There is no flowchart for F15 anywhere in M2 pp.44-50. The FlexFit hidden-code viewing procedure (hold the Emergency button for 15 seconds to view the code indoors) is a FlexFit procedure, not a split-wall procedure. Do NOT present any competitor's DIY terminal-block fix as a manual step. F15 is a one-row code in every manual that lists it — the page stays short rather than padding with invented diagnostics.

When to call a technician

  • F15 returns after a restart — the terminal block / board needs diagnosis by a technician.
  • The outdoor LED1 flashes 20 times — board / terminal overheating (F5, the power module overheating, is 23).
  • Any burning smell or visible damage at the outdoor unit — switch off and call a qualified technician.

More guidance: when an appliance error requires professional service.

Safety first

F15 is a short circuit / overheating fault at the outdoor terminal block — live electrical work. Never open the outdoor unit while it is connected to power, and never touch the terminal block yourself.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does F15 mean on a Haier split air conditioner?

F15 means board / terminal overheating: the outdoor terminal block has overheated, caused by short circuit / overheating on components. The outdoor PCB LED1 flashes 20 times (M3 Table A p.30; M7 p.25; FlexFit 3U24MS2VHB p.112).

Is F15 a compressor fault?

No. One list page (acerrorcode) calls F15 "Compressor running faulty", but no Haier manual supports that. F15 is a terminal-block / board overheating fault at the outdoor unit's wiring terminals — not the compressor.

How is F15 different from F5?

Both are temperature-protection faults, but on different parts: F5 is the SPDU/ISPM power module overheating (LED1 23), while F15 is the terminal block / board overheating (LED1 20). Different parts, different codes — never merge them.

Can I fix Haier F15 myself?

No fix step exists in any manual read. The manual cause is "short circuit / overheating on components" — live electrical work at the outdoor terminal block. Switch the unit off and call a technician; do not open the outdoor unit or touch the terminal block.

Is F15 the same on a Haier cabinet air conditioner?

No — this is the sharpest trap for this code. The cabinet 14kW table (M3 Table B) uses F15 for "Communication error between indoor and outdoor units" — the same wording as split-wall E7. On a split, F15 is terminal overheating; on a cabinet, F15 is a communication fault. Check whether your unit is a split or a cabinet before using any F-code meaning.
