Haier Split Air Conditioner Error Code F29

Quick answer

Error codeF29 — Haier Split Air Conditioner
What it meansF29 = gas pipe circuit "A" temperature probe (sensor) failure — the gas-pipe temperature sensor on refrigerant circuit A of the multi-split outdoor unit is faulty: sensor disconnected, broken, or poorly positioned. The indoor display shows F29 and the outdoor PCB LED1 flashes 32 times (two-LED boards: LED1 5 + LED2 2 = code 52). All three F-label manuals agree on code, meaning, circuit letter and flash count.
Most common causeGas pipe circuit A temperature probe faulty — sensor disconnected, broken, or poorly positioned (M3 Table A p.31).
Safe to check yourself?No — no fix step exists in any manual read. Switch the unit off, note which indoor unit / circuit A is affected, and call a technician; checking or replacing the outdoor gas-pipe-A probe is technician work on the outdoor unit.
Checked againstHaier European HVAC Technical Book 2024-25, DIAGNOSTIC Table A (Mono Residential and Multi Units) (Table A p.31); Haier FlexFit Series Multi Zone Split System Heat Pump Service Manual, 3U24MS2VHB (outdoor units 2U18/3U24/4U36MS2VHB, R410A, US), Error Codes (p.112 + p.35); Haier haier-ac.pt Cod.-Erros-Condutas-Alta-Pest.pdf (Round way cassette / cassette / convertible / duct unit troubleshooting, outdoor units 3U/4U/5U) (p.428); Haier 4U36MS2VHB Service Manual, MID-STATIC DUCTED TECHNICAL OVERVIEW, Error Codes (p.92) - numeric corroboration only

Applies to — read this first

Read this first, because F29 is a split-wall/ductless Table A code — it means the gas pipe circuit A temperature sensor on multi-split outdoor units (3U/4U/5U). The gas-pipe circuit sensors live on multi-split outdoor units; a single-split (mono) unit has only circuit A, but its single-split manuals (M2, M7) do not list F29 at all, so a reader with a single-split unit will never see it in their manual either. If your unit shows F29, it is a multi-split outdoor unit fault on circuit A. Cabinet Table B has NO F29 at all, and the old fixed-speed lamp table has no F29. Check the model and series, not just the letters.

No ranking competitor page covers F29 in prose at all: Arlington has no F29 section (its per-code sections stop at F28); acerrorcode has no F29 row (its main table ends at F28, then jumps to F66) and gets the neighbouring sensor family wrong — F10 "No AC power supply" (wrong: F10 = liquid pipe circuit A sensor, the liquid counterpart of F29) and F16 "Running state-detecting circuit failure" (wrong: F16 = liquid pipe circuit B sensor); decorexpro has no F29 (its F-codes stop at F12) and claims LED blinks run "1 to 25 times" (wrong: F29 = 32, F33 = 40, F43 = 46); lioncityaircon.sg uses a different Haier system (E01-E124) with no F-codes — its E04 "Gas Pipe Temperature Sensor Abnormality" uses the same words under a different code label. The gas family runs F29 A (32) / F30 B (33) / F31 C (34) / F32 D (35) / F26 E (36); the liquid family runs F10 A (28) / F16 B (29) / F17 C (30) / F18 D (31) / F33 E (40). Note the F26 side-note from the spec: Table A F26 is "Gas pipe circuit "E" temperature probe faulty", but the same book's Table B uses F26 for "Lack of a phase in the power module" — an intra-book collision on F26, which has no standalone page and is not presented here as resolved.

What the machine does when F29 fires

The indoor display shows F29 in place of the set temperature, and the outdoor PCB LED1 flashes 32 times (two-LED boards: LED1 5 + LED2 2 = code 52). The outdoor board cannot read the gas-pipe-A probe, so it cannot run the multi-split outdoor unit correctly.

Common causes

  1. Sensor disconnected (M3 Table A p.31).
  2. Sensor broken (M3 Table A p.31).
  3. Sensor poorly positioned (M3 Table A p.31).

Safe checks, in order

  1. Switch the unit off.
  2. Note which indoor unit / circuit A is affected, then call a technician — checking or replacing the outdoor gas-pipe-A probe is technician work on the outdoor unit. No manual gives a procedure, a resistance value, or a plug check for F29, so this page does not invent one.

There is NO F29 flowchart and NO fix step in any manual: the full extent of the manual evidence is the M3 Table A row-32 cause ("Sensor disconnected, broken, or poorly positioned"), the M8 p.112/p.35 table rows and the M9 p.428 table row. No lockout rule ("3 times in an hour") is stated for the F29 row in any manual — do not claim one. No detection window is stated for F29 — the 60-second short/open-circuit window is verified only for F6/F7/F21/F25 (M3 rows 10-13); do not claim it for F29. Do NOT present other sensors' steps (e.g. E1 indoor-sensor steps, or F6 ambient-sensor steps) as F29 steps. F29 is a one-row code in every manual: keep it short, do not pad with invented diagnostics.

When to call a technician

  • F29 returns after a restart — the outdoor gas-pipe-A probe needs checking or replacing.
  • The outdoor LED1 flashes 32 times — gas pipe circuit A (F10, the liquid pipe sensor on the same circuit, is 28).
  • Any burning smell or visible damage — switch off and call a qualified technician.

More guidance: when an appliance error requires professional service.

Safety first

The outdoor gas-pipe-A probe is on the outdoor unit: checking or replacing it is qualified-technician work. Never open the outdoor unit while it is connected to power.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does F29 mean on a Haier split air conditioner?

F29 means the gas pipe circuit "A" temperature probe (sensor) has failed — the gas-pipe temperature sensor on refrigerant circuit A of the multi-split outdoor unit is disconnected, broken, or poorly positioned. The indoor display shows F29 and the outdoor PCB LED1 flashes 32 times (M3 Table A p.31; M8 FlexFit p.112; M9 haier-ac.pt p.428).

Is F29 the same as F10?

No. F10 is the LIQUID pipe sensor on circuit A (LED 28); F29 is the GAS pipe sensor on the same circuit A (LED 32). Same circuit letter, different pipe — the outdoor unit has one liquid-pipe sensor and one gas-pipe sensor per circuit. Do not merge them.

Can a single-split Haier show F29?

Not in any manual read. The single-split manuals (M2, M7) do not list F29 at all, and the gas-pipe circuit sensors live on multi-split outdoor units (3U/4U/5U). If your unit shows F29, it is a multi-split outdoor unit fault on circuit A.

How is F29 different from F30, F31, F32 and F26?

They are five different gas-pipe sensors, one per circuit: F29 = A (LED 32), F30 = B (33), F31 = C (34), F32 = D (35), F26 = E (36). Each one points the technician at a different indoor unit's gas pipework. (Note: the same book also uses F26 for "Lack of a phase in the power module" in its cabinet table — see the F33 page for that collision.)

Can I fix Haier F29 myself?

No fix step exists in any manual read. The manuals give only the table row plus M3's cause ("Sensor disconnected, broken, or poorly positioned"). Switch the unit off, note that it is circuit A, and call a technician to check or replace the outdoor gas-pipe-A probe. Do not follow guides that tell you to use another sensor's fix for F29.
