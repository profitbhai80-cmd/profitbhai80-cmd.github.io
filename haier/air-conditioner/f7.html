Haier Split Air Conditioner Error Code F7

Quick answer

Error codeF7 — Haier Split Air Conditioner
What it meansF7 = compressor intake / suction temperature sensor (probe) failure — the outdoor unit's suction (compressor intake) temperature probe has failed. The indoor display shows F7 and the outdoor PCB LED1 flashes 11 times. No manual gives a lockout rule for F7, and no manual gives a resistance value for this sensor in the sections read. The 60-second detection window was verified verbatim only for F6 — do not claim it for F7.
Most common causeThe outdoor suction (compressor intake) temperature probe is faulty — in short circuit or open circuit (the Table A sensor-row cause pattern; the 60-second window is verified verbatim only for F6).
Safe to check yourself?No — no fix step exists in any manual read. Switch the unit off and call a technician to check or replace the outdoor suction probe. Do not use the E1 (indoor sensor) fix for F7 — the sensors are in different units.

Applies to — read this first

Read this first, because F7 is a split-wall/ductless Table A code — it means the suction (compressor intake) sensor on the US ductless split families, the EU mono/multi range, the AU/NZ R32 split families and the AS35/AS50 wall-split families (M2/M3/M7, identical LED count of 11). The cabinet 14kW table (M3 Table B) carries the same suction-sensor wording under a different label, F11 — the sharpest trap for this code. The old fixed-speed lamp table has no F7 at all. Check the model and series, not just the letters.

The ranking pages get F7 half-right at best. acerrorcode, the #1 list page, says F7 is 'Outdoor suction/defrosting temp. sensor abnormal' — suction right, defrosting wrong: defrost is F21 (LED1 10). Arlington gets the meaning and LED1 11 right but its only solution is 'Try the exact solutions as suggested for Error Code E1' — E1 is the INDOOR room sensor, a different sensor in a different unit. decorexpro has no F7 content at all — its F-section jumps from F6 to FF to F11. The other outdoor sensors have their own codes: F6 ambient (12 flashes), F21 defrost (10), F25 delivery (13) — do not merge them with F7 (11).

What the machine does when F7 fires

The indoor display shows F7 in place of the set temperature, and the outdoor PCB LED1 flashes 11 times. The outdoor board cannot read the suction (compressor intake) temperature, so it cannot run the outdoor unit correctly.

Common causes

  1. Suction (compressor intake) temperature probe faulty (M3).
  2. Outdoor suction temperature sensor failure (M2/M7).

Safe checks, in order

  1. Switch the unit off.
  2. Call a technician — the outdoor suction probe is on the outdoor unit, and its check or replacement is technician work. No manual gives the procedure, a resistance value, or a plug check for F7, so this page does not invent one.

There is NO F7 flowchart and NO fix step in any manual: the full extent of the manual evidence is the M2 p.43 table row, the M3 Table A row, the M7 p.25 row and the AS35 §10.4.1 grouping. M2's flowcharts (pp.44-50) cover E14, F8, F1, F22/F2/F23, F3, F19, F4, E7 and F11/F28 only. Do NOT follow guides that tell you to use the E1 (indoor sensor) fix for F7, and do not follow decorexpro's generic 'check the connection / replace faulty sensors' — those are the sites' own additions, not manual steps. F7 is a one-row code in every manual: keep it short, do not pad with invented diagnostics.

When to call a technician

  • F7 returns after a restart — the outdoor suction probe needs checking or replacing.
  • The outdoor LED1 flashes 11 times — suction sensor (F21 defrost is 10, F6 ambient is 12, F25 delivery is 13).
  • Any burning smell or visible damage — switch off and call a qualified technician.

More guidance: when an appliance error requires professional service.

Safety first

The outdoor suction probe is on the outdoor unit: checking or replacing it is qualified-technician work. Never open the outdoor unit while it is connected to power.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does F7 mean on a Haier split air conditioner?

F7 means the compressor intake (suction) temperature sensor (probe) has failed. The indoor display shows F7 and the outdoor PCB LED1 flashes 11 times (M2 p.43; M3 Table A pp.28-31; M7 p.25).

Is F7 the same as the defrost sensor fault?

No. F7 is the suction (compressor intake) sensor; the defrosting temperature sensor is F21 (LED1 10). One list page (acerrorcode) merges them into a single 'suction/defrosting' row — that is wrong. Each sensor has its own code and flash count.

Can I fix Haier F7 myself?

No fix step exists in any manual read. Unlike F8 and F11, F7 has no diagnostic flowchart at all — the manuals give only the table row. Do not follow guides that tell you to use the E1 (indoor sensor) fix for F7: the sensors are in different units. Switch the unit off and call a technician to check or replace the outdoor suction probe.

Is F7 the same on a Haier cabinet air conditioner?

No. The cabinet 14kW table (M3 Table B) has no code F7: the same suction-sensor wording appears there under F11, and cabinet F11 is a sensor fault — while on a split, F11 means loss of compressor synchronism. Check whether your unit is a split or a cabinet before using any F-code meaning.

How is F7 different from F6, F21 and F25?

They are four different outdoor sensors: F6 ambient (12 flashes), F7 suction / compressor intake (11), F21 defrost (10) and F25 delivery / discharge (13). Same outdoor unit, four probes, four codes — never merge them.
