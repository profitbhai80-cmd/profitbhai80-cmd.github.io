Haier Split Air Conditioner Error Code F14

Quick answer

Error codeF14 — Haier Split Air Conditioner
What it meansF14 = 4-way valve switching failure — the reversing (4-way) valve that switches the unit between heating and cooling has failed to switch. Cause per M3: the valve coil is damaged, disconnected or unpowered, or the valve itself has mechanically failed. The outdoor PCB LED1 flashes 17 times. M7 words it "4-way valve reverse failure" — same fault, different phrasing.
Most common cause4-way valve coil damaged, disconnected or unpowered, or mechanical failure of the 4-way valve (M3 Table A p.30).
Safe to check yourself?No — there is no owner fix in any manual. Switch the unit off and call a technician; reversing-valve work is on the refrigerant circuit.
Checked againstHaier European HVAC Technical Book 2024-25 (haierhvac.eu), DIAGNOSTIC Table A p.30; Haier 1U26MADFRA Room Air Conditioner Installation Manual (Sept 2024, R32, AU/NZ), Outdoor Unit Troubleshooting p.25; Haier FlexFit Series Multi Zone Split System Heat Pump Service Manual (3U24MS2VHB), Console Technical Overview p.112; Haier 4U36MS2VHB Service Manual, Mid-Static Ducted Technical Overview p.92

Applies to — read this first

Read this first, because F14 is a split-wall/ductless Table A code — it means 4-way valve switching failure on the EU mono residential / multi range, the AU/NZ R32 split families and the US FlexFit multi-zone consoles (M3/M7/FlexFit, identical LED count of 17), with numeric corroboration from the 4U36 ducted table. The US ductless split manual (M2) does NOT list F14. The cabinet 14kW table (M3 Table B) uses F14 for a different fault — "PFC circuit voltage too high" — and puts the 4-way-valve wording under F17. The old fixed-speed lamp table has no F14 at all. Check the model and series, not just the letters.

The ranking pages get F14 wrong. acerrorcode, the #1 list page, says F14 is "Compressor discharging temp. sensor failure" — wrong: that is F25's meaning (compressor delivery/discharge temperature sensor failure, LED1 13). Do NOT use E18's wording ("outdoor 4-way valve response abnormal") — E18 is an acerrorcode-only code with no manual support; F14 is the manual-backed 4-way valve code. Arlington has no F14 section at all, and decorexpro has no F14 content. F4 is compressor delivery high temperature protection (LED1 8) — a temperature trip, not a valve fault; F13 is lack of refrigerant (LED1 16) — low refrigerant can also cause poor heating/cooling, but it is a different fault from a valve that will not switch.

What the machine does when F14 fires

The reversing (4-way) valve that switches the unit between heating and cooling has failed to switch, and the outdoor PCB LED1 flashes 17 times. M7 marks F14 "Trouble record" — logged in the unit's trouble history rather than shown straight on the indoor panel.

Common causes

  1. 4-way valve coil damaged (M3 Table A p.30).
  2. 4-way valve coil disconnected or unpowered (M3 Table A p.30).
  3. Mechanical failure of the 4-way valve (M3 Table A p.30).

Safe checks, in order

  1. Switch the unit off.
  2. Call a technician — there is no fix step in any manual for F14. Do not tap, force or try to free the valve yourself; reversing-valve work is on the refrigerant circuit.

No "tap the valve" step, no coil-resistance value, no "switch modes to free it" step, no power-cycle reset time and no valve-replacement procedure exists in any manual for F14. There is no flowchart for F14 anywhere in M2 pp.44-50. The FlexFit hidden-code viewing procedure (hold the Emergency button for 15 seconds to view the code indoors) is a FlexFit procedure, not a split-wall procedure. Do NOT present any competitor's DIY valve fix as a manual step. F14 is a one-row code in every manual that lists it — the page stays short rather than padding with invented diagnostics.

When to call a technician

  • F14 returns after a restart — the 4-way valve coil or the valve itself needs diagnosis by a technician.
  • The outdoor LED1 flashes 17 times — 4-way valve switching failure (F25, the discharge sensor, is 13).
  • The unit will not switch between heating and cooling with F14 showing.

More guidance: when an appliance error requires professional service.

Safety first

The 4-way valve sits on the refrigerant circuit. Never open the outdoor unit while it is connected to power, and never attempt reversing-valve work yourself.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does F14 mean on a Haier split air conditioner?

F14 means 4-way valve switching failure: the reversing valve that switches the unit between heating and cooling has failed to switch. The outdoor PCB LED1 flashes 17 times (M3 Table A p.30; M7 p.25; FlexFit 3U24MS2VHB p.112).

What causes F14?

Per the European Technical Book (M3 Table A): the 4-way valve coil is damaged, disconnected or unpowered, or the valve itself has mechanically failed. Both causes are technician work on the refrigerant circuit.

Is F14 a temperature sensor fault?

No. One list page (acerrorcode) calls F14 "Compressor discharging temp. sensor failure", but that is F25's meaning — the compressor delivery/discharge temperature sensor failure, LED1 13 flashes. F14 is a valve fault, not a sensor fault.

Can I fix Haier F14 myself?

No fix step exists in any manual read. Unlike F1, F4 and F11, F14 has no diagnostic flowchart at all — the manuals give only the table row plus M3's cause. Switch the unit off and call a technician; do not tap, force or try to free the valve yourself.

Is F14 the same on a Haier cabinet air conditioner?

No. The cabinet 14kW table (M3 Table B) uses F14 for "PFC circuit voltage too high" — an inverter-module voltage fault — and puts the 4-way-valve wording under F17. Check whether your unit is a split or a cabinet before using any F-code meaning.
