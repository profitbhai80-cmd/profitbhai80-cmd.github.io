Haier Split Air Conditioner Error Code F24

Quick answer

Error codeF24 — Haier Split Air Conditioner
What it meansF24 = no charge / faulty amperometric (current-sensing) control — the outdoor board's current-transformer (CT) circuit is not reading compressor current: the CT is disconnected, or the current-detection circuit is faulty. The indoor display shows F24 (M7 marks it "Trouble record") and the outdoor PCB LED1 flashes 27 times. Wording split, stated honestly: M3 says "No charge / faulty amperometric control"; M7 says "CT disconnection"; Haier India says "CT detection current abnormal protection"; the ducted PDF says "Module current detect circuit malfunction" — one fault family, four wordings.
Most common causeDetached compressor cables, or faulty amperometric (current-sensing) control — the CT circuit is not reading compressor current (M3 Table A p.31).
Safe to check yourself?No — Haier India's official page says these codes "only can be solved by after-sale service engineers". Switch the unit off and call the Haier hotline / a technician; checking compressor cables and the CT circuit is technician work on a live inverter board.

(haier.com/in); haier-ac.pt ducted-high-pressure PDF (Cod.-Erros-Condutas-Alta-Pest.pdf), outdoor error 27 to indoor F24

Applies to — read this first

Read this first, because F24 is a split-wall/ductless Table A code — it means no charge / faulty amperometric control on the EU mono residential / multi range and the AU/NZ R32 split families, with the same current-sensing fault on Haier India's official self-service page and in the haier-ac.pt ducted PDF (M3/M7/Haier India/haier-ac.pt). The US ductless split manual (M2) does NOT list F24. The commercial and cabinet tables use F24 for a DIFFERENT fault — "Failed to start compressor / Overcurrent" (alarm 44) — the sharpest trap for this code, and commercial F28 carries Table A F24's headline. The old fixed-speed lamp table has no F24 at all. Check the model and series, not just the letters — and quote code + table together, never the cause alone.

Every ranking competitor page omits F24 entirely. acerrorcode has no F24 row — its table jumps F23 to F25 — and Arlington has no F24 section (its sections run F23 to F25). decorexpro has no F24 content, and askwhiz shows no F24 content behind its JS-gated lookup. F2 is "Failed to start compressor / Overcurrent" (LED1 24) — do not confuse F2 (LED1 24) with F24 (LED1 27): the numbers are one digit apart and the faults are different. F23 is U-V-W compressor phase overcurrent (LED1 25). Table A F27 is "Locked compressor" (LED1 7) — while commercial F27 is "Input current verification circuit failure" carrying the SAME cause text as Table A F24, so quote code + table together, never the cause alone.

What the machine does when F24 fires

The outdoor board's current-transformer (CT) circuit is not reading compressor current — the CT is disconnected, or the current-detection circuit is faulty — and the outdoor PCB LED1 flashes 27 times (M7, p.25; consistent with M3 Table A alarm 47 and the haier-ac.pt outdoor error 27). The indoor display shows F24 — M7 marks it "Trouble record" rather than "Directly display". "No charge" is M3's shorthand for the board seeing no current: a disconnected CT reads as no charge.

Common causes

  1. Detached compressor cables (M3 Table A p.31).
  2. Faulty amperometric control — the current-sensing (CT) circuit is faulty (M3 Table A p.31).
  3. CT disconnection (M7 p.25) / module current detect circuit malfunction (haier-ac.pt) — the same current-sensing circuit, worded differently.

Safe checks, in order

  1. Switch the unit off.
  2. Call a technician — Haier India's official page says these codes "only can be solved by after-sale service engineers" and asks you to "turn off the unit and call our Haier hotline for help". M3's cause ("Detached compressor cables / faulty amperometric control") is a pointer for a technician, not an owner step.

No power-cycle reset time, no CT resistance value, no "check the plug" step, no compressor-cable reseat procedure and no current-measurement step exists in any manual for F24. Do NOT present the commercial F24's lockout rule ("The alarm goes out 3 times in an hour and locks the machine") as Table A F24's — M3's Table A F24 row carries no lockout wording. M7's general warnings (auto-restart after power recovery, energise the crankcase heater 12 hours before a test run) are general installation warnings, NOT F24 steps. The haier-ac.pt reading rule ("The outdoor error code=(M*10+N). LED1 flash M times and LED2 flash N times.") is a reading rule, not a fix. F24 is a one-row code in every manual — the page stays short rather than padding with invented diagnostics.

When to call a technician

  • F24 returns after a restart — the compressor cables and CT circuit need diagnosis by a technician.
  • The outdoor LED1 flashes 27 times — current-sensing fault (F2 is 24, F23 is 25, F27 is 7).
  • Any burning smell or visible damage — switch off and call a qualified technician.

More guidance: when an appliance error requires professional service.

Safety first

Checking compressor cables and the CT circuit is technician work on the outdoor unit and on a live inverter board. Never open the outdoor unit while it is connected to power.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does F24 mean on a Haier split air conditioner?

F24 means no charge / faulty amperometric control: the outdoor board's current-transformer (CT) circuit is not reading compressor current — the CT is disconnected or the current-detection circuit is faulty. The indoor display shows F24 (a "Trouble record" code in the AU/NZ manual) and the outdoor PCB LED1 flashes 27 times (M3 Table A p.31; M7 p.25; Haier India official page; haier-ac.pt ducted PDF).

What is a CT, and what does "amperometric control" mean?

CT is a current transformer: a sensor that measures the current the compressor draws so the board can protect it. "Amperometric control" is the same circuit under its European-manual name. M7 calls the fault "CT disconnection", Haier India calls it "CT detection current abnormal protection", and the ducted manual calls it "Module current detect circuit malfunction" — four wordings for one current-sensing circuit.

Is F24 the same as F2?

No. F2 is "Failed to start compressor / Overcurrent" (LED1 24 flashes) — the compressor failed to start. F24 is the current-sensing circuit fault (LED1 27 flashes) — the board cannot read the current at all. The numbers are one digit apart; the faults are different. The same "failed to start" fault that F2 names on a split is called F24 on a cabinet or commercial unit — check your unit type before using the number.

Can I fix Haier F24 myself?

No fix step exists in any manual read. Haier India's official page says these codes "only can be solved by after-sale service engineers" and asks you to "turn off the unit and call our Haier hotline for help". The manual's only cause — "Detached compressor cables / faulty amperometric control" — is a pointer for a technician, not an owner step: checking compressor cables and the CT circuit means working on a live outdoor inverter board. Switch the unit off and call a technician.

How is F24 different from F23 and F27?

F23 is U-V-W compressor phase overcurrent (LED1 25) — current too high on a phase. F24 is the current-sensing circuit itself failing (LED1 27) — the board cannot measure the current. Table A F27 is a locked compressor (LED1 7). Three overcurrent-adjacent codes, three flash counts, three faults — never merge them.
