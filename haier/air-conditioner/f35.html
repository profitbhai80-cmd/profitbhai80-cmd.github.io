Haier Split Air Conditioner Error Code F35

Quick answer

Error codeF35 — Haier Split Air Conditioner
What it meansF35 = power module temperature sensor failure — the temperature sensor on the outdoor unit's power (compressor driver) module has failed: sensor disconnected, broken, or poorly positioned, or the power module itself has failed. The outdoor error number is 38 (M7: outdoor PCB LED1 flashes 38 times). M7 marks F35 a "Trouble record" rather than "Directly display". WORDING CONFLICT (carried explicitly, not resolved silently): M7 and the HVA103-era table label this same code/flash-count "Compressor driver board failure", while M3, FlexFit, the cassette/duct PDF, 4U36 and 1U105 name the module temperature SENSOR — the sensor sits on the driver board, and M3's own cause column covers both ("Sensor disconnected, broken, or poorly positioned / power module failure").
Most common causePower module temperature sensor failure — sensor disconnected, broken, or poorly positioned / power module failure (M3 Table A p.31).
Safe to check yourself?No — no fix step exists in any manual read. Switch the unit off and call a technician; checking or replacing the power-module temperature sensor is technician work on the outdoor unit.

Applies to — read this first

Read this first, because F35 is a split-wall/ductless Table A code — it means the power module temperature sensor on the EU mono/multi range, the AU/NZ R32 split families, the US FlexFit multi-zone/console families and the cassette/convertible/duct families (M3/M7/FlexFit, identical outdoor error number 38). The US ductless split manual (M2) does NOT list F35 at all. The cabinet 14kW table (M3 Table B) has no F35 — the same sensor wording sits under F38 there. The old fixed-speed lamp table has no F35. Check the model and series, not just the letters.

WORDING-CONFLICT BOX (must be on the page): M7 calls F35 (38 flashes) "Compressor driver board failure", and the HSU-09/12HVA103-era table (nikolabartakova.cz mirror, garbled OCR) says the same: "F35 Compressor driver board failure". M3, FlexFit, the cassette PDF, 4U36 and 1U105 all name the module temperature SENSOR. The code number (38) and the fault family (the power/driver module's temperature sensing) agree everywhere — only the label granularity differs. The reconciliation is inside M3's own row: its cause column reads "Sensor disconnected, broken, or poorly positioned / power module failure". The temperature sensor sits on the compressor driver (power) module, so a failed sensor and a failed driver board are the two ends M3 already lists for this one code. Lead with M3's sensor meaning ("Power module temperature sensor failure"), and carry this box stating that M7 and the HVA103-era table label the same code/flash-count "Compressor driver board failure" — the board that carries the sensor — so a reader whose manual says "driver board failure" knows it is the same F35, not a second fault. Do NOT present the two wordings as two different faults, and do NOT silently pick one. F5 is power-module temperature PROTECTION (module temperature too high, 3-in-1-hour lock) — a protection, not a sensor failure; F35 is the module temperature SENSOR failure. F34 is outdoor exchanger temperature protection (37); F36 is the piping TC probe fault (39). Cabinet Table B F38 = "Power module temperature sensor failure" — Table A F35's meaning under a different number; cabinet has no F35. E1 is the INDOOR room temperature sensor — a different sensor in a different unit. What the machine does when F35 fires

The indoor display shows F35 (where directly displayed; M7 marks it a "Trouble record" rather than "Directly display"), and the outdoor PCB LED1 flashes 38 times. The temperature sensor on the outdoor unit's power (compressor driver) module has failed, so the outdoor board cannot read the module temperature.

Common causes

  1. Sensor disconnected (M3 Table A p.31).
  2. Sensor broken (M3 Table A p.31).
  3. Sensor poorly positioned (M3 Table A p.31).
  4. Power module failure (M3 Table A p.31).

Safe checks, in order

  1. Switch the unit off.
  2. Call a technician — checking or replacing the power-module temperature sensor is technician work on the outdoor unit. No manual gives a procedure, a resistance value, or a plug check for F35, so this page does not invent one.

There is almost nothing in the manuals for F35: the full extent of the manual evidence is the M3 Table A row-38 cause ("Sensor disconnected, broken, or poorly positioned / power module failure"), the M7 p.25 row ("Compressor driver board failure", LED1 38, Trouble record), the FlexFit p.112 / cassette PDF wording ("Malfunction of module temperature sensor / Momentary power failure detection") and the 1U105 error-38 note ("Drive module's ambient temp. sensor abnormal — The temperature detected is not within the range of -25°C to 150°C"; Remark: Resumable). Do NOT invent: no power-cycle reset time, no resistance value, no "check the plug" step and no sensor-replacement procedure exists in any manual for F35. The 1U105 "Resumable" remark means the error clears once the fault factor is gone — do NOT turn that into a DIY reset procedure. Do NOT present F5's protection steps or E1's indoor-sensor steps as F35 steps. F35 is a one-row code in every manual: keep it short, do not pad with invented diagnostics.

When to call a technician

  • F35 returns after a restart — the power-module temperature sensor (or the driver board that carries it) needs checking or replacing.
  • The outdoor LED1 flashes 38 times — power module temperature sensor (F34 is 37, F36 is 39).
  • Any burning smell or visible damage — switch off and call a qualified technician.

More guidance: when an appliance error requires professional service.

Safety first

The power-module temperature sensor is on the outdoor unit's driver board: checking or replacing it is qualified-technician work. Never open the outdoor unit while it is connected to power.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does F35 mean on a Haier split air conditioner?

F35 means the power module temperature sensor has failed — the temperature sensor on the outdoor unit's power (compressor driver) module is faulty: disconnected, broken, or poorly positioned, or the power module itself has failed. The outdoor error number is 38, and the outdoor PCB LED1 flashes 38 times (M3 Table A p.31; M7 p.25).

My manual says F35 is "Compressor driver board failure" — is that a different fault?

No, it is the same code. The AU/NZ installation manual (M7) and the HVA103-era table label F35 "Compressor driver board failure", while the European Technical Book (M3), FlexFit and the cassette/duct manuals call it a module temperature sensor malfunction. M3's own cause column covers both: "Sensor disconnected, broken, or poorly positioned / power module failure". The sensor sits on the driver board — one fault, two labels.

Can I fix Haier F35 myself?

No fix step exists in any manual read. The ducted troubleshooting PDF notes the sensor is abnormal when the detected temperature is outside -25°C to 150°C and marks the error "Resumable" (it clears when the fault factor is gone), but no manual gives an owner reset procedure. Switch the unit off and call a technician to check or replace the power-module temperature sensor.

Is F35 the same as F5?

No. F5 is power-module temperature PROTECTION — the module itself is too hot. F35 is the module temperature SENSOR failure — the sensor that measures that temperature is faulty. Different codes, different faults.

Is F35 the same on a Haier cabinet air conditioner?

The fault is the same, but the number is different: the cabinet 14kW table (M3 Table B) carries this exact wording under F38, and has no F35. Check whether your unit is a split or a cabinet before using any F-code meaning.
