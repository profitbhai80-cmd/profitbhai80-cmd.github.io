Haier Split Air Conditioner Error Code F5

Quick answer

Error codeF5 — Haier Split Air Conditioner
What it meansF5 = SPDU/ISPM power module temperature protection — the outdoor power (driver) module has overheated / is in thermal overload. The outdoor PCB LED1 flashes 23 times. M3 (EU Technical Book, Table A p.30) words it "SPDU/ISPM power module temperature protection" ("SPDU/ISPM module temperature too high"); the FlexFit manual words the same fault "Module thermal overload". This is a temperature fault, not an overcurrent fault.
Most common causeSPDU/ISPM module temperature too high (M3 Table A p.30) — the outdoor power module has overheated.
Safe to check yourself?No — there is no owner fix in any manual. Switch the unit off and call a technician; the power module is a live outdoor-unit component.
Checked againstHaier European HVAC Technical Book 2024-25 (haierhvac.eu), DIAGNOSTIC Table A p.30; Haier FlexFit Series Multi Zone Split System Heat Pump Service Manual (3U24MS2VHB), Console Technical Overview p.112; Haier 4U36MS2VHB Service Manual, Mid-Static Ducted Technical Overview p.92

Applies to — read this first

Read this first, because F5 is a split-wall/ductless Table A code — it means SPDU/ISPM power module temperature protection on the EU mono residential / multi range (M3) and the US FlexFit multi-zone consoles, with numeric corroboration from the 4U36 ducted table (M3/FlexFit, identical LED count of 23). The US ductless split manual (M2) and the AU/NZ R32 manual (M7) do NOT list F5 at all. The cabinet 14kW table (M3 Table B) has NO F5: its F05 is "Compressor overcurrent detected by control board", and the power-module-temperature wording sits under cabinet F23. The old fixed-speed lamp table has no F5 at all. Check the model and series, not just the letters.

The ranking pages get F5 wrong. acerrorcode, the #1 list page, says F5 is "Module over current/current transducer failure" — wrong, no manual supports it; overcurrent belongs to F2/F22/F23/F20. plentifulair, a generic multi-brand guide, says F5 means a problem with the outdoor fan speed — wrong for Haier and not Haier-specific (the outdoor fan motor fault is F8, LED1 9). Arlington has no F5 section at all, and decorexpro has no F5 content. F1 is IPM/power module protection (LED1 2) — the module's general protection trip, not specifically temperature; F35 is power module temperature sensor failure (LED1 38) — the sensor has failed, which is different from the module itself overheating (F5).

What the machine does when F5 fires

The outdoor PCB LED1 flashes 23 times. The SPDU/ISPM power module has overheated, and the alarm goes out 3 times in an hour and then locks the machine (M3 Table A p.30). In the FlexFit manual F5 is a hidden indoor code (marked *): LED1 flashes outdoors but no error appears on the indoor display until the Emergency button is held for 15 seconds.

Common causes

  1. SPDU/ISPM module temperature too high (M3 Table A p.30).
  2. Module thermal overload (FlexFit p.112; 4U36 p.92) — the same fault, worded differently.

Safe checks, in order

  1. Switch the unit off.
  2. Call a technician — there is no fix step in any manual for F5; the power module is a live outdoor-unit component. Do not open the outdoor unit.

There is no flowchart for F5 anywhere in M2 pp.44-50, and no power-cycle reset time, no cool-down period, no resistance value, no "check the plug" step, no module-replacement procedure and no "clean the outdoor unit" step exists in any manual for F5. The only manual-stated consequence is the lockout: after the alarm goes out 3 times in an hour the machine locks. The FlexFit hidden-code viewing procedure (hold the Emergency button for 15 seconds to view the code indoors) is a FlexFit procedure, not a split-wall procedure. Do NOT present F1's IPM flowchart steps or F35's sensor steps as F5 steps. F5 is a one-row code in every manual that lists it — the page stays short rather than padding with invented diagnostics.

When to call a technician

  • F5 returns after a restart — the power module needs diagnosis by a technician.
  • The outdoor LED1 flashes 23 times — power module temperature protection (F35, the module temperature sensor failure, is 38).
  • Any burning smell or visible damage — switch off and call a qualified technician.

More guidance: when an appliance error requires professional service.

Safety first

The power module is a live outdoor-unit component. Never open the outdoor unit while it is connected to power, and never attempt power-module work yourself.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does F5 mean on a Haier split air conditioner?

F5 means SPDU/ISPM power module temperature protection: the outdoor power (driver) module has overheated. The outdoor PCB LED1 flashes 23 times (M3 Table A p.30; FlexFit 3U24MS2VHB p.112). The alarm goes out 3 times in an hour and then locks the machine.

Is F5 an overcurrent fault?

No. One list page (acerrorcode) calls F5 "Module over current/current transducer failure", but no Haier manual supports that. Overcurrent faults are F2 (failed to start / overcurrent), F22 (AC overcurrent) and F23 (phase overcurrent). F5 is a temperature fault on the power module, not a current fault.

How is F5 different from F35?

F5 means the power module itself is too hot (temperature protection trip, LED1 23). F35 means the power module's temperature sensor has failed (LED1 38). A failed sensor and an overheating module are different faults with different codes — never merge them.

Can I fix Haier F5 myself?

No fix step exists in any manual read. Unlike F1, F4 and F11, F5 has no diagnostic flowchart at all — the manuals give only the table row plus M3's cause. Switch the unit off and call a technician; the power module is a live outdoor-unit component. Do not open the outdoor unit.

Is F5 the same on a Haier cabinet air conditioner?

No. The cabinet 14kW table (M3 Table B) has no code F5: its F05 is "Compressor overcurrent detected by control board", and the power-module-temperature wording appears there under F23. Check whether your unit is a split or a cabinet before using any F-code meaning — and note the site's Gree F5 page is a different brand entirely.
