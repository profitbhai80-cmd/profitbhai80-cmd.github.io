Haier Split Air Conditioner Error Code F31

Quick answer

Error codeF31 — Haier Split Air Conditioner
What it meansF31 = gas pipe circuit "C" temperature probe (sensor) failure — the gas-pipe temperature sensor on refrigerant circuit C of the multi-split outdoor unit is faulty: sensor disconnected, broken, or poorly positioned. The indoor display shows F31 and the outdoor PCB LED1 flashes 34 times (two-LED boards: LED1 5 + LED2 4 = code 54). All three F-label manuals agree on code, meaning, circuit letter and flash count. This is the AIR CONDITIONER meaning only — the Haier INTELIUS 50 tumble dryer uses the same label F31 for a condenser thermal sensor fault, a different appliance.
Most common causeGas pipe circuit C temperature probe faulty — sensor disconnected, broken, or poorly positioned (M3 Table A p.31).
Safe to check yourself?No — no fix step exists in any manual read. Switch the unit off, note which indoor unit / circuit C is affected, and call a technician; checking or replacing the outdoor gas-pipe-C probe is technician work on the outdoor unit.
Checked againstHaier European HVAC Technical Book 2024-25, DIAGNOSTIC Table A (Mono Residential and Multi Units) (Table A p.31); Haier FlexFit Series Multi Zone Split System Heat Pump Service Manual, 3U24MS2VHB (outdoor units 2U18/3U24/4U36MS2VHB, R410A, US), Error Codes (p.112 + p.35); Haier haier-ac.pt Cod.-Erros-Condutas-Alta-Pest.pdf (Round way cassette / cassette / convertible / duct unit troubleshooting, outdoor units 3U/4U/5U) (p.428); Haier 4U36MS2VHB Service Manual, MID-STATIC DUCTED TECHNICAL OVERVIEW, Error Codes (p.92) - numeric corroboration only

Applies to — read this first

Read this first, because F31 is a split-wall/ductless Table A code — it means the gas pipe circuit C temperature sensor on multi-split outdoor units (3U/4U/5U). The gas-pipe circuit sensors live on multi-split outdoor units; a single-split (mono) unit has only circuit A, but its single-split manuals (M2, M7) do not list F31 at all, so a reader with a single-split unit will never see it in their manual either. If your unit shows F31, it is a multi-split outdoor unit fault on circuit C. Cabinet Table B has NO F31 at all, and the old fixed-speed lamp table has no F31. Check the model and series, not just the letters.

What the machine does when F31 fires

The indoor display shows F31 in place of the set temperature, and the outdoor PCB LED1 flashes 34 times (two-LED boards: LED1 5 + LED2 4 = code 54). The outdoor board cannot read the gas-pipe-C probe, so it cannot run the multi-split outdoor unit correctly.

Common causes

  1. Sensor disconnected (M3 Table A p.31).
  2. Sensor broken (M3 Table A p.31).
  3. Sensor poorly positioned (M3 Table A p.31).

Safe checks, in order

  1. Switch the unit off.
  2. Note which indoor unit / circuit C is affected, then call a technician — checking or replacing the outdoor gas-pipe-C probe is technician work on the outdoor unit. No manual gives a procedure, a resistance value, or a plug check for F31, so this page does not invent one.

There is NO F31 flowchart and NO fix step in any manual: the full extent of the manual evidence is the M3 Table A row-34 cause ("Sensor disconnected, broken, or poorly positioned"), the M8 p.112/p.35 table rows and the M9 p.428 table row. No lockout rule ("3 times in an hour") is stated for the F31 row in any manual — do not claim one. No detection window is stated for F31 — the 60-second short/open-circuit window is verified only for F6/F7/F21/F25 (M3 rows 10-13); do not claim it for F31. Do NOT present other sensors' steps (e.g. E1 indoor-sensor steps, or F6 ambient-sensor steps) as F31 steps. Do NOT present the dryer F31 (condenser thermal sensor) as the air-conditioner F31. F31 is a one-row code in every manual: keep it short, do not pad with invented diagnostics.

When to call a technician

  • F31 returns after a restart — the outdoor gas-pipe-C probe needs checking or replacing.
  • The outdoor LED1 flashes 34 times — gas pipe circuit C (F17, the liquid pipe sensor on the same circuit, is 30).
  • Any burning smell or visible damage — switch off and call a qualified technician.

More guidance: when an appliance error requires professional service.

Safety first

The outdoor gas-pipe-C probe is on the outdoor unit: checking or replacing it is qualified-technician work. Never open the outdoor unit while it is connected to power.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does F31 mean on a Haier split air conditioner?

F31 means the gas pipe circuit "C" temperature probe (sensor) has failed — the gas-pipe temperature sensor on refrigerant circuit C of the multi-split outdoor unit is disconnected, broken, or poorly positioned. The indoor display shows F31 and the outdoor PCB LED1 flashes 34 times (M3 Table A p.31; M8 FlexFit p.112; M9 haier-ac.pt p.428).

I found "F31 = condenser thermal sensor" — is that the same code?

No. That meaning belongs to the Haier INTELIUS 50 tumble dryer, whose manual groups F31/F32/F33 as "condenser thermal sensor open-circuited or short-circuited". It is a dryer fault, not an air-conditioner fault. On a Haier air conditioner, F31 is the gas pipe circuit C temperature sensor. Check which appliance you have before using any F31 meaning.

Is F31 the same as F17?

No. F17 is the LIQUID pipe sensor on circuit C (LED 30); F31 is the GAS pipe sensor on the same circuit C (LED 34). Same circuit letter, different pipe — the outdoor unit has one liquid-pipe sensor and one gas-pipe sensor per circuit. Do not merge them.

Can a single-split Haier show F31?

Not in any manual read. The single-split manuals (M2, M7) do not list F31 at all, and the gas-pipe circuit sensors live on multi-split outdoor units (3U/4U/5U). If your unit shows F31, it is a multi-split outdoor unit fault on circuit C.

Can I fix Haier F31 myself?

No fix step exists in any manual read. The manuals give only the table row plus M3's cause ("Sensor disconnected, broken, or poorly positioned"). Switch the unit off, note that it is circuit C, and call a technician to check or replace the outdoor gas-pipe-C probe. Do not follow guides that tell you to use another sensor's fix for F31.
