Haier Split Air Conditioner Error Code F30

Quick answer

Error codeF30 — Haier Split Air Conditioner
What it meansF30 = gas pipe circuit "B" temperature probe (sensor) failure — the gas-pipe temperature sensor on refrigerant circuit B of the multi-split outdoor unit is faulty: sensor disconnected, broken, or poorly positioned. The indoor display shows F30 and the outdoor PCB LED1 flashes 33 times (two-LED boards: LED1 5 + LED2 3 = code 53). All three F-label manuals agree on code, meaning, circuit letter and flash count. Do NOT confuse this displayed F30 with the hidden F30* in the same FlexFit manual ("High outdoor suction temperature", no LED number, shown only after holding the Emergency button 15 seconds) — a different fault under the same label.
Most common causeGas pipe circuit B temperature probe faulty — sensor disconnected, broken, or poorly positioned (M3 Table A p.31).
Safe to check yourself?No — no fix step exists in any manual read for the displayed F30. Switch the unit off, note which indoor unit / circuit B is affected, and call a technician; checking or replacing the outdoor gas-pipe-B probe is technician work on the outdoor unit.
Checked againstHaier European HVAC Technical Book 2024-25, DIAGNOSTIC Table A (Mono Residential and Multi Units) (Table A p.31); Haier FlexFit Series Multi Zone Split System Heat Pump Service Manual, 3U24MS2VHB (outdoor units 2U18/3U24/4U36MS2VHB, R410A, US), Error Codes (p.112 + p.35); Haier haier-ac.pt Cod.-Erros-Condutas-Alta-Pest.pdf (Round way cassette / cassette / convertible / duct unit troubleshooting, outdoor units 3U/4U/5U) (p.428); Haier 4U36MS2VHB Service Manual, MID-STATIC DUCTED TECHNICAL OVERVIEW, Error Codes (p.92) - numeric corroboration only

Applies to — read this first

Read this first, because F30 is a split-wall/ductless Table A code — it means the gas pipe circuit B temperature sensor on multi-split outdoor units (3U/4U/5U). The gas-pipe circuit sensors live on multi-split outdoor units; a single-split (mono) unit has only circuit A, but its single-split manuals (M2, M7) do not list F30 at all, so a reader with a single-split unit will never see it in their manual either. If your unit shows F30, it is a multi-split outdoor unit fault on circuit B. Cabinet Table B has NO F30 at all, and the old fixed-speed lamp table has no F30. Check the model and series, not just the letters.

What the machine does when F30 fires

The indoor display shows F30 in place of the set temperature, and the outdoor PCB LED1 flashes 33 times (two-LED boards: LED1 5 + LED2 3 = code 53). The outdoor board cannot read the gas-pipe-B probe, so it cannot run the multi-split outdoor unit correctly.

Common causes

  1. Sensor disconnected (M3 Table A p.31).
  2. Sensor broken (M3 Table A p.31).
  3. Sensor poorly positioned (M3 Table A p.31).

Safe checks, in order

  1. Switch the unit off.
  2. Note which indoor unit / circuit B is affected, then call a technician — checking or replacing the outdoor gas-pipe-B probe is technician work on the outdoor unit. No manual gives a procedure, a resistance value, or a plug check for F30, so this page does not invent one.
  3. Do NOT treat the hidden F30* ("High outdoor suction temperature") as this fault: it has no LED number, never appears on the indoor display by itself, and is shown only by pressing and holding the Emergency button for 15 seconds (M8 p.112).

There is NO flowchart and NO fix step in any manual for the displayed F30: the full extent of the manual evidence is the M3 Table A row-33 cause ("Sensor disconnected, broken, or poorly positioned"), the M8 p.112/p.35 table rows and the M9 p.428 table row. No lockout rule ("3 times in an hour") is stated for the F30 row in any manual — do not claim one. No detection window is stated for F30 — the 60-second short/open-circuit window is verified only for F6/F7/F21/F25 (M3 rows 10-13); do not claim it for F30. Do NOT present other sensors' steps (e.g. E1 indoor-sensor steps, or F6 ambient-sensor steps) as F30 steps. Do NOT present the hidden F30* "high outdoor suction temperature" as the displayed F30's meaning. F30 is a one-row code in every manual: keep it short, do not pad with invented diagnostics.

When to call a technician

  • F30 returns after a restart — the outdoor gas-pipe-B probe needs checking or replacing.
  • The outdoor LED1 flashes 33 times — gas pipe circuit B (F16, the liquid pipe sensor on the same circuit, is 29).
  • Any burning smell or visible damage — switch off and call a qualified technician.

More guidance: when an appliance error requires professional service.

Safety first

The outdoor gas-pipe-B probe is on the outdoor unit: checking or replacing it is qualified-technician work. Never open the outdoor unit while it is connected to power.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does F30 mean on a Haier split air conditioner?

F30 means the gas pipe circuit "B" temperature probe (sensor) has failed — the gas-pipe temperature sensor on refrigerant circuit B of the multi-split outdoor unit is disconnected, broken, or poorly positioned. The indoor display shows F30 and the outdoor PCB LED1 flashes 33 times (M3 Table A p.31; M8 FlexFit p.112; M9 haier-ac.pt p.428).

I saw "F30 = high outdoor suction temperature" somewhere — is that the same F30?

No, and this is a real trap. The FlexFit service manual lists a second, hidden code "F30*" meaning "High outdoor suction temperature" — it has no LED number and never appears on the indoor display by itself; you only see it by pressing and holding the emergency button for 15 seconds. The F30 your indoor unit displays is the gas pipe circuit B sensor fault (LED 33). Different faults, same label.

Is F30 the same as F16?

No. F16 is the LIQUID pipe sensor on circuit B (LED 29); F30 is the GAS pipe sensor on the same circuit B (LED 33). Same circuit letter, different pipe — the outdoor unit has one liquid-pipe sensor and one gas-pipe sensor per circuit. Do not merge them.

Can a single-split Haier show F30?

Not in any manual read. The single-split manuals (M2, M7) do not list F30 at all, and the gas-pipe circuit sensors live on multi-split outdoor units (3U/4U/5U). If your unit shows F30, it is a multi-split outdoor unit fault on circuit B.

Can I fix Haier F30 myself?

No fix step exists in any manual read. The manuals give only the table row plus M3's cause ("Sensor disconnected, broken, or poorly positioned"). Switch the unit off, note that it is circuit B, and call a technician to check or replace the outdoor gas-pipe-B probe. Do not follow guides that tell you to use another sensor's fix for F30.
