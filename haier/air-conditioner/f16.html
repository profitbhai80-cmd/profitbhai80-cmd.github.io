Haier Split Air Conditioner Error Code F16

Quick answer

Error codeF16 — Haier Split Air Conditioner
What it meansF16 = liquid pipe circuit 'B' temperature probe failure — the liquid-pipe temperature sensor for indoor unit / circuit B is disconnected, broken, or poorly positioned. The indoor display shows F16; the outdoor error number is 29. The '29' is the outdoor error/LED code, NOT an LED1 flash count — M2, which supplies flash counts, does not list F16. Multi-split ONLY: circuit B exists only where a multi-split outdoor unit serves a second indoor unit (3U/4U/5U). A single-split (mono) system physically has no circuit B, so F16 cannot be a real circuit-B sensor fault on a single-split display — if a single-split unit shows F16, the board/display is at fault, not a circuit-B sensor.
Most common causeSensor disconnected, broken, or poorly positioned (M3 Table A cause).
Safe to check yourself?No — no fix step exists in any manual. Switch the unit off and call a technician; checking or replacing the circuit-B liquid-pipe sensor is technician work on the outdoor/multi-split piping.
Checked againstHaier European HVAC Technical Book 2024-25, DIAGNOSTIC Table A (Mono Residential and Multi Units), pp.30–31; Haier FlexFit 3U24MS2VHB Service Manual, Error Codes table (p.112); Haier 4U36MS2VHB Service Manual, Error Codes table (p.92); haier-ac.pt ducted/cassette troubleshooting table (Cod.-Erros-Condutas-Alta-Pest.pdf)

Applies to — read this first

Read this first, because F16 is a split-wall/ductless Table A code — it means the liquid pipe circuit 'B' temperature probe has failed on the EU mono residential/multi range, the US FlexFit multi-zone/console and mid-static ducted ranges, and the EU cassette/convertible/duct ranges on 3U/4U/5U outdoor units (M3/FlexFit/haier-ac.pt, all agreeing on outdoor error 29 and circuit B). F16 is NOT in M2 (US ductless split, p.43) and NOT in M7 (1U26MADFRA, p.25) — do not claim M2/M7 corroboration. The same book's Commercial and Cabinet tables call F16 a DIFFERENT fault — 'Lack of refrigerant / clogging of refrigerant delivery tube' — while in Table A that fault is F13. Check the model and series, not just the letters.

What the machine does when F16 fires

The indoor display shows F16 in place of the set temperature, and the outdoor error number is 29. The liquid-pipe temperature sensor for indoor unit / circuit B has failed — disconnected, broken, or poorly positioned — so the outdoor unit cannot read that circuit's liquid-pipe temperature.

Common causes

  1. Sensor disconnected, broken, or poorly positioned (M3 Table A cause).

Safe checks, in order

  1. Switch the unit off.
  2. Call a technician to check or replace the circuit-B liquid-pipe sensor — there is no owner fix step in any manual.
  3. If the system is a single-split (one indoor, one 1U outdoor), tell the technician: there is no circuit-B sensor to fail, so the board or display is at fault.
  4. Do not follow guides that point you at the compressor's 'running state-detecting circuit' for F16 — no manual links that circuit to F16.

No power-cycle reset time, resistance value, 'check the plug' step, sensor-replacement procedure or 'clean the sensor' step exists in any manual for F16. Do not claim the 60-second short/open detection window for F16 — M3 gives that window verbatim only for the single-sensor rows (F6/F7/F11/F12/F13/F21/F25), not for the circuit A–E rows. Do not present E1's indoor-sensor steps, F13's refrigerant steps, or any compressor-drive-circuit steps as F16 steps.

When to call a technician

  • F16 returns after a restart — the circuit-B liquid-pipe sensor needs diagnosis.
  • Outdoor error 29 — liquid pipe circuit B (F10 is circuit A, 28; F17 is circuit C, 30; F18 is circuit D, 31).
  • A single-split unit shows F16 — there is no circuit B, so the board or display is at fault.
  • Any burning smell or visible damage — switch off and call a qualified technician.

Safety first

No owner repair exists in any manual for this code. Never open the indoor or outdoor unit while it is connected to power, and never attempt refrigerant, gas or high-voltage work without the proper qualifications.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does F16 mean on a Haier split air conditioner?

F16 means the liquid pipe circuit 'B' temperature probe has failed — the liquid-pipe temperature sensor for indoor unit / circuit B is disconnected, broken, or poorly positioned (M3 Table A; FlexFit 3U24MS2VHB p.112; 4U36MS2VHB p.92; haier-ac.pt ducted PDF). Outdoor error number 29.

Can F16 appear on a single-split air conditioner?

No — not as a real sensor fault. Circuit B exists only on a multi-split outdoor unit serving a second indoor unit. If a single-split unit (one indoor, one 1U outdoor) shows F16, there is no circuit-B sensor to fail; the board or display is at fault. Tell the technician the system is single-split.

Is F16 a refrigerant problem?

No — not in Table A. F16 is a temperature-sensor fault (circuit B liquid pipe). Lack of refrigerant is F13 in Table A. Confusingly, the same book's Commercial and Cabinet tables call F16 'lack of refrigerant' — that is the other numbering system, not Table A. On a mono-residential/multi unit, use the Table A meaning above.

Can I fix Haier F16 myself?

No fix step exists in any manual read. The manuals give only the table row plus M3's cause ('Sensor disconnected, broken, or poorly positioned'). Switch the unit off and call a technician to check or replace the circuit-B liquid-pipe sensor. Do not follow guides that point you at the compressor's 'running state-detecting circuit' for F16 — no manual links that circuit to F16.

How is F16 different from F10 and F17?

Same sensor type (liquid-pipe temperature probe), different circuits: F10 = circuit A (outdoor 28), F16 = circuit B (outdoor 29), F17 = circuit C (outdoor 30). The gas-pipe counterparts are F29 (A), F30 (B) and F31 (C). Each circuit has its own code — never merge them.
