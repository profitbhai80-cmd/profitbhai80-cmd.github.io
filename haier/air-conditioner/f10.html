Haier Split Air Conditioner Error Code F10

Quick answer

Error codeF10 — Haier Split Air Conditioner
What it meansF10 = liquid pipe circuit 'A' temperature probe failure — the liquid-pipe temperature sensor for indoor unit / circuit A is disconnected, broken, or poorly positioned. The indoor display shows F10; the outdoor error number is 28. The '28' is the outdoor error/LED code, NOT an LED1 flash count — M2, which supplies flash counts, does not list F10. F10 carries no '*' hidden-code marker in FlexFit p.112, so it displays directly on the indoor unit.
Most common causeSensor disconnected, broken, or poorly positioned (M3 Table A cause).
Safe to check yourself?No — no fix step exists in any manual. Switch the unit off and call a technician; checking or replacing the circuit-A liquid-pipe sensor is technician work on the outdoor/multi-split piping.
Checked againstHaier European HVAC Technical Book 2024-25, DIAGNOSTIC Table A (Mono Residential and Multi Units), pp.30–31; Haier FlexFit 3U24MS2VHB Service Manual, Error Codes table (p.112); Haier 4U36MS2VHB Service Manual, Error Codes table (p.92); haier-ac.pt ducted/cassette troubleshooting table (Cod.-Erros-Condutas-Alta-Pest.pdf)

Applies to — read this first

Read this first, because F10 is a split-wall/ductless Table A code — it means the liquid pipe circuit 'A' temperature probe has failed on the EU mono residential/multi range, the US FlexFit multi-zone/console and mid-static ducted ranges, and the EU cassette/convertible/duct ranges on 3U/4U/5U outdoor units (M3/FlexFit/haier-ac.pt, all agreeing on outdoor error 28 and circuit A). F10 is NOT in M2 (US ductless split, p.43) and NOT in M7 (1U26MADFRA, p.25) — do not claim M2/M7 corroboration. The same book's Commercial and Cabinet tables call F10 a DIFFERENT fault — the outdoor defrosting temperature probe (Te) — while in Table A the defrost sensor is F21. Check the model and series, not just the letters.

What the machine does when F10 fires

The indoor display shows F10 in place of the set temperature, and the outdoor error number is 28. The liquid-pipe temperature sensor for indoor unit / circuit A has failed — disconnected, broken, or poorly positioned — so the outdoor unit cannot read that circuit's liquid-pipe temperature.

Common causes

  1. Sensor disconnected, broken, or poorly positioned (M3 Table A cause).

Safe checks, in order

  1. Switch the unit off.
  2. Call a technician to check or replace the circuit-A liquid-pipe sensor — there is no owner fix step in any manual.
  3. Do not follow guides that tell you to check the power supply for F10 — 'No AC power supply' is a wrong list-page meaning, not a manual one.

No power-cycle reset time, resistance value, 'check the plug' step, sensor-replacement procedure or 'clean the sensor' step exists in any manual for F10. Do not claim the 60-second short/open detection window for F10 — M3 gives that window verbatim only for the single-sensor rows (F6/F7/F11/F12/F13/F21/F25), not for the circuit A–E rows. Do not present E1's indoor-sensor steps or F21's defrost-sensor steps as F10 steps.

When to call a technician

  • F10 returns after a restart — the circuit-A liquid-pipe sensor needs diagnosis.
  • Outdoor error 28 — liquid pipe circuit A (F16 is circuit B, 29; F17 is circuit C, 30; F18 is circuit D, 31).
  • Any burning smell or visible damage — switch off and call a qualified technician.

Safety first

No owner repair exists in any manual for this code. Never open the indoor or outdoor unit while it is connected to power, and never attempt refrigerant, gas or high-voltage work without the proper qualifications.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does F10 mean on a Haier split air conditioner?

F10 means the liquid pipe circuit 'A' temperature probe has failed — the liquid-pipe temperature sensor for indoor unit / circuit A is disconnected, broken, or poorly positioned (M3 Table A; FlexFit 3U24MS2VHB p.112; 4U36MS2VHB p.92; haier-ac.pt ducted PDF). Outdoor error number 28.

Is F10 the same as the defrost sensor fault?

No. F10 is the liquid-pipe circuit-A sensor. The defrosting temperature sensor is F21 in Table A. Confusingly, the same book's Commercial and Cabinet tables call F10 the defrosting (Te) probe — that is the other numbering system, not Table A. On a mono-residential/multi unit, use the Table A meaning above.

Can F10 appear on a single-split air conditioner?

F10 is a multi-split circuit code: circuits A–E exist where one outdoor unit serves several indoor units (3U/4U/5U). Circuit A is the first indoor unit, so F10 can appear on a multi-split; a single-split outdoor unit has only one circuit and no circuit B–E (F16/F17 cannot occur there at all).

Can I fix Haier F10 myself?

No fix step exists in any manual read. The manuals give only the table row plus M3's cause ('Sensor disconnected, broken, or poorly positioned'). Switch the unit off and call a technician to check or replace the circuit-A liquid-pipe sensor. Do not follow guides that tell you to check the power supply for F10 — 'No AC power supply' is a wrong list-page meaning, not a manual one.

How is F10 different from F16 and F17?

Same sensor type (liquid-pipe temperature probe), different circuits: F10 = circuit A (outdoor 28), F16 = circuit B (outdoor 29), F17 = circuit C (outdoor 30). The gas-pipe counterparts are F29 (A), F30 (B) and F31 (C). Each circuit has its own code — never merge them.
