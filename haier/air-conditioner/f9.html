Haier Split Air Conditioner Error Code F9

Quick answer

Error codeF9 — Haier Split Air Conditioner
What it meansF9 = power module reset — the outdoor power module (MCU) has reset. The outdoor PCB LED1 flashes 26 times. The three manuals phrase it differently — M3 says "Power module reset", M7 says "Module reset", FlexFit/4U36/haier-ac.pt say "MCU reset" — but it is one fault. M3's entire cause entry is "Reset the faulty system / power module". F9 has nothing to do with pressure.
Most common causeThe outdoor power module (MCU) has reset — M3's cause entry, in full, is "Reset the faulty system / power module".
Safe to check yourself?No — no reset procedure exists in any manual. Switch the unit off and call a technician; a module that keeps resetting is a technician fault (power module / outdoor PCB).
Checked againstHaier European HVAC Technical Book 2024-25 (haierhvac.eu), DIAGNOSTIC Table A p.31; Haier 1U26MADFRA Room Air Conditioner Installation Manual (Sept 2024, R32, AU/NZ), Outdoor Unit Troubleshooting p.25; Haier FlexFit Series Multi Zone Split System Heat Pump Service Manual (3U24MS2VHB), Console Technical Overview p.112; Haier 4U36MS2VHB Service Manual, Mid-Static Ducted Technical Overview p.92; haier-ac.pt Outdoor Unit Trouble Shooting (1U105S2SS1FA etc.), p.428

Applies to — read this first

Read this first, because F9 is a split-wall/ductless Table A code — it means power module reset on the EU mono residential / multi range, the AU/NZ R32 split families and the US FlexFit multi-zone consoles (M3/M7/FlexFit, identical LED count of 26), with numeric corroboration from the 4U36 ducted table and haier-ac.pt. The US ductless split manual (M2) does NOT list F9. The cabinet 14kW table (M3 Table B) has NO F9: its F09 is "DC fan motor failure". The old fixed-speed lamp table has no F9 at all. Check the model and series, not just the letters — and do not confuse code F26 with F9's LED1 count of 26.

The ranking pages get F9 wrong. acerrorcode, the #1 list page, says F9 is "Low pressure abnormal" — wrong: low pressure is F40 (low pressure switch alarm) / F42 (low system pressure protection); F9 is a power-module reset. clipzag says F9 typically indicates a problem with the outdoor fan motor — wrong for Haier and not Haier-specific (the outdoor fan motor fault is F8, LED1 9). Arlington has no F9 section at all, and decorexpro has no F9 content. F26 is a DIFFERENT code — Table A F26 is "Gas pipe circuit 'E' temperature probe faulty" (LED1 36); do not confuse code F26 with F9's LED1 count of 26.

What the machine does when F9 fires

The outdoor PCB LED1 flashes 26 times. The outdoor power module (MCU) has reset. M7 marks F9 "Trouble record" rather than "Directly display", i.e. the fault is logged in the unit's trouble history rather than shown straight on the indoor panel (M7 gives no retrieval procedure); FlexFit shows it directly displayed.

Common causes

  1. Power module (MCU) reset (M3 Table A p.31; M7 p.25; FlexFit p.112).
  2. M3's cause, in full: "Reset the faulty system / power module" — no further detail is given in any manual.

Safe checks, in order

  1. Switch the unit off.
  2. Call a technician — no manual gives a reset procedure, button, sequence or waiting time for F9, and unlike F1/F4/F5, M3 gives F9 NO lockout rule at all. A module that keeps resetting needs the power module or outdoor PCB checked.

Do NOT present a generic power-cycle as a manual step — if a power-cycle is mentioned at all, it must be labelled as general advice, not a manual instruction. No "switch off for 5 minutes then on" step, no breaker procedure, no "press reset" step and no "if it resets three times" rule exists in any manual for F9. There is no flowchart for F9 anywhere in M2 pp.44-50. F9 is the thinnest code in this batch — a one-row code whose entire cause column is just the word "reset" — so the page stays short rather than padding with an invented reset procedure.

When to call a technician

  • F9 returns after a restart — the power module or outdoor PCB needs diagnosis by a technician.
  • The outdoor LED1 flashes 26 times — power module reset (code F26 is a different fault: a gas-pipe sensor, LED1 36).
  • Any burning smell or visible damage — switch off and call a qualified technician.

More guidance: when an appliance error requires professional service.

Safety first

A module that keeps resetting is a power-module / outdoor-PCB fault. Never open the outdoor unit while it is connected to power.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does F9 mean on a Haier split air conditioner?

F9 means power module reset: the outdoor power module (MCU) has reset. The outdoor PCB LED1 flashes 26 times (M3 Table A p.31; M7 p.25; FlexFit 3U24MS2VHB p.112). The three manuals phrase it differently — "Power module reset", "Module reset", "MCU reset" — but it is one fault.

Is F9 a low-pressure fault?

No. One list page (acerrorcode) calls F9 "Low pressure abnormal", but no Haier manual supports that. Low-pressure faults are F40 (low pressure switch alarm) and F42 (low system pressure protection). F9 is a power-module reset, not a pressure fault.

How do I reset a Haier F9 error?

Honestly: no manual read gives a reset procedure for F9. M3's entire cause entry is "Reset the faulty system / power module" — no button, no sequence, no waiting time. Do not follow guides that invent a timed power-cycle for F9. Switch the unit off and call a technician; a module that keeps resetting needs the power module or outdoor PCB checked.

Is F9 the same as F26?

No. F9's outdoor LED1 flashes 26 times, but code F26 is a different code entirely: Table A F26 is the gas pipe circuit "E" temperature probe fault (LED1 36). Use the code letter+number on the display, not the flash count, to identify the fault.

Is F9 the same on a Haier cabinet air conditioner?

No. The cabinet 14kW table (M3 Table B) has no code F9: its F09 is "DC fan motor failure". Check whether your unit is a split or a cabinet before using any F-code meaning — and note the site's Gree F9 page is a different brand entirely.
