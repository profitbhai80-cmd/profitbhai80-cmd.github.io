Haier Split Air Conditioner Error Code F21

Quick answer

Error codeF21 — Haier Split Air Conditioner
What it meansF21 = outdoor defrosting (frost-removing) temperature sensor failure — the outdoor unit's defrosting temperature probe (Te) is faulty, in short circuit or open circuit. The indoor display shows F21 and the outdoor PCB LED1 flashes 10 times. M3 adds the detection window: the short/open circuit is detected 'within last 60 seconds'. F21 is a SENSOR fault, not a defrosting failure of the unit itself.
Most common causeThe outdoor defrosting temperature probe (Te) is in short circuit or open circuit within the last 60 seconds (M3 Table A).
Safe to check yourself?No — no fix step exists in any manual read. Switch the unit off and call a technician to check or replace the outdoor defrost probe. Do not use the E1 (indoor sensor) fix for F21 — the sensors are in different units.
Checked againstHaier Ductless Split Air Conditioner Service Manual (US models AW09/12/18/24ES2VHA + 1U09/12/18/24ES2VHA, R410A), Error Codes & Problem Solving (p.43) (p.43); Haier European HVAC Technical Book 2024-25, DIAGNOSTIC Table A (Mono Residential and Multi Units) (Table A pp.28-31); Haier 1U26MADFRA Room Air Conditioner Installation Manual (Sept 2024, R32, AU/NZ), Outdoor Unit Troubleshooting (p.25) (p.25); Haier AS24TD2HRA Service Manual §10.3.1

Applies to — read this first

Read this first, because F21 is a split-wall/ductless Table A code — it means the outdoor defrosting sensor on the US ductless split families, the EU mono/multi range, the AU/NZ R32 split families and the AS24/FlexFit wall-split families (M2/M3/M7, identical LED count of 10). The three manuals name this sensor three ways — M2 'Frost-removing temperature sensor', M3 'Outdoor unit defrosting temperature probe (Te)', M7 'Abnormal of piping sensor' — it is the SAME sensor (the outdoor coil/piping sensor Te), not three faults. The cabinet 14kW table (M3 Table B) carries the same defrosting-probe wording under a different label, F10. The old fixed-speed lamp table has no F21 at all. Check the model and series, not just the letters.

The ranking pages get F21 right and everything around it wrong. acerrorcode gets F21 right in one row ('Defrost temperature sensor fault') but gives no LED count, no 60-second window and no diagnostic — and its F7 row merges suction and defrost ('Outdoor suction/defrosting temp. sensor abnormal' — F7 is suction only, LED1 11; defrost is F21, LED1 10). Arlington gets the meaning and LED1 10 right but its only solution is 'Try the exact solutions as suggested for Error Code E1' — E1 is the INDOOR room sensor, a different sensor in a different unit; the same E1 cross-reference is used for F6, F7, F21 and F25, collapsing four separate outdoor sensors into one indoor fix. decorexpro has no F21 section at all — the defrosting sensor is never mentioned. Note: F21 is a SENSOR fault, not a defrosting failure of the unit itself — the unit is not saying 'defrosting failed', it is saying the sensor that measures the defrost temperature has failed.

What the machine does when F21 fires

The indoor display shows F21 in place of the set temperature, and the outdoor PCB LED1 flashes 10 times. The outdoor board cannot read the defrosting temperature, so it cannot run the outdoor unit correctly.

Common causes

  1. Outdoor defrosting temperature probe (Te) in short circuit (M3).
  2. Outdoor defrosting temperature probe (Te) in open circuit (M3).

Safe checks, in order

  1. Switch the unit off.
  2. Call a technician — the outdoor defrost probe is on the outdoor unit, and its check or replacement is technician work. No manual gives the procedure, a resistance value, or a plug check for F21, so this page does not invent one.

There is NO F21 flowchart and NO fix step in any manual: the full extent of the manual evidence is the M2 p.43 table row, the M3 Table A row-10 cause ('Temperature probe in short circuit or open circuit within last 60 seconds') and the M7 p.25 row. M2's flowcharts (pp.44-50) cover E14, F8, F1, F22/F2/F23, F3, F19, F4, E7 and F11/F28 only. M2 p.51 'Checking the Outdoor Unit Sensors' names the 'Tube sensor (defrost temperature)' in its generic component-check section, but it gives no F21-specific procedure or value — do not present it as an F21 fix. Do NOT follow guides that tell you to use the E1 (indoor sensor) fix for F21, and do not follow decorexpro's generic 'check the connection / replace faulty sensors' — those are the sites' own additions, not manual steps. F21 is a one-row code in every manual: keep it short, do not pad with invented diagnostics.

When to call a technician

  • F21 returns after a restart — the outdoor defrost probe needs checking or replacing.
  • The outdoor LED1 flashes 10 times — defrost sensor (F7 suction is 11, F6 ambient is 12, F25 delivery is 13).
  • Any burning smell or visible damage — switch off and call a qualified technician.

More guidance: when an appliance error requires professional service.

Safety first

The outdoor defrost probe is on the outdoor unit: checking or replacing it is qualified-technician work. Never open the outdoor unit while it is connected to power.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does F21 mean on a Haier split air conditioner?

F21 means the outdoor defrosting temperature sensor (probe) has failed — the probe is in short circuit or open circuit. The indoor display shows F21 and the outdoor PCB LED1 flashes 10 times (M2 p.43; M3 Table A pp.28-31; M7 p.25).

How does the unit detect Haier F21?

The European Technical Book says the fault is a 'Temperature probe in short circuit or open circuit within last 60 seconds' — the outdoor board watches the defrosting probe (Te) and raises F21 when it reads shorted or open.

Can I fix Haier F21 myself?

No fix step exists in any manual read. Unlike F19, F21 has no diagnostic flowchart at all — the manuals give only the table row. Do not follow guides that tell you to use the E1 (indoor sensor) fix for F21: the sensors are in different units. Switch the unit off and call a technician to check or replace the outdoor defrost probe. Note: F21 is a sensor fault, not a failed defrost cycle — the unit is reporting the sensor, not the defrosting itself.

Is F21 the same as F7?

No. F7 is the suction (compressor intake) temperature sensor (LED1 11 flashes); F21 is the defrosting temperature sensor (LED1 10). One list page (acerrorcode) merges them into a single 'suction/defrosting' row under F7 — the manuals keep them as two sensors with two codes. Also do not confuse F21 with F6 (ambient, 12) or F25 (delivery, 13).

Is F21 the same on a Haier cabinet air conditioner?

The fault is the same but the label is different: the cabinet 14kW table (M3 Table B) calls it F10, 'Outdoor unit defrosting temperature probe faulty (Te)', with the same 60-second wording. There is no cabinet code F21 — check whether your unit is a split or a cabinet before using any F-code meaning. Also note that some Haier manuals call this sensor the 'piping sensor' (M7) — same sensor, same code.
