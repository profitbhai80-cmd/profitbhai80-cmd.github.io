Haier Washing Machine Error Code EC1

Quick answer

Error codeEC1 — Haier Washing Machine
What it meansEC1 = heater fault — the water temperature does not change within 10 minutes. The manual's action is unusual: the machine does NOT stop — it continues "washing with cold water" with no heating. No user fix is documented for EC1. This code exists only on the XQG50 220V international washer-dryer models — the HWD1000 table has NO EC1, EC2 or EC3 rows. Do not merge EC1 with digitron top-load heater-adjacent codes, UK-platform Err4 (heater), or EC2/EC5 (sensors).
Most common causeThe wash heater or its circuit is not heating — the manuals give the condition, not a cause tree, and document no user fix.
Safe to check yourself?No user fix is documented. The wash will finish cold; if heating matters (hot programmes), call a technician (likely the wash heater or its circuit). Do not invent checks the manual does not give.

Applies to — read this first

Read this first, because EC1 exists ONLY on the XQG50 220V international washer-dryer models. The HWD1000 user manual's warning-code table contains NO EC1, EC2 or EC3 rows (its labeled table jumps EA3 → EC4) — verified 2026-11-03. If your manual is the HWD1000, this page is not your code. What the machine does when EC1 fires

The display shows EC1 and the machine continues "washing with cold water" — it does NOT stop; the heating is simply bypassed.

Common causes

  1. The water temperature does not change within 10 minutes — the manual's own condition (likely the wash heater or its circuit; the manuals name no cause).

Safe checks, in order

  1. The wash will finish cold — the manual's own action ("No heating and washing with cold water").
  2. If heating matters (hot programmes), call a technician — likely the wash heater or its circuit. The manual documents no user fix; this page invents none.

Stating this honestly: the manuals document no user fix for EC1, so there is no invented fix flow here. The wash finishing cold is the manual's own stated behaviour.

When to call a technician

  • EC1 shows at all — the heater circuit needs a technician (the manuals document no user fix).

Safety first

EC1 involves the heater circuit and mains-powered electronics: never open the machine or touch heater components yourself — the repair is technician work.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does EC1 mean on a Haier washing machine?

EC1 means a heater fault — the water temperature does not change within 10 minutes. It is verified in two Haier manuals: the XQG50-S1216 user manual and the XQG50-S1016 operation manual, both reading "The water temperature unchanged in 10 minutes" with the action "No heating and washing with cold water".

Does the cycle stop on EC1?

No — unusually, the manual says the machine does NOT stop: it continues "washing with cold water" with no heating. If you need hot washes, call a technician.

What is the difference between EC1, EC2 and EC5?

EC1 = heater (water temp not changing, wash continues cold). EC2 = water temperature sensor (circuit short/open, machine stops). EC5 = dry temperature sensor (circuit short/open, machine stops). Three different rows, three different faults.

Does my HWD1000 have EC1?

No — the HWD1000 table has no EC1, EC2 or EC3 rows (its table jumps EA3 → EC4). EC1 exists only on the XQG50 220V international models.
