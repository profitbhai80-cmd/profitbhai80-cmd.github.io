Haier Washing Machine Error Code FC

Quick answer

Error codeFC — Haier Washing Machine
What it meansFC = abnormal communication error, shown as FC0, FC1 or FC2 depending on family: on HW7014829, FC1 is a display-board/motor communication error and FC2 is a display-board/power-board communication error; on HLC1700AXS, FC is no feedback signal from the driver unit. Contact after-sales service. Front-load families only.
Most common causeThe control boards have lost communication with each other. The manuals name no cause beyond the communication error itself and prescribe no user diagnosis.
Safe to check yourself?No user repair step exists: the manuals print 'contact after-sales service' as the solution. Confirm the variant, power-cycle once, then call service.
Checked againstHaier HW80/HW100/HW120-B14979 §9.2 (FC0/FC1/FC2 abnormal communication error); Haier HW7014829 (FC1/FC2 split); Haier HW70-B14929-S; Haier HLC1700AXS (no feedback from driver unit)

Applies to — read this first

FC is one fault with display variants, not three faults — which is why this is one page with a variant table, not three pages. B14979 prints 'FC0 or FC1 or FC2: abnormal communication error'; HW7014829 splits FC1 (display board and motor) from FC2 (display board and power board); the HLC1700AXS washer-dryer prints plain FC as 'no feedback signal from driver unit.' All prescribe contact-service. Splitting the variants into separate pages would triple-count one fault.

Two competitor errors this page corrects: one table merges Unb with FC1 (unbalanced load and a communication fault are unrelated faults — the merge would send communication-fault owners to redistribute laundry), and communication advice must not be borrowed for F7 (F7 is the motor).

What the machine does when FC fires

The boards stop talking: depending on family, the machine may become unresponsive during cycles or stop altogether, since the display and control boards cannot exchange signals. The manuals' outcome is to stop and arrange service.

Common causes

  1. Abnormal communication between the control boards (display, main PCB, motor/power boards) — the manuals' full extent of the diagnosis.

Safe checks, in order

  1. Confirm the exact variant on the display: FC0, FC1, FC2 or plain FC — note it down, because FC1 and FC2 name different board pairs on HW7014829.
  2. Power-cycle once: switch off, unplug for a few minutes, plug back in and retry. If FC returns, the communication fault is genuine.
  3. Contact after-sales service with the exact variant — that is the manual's own solution, and there is no user step beyond it.

Work through the checks in order and stop as soon as the code clears. Do not reseat board connectors or open the control area yourself: the manuals prescribe contact-service only.

When to call a technician

  • FC returns after a power-cycle — the communication fault is genuine; call after-sales service.
  • The machine is unresponsive or stuck with no display updates — do not keep cycling power; arrange service.

More guidance: when an appliance error requires professional service.

Safety first

Board-level communication faults involve the main PCB and internal wiring harnesses. Never open the control area or reseat connectors yourself — the manuals say to contact after-sales service.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does FC mean on a Haier washing machine?

FC is an abnormal communication error between the control boards, shown as FC0, FC1 or FC2 depending on family. On HW7014829, FC1 = display-board/motor and FC2 = display-board/power-board; on HLC1700AXS, FC = no feedback signal from driver unit.

Is Haier FC1 an unbalanced load?

No. One competitor table merges Unb with FC1, but they are unrelated faults: Unb = unbalanced load, FC1 = communication error. Redistributing laundry does not fix a communication fault.

Is Haier FC the same as F7?

No. F7 = motor error; FC = communication error between boards. Different faults, different codes.

Can I fix Haier FC myself?

The manuals prescribe no user step — only contact after-sales service. You can confirm the variant and power-cycle once; beyond that it is a service matter.
