Haier Washing Machine Error Code Unb

Quick answer

Error codeUnb — Haier Washing Machine
What it meansUnb = unbalanced load error: check and balance the laundry load in the drum and reduce the load if needed. Front-load families — on these machines the code is Unb, while top-load imbalance is E3 (a separate code system). Includes the single-item case: one heavy item alone can trigger it.
Most common causeUnevenly distributed laundry — clumped to one side, overloaded, or a single heavy item washed alone.
Safe to check yourself?Yes — Unb is user-fixable: check, balance, reduce the load, and restart. The manuals' own solution.
Checked againstHaier HW80/HW100/HW120-B14979 §9.2; Haier HW70B1426S; Haier HW70-B14929-S; Haier HLC1700AXS (spin low speed / drying cancelled); Haier HWF5300AW (UNB unbalance, single item)

Applies to — read this first

Unb is the front-load imbalance code, and the single most useful fact for a Haier owner is the family split: on these front-load machines imbalance is Unb, while top-load imbalance is E3 — a separate page and a different system. Five manuals agree on Unb's meaning; the HWF5300AW manual adds the single-item case ('not recommended to wash a single item'); the HLC1700AXS washer-dryer manual notes the presentation — spin runs at low speed and drying is cancelled.

Haier HW80/HW100/HW120-B14979 §9.2Unb: unbalanced load error; check and balance laundry load in the drum; reduce the load.
Haier HW70B1426S user manualUnb: unbalanced load and not able to spin; check and balance, reduce if too heavy, restart with a spin programme.

Haier top-load E3 — do not borrowOn Haier top-load machines the imbalance code is E3, not Unb. Front-load owners reading top-load advice (and vice versa) would follow the wrong code.

Competitors pad Unb with transit-bolt and suspension causes the Haier manuals do not name for Unb, and one table merges Unb with FC1 (a communication fault). This page stays with the manuals: balance, reduce, restart — and the front-load Unb vs top-load E3 split no competitor states.

What the machine does when Unb fires

The machine detects the imbalance and will not spin normally: HW70B1426S notes it is 'not able to spin,' and the HLC1700AXS manual describes the washer-dryer presentation — spin at low speed and drying cancelled. The machine is protecting its suspension and bearings, not reporting a broken part.

Common causes

  1. Laundry clumped on one side of the drum.
  2. Overloading — too much laundry for the load to balance.
  3. A single heavy item washed alone (the HWF5300AW case).
  4. Laundry tangled together so it spins as one lump.

Safe checks, in order

  1. Stop the cycle and check the load: balance the laundry in the drum and reduce the load if it is too heavy.
  2. If there is a single heavy item, add a couple of similar items (like towels) so the load can balance — do not wash one heavy item alone.
  3. Redistribute by hand, close the door, and restart with a spin programme (the HW70B1426S sequence); on HWF5300AW the manual says to cut power, redistribute, then restart.
  4. If Unb recurs with balanced, correctly sized loads, stop and call service — persistent imbalance with correct loading is beyond the manuals' home steps.

Work through the steps in order and stop as soon as the spin runs. Unb is a protection behaviour — the machine is telling you about the load, not itself.

When to call a technician

  • Unb recurs with every load even when loading is balanced and correctly sized.
  • Violent shaking or banging that continues after redistribution — suspension wear is a technician's diagnosis.

Safety first

Unb is a load warning, not an electrical fault. Never reach into the drum while the machine is attempting to spin — let it stop completely before opening the door.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does Unb mean on a Haier washing machine?

Unb is an unbalanced load error on front-load families: check and balance the laundry load in the drum and reduce the load. HW70B1426S adds: restart with a spin programme.

Is Haier Unb the same as E3?

No — and this is the split to know. On these front-load machines the imbalance code is Unb; on Haier top-load machines imbalance is E3. Same symptom, different code systems.

Can washing one item cause Haier Unb?

Yes. The HWF5300AW manual says it is not recommended to wash a single item: one heavy item alone can trigger Unb. Add a couple of similar items to balance the load.

My Haier dryer cancelled drying with Unb — why?

On the HLC1700AXS washer-dryer, Unb's presentation is: unbalanced load, spin at low speed, and drying cancelled. Fix the balance and the drying will return on the next cycle.
