Haier Washing Machine Error Code E6

Quick answer

Error codeE6 — Haier Washing Machine
What it meansE6 means the water level sensor is bad, per seven Haier top-load user manuals that print the identical row: 'The digitron displays E6. The water level sensor is bad. Please contact the after-sales service department.' No home remedy is documented — this is a service-centre code, not a cleaning or hose-checking code.

Safe to check yourself?Only the power-cycle check. Everything else about E6 — sensor testing, sensor replacement — is service-staff work under the manuals' own instruction not to repair it yourself.

Applies to — read this first

E6 is a template top-load code with a single, consistent meaning: the water level sensor is bad. Seven Haier top-load user manuals print the identical row, and every one of them routes you to after-sales service — no home fix is documented anywhere. The critical scope note: this is NOT the code for the level-sensor fault on every Haier washer. On HLT/GWT models the same fault is E5, and on B14979 front-loads it is FA. Check your model family on the rating label before you act — see how to find your model number.

Do not read the template E6 meaning onto those families — and do not read their codes onto template models.

Do not confuse E6 with Err6: Err6 on Err-system documents is a motor speed fault (tachometer) — a different code system entirely. Do not confuse E6 with Haier dishwasher E6 either: the dishwasher manual gives E6 only as a 'contact the nearest authorised service centre' code with no stated meaning, on a different appliance.

What the machine does when E6 fires

The digitron displays E6 and the machine does not proceed: with the water level sensor bad, the control board cannot trust the level readings it needs to run a programme. The manuals document no behaviour beyond the code itself and no home remedy — the remedy is after-sales service.

Common causes

  1. The water level sensor is bad — the only reason the template manuals state for E6. The sensor can no longer report the water level to the control board, so the machine cannot run a programme on level readings it cannot trust.
  2. No user-serviceable cause is documented: the manuals' only remedy for E6 is 'Please contact the after-sales service department,' and they forbid user repair ('Do not repair it by yourself').

Safe checks, in order

  1. Confirm your model is a template top-load family (HWM70-0588H, HWM65-0528, HWM85-728, HWM100-828A, HWM65-0566, HWM80-0566, or HWM80-928NZP) — E6 exists only there. See our guide to finding your model number. If yours is an HLT/GWT model, see the E5 guide; if a B14979 front-load, the fault code is FA.
  2. Power-cycle once: switch the machine off, unplug it, wait a few minutes, plug it back in, and switch on — ruling out a display or control glitch. Note the exact code and model number before you call.
  3. If E6 returns, stop: the manuals' remedy is after-sales service, and they forbid user repair. Do not remove panels, test the sensor, or replace parts yourself — book the service call with the model number and the E6 code ready.

Work through the checks in order and stop as soon as the code clears. E6 has no manual-documented home fix beyond the power cycle — every generic checklist you may find elsewhere (clean the filter, check the hoses) belongs to other codes, not E6. If a check needs the machine opened or a part tested, it is no longer a safe home check — skip to the technician section.

When to call a technician

  • E6 returns after a power cycle — the water level sensor fault is confirmed as a service matter.
  • E6 on an HLT/GWT or B14979 model — that model has no E6, so check the code again against its own manual (E5 or FA respectively).
  • Any burning smell, smoke, sparking, or water near electrical parts — switch off immediately and call a qualified technician.

Safety first

Unplug the machine before doing anything around it, and never open the machine or touch internal parts: the manuals state the customer must not repair it themselves. Water and electricity are a dangerous mix — mop up any spills and never work on a powered machine with wet hands. If you notice a burning smell, smoke, or water near electrical parts, switch the machine off and call a qualified technician.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does E6 mean on a Haier washing machine?

On the template top-load families (HWM70-0588H, HWM65-0528, HWM85-728, HWM100-828A, HWM65-0566, HWM80-0566, HWM80-928NZP), E6 means the water level sensor is bad. All seven manuals use the identical wording and the identical remedy: contact the after-sales service department.

Can I fix Haier washer E6 myself?

No home fix is documented in any of the manuals. Power-cycle once to rule out a glitch; if E6 returns, contact after-sales service. The manuals forbid user repair — do not open the machine or attempt a sensor replacement yourself.

Is Haier E6 a temperature sensor error?

No — one ranking page claims that, but every template manual defines E6 as the water level sensor fault. The temperature sensor code on Haier front-loads is F3 (B14979 §9.2), not E6. Replacing a temperature sensor for an E6 code would fix nothing.

My Haier washer shows E5 for a level sensor fault, not E6. Is this page wrong?

No — the code depends on the family. The level-sensor fault is E6 on template top-loads, E5 on HLT364XXQ and GWT900AW/GWT700AW/GWT800AW models, and FA on B14979 front-loads. Check your model family; if yours is an HLT/GWT model, see our Haier washing machine E5 guide instead.
