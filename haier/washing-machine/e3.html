Haier Washing Machine Error Code E3

Quick answer

Error codeE3 — Haier Washing Machine
What it meansE3 means the safety switch acted and the machine cannot spin — an imbalance fault. The machine tried to rebalance the load automatically (twice, on most models) and gave up. Nine Haier top-load family manuals use the identical template wording. E3 is a top-load-family code: the HW80/HW100/HW120-B14979 front-load family has no E3 — imbalance there is 'Unb'.
Most common causeLaundry placed unevenly in the tub, an overloaded tub, or the machine not being level.
Safe to check yourself?Yes — redistributing the load, levelling the machine, and the manual's open-and-close-the-lid step are all user-safe.

Applies to — read this first

E3 is the most consistent Haier washer code we have checked — nine top-load family manuals print the same template: the safety switch acts, spinning cannot work (after two automatic imbalance corrections), the display shows E3 and it rings. The critical split: this is a TOP-LOAD code. The B14979 front-load family's troubleshooting table has no E3 — its unbalanced-load code is 'Unb'. If your machine is a front-loader showing E3, do not apply this page.

Unverified exception: one 9-year-old JustAnswer answer claims E3 = motor tachometer fault on front-load HW1P65-918 — single source, no manual cited; not accepted as a meaning.

What the machine does when E3 fires

Near the spin stage the machine tries to rebalance the load by itself — twice on most models. If the load is still uneven, the safety switch acts, the display shows E3, the buzzer rings, and spinning cannot start. The wash water usually stays in the tub.

Common causes

  1. Laundry placed unevenly in the tub — heavy items on one side.
  2. An overloaded tub.
  3. The machine is not level (feet uneven, floor sloping).
  4. A single heavy item (blanket, jeans) balling up during the wash.

Safe checks, in order

  1. Pause/stop the machine and redistribute the laundry evenly around the tub — break up balled items.
  2. Remove some items if the tub is overloaded.
  3. Open and close the top lid once — the manuals' own reset step for E3.
  4. Check the machine is level: rock it gently and adjust the feet until it stands firm.
  5. Restart the spin. If E3 returns with a balanced, level, normally-loaded machine, the suspension or balance system needs a technician.

Work through the checks in order and stop as soon as the code clears. E3 is almost always a loading problem, not a parts problem — do not let any page sell you a temperature sensor or a drain pump for it (both appear on ranking pages and both contradict the manuals). If a check needs the machine opened or parts tested, it is no longer a safe home check — skip to the technician section.

When to call a technician

  • E3 on every spin with balanced loads and a level machine.
  • Loud banging that redistribution never fixes (suspension rods/dampers worn).
  • E3 appearing even with an empty tub.
  • Any burning smell or the drum not turning at all.

Safety first

Always unplug the machine before adjusting feet underneath it or reaching deep into the tub. A machine that shakes violently can 'walk' — keep hands clear while it spins and never open the lid mid-spin to grab laundry.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does E3 mean on a Haier washing machine?

E3 means the safety switch acted and the machine cannot spin — an imbalance fault after the machine's own automatic rebalancing attempts failed. Nine Haier top-load manuals use the identical template wording. It is a top-load code; B14979 front-loads use 'Unb' instead.

How do I clear Haier washer E3?

Redistribute the laundry evenly, remove some items if overloaded, open and close the top lid once (the manuals' own step), make sure the machine is level, and restart the spin.

Some sites say Haier E3 is a temperature sensor or motor fault. Is that right?

No. One app page claims E3 = broken temperature sensor (that's F3's territory) and one old forum answer claims a motor tachometer fault on one front-load model — neither is in any Haier manual. The manuals define E3 as the safety-switch/imbalance code on top-load families.

My Haier front-loader shows E3. Does this page apply?

No — the B14979 front-load family has no E3; its imbalance code is 'Unb'. If your front-loader shows E3, check your exact model's manual rather than applying the top-load meaning.
