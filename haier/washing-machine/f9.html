Haier Washing Machine Error Code F9

Quick answer

Error codeF9 — Haier Washing Machine
What it meansF9 = Dry temperature sensor error - the sensor that monitors drying temperature on Haier washer-dryer combos is not reading correctly. Washer-dryer combos ONLY: F9 does not exist on washer-only models. All three Haier documents prescribe a service technician - no home fix is documented.
Most common causeDry temperature sensor failure (open/short circuit or out-of-range reading) on a washer-dryer combo.
Safe to check yourself?No - Haier gives no home fix for F9. If it appears repeatedly, switch the machine off, cut water and power, and contact Haier After sales service.
Checked againstHaier official support article, "Haier Washer/Dryer Combo Fault Codes" (support.haier.com.au); Haier HWD80/90/100-B14939S8 user manual, §9 Troubleshooting; Haier HWD100-BD1499U1 user manual, §10 Troubleshooting (indexed text only)

Applies to — read this first

Read this first, because Haier F9 is a washer-dryer-combo code ONLY - it does not exist on washer-only models (washer-only HW-B14979 §9.2 has no F9). F9 = Dry temperature sensor error, verified in three Haier documents that agree on the meaning: the official Haier AU support article, the HWD80/90/100-B14939S8 user manual §9, and (indexed text only) the HWD100-BD1499U1 user manual §10. The HWD-B14979 washer-dryer manual's grouped row proves only that the token can display on HWD-B14979 combos - it gives no distinct F9 meaning. Never present F9 as a washer code, and never merge it with the wash-side codes F3/F4, the dry element code Fd, the dry motor code FE, FY, Err9, or EC5 (see the table).

What the machine does when F9 fires

The display shows F9 when the machine is drying (or trying to dry) - the drying temperature sensor is not reading correctly - and the machine needs a service technician. F9 is not a drainage code: drainage faults on these machines are CLR FLTR or E2.

Common causes

  1. Dry temperature sensor failure - the sensor that monitors drying temperature has failed (open/short circuit or out-of-range reading).
  2. Not a drain fault: some template sites say "drain performance low", but three Haier documents give F9 its own row as a dry temperature sensor error; drainage is CLR FLTR/E2.
  3. Not F3/F4: those are wash-side temperature sensor (F3) and heating (F4) faults - F9 is the drying-side sensor.
  4. Not Fd or FE: Fd is the dry heating element and FE is the dry motor - different parts from the F9 sensor.
  5. Not Err9 (a different code system) and not EC5 (same fault concept on the XQG50/HWD1000 platform, different code token).

Safe checks, in order

  1. Check your model family on the rating label first - F9 exists only on Haier washer-dryer combos (HWD models). If yours is a washer-only model, F9 cannot be a valid code on it.
  2. Note the exact code and when it appears: F9 appears when the machine is drying (or trying to dry) - the drying temperature sensor is not reading correctly.
  3. If it appears repeatedly: switch the machine off and cut water and power (BD1499U1 manual), then contact Haier After sales service / book a service technician.
  4. Do NOT invent a sensor-cleaning step, a lint-filter fix, or a drain-pump-filter fix for F9: no manual gives a home fix for this code.

The manuals give only a label plus "book a service" for F9 - the official article says "You will need a Service Technician to assist with this" and the B14939S8 manual says "Contact the After sales service." There is no home fix, no test value, and no diagnostic step documented for F9. This page stays short and exact by design.

When to call a technician

  • F9 appears at all on a washer-dryer combo - every Haier document sends this code to a service technician.
  • F9 appears repeatedly - switch off, cut water and power, and contact Haier After sales service.
  • Any burning smell, damaged wiring, or other fault codes alongside F9 - switch off and call a qualified technician.

More guidance: when an appliance error requires professional service.

Safety first

F9 is a drying-side sensor fault in a mains-powered washer-dryer combo: never open the machine or probe the sensor wiring yourself. If F9 repeats, switch off and cut water and power as the manual directs, then call a qualified technician.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does F9 mean on a Haier washer dryer?

Dry temperature sensor error: the sensor that monitors drying temperature is not reading correctly. Book a service technician.

Is F9 a drain problem?

No. Some template sites say "drain performance low", but Haier's own article and two user manuals give F9 its own row as a dry temperature sensor error. Drainage on these machines is CLR FLTR (6 minutes) or E2.

What is the difference between F9, Fd and FE?

All three are drying-side codes: Fd = dry heating element, FE = dry motor, F9 = dry temperature sensor. Different parts, different faults.

Can I fix F9 myself?

Haier gives no home fix for F9. If it appears repeatedly, switch off, cut water and power, and contact Haier After sales service.

Does F9 exist on a Haier washing machine (washer-only)?

No. F9 is a washer-dryer-combo code. Washer-only models do not list it; if a washer-only machine shows a sensor fault it will be F3 (temperature sensor) or another wash-side code.
