Haier Washing Machine Error Code E13

Quick answer

Error codeE13 — Haier Washing Machine
What it meansE13 = water-supply overfill — "the water is above the warning level." The machine warns and stops running. The manuals prescribe NO user fix: "Ask the technician to repair it." This is a washer-dryer COMBO platform code only (XQG50 and HWD1000 families). ROUTE BY MODEL: UK-sold HWD washer dryers reuse the E13 label for drying/lint faults (a different platform) — if yours is a UK HWD, that meaning applies, not the overfill below. Do not merge E13 with Er13 (HWD-C1200TXVE service manual: "drying heating" abnormity — different code).
Most common causeThe inlet valve is stuck open or the water-level control has failed — the manuals name no cause, only the technician prescription.
Safe to check yourself?No homeowner fix in the manual. The safe moves are: switch the machine off, turn the water tap OFF (overfill risk — do not leave it filling unattended), and call a technician.

Applies to — read this first

Read this first, because E13 means different things on different Haier platforms — route by model. On the XQG50 / HWD1000 washer-dryer combo platform, E13 = water-supply overfill ("the water is above the warning level"), and the manual's prescription is "Ask the technician to repair it" — there is no user fix. On UK-sold HWD washer dryers, the E13 label is reused for drying/lint faults (clean the lint filter; drying heater/fan faults) — that is the other platform's meaning, stated here as a reader-routing note. Do NOT merge E13 with Er13 (HWD-C1200TXVE service manual: "drying heating" abnormity — different code) or with invented internet rows.

What the machine does when E13 fires

The display shows E13 and the machine warns and stops running — the control has detected water above the warning level.

Common causes

  1. The inlet valve is stuck open and keeps filling — the typical overfill mechanism.
  2. The water-level sensing has failed, so the machine cannot tell when to stop filling.
  3. The manuals name no cause — only the condition ("the water is above the warning level") and the prescription (technician).

Safe checks, in order

  1. Switch the machine off and turn the water tap OFF — overfill risk; do not leave it filling unattended.
  2. Do not keep restarting it: repeated overfill cycles can flood.
  3. Call a technician — the manual's own prescription ("Ask the technician to repair it"). A likely inlet valve stuck open or level-sensor failure is service work.

Stating this honestly: the manuals give NO user fix for E13, so there is no invented fix flow here. The steps above are safety guidance (stop the water, stop the machine, call service) — the repair itself is technician work.

When to call a technician

  • E13 shows at all — the overfill condition needs a technician by the manuals' own prescription.
  • Water keeps entering with the machine off — a stuck-open inlet valve, turn the tap off and call service.

Safety first

E13 is an overfill fault: water and mains-powered electronics together. Turn the tap off, switch the machine off before touching anything wet, and never keep restarting a machine that overfills — flood risk. The repair is technician work.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does E13 mean on a Haier washing machine?

On the XQG50/HWD1000 washer-dryer combo platform, E13 means water-supply overfill — "the water is above the warning level." It is verified verbatim in the Haier XQG50-S1216 user manual and the HWD1000 washer & dryer user manual.

What is the difference between E11, E12 and E13?

On the same warning-code table: E11 = water supply fill timeout (water level not reached in 5 minutes), E12 = drainage timeout (8 minutes), E13 = water-supply overfill (water above the warning level).

Why is there no user fix for E13?

The manuals prescribe none — the E13 row says "Warning and stop running" and "Ask the technician to repair it." No Haier manual gives a DIY step for E13, so this page does not invent one.

My UK Haier washer dryer shows E13 — same code?

The label is reused on a different platform: UK-sold HWD washer dryers use E13 for drying/lint faults (clean the lint filter; drying heater/fan faults). If yours is a UK HWD, that meaning applies — not the overfill above.

Is E13 the same as Er13?

No. Er13 on the HWD-C1200TXVE service manual is a "drying heating" abnormity — a different code format and a different fault.
