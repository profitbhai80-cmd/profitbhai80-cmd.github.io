Haier Washing Machine Error Code EC2

Quick answer

Error codeEC2 — Haier Washing Machine
What it meansEC2 = water temperature sensor fault — the sensor circuit is short-cut or open. The manual prescribes no user fix: "Warning and stop running" — technician-only. This code exists only on the XQG50 220V international washer-dryer models — the HWD1000 table has NO EC1, EC2 or EC3 rows. Phrase honesty: the XQG50 hosts' OCR scrambles the sensor phrases, so this page does NOT quote a reconstructed sentence as verbatim — only the item label "Water temperature sensor" (verbatim), the fault class (sensor circuit short/open), and the action "Warning and stop running" (verbatim).
Most common causeThe water temperature sensor circuit is short or open — the manuals give the fault class, not a cause tree, and document no user fix.
Safe to check yourself?No user fix is documented. Call a technician (likely the NTC/thermistor, its wiring, or the control board). Do not invent checks the manual does not give.

Applies to — read this first

Read this first, because EC2 exists ONLY on the XQG50 220V international washer-dryer models. The HWD1000 user manual's warning-code table contains NO EC1, EC2 or EC3 rows — verified 2026-11-03. And read the phrase honesty note: the XQG50 hosts' OCR scrambles the middle sensor phrases — manualowl's phrase list puts "The drying sensor circuit short cut or open" at EC2's position, but the HWD1000 manual's explicitly labeled EC5 row proves that phrase belongs to EC5 (dry temperature sensor), not EC2. What the machine does when EC2 fires

The display shows EC2 and the machine warns and stops running — the water temperature sensor circuit is short or open.

Common causes

  1. The water temperature sensor circuit is short-cut or open — the manual's fault class (likely the NTC/thermistor, its wiring, or the control board; the manuals name no cause).

Safe checks, in order

  1. Call a technician — the manual's own and only prescription ("Warning and stop running"; no user fix documented). Likely the NTC/thermistor, its wiring, or the control board.

Stating this honestly: the manuals document no user fix for EC2, so there is no invented fix flow here — and no reconstructed quote is presented as verbatim, per the phrase caveat above.

  • EC2 shows at all — the sensor circuit needs a technician (the manuals document no user fix).

Safety first

EC2 involves the sensor circuit and mains-powered electronics: never open the machine or touch sensors or wiring yourself — the repair is technician work.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does EC2 mean on a Haier washing machine?

EC2 means a water temperature sensor fault — the sensor circuit is short-cut or open. It is verified in two Haier manuals: the XQG50-S1216 user manual and the XQG50-S1016 operation manual, with the action "Warning and stop running".

Why doesn't this page quote the full EC2 sentence?

Because the XQG50 hosts' OCR scrambles the middle sensor phrases — it misplaces EC5's "drying sensor circuit" phrase at EC2's position. This page quotes only what is verbatim (the item label and the action) rather than inventing a quote.

What is the difference between EC2, EC1 and EC5?

EC2 = water temperature sensor (circuit short/open, machine stops). EC1 = heater (water temp unchanged 10 min, wash continues cold). EC5 = dry temperature sensor (circuit short/open, machine stops). Three different rows, three different faults.

Does my HWD1000 have EC2?

No — the HWD1000 table has no EC1, EC2 or EC3 rows. EC2 exists only on the XQG50 220V international models.
