Haier Washing Machine Error Code FA

Quick answer

Error codeFA — Haier Washing Machine
What it meansFA = water level sensor error (water level sensor circuit problem). Contact after-sales service. Front-load families only. Not the protective level (that is E8) and not an unbalanced load (that is Unb).
Most common causeThe machine is detecting a water level sensor (circuit) fault. The manuals name no cause beyond the sensor error itself and prescribe no user diagnosis.
Safe to check yourself?No user repair step exists: five manuals print contact-service as the solution. Confirm the code, power-cycle once, then call service.
Checked againstHaier HW80/HW100/HW120-B14979 §9.2; Haier HW70B1426S; Haier HW70-B14929-S; Haier HW7014829; Haier HLC1700AXS manual (water level sensor circuit problem)

Applies to — read this first

FA is the level-SENSOR code: five manuals print 'water level sensor error' (HLC1700AXS: 'water level sensor circuit problem'), all with contact-service as the solution. Two splits keep it straight: FA vs E8 (sensor circuit vs protective level exceeded) and FA vs Unb (sensor vs load). One competitor table prints FA as 'unbalanced load detected' with redistribute advice — in every manual, unbalanced load is Unb, and FA is the level sensor. That row is simply wrong.

Haier HW80/HW100/HW120-B14979 §9.2; HW70B1426S; HW70-B14929-S; HW7014829FA: water level sensor error. Contact after-sales service / customer support / maintenance personnel. No user step prescribed.
Haier HLC1700AXS manual (p.31 error codes)FA: water level sensor circuit problem; stop running; service needed.

Scope: front-load only — twin-tub FA meanings were not verified and are not imported. The aysonline FA row (unbalanced load) contradicts every manual above; the manuals' Unb row is the unbalanced-load code.

What the machine does when FA fires

The control cannot trust its water-level reading: FA is a sensor-circuit fault, so the machine reports it and the manuals' outcome is to stop and arrange service.

Common causes

  1. The machine has detected a water level sensor error / water level sensor circuit problem (the manuals' full extent of the diagnosis).

Safe checks, in order

  1. Confirm the display reads FA (not E8, not Unb): FA = level sensor; E8 = protective level; Unb = unbalanced load.
  2. Power-cycle once: switch off, unplug for a few minutes, plug back in and retry. If FA returns, the sensor fault is genuine.
  3. Contact after-sales service — that is the manual's own solution, and there is no user step beyond it.

Work through the checks in order and stop as soon as the code clears. Do not open the machine to reach the level sensor: the manuals prescribe contact-service only.

When to call a technician

  • FA returns after a power-cycle — the sensor fault is genuine; call after-sales service.

More guidance: when an appliance error requires professional service.

Safety first

The level sensor is an internal component wired into the control system. Never open the machine's panels or touch sensor terminals yourself; the manuals say to contact after-sales service.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does FA mean on a Haier washing machine?

FA is a water level sensor error (water level sensor circuit problem) on front-load families. Five manuals agree, all prescribing contact after-sales service.

Is Haier FA the same as E8?

No. FA = the water level sensor circuit is faulty. E8 = the water has exceeded the protective level. Different faults — one is the measuring device, the other is the measured condition.

Is Haier FA an unbalanced load?

No — unbalanced load is Unb in every manual. One competitor table prints FA as unbalanced load; that row contradicts the manuals.
