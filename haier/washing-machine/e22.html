Haier Washing Machine Error Code E22

Quick answer

Error codeE22 — Haier Washing Machine
What it meansE22 = memory function failure — the EEPROM is not functioning. Note the action is only "Warning" (NOT "Warning and stop running") — the one row on the table with a bare Warning action. The manual prescribes no user fix: "Ask the technician to repair it." This is a washer-dryer COMBO platform code only (XQG50 / HWD1000 families). Display trap resolved: the XQG50 host's tail OCR swaps the last two item cells, which would put "memory" on U04 — but the HWD1000's LABELED rows prove the opposite: U04 = "The door is opened", E22 = memory/EEPROM failure. Do not merge E22 with Haier chiller E22, Haier AC E22-class codes, Hisense E22 (door lock — different brand), or justanswer's generic fill/drainage E22 readings (fill = E11, drainage = E12 on this platform).
Most common causeThe EEPROM is not functioning — the manuals give the fault, not a cause tree, and document no user fix.
Safe to check yourself?One power-cycle to rule out a momentary glitch; if E22 returns, call a technician (likely the control board / EEPROM — board-level service).
Checked againstHaier XQG50-S1216 user manual, "Warning code" table (manualowl.com, p.5) + Haier HWD1000 (Front Load Clothes Washer & Dryer) user manual (manualmachine.com; identical table on notice-facile.com — explicitly labeled E22 row, DEFINITIVE) + Haier XQG50-S1016 operation manual (hugepdf.com — same table, third model)

Applies to — read this first

Read this first, because E22 exists ONLY on Haier's XQG50 / HWD1000 washer-dryer combo platform — the memory/EEPROM code, and the one row on the table whose action is a bare "Warning" (not "Warning and stop running"). And read the U04/E22 resolution: the manualowl XQG50-S1216 OCR lists the tail items against codes U01–U04, E22 in an order that would put "memory" on U04 — but HWD1000's LABELED rows prove the opposite: U04 = "The door is opened / Warning / Close the door"; E22 = "The memory function has failed / EEPROM is not functioning / Warning / Ask the technician to repair it". The XQG50 OCR swapped the last two item cells. Correct pairing on BOTH platforms: U04 = door opened, E22 = memory/EEPROM failure. Do NOT merge E22 with Haier chiller E22 (CA0035EAND — different appliance), Haier AC E22-class codes, Hisense E22 (door lock — different brand), or easybear's E9/EEPROM discussion (portable washers).

What the machine does when E22 fires

The display shows E22 and the machine warns — the one fault row on the table whose action is a bare "Warning" rather than "Warning and stop running".

Common causes

  1. The memory function has failed — the EEPROM is not functioning (the manuals give the fault, not a cause tree; likely the control board / EEPROM — board-level service).

Safe checks, in order

  1. Power-cycle once to rule out a momentary glitch.
  2. If E22 returns, call a technician — the manual's own prescription ("Ask the technician to repair it"). Likely the control board / EEPROM — board-level service.

Stating this honestly: the manuals document no user fix for E22 beyond the prescription, so there is no invented fix flow here — one power-cycle, then service.

When to call a technician

  • E22 returns after a power-cycle — the control board / EEPROM needs a technician (board-level service).

More guidance: when an appliance error requires professional service.

Safety first

E22 involves the control board and mains-powered electronics: never open the machine or touch the board yourself — that is qualified-technician work.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does E22 mean on a Haier washing machine?

E22 means a memory function failure — the EEPROM is not functioning. It is verified verbatim in the Haier XQG50-S1216 user manual and the HWD1000 front-load washer & dryer user manual ("E22 The memory function has failed | EEPROM is not functioning | Warning | Ask the technician to repair it").

What is the difference between E22 and U04?

The XQG50 host's tail OCR swaps them, but the HWD1000's labeled rows settle it: U04 = "The door is opened" (Warning — close the door); E22 = "The memory function has failed" (Warning — call a technician). Correct pairing on both platforms.

Why is the action only "Warning"?

E22 is the one row on the table whose action is a bare "Warning" rather than "Warning and stop running" — the manual's own wording, carried verbatim.

Does my top-load Haier have E22?

No — E22 exists only on the XQG50/HWD1000 washer-dryer combo platform.
