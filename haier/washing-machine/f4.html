Haier Washing Machine Error Code F4

Quick answer

Error codeF4 — Haier Washing Machine
What it meansF4 = heating error: the wash water is not heating as expected (on some families it appears at the end of a cycle). Contact after-sales service. Front-load families only. F4 is the heater; F3 is the sensor.
Most common causeThe machine is detecting that the water is not heating as expected. The manuals name no cause beyond the heating error itself and prescribe no user diagnosis.
Safe to check yourself?No user repair step exists: four user manuals print 'contact after-sales service' as the solution. Confirm the code, power-cycle once, then call service.
Checked againstHaier HW80/HW100/HW120-B14979 §9.2; Haier HW70B1426S (appears at end of cycle); Haier HW70-B14929-S; Haier HW7014829 (appears at end of cycle)

Applies to — read this first

F4 is short and exact because the manuals are: four front-load user manuals print F4 as 'heating error' with 'contact after-sales service' as the solution. Two manuals add a presentation note no competitor states: on some families F4 appears at the end of a cycle. The headline split: F4 is the HEATER (water not heating as expected); F3 is the temperature SENSOR.

One competitor pillar prints a 'typical' heater resistance figure and live-voltage check steps for F4 — neither is in the user manuals, which prescribe contact-service only. Another blurs F3 into F4. This page refuses the invented figures and keeps the F3/F4 split.

What the machine does when F4 fires

The wash water is not heating as expected; on some families the code appears at the end of a cycle, once the machine has detected the heating failure. The manuals give no home diagnosis beyond the code itself.

Common causes

  1. The machine has detected a heating error — the wash water is not heating as expected (the manuals' full extent of the diagnosis).

Safe checks, in order

  1. Confirm the display reads F4 (not F3): F4 = heating error; F3 = temperature sensor error.
  2. Note when it appears: on some families F4 shows at the end of a cycle — that presentation is normal for this code.
  3. Power-cycle once: switch off, unplug for a few minutes, plug back in and retry. If F4 returns, the heating fault is genuine.
  4. Contact after-sales service — that is the manual's own solution, and there is no user step beyond it.

Work through the checks in order and stop as soon as the code clears. Do not test the heater with a multimeter or open the machine: the manuals prescribe contact-service only.

When to call a technician

  • F4 returns after a power-cycle — the heating fault is genuine; call after-sales service.

More guidance: when an appliance error requires professional service.

Safety first

The heater is a mains-powered internal component at the bottom of the drum. Never open the machine's panels or probe heater wiring yourself; the manuals say to contact after-sales service.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does F4 mean on a Haier washing machine?

F4 is a heating error on front-load families: the wash water is not heating as expected. On some families it appears at the end of a cycle. Four manuals agree, all prescribing contact after-sales service.

Is Haier F4 the same as F3?

No. F3 = temperature sensor error; F4 = heating error. Separate rows in every manual, separate faults.

My Haier shows F4 at the end of the cycle — is that normal?

Yes: HW70B1426S and HW7014829 note that F4 can appear at the end of a cycle. It still means a heating error — contact after-sales service.

Can I test the heater myself for Haier F4?

The user manuals prescribe no test — only contact after-sales service. Resistance figures and live-voltage checks printed on blogs are not from these manuals and are not safe general advice.
