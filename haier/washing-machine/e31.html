Haier Washing Machine Error Code E31

Quick answer

Error codeE31 — Haier Washing Machine
What it meansE31 = motor fault — the motor's feedback signal does not change within 8 minutes while the motor runs. The manual prescribes NO user fix: "Warning and stop running" / "Ask the technician to repair it." This is a washer-dryer COMBO platform code only (XQG50 / HWD1000 families) — it does not exist on Haier top-loads or HW front-loads. It is NOT a drainage fault, despite a justanswer AI summary claiming so (drainage is E12 — both are 8-minute timeouts, different faults). Do not merge E31 with E3, Err7, or Haier chiller E31 (exhaust temperature sensor — different appliance).
Most common causeThe motor, its tachometer/feedback circuit, or the control board — the manuals name no cause, only the condition and the technician prescription.
Safe to check yourself?No homeowner fix in the manual. The safe moves are: switch the machine off, do not keep restarting a motor-faulted machine, and call a technician.

Applies to — read this first

Read this first, because E31 exists ONLY on Haier's XQG50 / HWD1000 washer-dryer combo platform — the 8-minute motor-feedback code. It is absent from the digitron top-load tables (E0–E9) and from the HW front-load E1/E2/E4/E8/F-series tables. Do NOT merge E31 with E3 (spin/imbalance or motor-tachometer on other lines), with Err7 (UK-platform motor), with Haier chiller E31 (exhaust temperature sensor — different appliance), or with justanswer's AI "drainage issue" reading (drainage is E12 on this same table — both are 8-minute timeouts, and the manuals keep them separate).

What the machine does when E31 fires

The display shows E31 and the machine warns and stops running — the control has flagged the motor feedback as unchanged for 8 minutes of motor run.

Common causes

  1. The motor's feedback signal does not change within 8 minutes of motor run — the manual's own condition.
  2. Likely motor, tachometer/feedback circuit, or control board — technician diagnosis; the manuals name no cause, only the prescription.

Safe checks, in order

  1. Switch the machine off — do not keep restarting a motor-faulted machine.
  2. Call a technician — the manual's own and only prescription ("Ask the technician to repair it"). Likely motor, tachometer/feedback circuit, or control board.

Stating this honestly: the manuals give NO user fix for E31, so there is no invented fix flow here. The steps above are safety guidance (stop the machine, call service) — the diagnosis and repair are technician work.

When to call a technician

  • E31 shows at all — the manuals' uniform instruction is "Ask the technician to repair it."

More guidance: when an appliance error requires professional service.

Safety first

E31 is a motor-drive fault: the motor is fed by mains-powered electronics. Switch the machine off before touching anything, and never dismantle the motor or drive circuitry yourself — that is qualified-technician work.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does E31 mean on a Haier washing machine?

E31 means a motor fault — the motor's feedback signal does not change within 8 minutes while the motor runs. It is verified verbatim in the Haier XQG50-S1216 user manual and the HWD1000 front-load washer & dryer user manual.

Is E31 a drainage fault?

No. A justanswer page's AI summary claims E31 is "a drainage issue, often caused by a clogged pump filter or blocked drain hose" — the manual contradicts this: E31 is the MOTOR row; drainage is E12. Both are 8-minute timeouts, and the manuals keep them separate.

Why does the manual give no user fix for E31?

The E31 row says "Warning and stop running" and "Ask the technician to repair it." No Haier manual gives a DIY step for E31, so this page does not invent one.

What is the "feedback signal"?

Plain-English: the motor sends a rotation signal back to the control (a tachometer-style feedback). If that signal stops changing for 8 minutes while the motor is supposed to be running, the control concludes the motor is not actually turning and flags E31.

Does my top-load Haier have E31?

No — E31 exists only on the XQG50/HWD1000 washer-dryer combo platform. Digitron top-loads and HW front-loads have no E31 row in their manuals.
