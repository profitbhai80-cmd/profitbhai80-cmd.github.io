Haier Refrigerator Error Code F3

Quick answer

Error codeF3 — Haier Refrigerator
What it meansF3 means a temperature sensor has a short or open circuit — but which sensor depends on the family: the environment/ambient sensor (RT SNR) on HB21F models, or the refrigerator sensor 1 (R1 SNR) on HRF-628 models. Both Haier service manuals define it as a hard sensor fault, not a glitch.
Most common causeA failed or disconnected temperature sensor — the ambient (RT) sensor on HB21F models, the refrigerator sensor 1 (R1) on HRF-628 models — or a wiring/connector fault between the sensor and the main board.
Safe to check yourself?Only partly. You can safely recall the code and power-cycle once. Sensor connector checks need the power off and the machine unplugged; resistance testing and replacement are technician work.
Checked againstHaier HB21FWRSS Refrigerator Service Manual (EDITION 2008-03-24); Haier HB21FNN Service Manual (breakdown table); Haier HRF-628AF6/IF6 Service Manual (Issue 2013-04-07, Ref1304S001V0); Haier HRF-663ISB2 Service Manual (Issue 20090416, Ref0904S016V0); Haier HRF-6631RG user manual (code list)

Applies to — read this first

F3 is the trickiest code in this set: Haier uses it for two different sensors. On HB21F-family models (HB21FWRSS, HB21FNN) the service manual defines F3 as the environment temperature sensor (RT SNR) — a short or open circuit. On HRF-628-family models (HRF-628AF6/IF6) the service manual defines F3 as the refrigerator sensor 1 (R1 SNR) — also a short or open circuit. On HRF-663/664 models Haier's own user manual lists F3 among the display codes but gives it no meaning, so treat any third-party meaning for that family as unverified. Check your model family on the rating label before you start — see how to find your model number.

User manual lists F3 among E0, E1, E2, F1, F2, F3 with 'please contact Customer Service' — no per-code meaning given. Do not read another family's F3 meaning across to this family.

Neighbouring codes for orientation. HB21F table: F1 = refrigerator sensor, F2 = freezer sensor, F5 = defrost sensor, F6 = icemaker sensor. HRF-628 list: F4 = freezer (F) sensor, F2 = ambient (RT) sensor, F8 = refrigerator sensor 2 (R2), F6 = defrost (D) sensor, FC = icemaker sensor. Do not borrow F3 meanings from other brands — error codes are not universal across brands.

What the machine does when F3 fires

On HB21F models the codes are not shown automatically — recall them with the 3-button press and the code appears on the cabinet display. The environment (RT) sensor feeds the fuzzy-logic automatic temperature control, so a failed RT sensor can make automatic mode misbehave while manual settings still work. On HRF-628 models the codes cannot display automatically either ('Fault code automatically hiding function') — use the LOCK + (E) + 'Ref. Temp' sequence. The R1 sensor sits at the refrigerator damper assembly and governs refrigerator-compartment temperature, so an R1 fault can leave the fridge compartment wrongly cooled.

Common causes

  1. The sensor has failed — short circuit or open circuit. On HB21F models that is the environment temperature sensor (RT SNR); on HRF-628 models it is the refrigerator sensor 1 (R1 SNR). Both Haier service manuals list the short/open circuit as the definition of F3.
  2. The sensor's wiring or connector to the main board is loose, corroded, or damaged — the manuals name the sensor connection as the first thing to check.
  3. On HB21F models the environment sensor connects at main-board connector CN5 pins 7–8; a fault at that connector reads the same as a failed sensor.
  4. A main-board fault misreading the sensor circuit — if the wiring and sensor test good, the board's reading circuit is the remaining suspect.

Safe checks, in order

  1. Identify your model family on the rating label (HB21F…, HRF-628…, HRF-663/664…) — F3 means a different sensor per family. See our guide to finding your model number.
  2. Recall the code properly: HB21F — press freezer (>) + fridge (<) + (>) for 3 seconds and read the cabinet display. HRF-628 — under LOCK status press (E) + 'Ref. Temp' (D) for 3 seconds; the display shows '--' with a buzzer, then the code appears after another 3 seconds. Confirm it really is F3.
  3. Switch the refrigerator off at the wall and unplug it. Leave it a few minutes, then plug it back in and recall the code once — a transient display glitch is rare, but ruling it out costs nothing.
  4. If F3 returns, stop: the manual's next step is the sensor resistance check at the main-board connector (HB21F: CN5 pins 7–8 for the environment sensor; HRF-628: the §7-3 'Sensors and error codes' resistance table) — back-panel-off, multimeter work the manuals reserve for service staff.

Work through the checks in order and stop as soon as the code clears. A hard sensor fault (short or open circuit) cannot be cleared by any reset — the power-cycle step only rules out a display glitch. If a check needs a panel removed, a connector probed, or a part tested, it is no longer a safe home check — skip to the technician section.

When to call a technician

  • F3 returns after every power cycle — the sensor is almost certainly failed or its circuit is broken.
  • The resistance measurement at the sensor connector is needed to confirm the fault — service-staff work.
  • Visible wire damage or a burnt connector anywhere near the sensor — do not attempt to repair wiring yourself.
  • On HRF-628 models: the refrigerator compartment is wrongly cooled (too warm or freezing) — the R1 sensor governs the damper, and food safety is at stake.

Safety first

Always unplug the refrigerator before touching any connector or wiring, and let it sit a few minutes. A failed sensor can let a compartment drift out of safe temperatures — check stored food for spoilage if cooling has been wrong. Never probe a live control board, and never attempt sealed-system (refrigerant) work: sensor faults are electrical and refrigerant is not involved here, but the boundary still stands.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does F3 mean on a Haier refrigerator?

It depends on your model family. On HB21F-family models (HB21FWRSS, HB21FNN), F3 means the environment temperature sensor (RT SNR) has a short or open circuit, per the Haier HB21FWRSS service manual. On HRF-628-family models (HRF-628AF6/IF6), F3 means the refrigerator sensor 1 (R1 SNR) has a short or open circuit, per the Haier HRF-628AF6/IF6 service manual. On HRF-663/664 models Haier's own user manual lists F3 without defining it.

How do I see the F3 code on my Haier fridge?

On HB21F models the codes are not shown automatically: press the freezer temperature control (>) and the fridge temperature controls (<) and (>) together for 3 seconds and read the cabinet display. On HRF-628 models, under LOCK status press (E) + 'Ref. Temp' (D) for 3 seconds — the display shows '--' with a buzzer, then the code appears after another 3 seconds.

Can I reset Haier refrigerator F3 by unplugging it?

A power cycle rules out a display glitch, but a genuine F3 is a hard sensor fault — a shorted or open sensor circuit — and no reset repairs that. If F3 comes back after the power cycle, the sensor or its wiring needs a technician.

One site says F3 is the ambient sensor and another says it is the R1 sensor. Which is right?

Both — for different families. The HB21F service manual defines F3 as the ambient (RT) sensor; the HRF-628 service manual defines F3 as the R1 refrigerator sensor. Be wary of lists that assign F3 a meaning on HRF-663/664 models: Haier's HRF-6631RG user manual lists F3 with no defined meaning, so those rows are unsourced.
