Haier Refrigerator Error Code F5

Quick answer

Error codeF5 — Haier Refrigerator
What it meansF5 means the defrost sensor (D SNR, top of the freezer evaporator) has a short or open circuit, per the Haier HB21FWRSS service manual and the HB21FNN service manual. It is an HB21F-family-only code: on HRF-628 models the defrost sensor is F6, and HRF-663 models have no F5 at all.
Most common causeA failed or disconnected defrost sensor (D SNR, top of the freezer evaporator), or a wiring fault between the sensor and the main board.
Safe to check yourself?Only the code recall, a power-cycle check, and a visual connector check with the power off. Sensor resistance testing (the manual's CN4 pins 3–4 check) and replacement are technician work.
Checked againstHaier HB21FWRSS Refrigerator Service Manual (EDITION 2008-03-24); Haier HB21FNN Service Manual (breakdown table); Haier HRF-628AF6/IF6 Service Manual (Issue 2013-04-07, Ref1304S001V0) — no F5; defrost sensor = F6; Haier HRF-663ISB2 Service Manual (Issue 20090416, Ref0904S016V0) — D(HS) SNR fault listed, no F5 code assigned; Haier HRF-6631RG user manual — code list stops at F3, no F5

Applies to — read this first

F5 is an HB21F-family-only code. The Haier HB21FWRSS service manual defines F5 as the defrost sensor malfunction — the D SNR (defrost sensor, top of the freezer evaporator) has a short or open circuit — and the HB21FNN service manual defines it the same way ("Frost sensor malfunction — F5"). Check your model family on the rating label first — see how to find your model number. If your model is an HRF-628 or HRF-663/664 model, this page does not apply: on HRF-628 models the defrost sensor is F6, not F5, and HRF-663 models have no F5 at all.

The HRF-663ISB2 manual lists a D(HS) SNR fault as a blink-pattern item with no F-code assigned, and the HRF-6631RG user manual lists only E0, E1, E2, F1, F2, F3. F5 is undefined on these families — do not read the HB21F meaning across.

Neighbouring codes (HB21F table): F1 = refrigerator sensor (R1 SNR), F2 = freezer sensor (F SNR), F3 = environment temperature sensor (RT SNR), F6 = icemaker sensor (ICE SNR). Do not confuse F5 with Ed: Ed = defrost HEATING system error (the defrost sensor temperature can't reach 7°C after a temperature rise of more than 2 hours) — a different code. And do not confuse F5 with E5: E5 is a separate code, not a sensor code.

What the machine does when F5 fires

On HB21F models the codes are not shown automatically — recall them with the freezer (>) + fridge (<) + (>) 3-second press and the code appears on the cabinet display. A defrost-sensor fault disrupts the defrost cycle: the evaporator is no longer defrosted on sensor readings, so watch for frost buildup on the freezer evaporator and for cooling that slowly degrades.

Common causes

  1. The defrost sensor (D SNR, top of the freezer evaporator) has failed — short circuit or open circuit. Both HB21F manufacturer documents list this as the definition of F5.
  2. The sensor's wiring or connector to the main board is loose, corroded, or damaged — on HB21FWRSS the defrost sensor connects at main-board connector CN4 pins 3–4.
  3. A main-board fault misreading the sensor circuit — if the wiring and sensor test good, the board's reading circuit is the remaining suspect.

Safe checks, in order

  1. Confirm your model is an HB21F-family model (check the rating label) — F5 exists as a defrost code only there. See our guide to finding your model number.
  2. Recall the code: press the freezer temperature control (>) and the fridge temperature controls (<) + (>) together for 3 seconds and read the cabinet display. Confirm it really is F5 (not Ed, not E5).
  3. Power-cycle once: unplug, wait a few minutes, replug, and recall the code — ruling out a display glitch.
  4. With the power OFF and the machine unplugged, visually inspect the visible sensor connector and harness for looseness or corrosion. Do not cut, splice, or probe any wires, and never chip at evaporator ice with tools.
  5. If F5 returns, stop: the manual's next step is the defrost-sensor resistance check at main-board connector CN4 pins 3–4 — back-panel-off, multimeter work reserved for service staff. Watch for frost buildup on the freezer evaporator in the meantime and call a technician promptly.

Work through the checks in order and stop as soon as the code clears. A hard sensor fault (short or open circuit) cannot be cleared by any reset — the power-cycle step only rules out a display glitch. If a check needs a panel removed, a connector probed, or a part tested, it is no longer a safe home check — skip to the technician section.

When to call a technician

  • F5 returns after every power cycle — the defrost sensor is almost certainly failed or its circuit is broken.
  • The CN4 pins 3–4 resistance measurement is needed to confirm the fault — service-staff work.
  • Visible wire damage or a burnt connector anywhere near the sensor — do not attempt to repair wiring yourself.
  • Heavy frost buildup on the freezer evaporator, or cooling that slowly degrades — the defrost cycle is not running on sensor readings.

Safety first

Always unplug the refrigerator before touching any connector or wiring, and let it sit a few minutes. A failed defrost sensor can let frost choke the evaporator — never chip at ice with tools (puncturing the evaporator releases refrigerant). Never probe a live control board or attempt sealed-system (refrigerant) work.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does F5 mean on a Haier refrigerator?

On HB21F-family models (HB21FWRSS, HB21FNN), F5 means the defrost sensor (D SNR) has a short or open circuit, per the Haier HB21FWRSS service manual (EDITION 2008-03-24) and the HB21FNN service manual. F5 does not exist as a defrost code on HRF-628 or HRF-663/664 models.

How do I see the F5 code on my Haier fridge?

HB21F codes are not shown automatically: press the freezer temperature control (>) and the fridge temperature controls (<) and (>) together for 3 seconds and read the cabinet display. Press the same buttons for 3 seconds again to exit.

Can I reset Haier refrigerator F5 by unplugging it?

A power cycle rules out a display glitch, but a genuine F5 is a hard sensor fault — a shorted or open defrost sensor circuit — and no reset repairs that. If F5 returns after the power cycle, the sensor or its wiring needs a technician.

One site says F5 is the variable temperature sensor, and another lists F5 for HRF-628 models. Which is right?

Neither. Both HB21F manufacturer documents define F5 as the defrost (frost) sensor, D SNR. On HRF-628 models the defrost sensor is F6, not F5, per the HRF-628AF6/IF6 service manual — so any HRF-628 F5 row is borrowed from the wrong family.
