Haier Refrigerator Error Code F6

Quick answer

Error codeF6 — Haier Refrigerator
What it meansF6 means a sensor has a short or open circuit — the icemaker sensor (ICE SNR) on HB21F models, or the defrost sensor (D SNR) on HRF-628 models. The two Haier service manuals define it differently per family, so the family split is the whole story.
Most common causeA failed or disconnected sensor — the icemaker sensor on HB21F models, the defrost sensor on HRF-628 models — or a wiring fault between the sensor and the main board.
Safe to check yourself?Only the code recall, a power-cycle check, and the HB21F icemaker self-test. Sensor resistance testing and replacement are technician work.
Checked againstHaier HB21FWRSS Refrigerator Service Manual (EDITION 2008-03-24); Haier HRF-628AF6/IF6 Service Manual (Issue 2013-04-07, Ref1304S001V0); Haier HRF-663ISB2 Service Manual (Issue 20090416, Ref0904S016V0) — D(HS) and ICE SNR faults listed, no F6 code assigned; Haier HRF-6631RG user manual — code list stops at F3

Applies to — read this first

F6 is the split-personality code: it means two different sensors on two different families. On HB21F-family models (HB21FWRSS) the service manual defines F6 as the icemaker sensor (ICE SNR) malfunction — short or open circuit. On HRF-628-family models (HRF-628AF6/IF6) the service manual defines F6 as the defrost sensor (D SNR) failure — short or open circuit. No ranking page explains this split, and following the wrong family's meaning sends you after the wrong part. Check your model family on the rating label first — see how to find your model number.

ManualExact wording for F6
Haier HB21FWRSS service manual (EDITION 2008-03-24)"Icemaker sensor malfunction — F6 — ICE SNR short circuit or open circuit" (Malfunction Codes Table, No. 6). Sensor intro: icemaker sensor = ICE SNR at the bottom of the ice maker; main-board map: CN6 pins 1–2 connect to the icemaker sensor. Fallback: "The ice maker will rotate every 100 minutes if the ice make sensor is error."
Haier HRF-628AF6/IF6 service manual (Issue 2013-04-07, Ref1304S001V0)"D SNR failure — F6 — D SNR is short circuit or open circuit" (Error code list, No. 5). D SNR = defrost sensor, above the freezer evaporator. Codes cannot display automatically; recall under LOCK with (E) + 'Ref. Temp' (D) for 3 seconds.
Haier HRF-663ISB2 service manual (Issue 20090416, Ref0904S016V0); HRF-6631RG user manualService manual lists 'D(HS) SNR is defective' and 'ICE SNR is defective' as blink-pattern faults — no F6 code assigned. User manual lists only E0, E1, E2, F1, F2, F3. F6 is undefined on this family.

Neighbouring codes for orientation. HB21F table: F1 = refrigerator sensor, F2 = freezer sensor, F3 = environment sensor, F5 = defrost sensor. HRF-628 list: F4 = freezer (F) sensor, F2 = ambient (RT) sensor, F3 = refrigerator sensor 1 (R1), F8 = refrigerator sensor 2 (R2), FC = icemaker sensor. Note the trap: on HRF-628 models the icemaker sensor is FC, not F6.

What the machine does when F6 fires

On HB21F models recall the code with the 3-button press. An icemaker-sensor fault triggers the manual's fallback: the ice maker rotates every 100 minutes instead of on sensor readings, so ice production becomes slow and erratic. You can run the manual's icemaker self-test: with the freezer light switch closed, press and hold freezer '<' + fridge '>' for 3 seconds — 'EXPRESS FRZ' blinks on the cabinet display. On HRF-628 models the codes hide automatically; use the LOCK + (E) + 'Ref. Temp' sequence. A defrost-sensor fault disrupts the defrost cycle — watch for frost buildup on the freezer evaporator.

Common causes

  1. HB21F models: the icemaker sensor (ICE SNR, at the bottom of the ice maker) has failed — short circuit or open circuit. The HB21FWRSS service manual lists this as the definition of F6.
  2. HRF-628 models: the defrost sensor (D SNR, above the freezer evaporator) has failed — short circuit or open circuit. The HRF-628AF6/IF6 service manual lists this as the definition of F6.
  3. The sensor's wiring or connector to the main board is loose, corroded, or damaged — on HB21F the icemaker sensor connects at main-board connector CN6 pins 1–2.
  4. A main-board fault misreading the sensor circuit — if the wiring and sensor test good, the board's reading circuit is the remaining suspect.

Safe checks, in order

  1. Identify your model family on the rating label — F6 is the icemaker sensor on HB21F, the defrost sensor on HRF-628. See our guide to finding your model number.
  2. Recall the code properly: HB21F — press freezer (>) + fridge (<) + (>) for 3 seconds and read the cabinet display. HRF-628 — under LOCK status press (E) + 'Ref. Temp' (D) for 3 seconds; '--' shows with a buzzer, then the code appears after another 3 seconds. Confirm it really is F6.
  3. Power-cycle once: unplug, wait a few minutes, replug, and recall the code — ruling out a display glitch.
  4. HB21F only: run the manual's icemaker self-test — with the freezer light switch closed, press and hold freezer '<' + fridge '>' for 3 seconds ('EXPRESS FRZ' blinks on the cabinet display). If the self-test fails or F6 returns, stop: the next step is the sensor resistance check (HB21F: CN6 pins 1–2; HRF-628: the §7-3 'Sensors and error codes' table) — back-panel-off, multimeter work reserved for service staff.

Work through the checks in order and stop as soon as the code clears. A hard sensor fault (short or open circuit) cannot be cleared by any reset — the power-cycle step only rules out a display glitch. If a check needs a panel removed, a connector probed, or a part tested, it is no longer a safe home check — skip to the technician section.

When to call a technician

  • F6 returns after every power cycle — the sensor is almost certainly failed or its circuit is broken.
  • The resistance measurement at the sensor connector is needed to confirm the fault — service-staff work.
  • Visible wire damage or a burnt connector anywhere near the sensor — do not attempt to repair wiring yourself.
  • HRF-628 models: heavy frost buildup on the freezer evaporator, or the unit stuck in (or never entering) defrost — the defrost-sensor fault is disrupting the cycle.

More guidance: when an appliance error requires professional service.

Safety first

Always unplug the refrigerator before touching any connector or wiring, and let it sit a few minutes. On HRF-628 models a defrost-sensor fault can let frost choke the evaporator — never chip at ice with tools (puncturing the evaporator releases refrigerant). Never probe a live control board or attempt sealed-system (refrigerant) work.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does F6 mean on a Haier refrigerator?

It depends on the family. On HB21F models, F6 means the icemaker sensor (ICE SNR) has a short or open circuit (Haier HB21FWRSS service manual, EDITION 2008-03-24). On HRF-628 models, F6 means the defrost sensor (D SNR) has a short or open circuit (Haier HRF-628AF6/IF6 service manual, Issue 2013-04-07). Same code, different sensor — check your rating label.

My icemaker still makes some ice with F6 showing. How?

On HB21F models the manual documents a fallback: 'The ice maker will rotate every 100 minutes if the ice make sensor is error.' So slow, erratic ice production can continue — it does not mean the sensor is fine.

How do I see the F6 code on my Haier fridge?

HB21F: press the freezer temperature control (>) and the fridge temperature controls (<) and (>) together for 3 seconds and read the cabinet display. HRF-628: under LOCK status press (E) + 'Ref. Temp' (D) for 3 seconds — the display shows '--' with a buzzer, then the code appears after another 3 seconds.

Can I reset Haier refrigerator F6 by unplugging it?

A power cycle rules out a display glitch, but a genuine F6 is a hard sensor fault and no reset repairs it. On HB21F you can also run the manual's icemaker self-test — with the freezer light switch closed, press and hold freezer '<' + fridge '>' for 3 seconds ('EXPRESS FRZ' blinks on the cabinet display). If F6 persists, it needs a technician.
