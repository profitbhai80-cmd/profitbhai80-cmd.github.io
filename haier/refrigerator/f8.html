Haier Refrigerator Error Code F8

Quick answer

Error codeF8 — Haier Refrigerator
What it meansF8 means the R2 sensor — the second refrigerator-compartment sensor, on the side wall of the refrigerator — has a short or open circuit, per the Haier HRF-628AF6/IF6 service manual. It is an HRF-628-family-only code.
Most common causeA failed or disconnected second refrigerator sensor (R2 SNR, side wall of the refrigerator), or a wiring fault between the sensor and the main board.
Safe to check yourself?Only the code recall and a power-cycle check. Sensor resistance testing (the manual's §7-3 table) and replacement are technician work.
Checked againstHaier HRF-628AF6/IF6 Service Manual (Issue 2013-04-07, Ref1304S001V0); Haier HRF-663ISB2 Service Manual (Issue 20090416, Ref0904S016V0) — R2 SNR fault documented (blink-pattern display); Haier HB21FWRSS Service Manual (EDITION 2008-03-24) — no F8, no R2 sensor; Haier HRF-6631RG user manual — code list stops at F3

Applies to — read this first

F8 is an HRF-628-family-only code. The Haier HRF-628AF6/IF6 service manual defines F8 as the R2 sensor failure — 'R2 SNR is short circuit or open circuit.' R2 SNR is the second refrigerator-compartment sensor (side wall of the refrigerator), distinct from R1 SNR at the refrigerator damper assembly. The HB21F manuals have no F8 and no R2 sensor; the HRF-663/664 user manual's code list stops at F3. Check your model family on the rating label first — see how to find your model number.

Haier HRF-663ISB2 service manual (Issue 20090416, Ref0904S016V0)§2.8.1 fault diagnostics, item 5: "R2 SNR is defective — R2 SNR short circuit or broken circuit" (display: 'Refrigerator setting 2 glitters'; remark: 'Check the connection of each sensor'). Same fault on a second family, different display scheme. Sensor table: R2 SNR — side wall of refrigerator; R1 SNR — refrigerator damper assembly.
Haier HB21FWRSS / HB21FNN service manuals; HRF-6631RG user manualNo F8 and no R2 sensor in the HB21F manuals (single R1 refrigerator sensor only); the HRF-6631RG user manual lists only E0, E1, E2, F1, F2, F3. F8 is undefined on these families.

Neighbouring codes (HRF-628 error code list): F3 = refrigerator sensor 1 (R1) failure, F4 = freezer (F) sensor failure, F2 = ambient (RT) sensor failure, F6 = defrost (D) sensor failure, FC = icemaker sensor failure. Do not confuse with other brands: on AEG fridge-freezers F8 is a defrost-element/software fault — error codes are not universal across brands.

What the machine does when F8 fires

HRF-628 codes cannot display automatically ('Fault code automatically hiding function') — recall them with the LOCK + (E) + 'Ref. Temp' (D) 3-second press. The R2 sensor helps regulate the refrigerator compartment; with it failed, compartment temperature control is degraded — check stored food if cooling has been off.

Common causes

  1. The R2 (second refrigerator compartment) sensor has failed — short circuit or open circuit. The HRF-628AF6/IF6 service manual lists this as the definition of F8.
  2. The sensor's wiring or connector to the main board is loose, corroded, or damaged — the manuals name the sensor connection as the first thing to check.
  3. A main-board fault misreading the sensor circuit — if the wiring and sensor test good, the board's reading circuit is the remaining suspect.

Safe checks, in order

  1. Confirm your model is an HRF-628-family model (check the rating label) — F8 exists only there. See our guide to finding your model number.
  2. Recall the code: under LOCK status press (E) + 'Ref. Temp' (D) for 3 seconds; '--' shows with a buzzer, then the code displays after another 3 seconds. Confirm it is F8.
  3. Power-cycle once: unplug, wait a few minutes, replug, and recall the code — ruling out a display glitch.
  4. If F8 returns, stop: the manual's next step is the R2 sensor resistance check (§7-3 'Sensors and error codes' table) — back-panel-off, multimeter work reserved for service staff.

Work through the checks in order and stop as soon as the code clears. A hard sensor fault (short or open circuit) cannot be cleared by any reset — the power-cycle step only rules out a display glitch. If a check needs a panel removed, a connector probed, or a part tested, it is no longer a safe home check — skip to the technician section.

When to call a technician

  • F8 returns after every power cycle — the R2 sensor is almost certainly failed or its circuit is broken.
  • The §7-3 resistance measurement is needed to confirm the fault — service-staff work.
  • Visible wire damage anywhere near the sensor — do not attempt to repair wiring yourself.
  • The refrigerator compartment is not holding its set temperature — the failed R2 sensor is degrading temperature control.

More guidance: when an appliance error requires professional service.

Safety first

Always unplug the refrigerator before touching any connector or wiring, and let it sit a few minutes. A failed R2 sensor can let the refrigerator compartment drift out of safe temperatures — check stored food for spoilage. Never probe a live control board or attempt sealed-system (refrigerant) work.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does F8 mean on a Haier refrigerator?

On HRF-628-family models (HRF-628AF6/IF6), F8 means the R2 sensor — the second refrigerator-compartment sensor — has a short or open circuit, per the Haier HRF-628AF6/IF6 service manual (Issue 2013-04-07). F8 does not exist on HB21F or HRF-663/664 models.

What is the difference between the R1 and R2 sensors?

Both sense the refrigerator compartment but sit in different places: R1 SNR is at the refrigerator damper assembly and controls the damper's start/stop; R2 SNR is on the side wall of the refrigerator (per the Haier HRF-663ISB2 sensor table, which uses the same sensor naming). On HRF-628 models, F3 = R1 failure and F8 = R2 failure.

How do I see the F8 code on my Haier fridge?

HRF-628 codes cannot display automatically. Under LOCK status press (E) + 'Ref. Temp' (D) for 3 seconds — the display shows '--' with one buzzer, then the code appears after another 3 seconds.

Can I reset Haier refrigerator F8 by unplugging it?

A power cycle rules out a display glitch, but a genuine F8 is a hard sensor fault and no reset repairs it. If F8 returns, the R2 sensor or its wiring needs a technician.
