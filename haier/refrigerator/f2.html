Haier Refrigerator Error Code F2

Quick answer

Error codeF2 — Haier Refrigerator
What it meansF2 means the freezer sensor has a malfunction — the F sensor has a short circuit or an open circuit, per the Haier HB21FWRSS service manual. The meaning is precisely defined only for the HB21F family: on HRF-663/664 and HRF-628 families Haier's own manuals list F2 among the display codes without defining it, and third-party lists contradict each other there — so this page carries the family split and flags those claims as unverified.
Most common causeA failed or disconnected freezer-compartment sensor (F SNR), or a wiring fault between the sensor and the main board.
Safe to check yourself?Only the code recall and a power-cycle check. Sensor resistance testing and replacement are technician work.
Checked againstHaier HB21FWRSS Refrigerator Service Manual (EDITION 2008-03-24); Haier HRF-370F user manual (self-check section); Haier HRF-6631RG user manual (code list); Haier HRF-348K operation manual

Applies to — read this first

F2 needs its family label read carefully — more carefully than F1. On the HB21F family the Haier service manual defines F2 exactly (freezer sensor malfunction). On the HRF-370F family the user manual lists F2 among the sensor-malfunction display codes. But on HRF-663/664 and HRF-628 families, Haier's manuals list F2 with no meaning at all — and the one ranking repair list assigns it two contradictory meanings ('refrigerator sensor R2' vs 'ambient sensor') with no source. Check your model family on the rating label first — see how to find your model number.

ManualExact wording for F2
Haier HB21FWRSS service manual (EDITION 2008-03-24)"Freezer sensor malfunction — F2 — F SNR short circuit or open circuit" (Malfunction Codes Table, No. 2). Sensor check: freezer sensor CN4 pins 1–2, about 10.9–25.19 kΩ at −10…−25 °C and 2.45–1.61 kΩ at room temperature.
Haier HRF-370F user manual (§14 Self-check function)"If one of the four refrigerator sensors does not work properly, indicator E, F or G will display F1, F2, F3 or F4 accordingly to the sensor malfunction."
Haier HRF-6631RG / HRF-663CJW user manualsF2 is listed among the display codes (E0, E1, E2, F1, F2, F3) with the instruction to contact customer service — no per-code meaning given. Do not read the HB21F meaning across to this family.

Neighbouring codes (HB21F table): F1 = refrigerator sensor malfunction, F3 = environment temperature sensor, F5 = defrost sensor. The 3-button recall (freezer > + fridge < + > for 3 seconds) is the same as for F1 — see our Haier refrigerator F1 guide.

What the machine does when F2 fires

On HB21F models the codes are not shown automatically — recall them with the freezer (>) + fridge (<) + (>) 3-second press; the code appears on the cabinet display. A freezer-sensor fault means the freezer compartment temperature is no longer being regulated — the compressor may run wrongly and food safety is at stake.

Common causes

  1. The F (freezer compartment) sensor has failed — short circuit or open circuit.
  2. The sensor's wiring or connector to the main board is loose, corroded, or damaged.
  3. A main-board fault misreading the sensor circuit.

Safe checks, in order

  1. Recall the code with the 3-button sequence (freezer > + fridge < + > for 3 seconds) and confirm it is F2.
  2. Power-cycle once: unplug, wait a few minutes, replug, and recall the code — ruling out a display glitch.
  3. With the power OFF and the machine unplugged, visually inspect visible sensor connectors for looseness or corrosion. Do not cut, splice, or probe any wires.
  4. If F2 returns, stop: the manual's next step is the CN4 resistance measurement — back-panel-off, multimeter work reserved for service staff.

Work through the checks in order and stop as soon as the code clears. A hard sensor fault cannot be cleared by any reset. If a check needs a panel removed, a connector probed, or a part tested, it is no longer a safe home check — skip to the technician section.

When to call a technician

  • F2 returns after every power cycle.
  • The CN4 resistance measurement is needed to confirm the fault.
  • Visible wire damage anywhere near the sensor.
  • The freezer is not holding temperature or the compressor runs abnormally — food safety is at risk, so do not delay the call.

Safety first

Always unplug the refrigerator before touching any connector or wiring. A failed freezer sensor can let food enter the danger zone — check frozen food for thawing and discard anything questionable. Never probe a live control board or attempt sealed-system work.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does F2 mean on a Haier refrigerator?

On the HB21F family, F2 means the freezer sensor has a malfunction — "F SNR short circuit or open circuit," per the Haier HB21FWRSS service manual. On HRF-663/664 and HRF-628 families Haier's manuals list F2 without defining it, so the meaning there is unverified.

How do I see the F2 code on my Haier fridge?

On HB21F models the codes don't display automatically: press the freezer temperature control (>) and the fridge temperature controls (<) and (>) together for 3 seconds; the code appears on the cabinet display.

Can I reset Haier fridge F2 by unplugging it?

A power cycle rules out a display glitch, but a genuine F2 is a hard sensor fault — a shorted or open freezer sensor circuit — and no reset repairs that.

One site says F2 is the ambient sensor and another says R2 sensor. Which is right?

Neither is manual-verified. The top-ranking repair list gives F2 two contradictory meanings on HRF-663/664 and HRF-628 ('refrigerator sensor R2' vs 'ambient sensor') with no source, while Haier's own manuals for those families define no F2 meaning. Only the HB21F family's F2 = freezer sensor is manual-verified.
