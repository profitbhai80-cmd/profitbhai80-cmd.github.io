Haier Error Codes

Haier error codes for washing machines and refrigerators, checked against Haier user and service manuals. Haier uses different code sets on top-load, front-load and refrigerator families, and each guide below states exactly which family it applies to.

28 verified Haier guides — each one names the manual it was checked against. You can also search all error codes across every brand.

Haier Washing Machine Error Codes

E2

Haier Washing Machine Error E2

Series-dependent: on the HW80-B14979 front-load model it is a door lock error; on the HWM90DD top-load model the top lid is not closed during the wash.

 E1

Haier Washing Machine Error E1

Drainage failure on all families that use E1: blocked drain hose (top-load HWM/HWT families) or clogged pump filter (European HW-B1426 front-load family). The HW80/HW100/HW120-B14979 and HWF85ANB1/HWF90ANB1 families do not use E1 — drainage faults there show as CLR FLTR.

 E3

Haier Washing Machine Error E3

E3 = safety switch acted: the machine cannot spin (imbalance fault after two automatic rebalancing attempts). Top-load families only — B14979 front-loads use 'Unb'. Manual fix: redistribute load, open/close lid once, level the machine.

 E4

Haier Washing Machine Error E4

E4 = water level not reached in time (fill timeout: 12 min B14979 front-load, ~15 min top-loads). Manual checklist: tap, pressure, inlet hose/filter. Distinct from FA (sensor) and E8 (self-syphoning).

 E5

Haier Washing Machine Error E5

E5 = split code: water level sensor fault (HLT/GWT — call service) OR water too hot over 60°C (HWM70-A — let it cool, press Start/Pause).

 E6

Haier Washing Machine Error E6

E6 = water level sensor is bad (template top-loads). No home fix is documented — power-cycle once, then call after-sales service.

 E7

Haier Washing Machine Error E7

E7 = communication fault ("The communication is bad"). No home fix is documented — power-cycle once, then call after-sales service.

 E8

Haier Washing Machine Error E8

E8 = water level not reached within 8 minutes (top-loaders). Check tap, hose, valve filter.

 F3

Haier Washing Machine Error F3

F3 = temperature sensor error. No user step — contact after-sales service.

 F4

Haier Washing Machine Error F4

F4 = heater error. No user step — contact after-sales service.

 F7

Haier Washing Machine Error F7

F7 = motor error. No user step — contact after-sales service.

 FA

Haier Washing Machine Error FA

FA = water level sensor error. No user step — contact after-sales service.

 FC

Haier Washing Machine Error FC

FC = board communication error (top-loaders). Power off/on once; then contact service.

 Unb

Haier Washing Machine Error Unb

Unb = unbalanced load — spin didn't reach full speed. Redistribute and retry.

Haier Refrigerator Error Codes

F1

Haier Refrigerator Error F1

F1 = refrigerator (R1) sensor malfunction: short circuit or open/broken circuit. Codes are recalled with a 3-button sequence on HB21F models; shown directly on HRF-663 models.

 F2

Haier Refrigerator Error F2

F2 = freezer sensor malfunction (F SNR short or open circuit) on the HB21F family. On HRF-663/664 and HRF-628 families Haier's manuals list F2 with no defined meaning — the family split matters.

 F3

Haier Refrigerator Error F3

F3 = temperature sensor fault — but WHICH sensor depends on your model family: ambient (RT) sensor on HB21F, refrigerator sensor 1 (R1) on HRF-628. No reset can fix a hard sensor fault.

 F4

Haier Refrigerator Error F4

F4 = freezer sensor fault (F SNR short or open circuit) on HRF-628-family models. No reset can fix it — this is a hard sensor fault.

 F6

Haier Refrigerator Error F6

F6 = sensor fault — but WHICH sensor depends on family: icemaker sensor (ICE SNR) on HB21F, defrost sensor (D SNR) on HRF-628. No reset fixes a hard sensor fault.

 F8

Haier Refrigerator Error F8

F8 = second refrigerator sensor (R2 SNR) fault — short or open circuit — on HRF-628-family models only. No reset can fix a hard sensor fault.

 F5

Haier Refrigerator Error F5

F5 = defrost sensor fault (D SNR short or open circuit) on HB21F models. No reset can fix it — and on HRF-628 models the defrost sensor is F6, not F5.

Haier Dishwasher Error Codes

E4

Haier Dishwasher Error E4

E4 = drain hose crimped/bent or too high (buzzer: 10 short signals every 30s). Straighten the hose, set its free end at 40–100 cm, power-cycle; if it persists, call the authorised service centre.

 E1

Haier Dishwasher Error E1

E1 = door not closed properly (buzzer: 10 short signals every 30s). Re-close the door firmly, power-cycle, and call the authorised service centre if it persists; XS models have no E1.

 E3

Haier Dishwasher Error E3

E3 = drain hose too low (DW/HDW) / dishwasher does not drain (XS: bent or blocked pipe, clogged filter or siphon). Re-route the hose into the 40-100 cm range, clear filter and siphon, power-cycle.

 E5

Haier Dishwasher Error E5

E5 = water-supply fault (tap on and hose connected, house pressure, supply hose not crimped/bent, supply filter clean). Power-cycle, then call the authorised service centre if it persists; XS models have no E5.

 E2

Haier Dishwasher Error E2

E2 = dishwasher does not fill with water (XS models only: check supply open, hose not bent/crushed, drain-pipe height, sand filter). On DW/HDW models E2 means contact service only.

 E8

Haier Dishwasher Error E8

Haier DW E8 (XS/XF) = heating element or clogged filter plate — clean the filter plate; XPI8 E8 means leak.

 E18

Haier Dishwasher Error E18

Haier DW E18 (XS) = water-level problem, clean the filter plate — not Bosch E18.
