Haier Error Codes

Haier error codes for washing machines, refrigerators, dishwashers and air conditioners, checked against Haier user and service manuals. Haier uses different code sets on top-load, front-load and refrigerator families, and each guide below states exactly which family it applies to.

117 verified Haier guides — each one names the manual it was checked against. You can also search all error codes across every brand.

Haier Washing Machine Error Codes

E2

Haier Washing Machine Error E2

Series-dependent: on the HW80-B14979 front-load model it is a door lock error; on the HWM90DD top-load model the top lid is not closed during the wash.

 E1

Haier Washing Machine Error E1

Drainage failure on all families that use E1: blocked drain hose (top-load HWM/HWT families) or clogged pump filter (European HW-B1426 front-load family). The HW80/HW100/HW120-B14979 and HWF85ANB1/HWF90ANB1 families do not use E1 — drainage faults there show as CLR FLTR.

 E3

Haier Washing Machine Error E3

E3 = safety switch acted: the machine cannot spin (imbalance fault after two automatic rebalancing attempts). Top-load families only — B14979 front-loads use 'Unb'. Manual fix: redistribute load, open/close lid once, level the machine.

 E4

Haier Washing Machine Error E4

E4 = water level not reached in time (fill timeout: 12 min B14979 front-load, ~15 min top-loads). Manual checklist: tap, pressure, inlet hose/filter. Distinct from FA (sensor) and E8 (self-syphoning).

 E5

Haier Washing Machine Error E5

E5 = split code: water level sensor fault (HLT/GWT — call service) OR water too hot over 60°C (HWM70-A — let it cool, press Start/Pause) OR Refresh drainage, water not fully drained within 1 minute (HW70-B12929-S / HWD-B14979 — clean pump filter, check drain hose).

 E6

Haier Washing Machine Error E6

E6 = water level sensor is bad (template top-loads). No home fix is documented — power-cycle once, then call after-sales service.

 E7

Haier Washing Machine Error E7

E7 = communication fault ("The communication is bad"). No home fix is documented — power-cycle once, then call after-sales service.

 E8

Haier Washing Machine Error E8

E8 = water level not reached within 8 minutes (top-loaders). Check tap, hose, valve filter.

 F3

Haier Washing Machine Error F3

F3 = temperature sensor error. No user step — contact after-sales service.

 F9

Haier Washing Machine Error F9

F9 = dry temperature sensor error (Haier washer-dryer combos only). No home fix documented — book a service technician.

 F4

Haier Washing Machine Error F4

F4 = heater error. No user step — contact after-sales service.

 F7

Haier Washing Machine Error F7

F7 = motor error. No user step — contact after-sales service.

 FA

Haier Washing Machine Error FA

FA = water level sensor error. No user step — contact after-sales service.

 FC

Haier Washing Machine Error FC

FC = board communication error (top-loaders). Power off/on once; then contact service.

 Unb

Haier Washing Machine Error Unb

Unb = unbalanced load — spin didn't reach full speed. Redistribute and retry.

 E9

Haier Washing Machine Error E9

E9 is a series split: on digitron top-loads (XQS/WM/HWM) it means power voltage too high — unplug and wait; on HWM200 series it means show-board/power-board communication failure — contact Customer Care.

 Fb

Haier Washing Machine Error Fb

Fb = water overflow: a leak reached the base pan and tripped the float. Close the tap immediately — the drain pump runs automatically for safety. Not the same as E8.

 E11

Haier Washing Machine Error E11

Haier washer E11: fill-timeout code on the XQG50/HWD1000 washer-dryer combo platform — tap, pressure, hose, filter checks.

 E13

Haier Washing Machine Error E13

Haier washer E13: overfill on the combo platform — tap off, do not restart, call a technician (no user fix in the manuals).

 EI

Haier Washing Machine Error EI

Haier washer EI: drainage error on the B1426 family — pump filter clean, drain hose check, EI-vs-E1 display-code split explained.

 F2

Haier Washing Machine Error F2

Haier washer F2: top-load overflow protection — verbatim rows from 5 manuals, F2-vs-Fb-vs-E8 split, honest no-DIY-fix boundary.

 E31

Haier Washing Machine Error E31

Haier washer E31: motor fault — the 8-min spec, justanswer drainage reading disproven.

 EA3

Haier Washing Machine Error EA3

Haier washer EA3: drying water level — the EA3-H display trap, EA3-vs-E13 split.

 EC1

Haier Washing Machine Error EC1

Haier washer EC1: heater fault — washes cold, XQG50-only scope note.

 EC2

Haier Washing Machine Error EC2

Haier washer EC2: water temp sensor — the EC2-vs-EC5 OCR phrase-swap trap.

 EC3

Haier Washing Machine Error EC3

Haier washer EC3: water level sensor — the 4-platform sensor disambiguation.

 EC4

Haier Washing Machine Error EC4

Haier washer EC4: air-vent temp — the 30-min/5-min spec, EC4-vs-EC5-vs-EC1 split.

 EC5

Haier Washing Machine Error EC5

Haier washer EC5: dry temp sensor — the sensor-trio disambiguation.

 E22

Haier Washing Machine Error E22

Haier washer E22: EEPROM failure — the U04/E22 OCR-swap resolution.

Haier Refrigerator Error Codes

F1

Haier Refrigerator Error F1

F1 = refrigerator (R1) sensor malfunction: short circuit or open/broken circuit. Codes are recalled with a 3-button sequence on HB21F models; shown directly on HRF-663 models.

 F2

Haier Refrigerator Error F2

F2 = freezer sensor malfunction (F SNR short or open circuit) on the HB21F family. On HRF-663/664 and HRF-628 families Haier's manuals list F2 with no defined meaning — the family split matters.

 F3

Haier Refrigerator Error F3

F3 = temperature sensor fault — but WHICH sensor depends on your model family: ambient (RT) sensor on HB21F, refrigerator sensor 1 (R1) on HRF-628. No reset can fix a hard sensor fault.

 F4

Haier Refrigerator Error F4

F4 = freezer sensor fault (F SNR short or open circuit) on HRF-628-family models. No reset can fix it — this is a hard sensor fault.

 F6

Haier Refrigerator Error F6

F6 = sensor fault — but WHICH sensor depends on family: icemaker sensor (ICE SNR) on HB21F, defrost sensor (D SNR) on HRF-628. No reset fixes a hard sensor fault.

 F8

Haier Refrigerator Error F8

F8 = second refrigerator sensor (R2 SNR) fault — short or open circuit — on HRF-628-family models only. No reset can fix a hard sensor fault.

 F5

Haier Refrigerator Error F5

F5 = defrost sensor fault (D SNR short or open circuit) on HB21F models. No reset can fix it — and on HRF-628 models the defrost sensor is F6, not F5.

Haier Dishwasher Error Codes

E4

Haier Dishwasher Error E4

E4 = drain hose crimped/bent or too high (buzzer: 10 short signals every 30s). Straighten the hose, set its free end at 40–100 cm, power-cycle; if it persists, call the authorised service centre.

 E1

Haier Dishwasher Error E1

E1 = door not closed properly (buzzer: 10 short signals every 30s). Re-close the door firmly, power-cycle, and call the authorised service centre if it persists; XS models have no E1.

 E3

Haier Dishwasher Error E3

E3 = drain hose too low (DW/HDW) / dishwasher does not drain (XS: bent or blocked pipe, clogged filter or siphon). Re-route the hose into the 40-100 cm range, clear filter and siphon, power-cycle.

 E5

Haier Dishwasher Error E5

E5 = water-supply fault (tap on and hose connected, house pressure, supply hose not crimped/bent, supply filter clean). Power-cycle, then call the authorised service centre if it persists; XS models have no E5.

 E6

Haier Dishwasher Error E6

Haier DW E6: water overflow trouble — float/overflow switch tripped, drain pump keeps running. DW12-PFE8 + DW12-TFE3 only; not the door, leak or water supply.

 E2

Haier Dishwasher Error E2

E2 = dishwasher does not fill with water (XS models only: check supply open, hose not bent/crushed, drain-pipe height, sand filter). On DW9/DW12-TFE1/TFE2/HDW12 models E2 means contact service only; on DW12-PFE8/TFE3 it is a sensor fault.

 E8

Haier Dishwasher Error E8

Haier DW E8 (XS/XF) = heating element or clogged filter plate — clean the filter plate; XPI8 E8 means leak.

 E18

Haier Dishwasher Error E18

Haier DW E18 (XS) = water-level problem, clean the filter plate — not Bosch E18.

 E9

Haier Dishwasher Error E9

E9 = a touch button registered as pressed for over 30 seconds — caused by water or substance on the button. A wet touch key, not a software fault.

 E10

Haier Dishwasher Error E10

Haier DW E10: inlet/fill fault (E11/E12 tap-closed sub-codes) - manuals' own checks and reset.

 E20

Haier Dishwasher Error E20

Haier DW E20: drainage fault - manuals' checks, install data, turbidity-drain myth debunked.

 E30

Haier Dishwasher Error E30

Haier DW E30: overflow / anti-flood alarm - verbatim F30 rows, honest service routing.

 E40

Haier Dishwasher Error E40

Haier DW E40: flow-meter fault (F40/E41/E42) - invented E41 story corrected.

 E50

Haier Dishwasher Error E50

Haier DW E50: communication/electronics fault - invented E51/E52 board claims debunked.

 E60

Haier Dishwasher Error E60

Haier DW E60: heating fault (A60, not F60) - false F60 alias corrected.

 E70

Haier Dishwasher Error E70

Haier DW E70: NTC sensor fault - E60-vs-E70 split, CANCEL-reset procedure.

 E80

Haier Dishwasher Error E80

Haier DW E80: turbidity sensor fault - dishwasherusa E7 trap called out.

 E81

Haier Dishwasher Error E81

Haier DW E81: turbidity calibration sub-fault - thin page, honest caveat.

 E82

Haier Dishwasher Error E82

Haier DW E82: turbidity signal sub-fault - own official row, honest caveat.

 FA0

Haier Dishwasher Error FA0

Haier DW FA0 (FAO): frequency synchronisation / power supply fault - check whether other appliances are misbehaving.

 FC0

Haier Dishwasher Error FC0

Haier DW FC0 (FCO): wash pump / motor fault - switch OFF at the power supply, wait a few moments, switch ON again.

 A09

Haier Dishwasher Error A09

Haier DW A09: sanitise cycle did not reach the temperature needed to sanitise dishes - re-run the cycle; book a service if it faults again.

 F90

Haier Dishwasher Error F90

Haier DW F90: data/electronics error ('6' variants only - DW24U6I / DW60FC6 / DW60U6I) - switch OFF and ON again; if it persists, call Customer Care.

Haier Air Conditioner Error Codes

E7

Haier Split Air Conditioner Error E7

Haier split AC E7: communication fault between indoor and outdoor units — LED1 flashes 15 times, 4-minute rule, wiring checks (M1/M2/M3). Not the remote control, not a fan fault.

 E1

Haier Split Air Conditioner Error E1

Haier split AC E1: room temperature sensor failure — defective connector, thermistor or indoor PCB (M1/M2/M3/M4). Portable E1 is the coil sensor instead.

 E14

Haier Split Air Conditioner Error E14

Haier split AC E14: indoor fan motor failure — wire-break causes, M2/M4 flowcharts (M1/M2/M3/M4). Not the outdoor fan (F8).

 F1

Haier Split Air Conditioner Error F1

Haier split AC F1: power module (IPM) protection — LED1 2 flashes, locks after 3 trips in an hour (M2/M3/M7). No owner fix.

 F2

Haier Split Air Conditioner Error F2

Haier split AC F2: failed to start compressor / compressor overcurrent — LED1 24 flashes, locks after 3 trips in an hour (M2/M3/M7). Cabinet F24, not F2.

 F3

Haier Split Air Conditioner Error F3

Haier split AC F3: communication fault between the IPM power module and the outdoor PCB — LED1 4 flashes, 4-minute rule (M2/M3/M7). Not E7.

 F4

Haier Split Air Conditioner Error F4

Haier split AC F4: compressor discharge overheat protection — LED1 8 flashes, locks after 3 trips in an hour (M2/M3/M7/M8). Threshold 110 °C vs above 120° — both shown.

 F6

Haier Split Air Conditioner Error F6

Haier split AC F6: outdoor ambient temperature sensor failure — LED1 12 flashes, short/open within 60 seconds (M2/M3/M7). No flowchart or fix in any manual; F66 is a phantom.

 E2

Haier Split Air Conditioner Error E2

Haier split AC E2: heat exchanger (coil) temperature sensor failure — CN6 test, 2-minute rule (M1/M2/M3/M4). Not coil freezing (E5).

 E4

Haier Split Air Conditioner Error E4

Haier split AC E4: indoor EEPROM error — data error / defective EEPROM / defective PCB (M1/M2/M3/M4). No reset fixes it; M4 says replace the PCB.

 F19

Haier Split Air Conditioner Error F19

Haier split AC F19: power voltage too high or too low — LED1 6 flashes, M2 p.48 flowchart (M2/M3/M7). Thresholds 270V/187V AC vs >390V/<150V DC-bus — both shown.

 F8

Haier Split Air Conditioner Error F8

Haier split AC F8: outdoor DC fan motor fault — LED1 9 flashes, 2-minute feedback rule, M2 p.45 flowchart (M2/M3/M7). Not a sensor or high-pressure fault.

 F11

Haier Split Air Conditioner Error F11

Haier split AC F11: loss of compressor synchronism detection — LED1 18 flashes, rotor position undetectable (M2/M3/M7). Not EEPROM (F12) or voltage (F19).

 F22

Haier Split Air Conditioner Error F22

Haier split AC F22: AC overcurrent protection for the outdoor model — LED1 3 flashes, shared F22/F2/F23 flowchart (M2/M3/M7). Cabinet F22 is PFC overcurrent.

 F23

Haier Split Air Conditioner Error F23

Haier split AC F23: single-phase / U-V-W compressor phase overcurrent — LED1 25 flashes, shared F22/F2/F23 flowchart (M2/M3/M7). M7 trouble record.

 F7

Haier Split Air Conditioner Error F7

Haier split AC F7: suction (compressor intake) temperature sensor failure — LED1 11 flashes (M2/M3/M7). Not defrost (F21); no flowchart or fix in any manual.

 F12

Haier Split Air Conditioner Error F12

Haier split AC F12: outdoor EEPROM error — LED1 1 flash, outdoor motherboard EEPROM faulty (M2/M3/M7). Not E4 (indoor EEPROM).

 F21

Haier Split Air Conditioner Error F21

Haier split AC F21: outdoor defrosting temperature sensor failure — LED1 10 flashes, short/open within 60 seconds (M2/M3/M7). Not F7 (suction).

 F25

Haier Split Air Conditioner Error F25

Haier split AC F25: delivery temperature sensor failure — LED1 13 flashes (M2/M3/M7). Not F4 (overheat protection); no flowchart or fix in any manual.

 F27

Haier Split Air Conditioner Error F27

Haier split AC F27: compressor locked rotor / stall — LED1 7 flashes, locks after 3 alarms in an hour (M2/M3/M7). No DIY fix in any manual.

 F28

Haier Split Air Conditioner Error F28

Haier split AC F28: outdoor compressor-drive fault — LED1 19 flashes, three manual wordings shown honestly (M2/M3/M7). Not loss of synchronism alone.

 F36

Haier Split Air Conditioner Error F36

Haier split AC F36: condenser temperature sensor (TC) failure — LED1 39 flashes, highest in this batch (M2/M3). M7 does not list F36.

 F5

Haier Split Air Conditioner Error F5

Haier split AC F5: SPDU/ISPM power module temperature protection — LED1 23 flashes, locks after 3 trips in an hour (M3/FlexFit). Not overcurrent.

 F9

Haier Split Air Conditioner Error F9

Haier split AC F9: power module (MCU) reset — LED1 26 flashes (M3/M7/FlexFit). No reset procedure in any manual.

 F13

Haier Split Air Conditioner Error F13

Haier split AC F13: lack of refrigerant / clogged delivery tube — LED1 16 flashes, Td-Tci >= 25°C rule (M3/M7/FlexFit). Not F3.

 F14

Haier Split Air Conditioner Error F14

Haier split AC F14: 4-way valve switching failure — LED1 17 flashes, coil or mechanical failure (M3/M7/FlexFit). Not F25.

 F15

Haier Split Air Conditioner Error F15

Haier split AC F15: board / terminal overheating — LED1 20 flashes (M3+M7 only). Not a compressor fault; cabinet F15 is a comms fault.

 F20

Haier Split Air Conditioner Error F20

Haier split AC F20: compressor overcurrent / high-pressure protection — LED1 5 flashes, locks after 3 trips in an hour (M3/M7/Haier India). Not cabinet F20.

 F24

Haier Split Air Conditioner Error F24

Haier split AC F24: no charge / faulty amperometric (CT) control — LED1 27 flashes (M3/M7/Haier India/haier-ac.pt). Not cabinet F24.

 E5

Haier Split Air Conditioner Error E5

Haier split AC E5: indoor unit ice protection — LED1 22 flashes (M7 p.25; M3 Table A). Not overcurrent or a drainage fault.

 E8

Haier Split Air Conditioner Error E8

Haier split AC E8: wired-controller ↔ indoor-unit communication fault — no comms for 4+ minutes (M3/FlexFit). Not E7 and not a motor fault.

 E9

Haier Split Air Conditioner Error E9

Haier split AC E9: indoor piping too high — internal unit overload, LED1 21 flashes (M3/M7/HSU). Not a comms fault.

 F10

Haier Split Air Conditioner Error F10

Haier split AC F10: liquid pipe circuit A sensor failure — outdoor error 28 (M3/FlexFit). Not a power fault.

 F16

Haier Split Air Conditioner Error F16

Haier split AC F16: liquid pipe circuit B sensor failure — outdoor error 29, multi-split only (M3/FlexFit).

 F17

Haier Split Air Conditioner Error F17

Haier split AC F17: liquid pipe circuit C sensor failure — outdoor error 30, multi-split only, 3+ indoor units (M3/FlexFit).

 F18

Haier Split Air Conditioner Error F18

Haier split AC F18: liquid pipe circuit D sensor failure — LED1 31 flashes, multi-split only (M3/M8/M9). Cabinet F18 is synchronism loss.

 F29

Haier Split Air Conditioner Error F29

Haier split AC F29: gas pipe circuit A temperature sensor failure — LED1 32 flashes, multi-split only (M3/M8/M9). Not the liquid pipe sensor (F10).

 F30

Haier Split Air Conditioner Error F30

Haier split AC F30: gas pipe circuit B temperature sensor failure — LED1 33 flashes, multi-split only (M3/M8/M9). Not F16, and not the hidden F30* suction code.

 F31

Haier Split Air Conditioner Error F31

Haier split AC F31: gas pipe circuit C temperature sensor failure — LED1 34 flashes, multi-split only (M3/M8/M9). Not F17, and not the dryer F31.

 F32

Haier Split Air Conditioner Error F32

Haier split AC F32: gas pipe circuit D temperature sensor failure — LED1 35 flashes, multi-split only (M3/M8/M9). Not F18, and not the dryer F32.

 F33

Haier Split Air Conditioner Error F33

Haier split AC F33: liquid pipe circuit E temperature sensor failure — LED1 40 flashes, multi-split only (M3/M8/M9). Not the gas pipe sensor (F26), and not the dryer F33.

 F34

Haier Split Air Conditioner Error F34

Haier split AC F34: outdoor exchanger temperature protection — outdoor error 37, LED1 37 flashes (M3/M7/FlexFit). Not F36 (the TC sensor fault).

 F35

Haier Split Air Conditioner Error F35

Haier split AC F35: power module temperature sensor failure — outdoor error 38, LED1 38 flashes (M3/M7/FlexFit). M7's "driver board failure" is the same code.

 F39

Haier Split Air Conditioner Error F39

Haier split AC F39: high pressure switch alarm — outdoor error 42, locks after 3 trips in an hour (M3/FlexFit/1U105). Not F41's protection.

 F40

Haier Split Air Conditioner Error F40

Haier split AC F40: low pressure switch alarm — outdoor error 43, 60-second / 30-second-standby rule (M3/FlexFit/1U105). Not F42's system protection.

 F41

Haier Split Air Conditioner Error F41

Haier split AC F41: outdoor heat exchanger TC too high — outdoor error 44, Tc/Te over 65°C, 3-in-30-min lock (M3/FlexFit/1U105). One fault, two labels.

 F42

Haier Split Air Conditioner Error F42

Haier split AC F42: low system pressure protection — outdoor error 45, below -45°C (M3/FlexFit/1U105). Not F40's switch alarm; numeric 42 is F39.

 F43

Haier Split Air Conditioner Error F43

Haier split AC F43: indoor–outdoor protocol incorrect — model matching abnormality, LED1 46 flashes (M3/M7/FlexFit). Not E7's no-communication fault.

Haier Portable Air Conditioner Error Codes

E1

Haier Portable Air Conditioner Error E1

Haier portable E1: abnormal sense of coil pipe sensor — verified in three portable manuals (QPFA/QPCA/QPWA). Not a stuck button; split E1 is the room sensor.

 E2

Haier Portable Air Conditioner Error E2

Haier portable E2: abnormal sense of room temperature sensor — verified in three portable manuals (QPFA/QPCA/QPWA). Not a PCB fault; split E2 is the coil sensor.

 E4

Haier Portable Air Conditioner Error E4

Haier portable E4: anti-frozen protection — verified in three portable manuals (QPFA/QPCA/QPWA). Not a tank float; split E4 is the indoor EEPROM.

 FL

Haier Portable Air Conditioner Error FL

Haier portable FL: full water — the internal tank is full, unit auto-shuts-off (M5/M6/M7). Not a fault; drain from the lower drain, 5 manual steps.

Haier HDU Air Conditioner Error Codes

E0

Haier HDU Air Conditioner Error E0

Haier HDU E0: drainage system trouble — float switch down for more than 25 minutes (M6/M8). CHECK lamp flickers, flash 10; no E0 in split/portable.

 E3

Haier HDU Air Conditioner Error E3

Haier HDU E3: outdoor temperature sensor failure — broken or short-circuited for more than 2 minutes (M6/M8). Flash 3; split E3 is a voltage anomaly.

 E5

Haier HDU Air Conditioner Error E5

Haier HDU E5: overload current — CT check abnormal 3 times in 30 minutes (M6/M8). Flash 5; split E5 is ice protection.

 E6

Haier HDU Air Conditioner Error E6

Haier HDU E6: pressure protection — low-pressure switch on most models, high-pressure on HDU-14/18CL03/M (M6/M9/M8). Flash 6; not a communication fault.

 E8

Haier HDU Air Conditioner Error E8

Haier HDU E8: indoor PCB to wired controller communication fault — silent for more than 4 minutes (M6/M7/M8). Flash 8; not E9 or a motor fault.

 E9

Haier HDU Air Conditioner Error E9

Haier HDU E9: indoor to outdoor PCB communication fault (M6/M7/M8). Flash 9; split E9 is piping too high, E8 is the wired controller.
