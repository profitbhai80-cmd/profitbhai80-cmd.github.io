Haier Error Codes

Haier error codes for washing machines and refrigerators, checked against Haier user and service manuals. Haier uses different code sets on top-load, front-load and refrigerator families, and each guide below states exactly which family it applies to.

Haier Washing Machine Error Codes

E2

Haier Washing Machine Error E2

Series-dependent: on the HW80-B14979 front-load model it is a door lock error; on the HWM90DD top-load model the top lid is not closed during the wash.

 E1

Haier Washing Machine Error E1

Drainage failure on all families that use E1: blocked drain hose (top-load HWM/HWT families) or clogged pump filter (European HW-B1426 front-load family). The HW80/HW100/HW120-B14979 and HWF85ANB1/HWF90ANB1 families do not use E1 — drainage faults there show as CLR FLTR.

 E3

Haier Washing Machine Error E3

E3 = safety switch acted: the machine cannot spin (imbalance fault after two automatic rebalancing attempts). Top-load families only — B14979 front-loads use 'Unb'. Manual fix: redistribute load, open/close lid once, level the machine.

 E4

Haier Washing Machine Error E4

E4 = water level not reached in time (fill timeout: 12 min B14979 front-load, ~15 min top-loads). Manual checklist: tap, pressure, inlet hose/filter. Distinct from FA (sensor) and E8 (self-syphoning).

Haier Refrigerator Error Codes

F1

Haier Refrigerator Error F1

F1 = refrigerator (R1) sensor malfunction: short circuit or open/broken circuit. Codes are recalled with a 3-button sequence on HB21F models; shown directly on HRF-663 models.

 F2

Haier Refrigerator Error F2

F2 = freezer sensor malfunction (F SNR short or open circuit) on the HB21F family. On HRF-663/664 and HRF-628 families Haier's manuals list F2 with no defined meaning — the family split matters.
