Hisense Washing Machine — Error Code E3 Guide available

A drainage error on top-load models; a water filling error in the front-load table.

Draining fault: waste water is not being pumped out.

Daewoo Washing Machine — Error Code IE Guide available

Water fill problem: the level sensor reading is not changing, or the machine does not fill in time.

Daewoo Washing Machine — Error Code E8 Guide available

Daewoo Washing Machine — Error Code H2 Guide available

Daewoo Washing Machine — Error Code OE Guide available

Daewoo Washing Machine — Error Code UE Guide available

Midea Dishwasher — Error Code E4 Guide available

Overflow or leak protection activated; the drain pump runs.

Midea Dishwasher — Error Code E1 Guide available

Longer inlet time: the inlet valve has been open about 4 minutes without enough water entering; consistent across Midea dishwasher families.

Midea Air Conditioner — Error Code EL OC Guide available

Refrigerant leakage detection on U-shaped window units. Technician-only territory.

Haier Washing Machine — Error Code E2 Guide available

A door lock error on the HW80-B14979 front-load; a lid-not-closed error on the HWM90DD top-load.

Haier Washing Machine — Error Code E1 Guide available

Drainage failure: blocked drain hose on top-load families, or a clogged pump filter on front-load families. Some Haier families do not use E1.

Beko Dishwasher — Error Code E01 Guide available

Chassis water filling fault: water in the base tripped the anti-flood switch; the machine discharges water. On non-display models it blinks P1.

Beko Washing Machine — Error Code E08 Guide available

The machine may not be taking in water. Beko's manuals call this fault E8 — your display shows E08.

Haier Refrigerator — Error Code F1 Guide available

F1 = refrigerator (R1) sensor malfunction: short circuit or open/broken circuit. Codes are recalled with a 3-button sequence on HB21F models; shown directly on HRF-663 models.

Midea Air Conditioner — Error Code E1 Guide available

E1 = communication malfunction between the indoor and outdoor units (no feedback for 110 seconds, happening 4 times). Check wiring first; the S-to-N voltage test is technician work.

Midea Air Conditioner — Error Code EC Guide available

EC = refrigerant leak detection: the T2 coil temperature fails to drop after the compressor starts (8-minute/3-times trigger logic). Power-cycle only; pressure, leak and recharge work is technician-only.

Gree Air Conditioner — Error Code H3 Guide available

H3 = compressor overload protection on mini-split families (low charge, blocked capillary, compressor motor, loose OVC-COMP terminal; outdoor unit flashes 8×). On GMV VRF platforms H3 = fan drive module reset protection instead.

Daewoo Washing Machine — Error Code E9 Guide available

E9 = water-level sensor fault: sensor frequency above 30 kHz or below 15 kHz, a sudden >1.44 kHz jump after filling, or the sensor hose disconnected. Daewoo manuals route E9 to the service center.

Hisense Washing Machine — Error Code E4 Guide available

Series split: on top-loaders (HW-K60B, HWT3K8065B) E4 = too-long-to-fill water supply fault (check tap, hose, and drain-hose height ≥90 cm); on front-load E-series (WFQY9014EVJM) E4 = motor error. F-code front-loads have no E4.

Beko Dishwasher — Error Code E02 Guide available

E:02 = water cut-off warning: mains water cut or inlet tap closed. The programme pauses and resumes by itself when water is restored — no reset needed. Do not confuse with E:01 (overflowing).

Beko Washing Machine — Error Code E05 Guide available

E05 = drainage fault: the pump filter is likely clogged. The manual's fix order: clean the pump filter, retry in a spin cycle, then call service. E08 is the inlet-side code.

Daewoo Washing Machine — Error Code LE Guide available

LE = the door was opened while the machine was running (front-loader DWD families). Close the door and the course continues by itself. Not the same as DE (door-lock solenoid fault); top-loaders use E2, not LE.

Haier Refrigerator — Error Code F2 Guide available

F2 = freezer sensor malfunction (F SNR short or open circuit) on the HB21F family. On HRF-663/664 and HRF-628 families Haier's manuals list F2 with no defined meaning — the family split matters.

Haier Washing Machine — Error Code E3 Guide available

E3 = safety switch acted: the machine cannot spin (imbalance fault after two automatic rebalancing attempts). Top-load families only — B14979 front-loads use 'Unb'. Manual fix: redistribute load, open/close lid once, level the machine.

Haier Washing Machine — Error Code E4 Guide available

E4 = water level not reached in time (fill timeout: 12 min B14979 front-load, ~15 min top-loads). Manual checklist: tap, pressure, inlet hose/filter. Distinct from FA (sensor) and E8 (self-syphoning).

Hisense Washing Machine — Error Code E1 Guide available

Series split: on top-loaders (HWT3K8065B, HW-K60B) E1 = lid not closed (open/close lid + Start/Pause); on front-load E-series (WFQY9014EVJM) E1 = temperature sensor error. F-code front-loads have no E1.

Hisense Washing Machine — Error Code E2 Guide available

E2 = door lock error on front-load families (WFQY9014EVJM, WFGE90141VM): close the door, unplug/replug, restart. E2 does not exist on Hisense top-loaders. The manual also defines E22 (cannot lock) and E23 (cannot unlock).

Midea Air Conditioner — Error Code F0 Guide available

F0 = overcurrent protection: an abnormal current rise detected in the current detection circuit. F0 is NOT the refrigerant-leak code (that is EC) — the 'F0 = leak' claim is Gree-family contamination. F0 straight after power-up on standby points to the outdoor PCB.

Midea Air Conditioner — Error Code P1 Guide available

P1 = over-voltage or under-voltage protection (abnormal voltage rise/drop in the detection circuit). Check the mains supply first; if good, the rectifier or outdoor ebox/PCB is faulty. Not the portable-AC 'tray full' code.

Midea Air Conditioner — Error Code P4 Guide available

P4 = inverter compressor drive error (abnormal drive signal). Causes: wiring mistakes, IPM fault, outdoor fan motor, compressor, outdoor PCB, surge — or bad commissioning (no vacuum drying) on new installs. Indoor display P4; outdoor display maps it to inverter module protection.

Haier Refrigerator — Error Code F8 Guide available

Daewoo Washing Machine — Error Code E7 Guide available

E7 = Direction error: the Hall signal IC differs from the predicted signal for the direction of rotation. The motor stops and E7 is displayed; the alarm sounds for 10 seconds every 10 minutes and the display clears when the power is turned off and on.

Daewoo Washing Machine — Error Code H1 Guide available

H1 = Thermistor Dry OPEN/SHORT: the drying temperature sensor has failed. DWC-ED1213 causes: sensor temp. broken (change the sensor temp.) or connector problem (check the contact of the connector). Washer-dryer combos only.

Daewoo Washing Machine — Error Code H4 Guide available

H4 = Wash Overheating: the wash temperature sensor reading is over 95 °C. DWC-ED1213 causes: wash heater working with no water supply (check water level) or wash sensor temp. broken (change the sensor temp.). Alarm 10 seconds every 10 minutes; display clears on power off/on.

Midea Air Conditioner — Error Code E2 Guide available

E2 = zero-crossing signal detection error: the system cannot detect the correct zero-crossing signal time interval (bad power-cable connection, faulty power supply, or faulty indoor PCB).

Midea Air Conditioner — Error Code E3 Guide available

E3 = indoor fan speed out of control: fan speed keeps too low (300 RPM) for a set time, then the unit stops and displays E3 (wiring, fan wheel/bearing, fan motor, PCB, or surge).

Midea Air Conditioner — Error Code P0 Guide available

P0 = IPM malfunction / IGBT over-strong current protection: the voltage signal the IPM sends to the compressor drive chip is abnormal, so the display shows P0 and the AC turns off (wiring, IPM, outdoor fan motor, compressor, outdoor PCB, or surge).

Midea Air Conditioner — Error Code P2 Guide available

P2 = high temperature protection of compressor top: protection trips at ≥120°C (248°F) and resumes at 105°C (221°F) (outdoor airflow, refrigerant system, blockage, protector, or outdoor PCB).

Gree Air Conditioner — Error Code E2 Guide available

E2 = indoor anti-freeze protection: the indoor coil dropped too cold in cooling or dry mode and the unit paused the compressor to stop it freezing. Restore return airflow and clean the coil; persistent E2 needs a technician.

Gree Air Conditioner — Error Code E4 Guide available

E4 = compressor high discharge temperature protection: discharge temperature exceeded the safe limit (over 118°C) and the unit stopped to protect the compressor. Check airflow, then call a technician if it returns.

Gree Air Conditioner — Error Code E5 Guide available

E5 = AC over-current protection: current exceeded the safe limit and the unit stopped. Causes are unstable supply voltage, low supply voltage under high load, or a blocked/dirty indoor coil. Restart once; persistent E5 is electrician/technician work.

Gree Air Conditioner — Error Code H1 Guide available

H1 = defrosting status: in heating mode the unit detected frost on the outdoor coil and paused heating to clear it. Fans stop during defrost, then the display returns to the setpoint and heating resumes. No action needed.

Gree Air Conditioner — Error Code H6 Guide available

H6 = no feedback of the indoor fan motor: the control board is not receiving the fan's feedback signal, so the unit stops. Check for a blocked fan and restart once; persistent H6 needs a technician for the motor, connector, or board.

Haier Refrigerator — Error Code F5 Guide available

F5 = defrost sensor malfunction: D SNR short circuit or open circuit. HB21F family only (HB21FWRSS, HB21FNN); HRF-628 defrost = F6, HRF-663 has no F5.

Haier Washing Machine — Error Code E5 Guide available

E5 = water level sensor fault (HLT364XXQ, GWT900AW/GWT700AW/GWT800AW — call service) OR water temperature too high, over 60°C (HWM70-A — cool, then Start/Pause).

Haier Washing Machine — Error Code E6 Guide available

E6 = the water level sensor is bad. Template top-load families only (7 manuals, identical wording). Same fault = E5 on HLT/GWT, FA on B14979.

Haier Washing Machine — Error Code E7 Guide available

E7 = communication fault: 'The communication is bad.' Four Haier washer manuals agree; remedy is after-sales service. Not Err7 (motor).

Beko Dishwasher — Error Code E06 Guide available

E06 = temperature sensor in the dishwasher is faulty (P2 + P6 flashes on LED models). If the error is continuous and washing performance has reduced, close the dishwasher and get in touch with the authorized service.

Beko Dishwasher — Error Code E07 Guide available

E07 = flowmeter faulty (P2 + F1/F2 flashes on LED models). The error algorithm activates and the cycle ends; if continuous, cut off the electricity, close the valve, and get in touch with the authorized service.

Beko Washing Machine — Error Code E04 Guide available

E04 = continuous-fill fault: the machine keeps taking in water (inlet valve stuck open, valve triac short circuit, or control board fault). Turn the taps off first; if water still enters with the machine unplugged, the valve is mechanically faulty; if it stops, the triac/board is at fault.

Beko Washing Machine — Error Code E07 Guide available

E07 = water level sensor (pressure sensor) error: the machine discharges every time it is turned on, or the programme does not start. Service checks: level-sensor socket and control-card KN2 socket fitted and secure, else repair sockets/cables, else replace the level sensor.

Midea Air Conditioner — Error Code E4 Guide available

E4 = indoor room temperature sensor (T1) open circuit or short circuit: sampling voltage below 0.06V or above 4.94V (wiring mistake, faulty sensor, or faulty indoor PCB).

Midea Air Conditioner — Error Code F1 Guide available

F1 = outdoor room (ambient) temperature sensor T4 open circuit or short circuit: sampling voltage below 0.06V or above 4.94V (wiring mistake, faulty sensor, or faulty outdoor PCB).

Midea Air Conditioner — Error Code F2 Guide available

F2 = outdoor condenser pipe (coil) temperature sensor T3 open circuit or short circuit: sampling voltage below 0.06V or above 4.94V (wiring mistake, faulty sensor, or faulty outdoor PCB).

Midea Air Conditioner — Error Code F3 Guide available

F3 = discharging air / compressor discharge temperature sensor T5 open circuit or short circuit: sampling voltage below 0.06V or above 4.94V (wiring mistake, faulty sensor, or faulty outdoor PCB).

Gree Air Conditioner — Error Code F1 Guide available

F1 (Gree wall-split) = indoor ambient (room) temperature sensor open circuit or short circuit (bad connection, faulty sensor, short from tripped parts, or faulty mainboard).

Midea Refrigerator — Error Code E1 Guide available

E1 = temperature sensor failure of the refrigerating (fresh-food) chamber (loose/contaminated connection, faulty sensor, or faulty main PCB).

Haier Dishwasher — Error Code E4 Guide available

E4 = drain hose crimped or bent, or drain hose positioned too high (installation range 40–100 cm for the free end).

Hisense Air Conditioner — Error Code E5 Guide available

E5 (Hisense portable) = unit full of water: the internal water container/tank has reached its limit and must be drained before the unit will run again.

Haier Dishwasher — Error Code E1 Guide available

E1 = the door is not closed properly (DW9/DW12/HDW12 families; buzzer: 10 short signals every 30 seconds). Series split: the newer XS family has no E1 (its fill fault is E2), and the US HDBL655AFS family's E1 is a longer-inlet-time fill code, not a door code.

Haier Dishwasher — Error Code E3 Guide available

E3 = the drain hose is too low (DW9/DW12/HDW12 families; buzzer: 10 short signals every 30 seconds; installation range 40-100 cm for the hose free end) / the dishwasher does not drain water (XS family: drain pipe bent, trapped or blocked, filter clogged, siphon clogged). E3 is E4's mirror: too low is E3, too high/crimped is E4.

Haier Dishwasher — Error Code E5 Guide available

E5 = water-supply fault (DW9/DW12/HDW12 families; buzzer: 10 short signals every 30 seconds): check the water is turned on and the hose connected properly, the house supply is on with sufficient pressure, the supply hose is not crimped or bent, and the supply-hose filter is not clogged. Series split: the XS family has no E5 (its fill fault is E2).

Midea Dishwasher — Error Code E3 Guide available

E3 = heating exceed pre-set time: the heating element has worked for 60 minutes but the water temperature detected by the NTC has not reached the desired value, after which the drain pump runs until the flowmeter is motionless for 2 minutes, all other components stop, and the buzzer alarms for 30 seconds.

Midea Refrigerator — Error Code E2 Guide available

E2 = temperature sensor failure of the freezing (freezer) chamber; wording varies by family (freezer drawer, freezing chamber, freezer room) but the sensor zone is identical, and it is not the fresh-food sensor (E1) or the ambient sensor (E7).

Midea Refrigerator — Error Code E5 Guide available

E5 = failure of the defrost sensor (defrost sensor detection circuit) of the freezing (freezer) chamber; it is a defrost fault, not the freezer temperature sensor (E2), and on four-door models it pairs with E4 (fresh-food defrost sensor) while on combi models it is the only defrost code.

Midea Refrigerator — Error Code E6 Guide available

E6 = communication error between the main control board and the display board; it is universal across checked refrigerator families with no scope split, and it is not CA (main board to ice-making board communication, French-door ice-maker models only).

Gree Air Conditioner — Error Code E3 Guide available

E3 = compressor low-pressure protection, including refrigerant-lacking protection and refrigerant-collecting (recovery) mode; the system stops when suction pressure falls below the protection value (floor-standing service manual: below -41C equivalent), and E3 during refrigerant recovery is a normal mode, not a fault.

Gree Air Conditioner — Error Code F3 Guide available

F3 = outdoor ambient temperature sensor open circuit or short circuit; unusually, wall-split and U-Match numbering agree on F3, so there is no platform split for this code.

Daewoo Refrigerator — Error Code F1 Guide available

F1 = freezer (F) sensor disconnection or short circuit, shown as Lo for disconnection and Hi for short circuit; while faulty, the compressor and freezer fan cycle 25 minutes ON / 25 minutes OFF, and the code clears automatically once the sensor reads normal.

Daewoo Refrigerator — Error Code r1 Guide available

r1 = refrigerator-compartment (R) sensor disconnection or short circuit, shown as Lo for disconnection and Hi for short circuit; while faulty, control falls back to the ambient-temperature work-rate table, and the code clears automatically once the sensor reads normal.
