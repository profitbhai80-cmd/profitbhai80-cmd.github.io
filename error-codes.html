Midea Air Conditioner — Error Code E1 Guide available

Midea Air Conditioner — Error Code EC Guide available

EC = refrigerant leak detection: the T2 coil temperature fails to drop after the compressor starts (8-minute/3-times trigger logic). Power-cycle only; pressure, leak and recharge work is technician-only.

Gree Air Conditioner — Error Code H4 Guide available

H4 = system overload protection (system abnormal, overload / high-temperature resistance): when the tube temperature gets too high — outdoor heat-exchanger temperature in cooling, indoor heat-exchanger temperature in heating — the protection activates; in cooling/drying the compressor stops while the indoor fan keeps running, and in heating the whole unit stops; manual causes: outdoor temperature too high when cooling, insufficient outdoor air circulation, refrigerant flow malfunction; GMV VRF H4 is fan drive PFC protection.

Midea Dishwasher — Error Code E9 Guide available

E9 = a button/touch key held down for more than 30 seconds — a stuck touch key on touch-key models only; manual's fix: check for foreign objects on the button, clean it, then power on again; NOT in the 7601S platform valid-code list.

Haier Dishwasher — Error Code E8 Guide available

E8 (XS/XF) = water heating element not working correctly or filter plate clogged; manual's fix: clean the filter plate. SPLIT: XPI8D9FFB E8 = leak (drain pump runs permanently, anti-overflow device on).

Haier Dishwasher — Error Code E18 Guide available

E18 (XS) = water-level problems; check clogged filter plate, clean the filter plate; if it continues or recurs, contact the Technical Assistance Centre. Not Bosch E18 (drain fault). Display-less models: 18 flashes.

Midea Refrigerator — Error Code F6 Guide available

F6 = the initialization of the refrigerating (fresh-food) ice maker fails — the maker never completes its start-up sequence. Not F5 (harvest/turn-over failure) and not E0 (freezer initialization failure).

Midea Refrigerator — Error Code EP Guide available

EP = the freezer ice maker fails to turn over (release) its ice — a mechanical harvest failure of the freezer maker. Freezer counterpart of F5. On single-ice-maker families the same code is worded generically as the (only) ice maker failing to drop/separate ice.

Midea Refrigerator — Error Code EE Guide available

EE = the sensor at the bottom of the freezer ice maker fails. Freezer counterpart of F4 (fresh-food bottom sensor). On single-ice-maker families the same code is worded generically as 'ice maker sensor fault'.

Midea Refrigerator — Error Code CC Guide available

CC = the defrosting sensor in the ice-making chamber fails. Not C9 (chamber temperature sensor) and not E5/E4 (freezer/fresh-food defrost sensors).

Midea Refrigerator — Error Code C9 Guide available

C9 = the sensor in the ice-making chamber fails (MRF29D9BST English table: the temperature sensor in the ice-making chamber). Not CC (chamber defrost sensor). One French-language D9BST copy words C9 as a defrost sensor; the English tables distinguish CC from C9 and are followed here.

Midea Refrigerator — Error Code CA Guide available

CA = the communication between the main control board and the ice-making board fails. NOT E6: E6 is the display-board to main-control-board link — a different link, different boards, different repair.

Daewoo Refrigerator — Error Code dH Guide available

dH = the home-bar door switch is defective — the small home-bar door in the refrigerator door is sensed open for an hour or longer. Not dr (refrigerator door) or dF (freezer door). Only applies to dispenser models that have a home bar.

Daewoo Refrigerator — Error Code Et Guide available

Et (Ft on FRS-2011/2031) = level switch error — no pulse sensed, supply mode skipped.

Daewoo Refrigerator — Error Code Eu Guide available

Eu = full-ice switch error — drop motor rotates only 90 degrees.

Daewoo Refrigerator — Error Code EI Guide available

EI = ice-maker I-sensor disconnected (Lo) or shorted (Hi); CN11 check.

Daewoo Refrigerator — Error Code Ea Guide available

Ea = ice-drop motor malfunction (test-switch check). EA also covered: level-sensor timing fault, ice maker paused.

Daewoo Refrigerator — Error Code ES Guide available

ES = dispenser micro-switch error — sensed continuously for 1 minute; dispenser stops.

Daewoo Refrigerator — Error Code EF Guide available

EF = flow-sensor error — no pulse while water should flow; timed supply fallback.

Daewoo Refrigerator — Error Code Eg Guide available

Eg = I-sensor temperature does not rise 5 minutes after water supply.

Midea Dishwasher — Error Code EC Guide available

EC = BLDC wash-pump fault — reveal subcode L0-L6 by 5-second button hold.

Midea Dishwasher — Error Code Ed Guide available

Ed = communication failure main board to display board, 20-second trigger.

Hisense Dishwasher — Error Code Ed Guide available

Ed = communication failure main PCB to display PCB, open/broken wiring.

Gree Air Conditioner — Error Code FH Guide available

FH (wall-split) = limit/decrease frequency due to antifreezing; keeps running slower.

Midea Air Conditioner — Error Code P3 Guide available

P3 (indoor display) = outdoor temperature too low protection; thresholds split by family.
