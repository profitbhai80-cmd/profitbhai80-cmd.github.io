Midea Air Conditioner Error Code E7

Quick answer

Error codeE7 — Midea Air Conditioner
What it meansE7 has no single meaning - it depends on the model family. On 9V/9A and High Wall DB units E7 = outdoor fan speed out of control. On Mission/Aurora/Altimate/MSX midwall units E7 = condenser coil temperature sensor T3 (or T4) open/short circuit, model-limited. On cassette/ducted LCAC and floorstanding units E7 = indoor EEPROM malfunction. Check your model number first.
Most common causeBranch-dependent: outdoor fan speed out of control (9V/9A, High Wall DB); condenser coil temperature sensor T3 (or T4) open or short circuit (Mission/Aurora/Altimate/MSX midwall); or indoor EEPROM malfunction (cassette/ducted LCAC, floorstanding). No single cause covers all E7s.
Safe to check yourself?Branch-dependent. For Branch A (fan speed): power off, turn on after 5 seconds; if it returns, spin the outdoor fan by hand - if it does not spin freely, clear the obstruction. For Branch B (sensor) and Branch C (EEPROM): power-cycle once, then call a technician - sensor resistance and PCB work are not homeowner DIY.

Applies to — read this first

Read this first, because Midea E7 is a series-split code: it has NO single meaning, and any page that gives one E7 meaning as universal is wrong. Use the decision path: 9V/9A or High Wall DB units - outdoor fan speed out of control (Branch A); Mission/Aurora/Altimate/MSX midwall units - condenser coil temperature sensor T3 (or T4) open or short circuit, model-limited (Branch B); cassette/ducted LCAC or floorstanding units - indoor EEPROM malfunction (Branch C). The Blanc series has its own single-series variant (indoor PCB / display board communication error). Portable units, outdoor-display E7, M-thermal heat pumps, air-cooled chillers, and Midea VRF all use E7 differently - none of those is this page.

The only page that states E7's three indoor-display meanings side by side with named manuals and model lists - every competitor picks one branch (usually Branch A) and states it as universal. It carries the "which E7 is mine" decision path (9V/9A or High Wall DB - fan speed; Mission/Aurora/Altimate/MSX midwall - T3 sensor; cassette/ducted LCAC or floorstanding - EEPROM); the Blanc, portable (zero-crossing), outdoor-display (IC/DSP comms), M-thermal (balance tank) and chiller variants documented as scope warnings; branch-specific manual procedures quoted (fan hand-spin check for Branch A; sensor connection/resistance check for Branch B) instead of one generic fix; and the E7 omission on the #1 Singapore guide, which has no E7 row at all.

What the machine does when E7 fires

Branch A (High Wall DB): when fan speed keeps too low (300RPM) for a certain time, the unit will stop and the LED will display the failure. No A/C status is given in the manuals for Branch B (T3 sensor) or Branch C (EEPROM) E7 - this page does not invent one.

Common causes

  1. Branch A - outdoor fan speed out of control: the outdoor fan speed keeps too low (300RPM) for a certain time on the High Wall DB platform (9V/9A families).
  2. Branch B - condenser coil temperature sensor T3 (or T4) open circuit or short circuit, model-limited (Mission MSMBD-24HRN1-QB8W only for T3; the listed Aurora/Altimate models for T3 or T4; MSX-07HRN1-QC2 for T3).
  3. Branch C - indoor EEPROM malfunction (cassette/ducted LCAC, previous-generation Inverter LCAC) or EEPROM chip malfunction (floorstanding).
  4. Blanc variant - indoor PCB / display board communication error (9 flashes), single-series only.

Safe checks, in order

  1. Find your model number first and match it to Branch A, B, or C above - the fix depends on which E7 yours is.
  2. Branch A (fan speed, High Wall E3/F5 section covering E3/E7(DB)): shut off the power supply and turn it on 5 seconds later. Is it still displaying the error code? If yes: shut off the power supply, rotate the fan by hand. Does it rotate properly? If the fan blade does not spin freely by hand, clear any obstruction and restart the system. Are all the connections and wiring between the fan motor and PCB ok? If not, remedy and restart the system. If both are good, check the fan motor and the PCB.
  3. Branch B (T3 sensor, High Wall temperature-sensor section): check the connections of the sensor, the placement of the sensor, and the cable condition. If all is good, measure the resistance of the sensor using the Resistance curve table - a technician step.
  4. Branch C (EEPROM): no manual gives homeowner steps for E7-as-EEPROM. The High Wall guide's E0/F4 EEPROM procedure is the closest manual pattern (power off, restart after 2 minutes; if unresolved, replace the main PCB) - presented here as the EEPROM-pattern procedure, clearly labelled as from the E0/F4 section, not as an E7-specific step. Do not invent E7-specific DIY steps.

Branch C has no E7-specific manual procedure: the 2-minute restart and PCB step quoted there is the E0/F4 EEPROM-pattern procedure from the High Wall guide, labelled as such. Do not present it as an E7-specific step.

When to call a technician

  • Branch A: the outdoor fan does not spin freely by hand, or E7 returns after the 5-second restart and the hand-spin check - the fan motor or PCB needs a technician.
  • Branch B: E7 returns after one power-cycle - the T3/T4 sensor, its connections, or the PCB needs a technician (sensor resistance check).
  • Branch C: E7 returns after one power-cycle - the indoor EEPROM / main PCB needs a technician.
  • Any burning smell, visibly damaged wiring, or other fault codes alongside E7 - switch off and call a qualified technician.

More guidance: when an appliance error requires professional service.

Safety first

E7 work can involve the outdoor fan and live PCB wiring: never open the outdoor unit or probe the fan motor or PCB yourself. The hand-spin check is done only with the power supply shut off. Sensor resistance and PCB work are qualified-technician work.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does E7 mean on a Midea air conditioner?

It depends on the model family: on 9V/9A and High Wall DB units it is the outdoor fan speed out of control; on Mission/Aurora/Altimate/MSX midwall units it is the condenser coil temperature sensor T3 (or T4) open or short-circuited; on cassette/ducted LCAC and floorstanding units it is an indoor EEPROM malfunction. Check your model number first.

Is E7 always the outdoor fan motor?

No. That is only Branch A. Most Singapore guides state it as universal because they only cover 9V/9A-type splits - on a Mission/Aurora midwall the same E7 is a T3 sensor fault, and on a cassette it is an EEPROM fault.

My Midea portable AC shows E7 - is it the fan?

No. On Midea portable units (3-in-1, WPPF10CW71N) E7 means a zero-crossing malfunction - a different appliance class with its own code table. Do not apply split-system E7 meanings to a portable.

Can I fix E7 myself?

For Branch A (fan speed): power off, turn on after 5 seconds; if it returns, spin the outdoor fan by hand - if it does not spin freely, clear the obstruction; otherwise it is the fan motor or PCB (technician). For Branch B (sensor) and Branch C (EEPROM): power-cycle once, then a technician - sensor resistance/PCB work is not homeowner DIY.

Why do different websites give different E7 meanings?

Because they each cover one Midea platform and present it as universal. Midea reuses the E7 string across at least five platforms (9V/9A fan, midwall T3 sensor, LCAC/floorstanding EEPROM, Blanc PCB comms, portable zero-crossing). Only the model number tells you which one applies.
