Midea Air Conditioner Error Code EL OC

Quick answer

Error codeEL OC — Midea Air Conditioner
What it meansRefrigerant leakage detection on Midea U-shaped window air conditioners (shown as EL OC / EL0C).
Most common causeThe unit's leak-detection system believes refrigerant is low or leaking — or, less commonly, the detection sensor itself is faulty.
Safe to check yourself?No — never attempt refrigerant work. Your only jobs are to switch off, ventilate, and call a technician.
Checked againstMidea U-series window air conditioner documentation (manual-style documentation for U window units)

Applies to — read this first

This code applies to Midea's U-shaped window units (the U/U+ family). Note honestly: some secondary sources describe EL OC differently (for example as an overcurrent protection). The manual-style documentation for the U window units defines it as refrigerant leakage detection, and that is the meaning this page uses — but because sources conflict, treat any web answer, including ours, as a pointer to your unit's own manual, and let a technician confirm with gauges.

Find your model number on the rating label if you are not sure which family your machine belongs to — see how to find your model number.

Common causes

  1. An actual refrigerant leak in the sealed system (the reason the code exists).
  2. Refrigerant charge lost over time through a joint or corrosion.
  3. A faulty leak-detection sensor giving a false reading.

Safe checks, in order

  1. Switch the unit off and unplug it. Do not keep running it — a compressor running low on refrigerant can be damaged.
  2. Open windows to ventilate the room as a precaution, and keep flames and sparks away from the unit.
  3. Do not open the unit, and do not buy refrigerant or a recharge kit — handling refrigerant requires certification and is illegal for unqualified people in many regions.
  4. Note the exact model number from the side label and the code shown, and book a qualified AC/refrigeration technician.

Work through the checks in order and stop as soon as the code clears. If a check needs a panel removed, a part tested, or a wire touched, it is no longer a safe home check — skip to the technician section.

When to call a technician

  • EL OC appears at all — this code always needs a technician with leak-detection and refrigerant-handling equipment.
  • The unit ices up, cools poorly, or hisses — switch it off and ventilate.
  • You smell a sweet/chemical odour near the unit — leave it off and ventilate.

More guidance: when an appliance error requires professional service.

Safety first

Refrigerant systems are sealed, pressurised and regulated. Never open the unit, never attempt a recharge, and never bypass the leak-detection sensor. This is one of the clearest “technician only” codes on this site.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does EL OC mean on a Midea window air conditioner?

On the U-shaped window units, Midea's documentation defines EL OC (EL0C) as refrigerant leakage detection — the unit believes refrigerant is leaking or low.

Some sites say EL OC is overcurrent. Which is right?

Sources genuinely conflict. The manual-style documentation for the U window family says refrigerant leakage detection. Because the stakes (a sealed refrigerant system) are the same either way — switch off and call a technician — the safe action does not change.

Can I just reset it and keep cooling?

No. If the leak is real, running the unit can destroy the compressor, and resetting defeats a protection system.

Can I recharge the refrigerant myself?

No. Refrigerant handling requires certification, recovery equipment and leak repair first — a recharge without fixing the leak will simply leak again.
