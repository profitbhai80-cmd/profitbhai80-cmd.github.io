Midea Air Conditioner Error Code P1

Quick answer

Error codeP1 — Midea Air Conditioner
What it meansP1 means over-voltage or under-voltage protection on Midea mini-splits: an abnormal voltage rise or drop was detected in the voltage detection circuit. The service manuals' action order is: check the power supply first — if it is good, the fault is in the outdoor ebox/PCB (rectifier, main PCB). P1 is NOT the water-full code — that is Midea PORTABLE air conditioners, a different appliance.
Most common causeA drop (or surge) in the mains supply voltage — the technical document calls the supply drop the most likely cause.
Safe to check yourself?Checking the household supply and the manual's power-cycle is user-safe. DC-bus and board-level tests are technician work.
Checked againstMidea MSV1-12HRFN1-MT0W service manual (Vertu series, 3D DC Inverter Split Wall-Mounted); Midea MSV1I09HRDN1 service manual; Midea High Wall System Error Codes and Fault Diagnosis Guide (Troubleshooting Type A 230VAC); Midea 'New Error Code System' troubleshooting presentation; Midea Cassette/Duct/Ceiling & Floor owner's manual (document 16122500000082, 20150328)

Applies to — read this first

P1 is the code that punishes anyone who reads it across appliances. On Midea MINI-SPLITS the manufacturer service manuals define P1 as over/under-voltage protection. On Midea PORTABLE air conditioners P1 means the bottom water tray is full — drain it and the code clears. A 'Midea P1' search mixes both, and the portable-AC meaning (plus its YouTube videos) is the #1 confusion source. This page is mini-splits only.

Display variants: P10/P11 on DB platforms (same fault). The MSV1I09HRDN1 manual's outdoor-unit display table uses a different P-mapping — the indoor display P1 is the user-facing code this page covers. Voltage thresholds (e.g. 185V/265V on some Singapore pages) are grid-specific, not code-specific — the service document specifies DC-bus checks (P&N standby values) that vary by unit.

What the machine does when P1 fires

When the abnormal voltage is detected, the unit stops and displays P1 as a protection response — the drive is protecting the compressor and electronics from the out-of-range supply.

Common causes

  1. A drop in the mains supply voltage — the technical document's most likely cause.
  2. A voltage surge.
  3. A faulty rectifier.
  4. A faulty outdoor ebox / main PCB.
  5. Loose mains power connections.

Safe checks, in order

  1. Check whether other appliances or lights in the house are affected — a neighbourhood-wide dip or a recent storm points at the supply, not the AC.
  2. Shut off the unit's isolator/breaker, wait a few seconds, and restore power — one clean restart.
  3. If the building has known voltage problems (older wiring, frequent dips), note this for the electrician — stabilising the supply is the fix, not AC parts.
  4. If P1 returns on a normal, stable supply, stop: the service manual's next steps are the DC-bus P&N voltage check, rectifier test, and outdoor ebox replacement — technician work.

Work through the checks in order and stop as soon as the code clears. P1 after a thunderstorm or during known grid instability is almost always the supply — do not let any page sell you a filter cleaning for it (one ranking page prescribes exactly that, and it contradicts the service manual). If a check needs an electrical cover removed or voltage measured, it is no longer a safe home check — skip to the technician section.

When to call a technician

  • P1 on a stable, normal supply (rectifier/PCB fault).
  • P1 immediately after every restart.
  • Burning smell or scorch marks at the outdoor unit.
  • Repeated P1 with flickering house lights (supply fault — call an electrician, then the AC technician).

Safety first

Never open the outdoor unit's electrical covers — the DC bus carries high voltage that persists after switch-off. Voltage measurements (including the P&N bus check) are technician work. If the supply itself is suspect, a qualified electrician should check it before the AC is run again.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does P1 mean on a Midea mini split?

P1 is over-voltage or under-voltage protection: an abnormal voltage rise or drop detected in the voltage detection circuit. The service manuals' action order: check the power supply first; if it is good, the fault is the rectifier or the outdoor ebox/PCB.

Is Midea P1 the water-full code?

Only on Midea PORTABLE air conditioners, where P1 means the bottom tray is full — drain it. On mini-splits P1 is voltage protection. The portable-AC meaning is the #1 confusion source in 'Midea P1' searches.

My Midea shows P1 after a storm. What should I check?

The supply first: storms cause the dips and surges P1 protects against. Check house lights and other appliances, give the unit one clean isolator restart, and if the supply is unstable call an electrician. The service document calls the supply drop the most likely cause.

A site says P1 means clean the filters. Is that right?

No. The top-ranking blog fuses 'freeze/over-voltage protection' with filter cleaning — the Midea service manuals prescribe supply-voltage and DC-bus checks for P1, never filter cleaning.
