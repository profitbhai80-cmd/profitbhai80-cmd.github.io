Midea Air Conditioner Error Code F6

Quick answer

Error codeF6 — Midea Air Conditioner
What it meansF6 on a Midea air conditioner (indoor display, timer ON, running lamp 7 flashes) means T2b sensor error. T2b is a SEPARATE sensor from T2: E5 is the evaporator coil temperature sensor (T2, timer OFF / 6 flashes) and F6 is the T2b sensor (timer ON / 7 flashes) — the manuals list them as different rows with different lamp patterns, and they must never be merged into one 'evaporator sensor fault'.
Most common causeThe T2b sensor circuit is open or shorted — wiring mistake, failed sensor, or faulty PCB, following the same sensor-fault pattern the High Wall guide gives for temperature sensors.
Safe to check yourself?Partly. A power-cycle and a visual check of obvious wiring damage are the only safe home checks. Sensor diagnosis is technician work.

Applies to — read this first

Midea F6 is the code the generic lists erase: they either merge it with E5 ('evaporator sensor fault') or copy the outdoor-unit F6 rows from other families ('indoor room temperature sensor is open or short'). The manuals say otherwise on all counts — on the current-generation indoor display F6 is the T2b sensor error with its own lamp pattern (timer ON, 7 flashes), distinct from E5's T2 (timer OFF, 6 flashes). Check the lamp pattern before you trust any list.

This page's difference is the distinction no ranking page makes with manuals behind it: T2b is not T2, and the lamp patterns prove it. Merging them sends you to the wrong sensor.

What the machine does when F6 fires

The indoor display shows F6 with the timer lamp ON and the running lamp flashing 7 times; with the T2b sensor unreadable the control cannot trust that reading and the unit does not run normally.

Common causes

  1. The T2b sensor circuit is open or shorted — the manual's meaning.
  2. A wiring mistake at the sensor-to-PCB connection.
  3. A faulty sensor itself, or a faulty PCB.

Safe checks, in order

  1. Power the unit off, wait a few minutes, and power it back on once — to rule out a start-up glitch.
  2. With the power off, visually check the sensor area for obviously damaged or disconnected wiring — touch nothing inside the electrical enclosure.
  3. Confirm the code is F6 (timer ON, 7 flashes), not E5 (timer OFF, 6 flashes) — the fix targets different sensors.
  4. If F6 returns, stop: sensor circuit diagnosis is technician work.

One restart, one visual check, and the E5/F6 fork — that is the whole home side. The lamp pattern decides which sensor tree the technician climbs, so report it exactly.

When to call a technician

  • F6 returns after a restart with no visible wiring damage.
  • You are unsure whether the code is F6 or E5 — note the timer lamp state (ON vs OFF) and flash count for the technician.
  • Any burnt connectors, melted wiring or breaker trips — switch off and call a technician immediately.

More guidance: when an appliance error requires professional service.

Safety first

Sensor wiring lives inside the electrical enclosure. Switch power off at the breaker before any visual check, and never probe, disconnect or replace sensors or boards yourself.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does F6 mean on a Midea air conditioner?

F6 means T2b sensor error — the T2b sensor circuit is open or shorted. The indoor display shows F6 with the timer lamp ON and the running lamp flashing 7 times, per the owner's manual, duct manual and current-generation indoor table.

Is Midea F6 the same as E5?

No — this is the split the generic lists get wrong. E5 is the evaporator coil temperature sensor (T2: timer OFF, 6 flashes); F6 is the separate T2b sensor (timer ON, 7 flashes). The manuals list them as different rows; never merge them.

Why do some sites say Midea F6 is an indoor room temperature sensor fault?

They are copying the outdoor-unit (after-2012 versions) F6 rows from other Midea families — a different code map. This page covers the current-generation indoor display, where the manuals agree F6 is the T2b sensor error.

Can I replace the T2b sensor myself?

No. Sensor circuit diagnosis and replacement run through the sensor-to-PCB connection and the board — technician work. The home side is one restart and a visual check.

How do I tell F6 apart from E5 on the display?

Watch the timer lamp: F6 = timer ON with 7 running-lamp flashes; E5 = timer OFF with 6 flashes. That lamp pattern is the fastest way to know which sensor the manuals point to.
