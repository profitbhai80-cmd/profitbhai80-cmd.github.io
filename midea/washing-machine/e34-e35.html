Midea Front-Load Washing Machine Error Code E34/E35

Quick answer

Error codeE34/E35 — Midea Front-Load Washing Machine
What it meansE34/E35 = water temperature sensor failure — the NTC sensor that monitors the water temperature in the drum has failed. M6 adds the background note that the fault relates to the water temperature in the drum exceeding a set level for alarm. Midea's service manuals list E34/E35 as ONE combined row and do NOT say which code is the open circuit and which is the short circuit — the popular "E34 = open, E35 = short" split is a guess, not a manual fact.
Most common causeThe water temperature (NTC) sensor itself, its wiring to the main PCB, or the heater circuit it monitors (M6 §5 check: "Check the heater NTC").
Safe to check yourself?No — there is no owner-level fix for E34/E35 beyond unplugging and calling service. NTC, heater and PCB work is technician work.
Checked againstMidea MF210 Series Service Manual (midea.com), §6 "ERORR CODES AND EXPLANATIONS"; Midea MF100W70BA-W-IT Service Manual (midea.com official PDF, Model L01), §5 + §6 fault trees + §7 component values; Midea Drum Washing Machine Service Manual (global.midea.com.cn), §3.2/§3.3

Applies to — read this first

Read this first, because E34/E35 is a FRONT-LOAD / WASHER-DRYER combined code — it means water temperature sensor failure on the MF210 series and the MF100W70BA-W-IT (Model L01) front-load washer-dryer families (M1 §6; M6 §5, word-for-word agreement on the combined row). Separate E34 and E35 pages stay HOLD — no manual splits the two codes; never invent an open/short split. The fault trees ask "short or open circuit?" as a technician's diagnostic question, not as a code assignment. Top-loaders have no E34/E35 (their level-sensor code is F8). The MF110W60D washer-only front-load family has no E34/E35 in its extracted table. Do not confuse this with Bosch E35 (a flood code) or the Midea dishwasher's E6/E7 thermistor split (E6 = open-circuit thermistor, E7 = short-circuit thermistor) — the washer does not split open/short into two codes.

The top ranking page gets the split wrong: appliancemode's front-load hub prints "E34: NTC Sensor Open Error / E35: NTC Sensor Short Error" with an NTC "typical 4.6 kΩ at 25 °C — example" — the open/short split is UNVERIFIED (no manual states it), and the 4.6 kΩ figure is a self-flagged example, not a manual value; the hub also swaps E37/E38 vs M1 (correct assignment: E37 = dry-IN, E38 = dry-OUT), gives the wrong E36 heater values ("16 Ω/300 Ω"), and invents E40/E52–E5D/E70/E81/E11/E20. applianceteacher's claim that "in front-load washers, E4 could point to problems with the water temperature sensor" has no manual support — E4 is a top-load unbalance code and front-load temperature codes are E34/E35. No dedicated per-code E34 or E35 article exists.

What the machine does when E34/E35 fires

The water temperature sensor (NTC) in the drum has failed, so the machine cannot trust its water-temperature reading. M6 §5 gives the background: "The water temperature in the drum exceed a certain level for alarm (background)".

Common causes

  1. The water temperature (NTC) sensor has failed — short or open circuit (M6 §6 fault trees).
  2. The NTC sensor wiring to the main PCB is faulty (M6 §6 tree 4: if the connection is good, change the control panel).
  3. The heater circuit the sensor monitors is faulty (M6 §5 check: "Check the heater NTC"; M6 §6 tree 1: if not the NTC, check the heater, else the PCB).

Safe checks, in order

  1. Unplug the machine and call service — there is no owner-level fix for E34/E35 beyond unplugging and calling service.
  2. Technician check (M6 §5, verbatim): "Check the heater NTC".
  3. Technician tree 1, non-heating (M6 §6): "Whether NTC is short or open circuit — Change NTC"; if not the NTC, check the heater, else the PCB.
  4. Technician tree 4, heating beyond the setting temperature (M6 §6): "Whether NTC is short circuit or open circuit — Change NTC"; if the connection is good, change the control panel.
  5. Technician component values — M1: NTC 4–6 kΩ, heater 27–33 Ω / 30±3 Ω; M6 §7: heater 20–35 Ω, NTC 4.8 kΩ ±8% @ 25 °C. Quote both ranges; do not pick one as "the" value.

Do NOT invent: no owner power-cycle reset time; no "E34 = open, E35 = short" assignment; no NTC value other than the two manual ranges above (appliancemode's "typical 4.6 kΩ" is a self-flagged example, not a manual value — do not present it as one). A technician tests the NTC for both open and short; the code letters do not tell you which one it is. NTC/heater/PCB work is technician work.

When to call a technician

  • E34/E35 returns after a restart — the NTC sensor, its wiring, the heater or the PCB needs diagnosis.
  • The machine does not heat, or heats beyond the set temperature (M6 §6 trees 1 and 4).
  • Any burning smell or visible damage — switch off and call a qualified technician.

More guidance: when an appliance error requires professional service.

Safety first

E34/E35 diagnosis means testing and replacing the NTC sensor, heater and PCB: that is technician work. Never open the machine while it is connected to power.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What do E34 and E35 mean on a Midea front-load washing machine?

Both codes mean the same thing: water temperature sensor failure — the NTC sensor that monitors the water temperature in the drum has failed. Midea's service manuals (MF210 §6; MF100W70BA §5) list E34/E35 as ONE combined row, not two separate faults.

Is E34 the open circuit and E35 the short circuit?

No Midea manual says that. Third-party guides print "E34 = open, E35 = short", but the service manuals list one combined row and their fault trees only ask "short or open circuit?" as a diagnostic question. A technician tests the NTC for both; the code letters do not tell you which one it is.

What causes Midea washer E34/E35?

Per the manuals: the water temperature (NTC) sensor itself, its wiring to the main PCB, or the heater circuit it monitors (M6 §5 check: "Check the heater NTC"). The sensor values are M1: 4–6 kΩ; M6: 4.8 kΩ ±8% at 25 °C. Sensor, heater and PCB work is technician work.

Is E34/E35 the same as E36?

No. E36 is the water HEATER error (heater runs 10 minutes, temperature changes less than 3 °C). E34/E35 is the temperature SENSOR error. Different parts, different rules — and E33 is different again (water LEVEL sensor).

Is E34/E35 the same on a Midea top-load washer?

No. Top-load Midea washers (MAS70/80/120, MAV160/MLV47) have NO E34/E35 code in any manual read; their level-sensor code is F8. Do not apply this page to a top-load machine. And do not confuse it with Bosch E35 (a flood code) or the Midea dishwasher's E6/E7 thermistor split — different appliances, different code systems.
