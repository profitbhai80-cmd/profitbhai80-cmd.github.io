Midea Top-Load Washing Machine Error Code F5

Quick answer

Error codeF5 — Midea Top-Load Washing Machine
What it meansF5 = load sensing failed — the washer's fuzzy-weighing system, which counts pulses as it weighs the load, is returning an abnormal pulse number. M4 (MAS70/80/120) calls it "abnormal pulse number in fuzzy weighing"; M12 (MAV160/MLV47) calls it "Load sensing failed". Fuzzy weighing IS load sensing — the two manuals use different words for one fault.
Most common causeThe load-sensing / fuzzy-weighing pulse count is abnormal — the manuals point at the PCB, not at the laundry: M4 says "Change the PCB" and M12 says "Call service center".
Safe to check yourself?No — no owner fix exists in either manual. The manuals send F5 straight to PCB replacement / service. Redistributing the laundry will not clear it.
Checked againstMidea MAS70/MAS80/MAS120 Top-Load Service Manual (manuals.plus), §6 "ERORR CODES AND EXPLANATIONS" + §4 test mode; Midea MAV160-A2808PS/01FM-US Top-Loading Service Manual (MLV47R5BWW-service-manual-canada.pdf), §4.3 error codes pp.17–19

Applies to — read this first

Read this first, because F5 is a TOP-LOAD code — it means load sensing failed on the MAS70/MAS80/MAS120 and MAV160/MLV47 top-load families (M4 §6; M12 §4.3). Front-loaders have no F5 in any manual read. F5 (load sensing / fuzzy weighing) is NOT E4/E5 (unbalance in spin) — E4/E5 are about the load being uneven; F5 is about the machine failing to sense/weigh the load at all. F5 is NOT F8 (water level sensor) — different sensor, different code. E5 stays HOLD (1 manual) — never merge E4/E5.

ManualExact wording for F5

No dedicated per-code F5 article exists anywhere. appliancemode's top-load hub has NO F5 section at all (and its other hub errors: it merges E4/E5; "F2/C9: EEPROM Error" — C9 is invented, its printed definition is M12's Fd; "F3: Water Level Sensor Error" — M4 has no F3, F8 is the level-sensor code; "FD: Lid Lock Error" — wrong vs M12's Fd definition; "C8: Communication Error" — no M4 support). removeandreplace's top-load hub has NO F5 row (its F0/HU entries are unverified as code letters — neither appears in M4 §6 or M12 §4.3). codigodeerror's dedicated F2 page wrongly describes F2 as "load detection failure" — that meaning belongs to F5's family, not to F2 (M4: F2 = EEPROM read/write error). Miele F5 is a drainage code on a different brand — never import it.

What the machine does when F5 fires

The washer's load-sensing (fuzzy-weighing) system, which counts pulses as it weighs the load, is returning an abnormal pulse number, so the machine raises F5 and the load cannot be sensed.

Common causes

  1. Abnormal pulse number in fuzzy weighing (M4 §6).
  2. Load sensing failed (M12 §4.3).

Safe checks, in order

  1. Unplug the machine and call service — there is no owner-level fix for F5 in either manual.
  2. M4 §6 remedy, verbatim: "Change the PCB."
  3. M12 §4.3 remedy, verbatim: "Call service center."

Do NOT invent: no owner power-cycle reset time; no "redistribute the load and restart" fix (that is E4/E5 unbalance advice, not F5); no sensor or resistance values for F5 (none exist in the manuals). There is no F5 diagnostic tree in M12 §4.5 and no component values for F5 in either manual. F5 is a control-board fault, not a load or level problem.

When to call a technician

  • F5 shows at the start of a cycle — the load-sensing system cannot weigh the load.
  • F5 returns after a restart — the PCB needs diagnosis (M4: "Change the PCB").
  • Any burning smell or visible damage — switch off and call a qualified technician.

More guidance: when an appliance error requires professional service.

Safety first

F5 is a control-board fault: PCB replacement is technician work. Never open the machine while it is connected to power.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does F5 mean on a Midea top-load washing machine?

Load sensing failed. The washer's fuzzy-weighing system — the part that weighs the load by counting pulses — is returning an abnormal pulse number. Two service manuals say it in different words: M4 (MAS70/80/120) calls it "abnormal pulse number in fuzzy weighing"; M12 (MAV160/MLV47) calls it "Load sensing failed". Same fault.

Can I fix Midea washer F5 myself?

No owner fix exists in either manual. M4 says "Change the PCB"; M12 says "Call service center". F5 is a control-board fault, not a load or level problem — redistributing the laundry will not clear it.

Is F5 the same as E4 or E5?

No. E4/E5 mean the load is OUT OF BALANCE during spin. F5 means the machine failed to SENSE/WEIGH the load in the first place. Different faults, different codes — never merge them.

Is F5 the same as F2?

No. F2 is the EEPROM read/write error (also "change the PCB"). One competitor site (codigodeerror) wrongly describes F2 as a "load detection failure" — that meaning actually belongs to F5.

Does F5 exist on Midea front-load washers?

No. F5 is a top-load code only (MAS70/80/120 and MAV160/MLV47 families). Front-load Midea washers have no F5 in any manual read.
