Midea Top-Load Washing Machine Error Code F8

Quick answer

Error codeF8 — Midea Top-Load Washing Machine
What it meansF8 = water level sensor failure — the sensor that tells the control board how much water is in the tub has failed. M4 (MAS70/80/120) says "Alarm for fault of water level sensor"; M12 (MAV160/MLV47) says "Water leveling sensor failed". TOP-LOAD only: front-loaders use E33 for the water level sensor — same component, different code by family.
Most common causeThe water level sensor itself has failed (M4: "Change the water level sensor") — M12 §4.5 tree E tests the sensor: capacitance 40–50 nF (terminals 1–2 and 2–3) and resistance 20–40 Ω (terminals 1–3); out of range on either test means replace the sensor.
Safe to check yourself?No — no owner fix exists in either manual. M4 says "Change the water level sensor"; M12 gives the sensor test values for a technician. If the sensor tests within range, the fault is the wiring or the PCB — call service.
Checked againstMidea MAS70/MAS80/MAS120 Top-Load Service Manual (manuals.plus), §6 "ERORR CODES AND EXPLANATIONS" + §4 test mode; Midea MAV160-A2808PS/01FM-US Top-Loading Service Manual (MLV47R5BWW-service-manual-canada.pdf), §4.3 error codes pp.17–19 + §4.5 fault trees pp.21–32 (tree E)

Applies to — read this first

Read this first, because F8 is a TOP-LOAD code — it means water level sensor failure on the MAS70/MAS80/MAS120 and MAV160/MLV47 top-load families (M4 §6; M12 §4.3 + §4.5 tree E). Front-loaders have NO F8 — the front-load water level sensor code is E33 (capacitance 40–50 nF), same component, different code by family. F8 is NOT a door/lid lock fault (that is the E3/Fd family) and NOT E1 (water inlet timeout — E1 is about filling too slowly; F8 is about the sensor that measures the level).

The ranking pages get F8 wrong in two ways. codigodeerror's dedicated F8 page says "F8 = door or lid lock signal fault" — WRONG: M4 §6 and M12 §4.3 both say F8 = water level sensor failure, and the door/lid meaning belongs to E3/Fd, not F8. appliancemode's top-load hub says "F3: Water Level Sensor Error" — WRONG code letter: M4 has NO F3; the level-sensor code is F8. The same hub also merges E4/E5, prints "F2/C9: EEPROM Error" (C9 is REJECTED — its printed definition is M12's Fd, the door-open code: door open >20 s with child lock), prints "FD: Lid Lock Error" (wrong vs M12's Fd definition), and prints "C8: Communication Error" (no M4 support). removeandreplace's top-load hub is consistent ("F8: Water level sensor failed. Remove and replace water level sensor.") but has no family split, no test values and no named manual, and its F0/HU entries are unverified as code letters (neither appears in M4 §6 or M12 §4.3). E5 stays HOLD (1 manual) — never merge E4/E5.

What the machine does when F8 fires

The water level sensor has failed, so the control board cannot trust its reading of how much water is in the tub. M4's remedy is to change the water level sensor; M12 refers the fault to §4.5 tree E for the sensor test.

Common causes

  1. Water level sensor failed (M4 §6; M12 §4.3).
  2. Sensor capacitance out of range — not 40–50 nF between terminals 1–2 and 2–3 (M12 §4.5 tree E).
  3. Sensor resistance out of range — not 20–40 Ω between terminals 1–3 (M12 §4.5 tree E).
  4. If the sensor tests within range, the fault is the wiring or the PCB (M12's tree ends at sensor replacement for out-of-range readings; no further manual step is quoted).

Safe checks, in order

  1. Unplug the machine and call service — no owner fix exists in either manual for F8.
  2. M4 §6 remedy, verbatim: "Change the water level sensor."
  3. Technician test (M12 §4.5 tree E, verbatim): "Test the electric capacity between terminal 1 and terminal 2, terminal 2 and terminal 3. If the capacity is not in range from 40nF to 50nF, replace the water level sensor. Test the resistance between terminal 1 and terminal 3. If the resistance is not in range from 20 to 40 Ohms, replace the water level sensor."

Do NOT invent: no owner power-cycle reset time; no "clean the pressure hose" step (not in M4/M12 for F8 — that is generic washer advice, not the manual's F8 procedure); no capacitance/resistance values other than 40–50 nF and 20–40 Ω. The water level sensor is the pressure-switch-type sensor; replacement is technician work.

When to call a technician

  • F8 returns after a restart — the sensor, its wiring, or the PCB needs diagnosis.
  • Sensor capacitance outside 40–50 nF or resistance outside 20–40 Ω — replace the sensor (M12 §4.5 tree E).
  • Any leak, burning smell or visible damage — switch off and call a qualified technician.

More guidance: when an appliance error requires professional service.

Safety first

F8 diagnosis means testing and replacing the water level sensor: that is technician work. Never open the machine while it is connected to power.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does F8 mean on a Midea top-load washing machine?

Water level sensor failure. Two service manuals agree: M4 (MAS70/80/120) says "Alarm for fault of water level sensor"; M12 (MAV160/MLV47) says "Water leveling sensor failed". The sensor that tells the control board how much water is in the tub has failed.

How do I test a Midea washer F8 water level sensor?

Per M12 §4.5 (technician test): measure the electric capacity between terminals 1–2 and 2–3 — it must be 40–50 nF; measure the resistance between terminals 1–3 — it must be 20–40 Ω. Out of range on either test means replace the sensor. Sensor work is technician work.

Is F8 the same as E33?

Same component, different code. E33 is the water level sensor code on FRONT-load Midea washers; F8 is the water level sensor code on TOP-load Midea washers. Do not apply this page to a front-load machine.

Is F8 a door or lid lock fault?

No. One competitor site (codigodeerror) wrongly describes F8 as a door/lid lock signal fault. The manuals are clear: F8 is the water level sensor. Door/lid faults on top-loaders are E3 (lid open) and Fd (door open >20 s with child lock).

Can I fix Midea washer F8 myself?

No owner fix exists in either manual. M4 says "Change the water level sensor"; M12 gives the sensor test values for a technician. If the sensor tests within range, the fault is the wiring or the PCB — call service.
