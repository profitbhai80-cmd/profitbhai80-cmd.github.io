Midea Front-Load Washing Machine Error Code E80

Quick answer

Error codeE80 — Midea Front-Load Washing Machine
What it meansE80 = no communication between the main control board and the display panel (M5 §5 p.50; M1 §6).
Most common causeA loose communication cable connector between the main control board and the display panel, a failed main-board communication terminal, or a failed display-panel communication terminal (M5 pp.50–51).
Safe to check yourself?Limited — check the communication cable and its connectors are secure. Board and panel terminal work is technician work.
Checked againstMidea MF110W60D Service Manual (manua.ls, 71 pp.), §5 'MALFUNCTION CODES AND EXPLANATIONS' (§5 p.50, pp.50–51); Midea MF210 Series Service Manual (midea.com), §6 'ERORR CODES AND EXPLANATIONS' (§6, E80 row); Midea MF110W70BA10 / MF110W80BA10 manual FAQs (manua.ls / manuals.co.uk) — E80 corroboration

Applies to — read this first

Read this first, because E80 is a FRONT-LOAD code — it means no communication between the main control board and the display panel on the MF110, MF210 and MF110W70/80/90BA10 front-load families (M1/M5/FAQs, identical meaning). E81 ('Missing signal between UI and PCB' per appliancemode) has NO support in M1 or M5 §5 — M1 lists only E80; never present E81 as verified. C8 is the TOP-LOAD communication code (appliancemode top-load hub) — different code, different family, never merge with E80. A generic power-cycle reset is not in M5's E80 check procedure — do not present it as the manual fix.

The ranking pages give E80 no procedure. appliancemode's section 'E80, E81: Communication Failure Errors' gets E80 roughly right but invents E81 ('Missing signal') alongside with NO manual support, and gives no cable-connector check steps from M5, no terminal-failure split (main board vs display panel) and no named manual. savic.ac.za is a scraped mirror of the same content, repeating the unverified E81. The YouTube 'How To Hard Reset a Midea Washing Machine' video is a generic power-cycle reset with no per-code content — and a power cycle is not in M5's E80 procedure.

What the machine does when E80 fires

The main control board and the display panel cannot communicate, so the machine raises E80 (M5 §5 p.50; M1 §6).

Common causes

  1. Communication cable connector between the main control board and the display panel loose (M5 pp.50–51).
  2. Main control board communication terminal failure (M5 pp.50–51).
  3. Display panel communication terminal failure (M5 pp.50–51).

Safe checks, in order

  1. Check the communicate cable connector between the main control board and the display panel (M5 pp.50–51).
  2. Main control board communication terminal failure — if damaged, repair or change the main control board (M5 pp.50–51, technician step).
  3. Display panel communication terminal failure (M5 pp.50–51, technician step).
  4. Consistent with the MF110W70BA10 FAQ: check the communication cable to ensure it is secure; if the cable and connections appear fine but the error persists, the main control board may require servicing.

Do NOT invent: no resistance or voltage value for the E80 communication check is given in M1/M5 as read. No power-cycle reset time is given for E80 — a reset may clear the display temporarily, but it does not fix a loose cable or a failed terminal. Board and panel replacement is technician work; the owner-checkable step is the communication cable and its connectors.

When to call a technician

  • E80 returns after the cable and connector check — a board or panel terminal needs diagnosis.
  • The display is unresponsive or shows wrong readings.
  • Any burning smell or visible damage — switch off and call a qualified technician.

More guidance: when an appliance error requires professional service.

Safety first

E80's owner step is the communication cable and its connectors only. Board and panel terminal work is technician work. Never open the machine while it is connected to power.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does E80 mean on a Midea front-load washing machine?

E80 means there is no communication between the main control board and the display panel (M5 §5 p.50; M1 §6).

How do I check Midea E80?

Per the MF110W60D service manual (M5 pp.50–51), in order: check the communication cable connector between the main control board and the display panel; if the main control board's communication terminal is damaged, repair or change the main control board; then check the display panel's communication terminal.

Will unplugging the washer fix E80?

A power cycle is not in the manual's E80 check procedure. The manual's fix path is the communication cable and the two board terminals. A reset may clear the display temporarily, but it does not fix a loose cable or a failed terminal.

Is E80 the same as E81?

No. E81 ('missing signal between UI and PCB') appears on one hub page but has no support in the MF210 or MF110W60D service manuals — M1 lists only E80. Do not treat E81 as a verified code.

Is E80 the same on a Midea top-load washer?

No. The top-load family's communication fault is C8, not E80. This page covers front-load E80 only (MF100/MF110/MF200/MF210 and the MF110W70/80/90BA10 family).
