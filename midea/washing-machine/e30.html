Midea Front-Load Washing Machine Error Code E30

Quick answer

Error codeE30 — Midea Front-Load Washing Machine
What it meansE30 = door is not closed properly — the door can't be locked after over 3 failed attempts. The machine tries to lock the door and raises E30 when it fails three times (M1 §6; M5 §5 p.26).
Most common causeThe door is not fully closed, clothing is jammed in the door, or the door is misaligned with the lock — or the door lock itself has failed (door lock resistance 100–300 Ω, M5 p.27).
Safe to check yourself?Yes — close the door properly, check for clothing jammed in the door, and check the door is aligned with the lock. Lock resistance testing (100–300 Ω) is technician work.
Checked againstMidea MF210 Series Service Manual (midea.com), §6 'ERORR CODES AND EXPLANATIONS' (§6, E30 row); Midea MF110W60D Service Manual (manua.ls, 71 pp.), §5 'MALFUNCTION CODES AND EXPLANATIONS' (§5 pp.26–27); Midea MF200W120WB User Manual (manuals.plus), user error table; Midea MFE50/60/75 Owner's Manual (AU, manuals.plus), user error table; Midea WBMF310 Washer-Dryer User Manual (manua.ls), user error table; Midea Drum Washing Machine Service Manual (guidespdf), §3.2; Midea MF110W70BA10 manual FAQ (manua.ls) — 'E30 error indicates the door can't be locked'

Applies to — read this first

Read this first, because E30 is a FRONT-LOAD code — it means the door is not closed properly on the MF210, MF110, MF200, MFE and WBMF310 front-load families (M1/M2/M3/M5/M6/M7, identical wording). The top-load family has NO E30 — its lid fault is E3 (lid open). E33 is the front-load water-level-sensor code — not E30. UE / unbalance is a spin-balance symptom, not E30. And a Midea DRYER E30 is a heating element error — a different appliance entirely; this page is a washing-machine page. Check the machine type and the appliance, not just the letters.

The ranking pages get E30 wrong in four ways. appliancemode gives the door-lock resistance as 'typical 40–190 Ω' — WRONG vs M5's 100–300 Ω — and gives no '3 times fail' rule and no named manual; its own dryer page says E30 is a heating element error, with no warning about the cross-appliance collision. crownclassiccleaners maps 'E30 / UE (Unbalanced)' to a heavy-load spin pause — WRONG, E30 is door lock, UE/unbalance is not E30 — and it also maps E21 to an inverter fault. vectorlinux says E30 is 'a problem with the water level sensor' — WRONG, that is E33 — and it swaps E2/E3 meanings too. codigodeerror merges 'E3 or E30 | Door or lid is not detected as closed' — the E3/E30 merge trap; E3 is top-load lid-open, E30 is front-load door lock.

What the machine does when E30 fires

The machine tries to lock the door before the cycle can start. If the door can't be locked after over 3 failed attempts, the board raises E30 instead of starting the cycle (M5 §5 p.26).

Common causes

  1. Door is not closed properly (M1 §6; M5 §5 p.26).
  2. Door can't be locked after over 3 failed attempts (M5 §5 p.26).
  3. Clothing jammed in the door (removeandreplace hub — sensible owner advice, not a manual quote).
  4. Door not aligned with the door lock (MF110W70BA10 FAQ).
  5. Door lock itself failed — resistance should read 100–300 Ω (M5 p.27, technician check).

Safe checks, in order

  1. Check the door is completely closed.
  2. Check if clothing is jammed in the door (removeandreplace 2016 hub — sensible owner advice, not a manual quote).
  3. Check the door is closed properly and aligned with the door lock (MF110W70BA10 FAQ).
  4. Technician check (M5 p.27, not an owner step): door lock resistance 100–300 Ω OK. If the lock fails after over 3 attempts, the lock itself is tested — not the load, not the water level.

Source honesty note: the 'clothing jammed in the door' step comes from the removeandreplace hub, NOT from a Midea manual — the user manuals (M2/M3/M6) give the E30 meaning only, and the manuals' owner actions are the door-closed and door-aligned checks. Do NOT invent: no power-cycle reset time, no other resistance value, no 'replace the door seal' step and no load-redistribution step exists in any manual for E30. In particular: do NOT use appliancemode's 'typical 40–190 Ω' — it is WRONG vs M5's 100–300 Ω; do NOT tell the reader to redistribute the load (E30 is not unbalance); do NOT send the reader to the water level sensor (that is E33).

When to call a technician

  • E30 returns even though the door is closed and aligned — the lock itself is the suspect, not the load.
  • The door lock resistance is outside 100–300 Ω (technician check).
  • Visible damage to the door lock or the door latch.
  • Any burning smell or visible damage — switch off and call a qualified technician.

More guidance: when an appliance error requires professional service.

Safety first

E30's owner checks are external only — close the door, check for jammed clothing, check alignment. Testing or replacing the door lock means opening the machine: that is technician work. Never open the machine while it is connected to power.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does E30 mean on a Midea front-load washing machine?

E30 means the door is not closed properly: the door can't be locked after over 3 failed attempts (M1 §6; M5 §5 p.26). The machine tries to lock the door and raises E30 when it fails three times.

What should I check first for Midea E30?

Check the door is completely closed, check no clothing is jammed in the door, and check the door is aligned with the door lock (MF110W70BA10 FAQ; removeandreplace hub). If the door looks closed and aligned but E30 keeps coming back, the lock itself is the suspect — not the load.

How does a technician test the door lock for E30?

By resistance: the door lock should read 100–300 Ω (M5 p.27). That is a service-manual check, not an owner step. Note the common wrong figure online: one hub gives 'typical 40–190 Ω' — that contradicts the Midea service manual.

Is E30 the same as E3?

No. E3 is a top-load-only code (lid open). Front-load Midea washers have no E3 — their door fault is E30 with the 3-fail lock rule. Some code lists merge them as 'E3 or E30'; they are different codes on different machine types.

My dryer shows E30 — is it the same fault?

No. On a Midea dryer, E30 is a heating element error — a completely different fault on a different appliance. This page is for front-load washing machines only. And E30 is not a water-level problem either: the water level sensor is E33, and unbalance is not E30.
