Midea Front-Load Washing Machine Error Code E64

Quick answer

Error codeE64 — Midea Front-Load Washing Machine
What it meansE64 = motor inverter PCB error — poor communication between the main PCB board and the motor inverter PCB (abnormal signal transmission) (M5 §5 pp.45–49; M1 §6). BLDC models only.
Most common causeHarness not installed in place (motor side or main PCB side — the biggest possibility), motor inverter PCB damaged, defective main PCB, or a broken harness (M5 pp.45–49).
Safe to check yourself?No — no owner step exists in any manual read. Switch the unit off and call a technician; harness, motor and board checks are technician work.
Checked againstMidea MF110W60D Service Manual (manua.ls, 71 pp.), §5 'MALFUNCTION CODES AND EXPLANATIONS' (§5 pp.45–49); Midea MF210 Series Service Manual (midea.com), §6 'ERORR CODES AND EXPLANATIONS' (§6, E64 row)

Applies to — read this first

Read this first, because E64 is a FRONT-LOAD code for BLDC models ONLY — it means a motor inverter PCB communication error on the MF110 and MF210 front-load families (M5/M1). E64 is BLDC models only — a non-BLDC Midea front-loader cannot show this code. E50 = the inverter PCB detects abnormal signals (voltage / overload / IPM) — a fault the inverter itself reports. E64 = communication failure between the main PCB and the inverter PCB (20-second no-reply + 2-minute reset). Different faults, separate pages, cross-linked both ways. E52/E53/E55–E58/E5A–E5D (listed alongside E64 by appliancemode) have NO support in M1/M5 — never present them as manual-verified codes. The JustAnswer 'heater circuit is open' meaning belongs to different (non-Midea-built / Edgestar) models (US-FC70-DS12DSH, MFL70-D1211s) — never adopt it for Midea front-loaders.

MF110 front-load (BLDC) — MF110W60D — M5 service manual, §5 pp.45–49'Motor inverter PCB error (Only BLDC model have this error code). Poor communication between main PCB board and motor inverter PCB.' 20-second no-reply rule; 2-minute inverter reset

The ranking pages give E64 one line or the wrong fault. appliancemode's section 'E50, E52, E53, E55, E56, E57, E58, E5A, E5B, E5C, E5D, E64: BLDC Motor and Inverter Board Errors' gives E64 one line ('Abnormal signal between inverter and main PCB error: Irregular communication signals') — no 20-second no-reply rule, no 2-minute inverter reset, no BLDC-only scope, no harness-first check order — and lists E52/E53/E55–E58/E5A–E5D alongside with NO manual support in M1/M5. Two JustAnswer threads say 'heater circuit is open' for the US-FC70-DS12DSH and MFL70-D1211s washer-dryer combos — CONTRADICTS M1/M5 (inverter communication); wrong model family (Edgestar-built), and the experts themselves note the models are made by someone else.

What the machine does when E64 fires

On pressing start, the main PCB sends a command to communicate with the motor inverter PCB. If there is no reply from the motor inverter PCB within 20 seconds, it is considered a communication failure. After disconnecting the power supply of the motor inverter PCB for 2 minutes (resetting the motor inverter), power on again and try to send a command to connect (M5 §5 pp.45–49).

Common causes

  1. Harness not installed in place — motor side or main PCB side (M5 pp.45–49; the biggest possibility).
  2. Motor inverter PCB damaged (M5 pp.45–49).
  3. Defective main PCB (M5 pp.45–49).
  4. Broken harness (M5 pp.45–49).

Safe checks, in order

  1. Detection/reset sequence (M5 pp.45–49): press the start button; the main PCB sends a command to communicate with the motor inverter PCB; if there is no reply within 20 seconds, it is a communication failure; disconnect the power supply of the motor inverter PCB for 2 minutes (resetting the motor inverter), then power on again and try to send a command to connect.
  2. Check order (M5 pp.45–49, technician work): harness seating first — the harness not installed in place (motor side or main PCB side) is the biggest possibility; then motor defect; then main PCB defect; then broken harness.
  3. The page's only owner action is to switch the unit off and call a technician — checking the harness seating, motor, main PCB and inverter PCB is technician work.

Do NOT invent: no owner reset step, no resistance or voltage value, no motor test value and no board-replacement procedure exists in any manual for E64. Do NOT present the JustAnswer 'heater circuit is open' diagnosis as an E64 step — that belongs to different (Edgestar-built) models, and the experts in those threads note the models are made by someone else.

When to call a technician

  • E64 returns after the 2-minute inverter reset — the harness, motor, main PCB or inverter PCB needs diagnosis.
  • A harness is visibly loose or unseated (technician check).
  • Any burning smell or visible damage — switch off and call a qualified technician.

More guidance: when an appliance error requires professional service.

Safety first

E64's checks — harness seating, motor, main PCB and inverter PCB — are technician work. Never open the machine while it is connected to power.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does E64 mean on a Midea front-load washing machine?

E64 means a motor inverter PCB error: poor communication between the main PCB board and the motor inverter PCB (abnormal signal transmission) (M5 §5 pp.45–49; M1 §6). It appears only on BLDC models.

How does the washer detect E64?

When you press start, the main PCB sends a command to the motor inverter PCB. If there is no reply within 20 seconds, it is considered a communication failure. The inverter is then reset by disconnecting its power supply for 2 minutes before trying to connect again (M5 §5 pp.45–49).

Can I fix E64 myself?

No owner step exists in any manual read. The service manual's check order is: harness seating first (motor side or main PCB side — the biggest possibility), then motor defect, then main PCB defect, then broken harness. Checking or replacing these boards is technician work — switch the unit off and call a technician.

Is E64 the same as E50?

No. E50 is when the inverter PCB itself detects abnormal signals (voltage, overload, IPM). E64 is a communication failure between the main PCB and the inverter PCB — the main board gets no reply within 20 seconds. They are different faults with separate pages; cross-check which code your machine actually shows.

A forum said E64 means the heater circuit is open — is that right?

Not for a Midea-built front-loader. Two JustAnswer threads say 'heater circuit is open' for the US-FC70-DS12DSH and MFL70-D1211s washer-dryer combos — models the experts themselves note are made by someone else (Edgestar). The Midea service manuals (M1 §6; M5 §5 pp.45–49) say E64 is inverter-PCB communication failure. Do not test the heater for an E64 on a Midea front-loader.
