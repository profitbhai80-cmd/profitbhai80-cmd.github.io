Midea Refrigerator Error Code CA

Quick answer

Error codeCA — Midea Refrigerator
What it meansCA on a Midea refrigerator means the communication between the main control board and the ice-making board fails — the two boards that run the ice maker cannot talk to each other. CA is NOT E6, and this matters: E6 is the communication between the DISPLAY board and the main control board — a different link, different boards, different repair. Both ranking aggregator pages say CA and E6 are the same error. They are wrong, and a CA owner following their advice would chase the wrong board.
Most common causeThe wiring harness between the main control board and the ice-making board is loose or damaged, or one of the two boards has failed — so the link between them is broken and the ice maker cannot be driven.
Safe to check yourself?Barely. The only safe home step for a board-to-board communication fault is a single power-cycle: if the link re-establishes, the code clears. Everything else — harness checks, board testing, board replacement — is technician-only. The manuals say to contact maintenance personnel.

Applies to — read this first

This page is for Midea French-door and 4-door refrigerators with a separate ice-making board. The ice maker is run by TWO boards: the main control board (the refrigerator's brain) and the ice-making board (the ice maker's own controller). CA is the link between those two. It is not a sensor fault — F4, EE, CC and C9 are the sensors — and it is not E6, which is the display board's link to the main board.

CA vs E6 — the correctionCA: main control board <-> ice-making board. E6: display board <-> main control board. Both aggregators title their E6 sections 'Same as CA' and say the two 'often refer to the same issue'. They do not. If you replace the display board for a CA fault, or the ice-making board for an E6 fault, you have replaced the wrong part.
CA vs EE/F4/CC/C9 — do not mix themCA is a communication fault between two boards. EE, F4, CC and C9 are sensor faults. A sensor can be replaced; a broken board link has to be traced, and tracing is technician work.

No competitor page has a CA section at all: both aggregators fold CA into their E6 sections under the false 'Same as CA' label, with board replacement presented as a home step. This page is the first dedicated CA page, and its core value is the CA-vs-E6 correction stated up front, plus a hard stop after the power-cycle.

What the machine does when CA fires

The display shows CA and the main control board cannot communicate with the ice-making board: the ice maker receives no usable instructions, so ice production stops. The refrigerator itself keeps cooling and freezing — the manuals say so explicitly — but the ice maker is out of service until the board link is restored.

Common causes

  1. The wiring harness between the main control board and the ice-making board is loose, damaged or disconnected.
  2. The ice-making board has failed and cannot answer the main board.
  3. The main control board's ice-maker communication circuit has failed.
  4. A power disturbance corrupted the link, so the two boards stopped synchronizing.

Safe checks, in order

  1. Confirm the code letter: CA is the main-to-ice-making-board link. If your display shows E6, that is the display-to-main-board link — a different page and a different repair.
  2. Power-cycle once: switch the refrigerator off, wait a few minutes, switch it back on, and see whether CA returns. A disturbed link sometimes re-establishes after a clean restart.
  3. If CA returns after the power-cycle, stop. Do not open any panel, do not touch any harness or board, and do not order a replacement board — a board-to-board fault has to be traced, and tracing belongs to a qualified technician.

That is the whole home procedure for CA, by design: one power-cycle, then the technician. The aggregators' board-replacement steps are not home steps — replacing the wrong board is exactly what their CA=E6 conflation invites, and this page refuses to repeat that mistake.

When to call a technician

  • CA returns after a power-cycle.
  • Ice production stops completely while CA is showing.
  • Any burning smell, damaged wiring, or visible board damage — switch off and call a qualified technician immediately.

Safety first

CA involves mains-powered control boards: never open the refrigerator's control panels, never touch wiring harnesses or boards, and never replace a board yourself — board work carries shock risk and a wrong board wastes money and can damage the machine. Switch the unit off before any handling, keep hands dry, and leave all board work to a qualified technician.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does CA mean on a Midea refrigerator?

CA means the communication between the main control board and the ice-making board fails — the two boards that run the ice maker cannot talk to each other. Three French-door manual families (MRF29D3, MRF29D9BST, MRF29D6AST) list it identically, and the MRQ22D7AST table words it as a communication fault of the ice-making board of the mainboard.

Is CA the same as E6?

No — and this is the most important sentence on this page. CA is the main control board <-> ice-making board link. E6 is the display board <-> main control board link. Both aggregator pages say they are the same; the manuals list them as separate faults with separate board pairs. Replacing the display board for CA, or the ice-making board for E6, replaces the wrong part.

Can I fix CA myself by replacing a board?

No. Beyond a single power-cycle, every CA step — harness tracing, board testing, board replacement — is technician work. Board faults have to be traced to the right board, and this is exactly where the CA=E6 confusion costs owners money.

Is CA a sensor fault like EE or C9?

No. EE, F4, CC and C9 are sensor faults. CA is a communication fault between two boards — a different category with a different repair.

Does the refrigerator still cool with CA showing?

Yes. The manuals say the refrigerator can still provide cooling and freezing functions in this fault case, but that you should contact maintenance personnel to ensure normal use.
