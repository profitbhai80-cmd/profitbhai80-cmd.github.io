Midea Refrigerator Error Code E1

Quick answer

Error codeE1 — Midea Refrigerator
What it meansE1 on a Midea refrigerator means the fresh-food (refrigerating chamber) temperature sensor has failed: the sensor that tells the control how cold the fresh-food compartment actually is. The manuals for MERB345MG, MDRB470MG, MDRB521MGA, MDRB521MIE02, MDRS619FIE, MDRS791MIE, MRF23I5AST and MRQ23BCAST all list it identically, and they all warn that the refrigerator may still cool while E1 is showing — that does not mean it is fine. The service manual's tree checks the sensor connection terminals first, then sensor resistance, then the sensor, then the main PCB. Power-cycle once; if E1 returns, the sensor circuit needs a qualified technician.
Most common causeThe fresh-food (refrigerating chamber) temperature sensor has failed, or its connection to the main PCB is loose or contaminated — the control can no longer trust the fresh-food temperature reading.
Safe to check yourself?Partly. The safe home checks are: power-cycle once (unplug, wait a few minutes, plug back in); check the actual fresh-food compartment temperature with a thermometer; and move perishables to another cold store if the temperature is rising. Anything beyond that (checking PCB terminals, measuring sensor resistance, replacing the sensor or PCB) is technician work under the service manual's own tree; never open the refrigerator's electrical covers or the main PCB housing yourself.

Applies to — read this first

On the bottom-freezer, side-by-side, French-door and built-in Midea refrigerator families we checked, E1 is consistent — it is always the refrigerating (fresh-food) chamber temperature sensor, failed. The manuals add an important warning that owners miss: the refrigerator may still cool with E1 showing. 'Still cooling' does not mean 'fine' — the control is running without a trustworthy fresh-food temperature reading, and every one of these manuals tells the owner to contact a maintenance specialist.

What the machine does when E1 fires

The display shows E1 and the refrigerator may still cool — the manuals warn about this explicitly: 'Though the refrigerator may still have cold storage function with the following faults, the user shall contact a maintenance specialist.' The control is running without a trustworthy fresh-food temperature reading, so compartment temperature may drift from the setpoint even while the unit sounds normal. Do not wait for food to spoil before calling a technician.

Common causes

  1. A loose, unseated or contaminated connection terminal for the refrigerating-chamber sensor on the main PCB — the service manual's first check (clean the terminals and re-plug them).
  2. A faulty refrigerating-chamber temperature sensor itself — its resistance no longer matches the expected value when measured with a multimeter.
  3. A faulty main PCB — the service manual's final verdict when the terminals are good and the sensor resistance is normal but E1 persists.
  4. Foreign matter in the sensor connection terminals — explicitly named in the service manual's first step.

Safe checks, in order

  1. Unplug the refrigerator, wait a few minutes, and plug it back in. If E1 clears, it was a transient detection glitch — keep an eye on it, because a repeat points to the sensor circuit.
  2. While you wait, check the actual fresh-food compartment temperature with a thermometer (the setpoint is usually around 4 °C / 39 °F on these families). If it is rising, move perishables to another cold store — do not rely on the display while E1 is showing.
  3. Confirm your model family: if your Midea refrigerator is a single-door model, stop — your E1 is a defrost-sensor fault, not the chamber sensor fault on this page.
  4. If E1 returns after the power-cycle, stop: the service manual's next steps are checking the sensor's connection terminals on the main PCB (seating and foreign matter), then measuring the sensor's resistance — all technician work. If the terminals are good but the resistance is wrong, the sensor gets replaced; if the resistance is normal, the manual condemns the main PCB.

Work through the checks in order and stop as soon as the code clears. E1 has no deeper home diagnostic in any manual — power-cycle, temperature check, food check, then the technician's terminal/resistance/PCB tree. Never open the refrigerator's electrical covers or PCB housing.

When to call a technician

  • E1 returns after a power-cycle — the chamber sensor circuit fault is genuine, not a glitch.
  • The fresh-food compartment temperature is drifting from its setpoint or rising — the control has lost its trustworthy reading.
  • Sensor connection terminals loose or contaminated, or sensor resistance wrong — the service manual's first checks.
  • Terminals good and resistance normal but E1 persists — the service manual condemns the main PCB.
  • Any burning smell, damaged wiring, or water leaking from electrical parts — unplug immediately and call a qualified technician.

Safety first

E1 involves mains-powered refrigerator electronics: never open the refrigerator's electrical covers or the main PCB housing, and never touch sensor or PCB terminals while investigating it. Unplug the refrigerator before any visible check. The terminal, resistance and PCB verdicts in the service manual use live measurements and belong to a qualified technician. If E1 persists after a power-cycle, keep perishables cold by other means and call a qualified technician — food that has warmed above safe temperatures should be discarded, not tasted to check.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does E1 mean on a Midea refrigerator?

E1 means the temperature sensor of the refrigerating (fresh-food) chamber has failed. The Midea refrigerator user manuals for MERB345MG, MDRB470MG, MDRB521MGA, MDRB521MIE02, MDRS619FIE, MDRS791MIE, MRF23I5AST and MRQ23BCAST all list it identically: 'E1 | Temperature sensor failure of refrigerating chamber' (wording varies slightly by manual: 'Failure of refrigerator compartment temperature sensor').

Can I still use my fridge if it shows E1?

The manuals say the refrigerator may still have cold-storage function with E1 showing, but they still tell you to contact a maintenance specialist. Do not treat 'still cooling' as 'fixed': without a trustworthy fresh-food reading the control cannot hold the compartment at its set temperature. Check the actual compartment temperature with a thermometer, move perishables to another cold store if it is rising, and book a technician.

How do I clear Midea refrigerator E1?

Power-cycle the refrigerator once — unplug it, wait a few minutes, plug it back in. If E1 was a transient detection glitch it clears. If it returns, the fault is genuine: the service manual's tree is connection terminals first, then sensor resistance, then the sensor, then the main PCB. Resistance and PCB checks are technician work; there is no deeper home fix.

Is Midea refrigerator E1 the same as air-conditioner E1?

No — same letter, different appliance. Midea air-conditioner E1 is a communication fault between indoor and outdoor units. Midea refrigerator E1 is a fresh-food temperature sensor failure. Never carry a code meaning across appliances.

How do I tell E1 from E2 or E7?

E1 = refrigerating (fresh-food) chamber sensor; E2 = freezing (freezer) chamber sensor; E7 = ambient temperature sensor (on most of these families). If the freezer is the compartment misbehaving, suspect E2, not E1. The manual table lists them side by side, so read the code exactly as displayed.
