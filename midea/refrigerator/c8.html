Midea Refrigerator Error Code C8

Quick answer

Error codeC8 — Midea Refrigerator
What it meansC8 = communication failure between the main PCB and the human sensor. The "human sensor" is the proximity sensor that turns the door light blue when you approach the fridge - so C8 means the approach-lighting feature stops working. It is NOT a cooling fault: the refrigerator may still have cold storage function. The manuals print the code lowercase ("c8"); C8 is the same code. Scope: human-sensor BMF models only (MDRB600MIC46P, MERB445MIC46).
Most common causeThe main PCB lost communication with the human (proximity) sensor. Neither manual gives a C8-specific cause or procedure - their only instruction for any fault-table code is to contact a maintenance specialist.
Safe to check yourself?One power-cycle only (unplug, wait at least 5 minutes, plug back in). If C8 returns, contact a maintenance specialist - the manuals give no owner procedure for C8.
Checked againstMidea MDRB600MIC46P User Manual (midea.com UK PDF, Fault indication table) + Midea MERB445MIC46 User Guide (midea.com IT PDF, Fault indication table)

Applies to — read this first

Read this first, because C8 is a human-sensor-model-only code: it is verified on exactly two BMF bottom-freezer families with the human-sensing feature (MDRB600MIC46P and MERB445MIC46), and absent from the BMF section 9.7 (MDRE411FG) and SBS section 8.6 (MDRS925CIE46M) service-manual tables, from the MDRB600MME46 BMF service manual (section 9.6 LED table + section 11 headings), from the MDRS791MIC46 SBS service manual (section 9.6), from the French-door 2022-V2.0 service manual (section 9.6), from the MRF29D3 / MDRF632FGF46APD / MDRS619FIE / MDRS791MYA user-manual fault tables, from the MDRB424FGE / MT18DDSCR1RCM / WHD-663FW LED-code manuals, and from the ZLINE RFM-W / RSM-W tables (the rebadged Midea platform has no human sensor). Do NOT confuse C8 with C9 (ice-making compartment sensor fault - adjacent letter, unrelated part) or with Midea M thermal heat-pump C7 (transducer over-temp - wrong appliance).

What the machine does when C8 fires

The display shows c8 and the proximity-light feature stops working - the blue light no longer comes on when you approach the fridge. Cooling continues: per both manuals' fault-table preamble, the refrigerator "may still have cold storage function" with a C8 fault.

Common causes

  1. Main PCB and human sensor communication failure - the manuals' own fault definition; neither manual gives a C8-specific cause.
  2. The human sensor's switches, sensors and connecting lines run through the hinge cover (door-reversal section) - a specialist would check that wiring path; an owner should not open the hinge cover electrics.

Safe checks, in order

  1. Power-cycle once (unplug, wait, plug back in). The manuals' own restart caution, quoted verbatim: "Allow at least 5 minutes before restarting the appliance, as frequent starting may damage the compressor."
  2. If C8 returns, contact a maintenance specialist - per the manuals' fault-table preamble. Cooling continues in the meantime, but the proximity light will not work until the communication fault is fixed.
  3. Do not invent terminal-check, multimeter, or sensor-replacement steps for C8 - neither manual gives a C8-specific procedure.

The steps above are the manuals' only instruction for C8 (contact a maintenance specialist) plus one labelled-as-general power-cycle. This page does not invent terminal-check, multimeter, or sensor-replacement steps - neither manual gives a C8 procedure.

When to call a technician

  • C8 returns after one power-cycle - contact a maintenance specialist; the human-sensor communication fault needs a specialist.
  • Any other fault code alongside C8 - switch off and call a qualified technician.

More guidance: when an appliance error requires professional service.

Safety first

C8 is a communication fault in a mains-powered refrigerator: never open the hinge cover electrics or probe the main PCB or sensor wiring yourself. The sensor wiring path is specialist work.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What is the human sensor on a Midea fridge?

The proximity sensor that turns the door light blue when you approach the fridge (off 30 seconds after you leave); blue when the fridge door is open, white when only the freezer door is open.

Does C8 stop my fridge from cooling?

No - per both manuals' fault-table preamble, the refrigerator "may still have cold storage function" with a C8 fault. Only the proximity-light feature is affected.

C8 vs C9 - what's the difference?

C8 = main PCB lost communication with the human (proximity) sensor. C9 = the sensor in the ice-making compartment failed. Adjacent letters, completely different parts.

Can I fix C8 myself?

The manuals give no owner procedure for C8 - their instruction is to contact a maintenance specialist. You can try one power-cycle (unplug, wait at least 5 minutes, plug back in); if C8 returns, book a specialist.

Which Midea models show C8?

BMF bottom-freezer models with the human sensing feature - MDRB600MIC46P and MERB445MIC46. It does not appear on SBS, French-door, or LED-display models, or on ZLINE's rebadged Midea line. The manuals print the code lowercase ("c8"); C8 is the same code.
