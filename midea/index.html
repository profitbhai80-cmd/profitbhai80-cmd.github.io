Midea Error Codes

Midea error codes for dishwashers and air conditioners, checked against Midea manuals and official fault-diagnosis documentation. The same code can mean different things on a Midea dishwasher and a Midea mini-split, so always start from your appliance type.

30 verified Midea guides — each one names the manual it was checked against. You can also search all error codes across every brand.

Midea Dishwasher Error Codes

E4

Midea Dishwasher Error E4

Overflow or leak protection activated: too much water in the tub or a leak has been detected, and the drain pump runs.

 E1

Midea Dishwasher Error E1

Longer inlet time: the inlet valve has been open about 4 minutes without enough water entering; consistent across Midea dishwasher model families.

 E6

Midea Dishwasher Error E6

E6 = open-circuit failure of the thermistor (water-temperature sensor). Power-cycle; if it returns, the NTC circuit needs a technician's resistance check.

 E7

Midea Dishwasher Error E7

E7 = short-circuit failure of the thermistor (water-temperature sensor). Power-cycle; if it returns, the NTC circuit needs a technician's resistance check.

 E3

Midea Dishwasher Error E3

E3 = the water did not reach temperature in time: the heater ran 60 minutes without the sensor reporting the target. Clean the filter and check the drain hose before assuming the heater is dead.

 E8

Midea Dishwasher Error E8

E8 = diverter valve fault — only on models with a diverter that switches water between spray arms. During a wash it is only reported after the program ends.

 E9

Midea Dishwasher Error E9

Midea DW E9 = stuck touch key held over 30 seconds — touch-key models only, not 7601S.

Midea Air Conditioner Error Codes

EL OC

Midea Air Conditioner Error EL OC

Refrigerant leakage detection on Midea U-shaped window air conditioners (displayed EL OC / EL0C). Refrigerant work is technician-only.

 E1

Midea Air Conditioner Error E1

E1 = communication malfunction between the indoor and outdoor units (no feedback for 110 seconds, happening 4 times). Check wiring first; the S-to-N voltage test is technician work.

 EC

Midea Air Conditioner Error EC

EC = refrigerant leak detection: the T2 coil temperature fails to drop after the compressor starts (8-minute/3-times trigger logic). Power-cycle only; pressure, leak and recharge work is technician-only.

 F0

Midea Air Conditioner Error F0

F0 = overcurrent protection: an abnormal current rise detected in the current detection circuit. F0 is NOT the refrigerant-leak code (that is EC) — the 'F0 = leak' claim is Gree-family contamination. F0 straight after power-up on standby points to the outdoor PCB.

 P1

Midea Air Conditioner Error P1

P1 = over-voltage or under-voltage protection (abnormal voltage rise/drop in the detection circuit). Check the mains supply first; if good, the rectifier or outdoor ebox/PCB is faulty. Not the portable-AC 'tray full' code.

 P4

Midea Air Conditioner Error P4

P4 = inverter compressor drive error (abnormal drive signal). Causes: wiring mistakes, IPM fault, outdoor fan motor, compressor, outdoor PCB, surge — or bad commissioning (no vacuum drying) on new installs. Indoor display P4; outdoor display maps it to inverter module protection.

 P5

Midea Air Conditioner Error P5

P5 = indoor-units mode conflict (multi-zone only): one indoor unit heating while another cools. Set all indoor units to the same mode.

 E2

Midea Air Conditioner Error E2

E2 = zero-crossing signal detection error: the indoor PCB cannot detect the correct zero-crossing time interval. Check power and connections, restart, else the indoor PCB needs a technician.

 E3

Midea Air Conditioner Error E3

E3 = indoor fan speed out of control: the fan stays too slow (~300 RPM) and the unit stops. Spin the fan by hand with power OFF, check the connector, else fan motor/PCB — technician.

 P0

Midea Air Conditioner Error P0

P0 = IPM protection: the inverter power module's signal to the compressor drive chip is abnormal and the AC turns off. One power-cycle + outdoor airflow check; the rest is technician work.

 P2

Midea Air Conditioner Error P2

P2 = high temperature protection of compressor top: trips at 120°C, resets at 105°C. Check outdoor airflow + compressor running; protector, refrigerant, blockage and PCB are technician work.

 E4

Midea Air Conditioner Error E4

E4 = indoor room temperature sensor (T1) open/short circuit: the unit can't read room temperature. Power-cycle; if it returns, the T1 sensor, its wiring, or the indoor PCB needs a technician.

 F1

Midea Air Conditioner Error F1

F1 = outdoor room temperature sensor (T4) open/short circuit: timer lamp ON, running lamp 2 flashes. Power-cycle; if it returns, the T4 sensor, its wiring, or the outdoor PCB needs a technician.

 F2

Midea Air Conditioner Error F2

F2 = outdoor condenser-pipe sensor (T3) open/short circuit: timer lamp ON, running lamp 3 flashes. Power-cycle; if it returns, the T3 sensor, its wiring, or the outdoor PCB needs a technician.

 F3

Midea Air Conditioner Error F3

F3 = compressor discharge sensor (T5) open/short circuit: timer lamp ON, running lamp 4 flashes. Power-cycle; if it returns, the T5 sensor, its wiring, or the outdoor PCB needs a technician — do not confuse it with P2 overheating protection.

Midea Refrigerator Error Codes

E1

Midea Refrigerator Error E1

E1 = fresh-food (refrigerating chamber) temperature sensor failure. The fridge may still cool — that does not mean it is fine. Power-cycle once; if E1 returns, the sensor, its connection, or the main PCB needs a technician.

 E2

Midea Refrigerator Error E2

E2 = freezer temperature sensor failure. The fridge may still cool — that does not mean it is fine. Power-cycle once; if E2 returns, the freezer sensor, its connection, or the main PCB needs a technician.

 E5

Midea Refrigerator Error E5

E5 = freezer defrost sensor failure — frost can build on the freezer evaporator and choke airflow. Do not chip ice off; power-cycle once and check for heavy frost before calling a technician.

 E6

Midea Refrigerator Error E6

E6 = the fridge's two control boards stopped talking to each other. Power-cycle once and check for unresponsive or wrong display readings; board and door-harness checks are technician work.

 E3

Midea Refrigerator Error E3

E3 = meat & fish zone temperature sensor failure — only on models that have that zone. Check whether your model even has a meat & fish drawer first; if it does not, this is not your code.

 E4

Midea Refrigerator Error E4

E4 = fresh-food defrost sensor failure — but only on four-door / variable-zone models, which pair it with E5 for the freezer. Combi-model owners: your fridge has no E4, so check your display again.

 F4

Midea Refrigerator Error F4

F4 = the fresh-food ice maker's bottom sensor has failed — French-door ice-maker models only. The fridge still refrigerates; only ice production is affected.

 F5

Midea Refrigerator Error F5

F5 = the fresh-food ice maker cannot turn over and release its ice — French-door ice-maker models only. Check for jammed or bridged cubes first; the fridge itself keeps refrigerating.
