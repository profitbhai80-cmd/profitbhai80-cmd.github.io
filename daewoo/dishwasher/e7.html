Daewoo Dishwasher Error Code E7

Quick answer

Error codeE7 — Daewoo Dishwasher
What it meansE7 = short-circuit failure of the thermistor - the NTC temperature-sensor circuit is shorted. Controller-detected; reaction: drain pump runs, all other loads cut, 30-second buzzer. MQ shows "error 7"; the EGSP variant flickers ECO + RAPID LEDs. E7 is E6's pair: same sensor, opposite failure (open vs short), routed to the same "E6&E7 tree Inspection". It is NOT a heater failure - repairserviceuae's "failed heating element" E7 conflates it with E3's heating-timeout territory.
Most common causeThe NTC thermistor circuit is shorted (the MQ manual's "E6&E7 tree Inspection" routes E7 to an NTC-circuit inspection tree).
Safe to check yourself?Limited: no manual reset procedure exists. The MQ p.32 inspection tree is technician-level. If the code persists after a power-cycle, the thermistor circuit or PCB is suspect - service per the manuals.
Checked againstDaewoo DDW-MQ1214S Technical Service Manual, Error code pp.28-30 + p.32 "E6&E7 tree Inspection" + Daewoo EGSP-130E / EGSP-13E / EGSP-90E / EGSP-9E Technical & Service Manual, second error-code block (manualslib p.50)

Applies to — read this first

Read this first, because E7 is one half of a thermistor pair: E7 = short circuit, E6 = open circuit - same sensor, opposite failure, routed to the same MQ "E6&E7 tree Inspection" (p.32). The meaning is identical on the MQ flowmeter family (DDW-MQ1214S, digital "error 7") and the EGSP pressure-switch family (EGSP-130E/13E/90E/9E, ECO + RAPID LEDs flicker). Do NOT merge E7 with the DDW-G1211F 2011 UK line, where E7 = heating element / "Abnormal heating" - a different Daewoo DW code system entirely.

What the machine does when E7 fires

The drain pump runs (MQ: until the flowmeter is motionless for 2 minutes; EGSP: until the pressure switch resets + 60 seconds), all other loads are cut immediately, the buzzer alarms 30 seconds, and "error 7" shows (MQ) or ECO + RAPID LEDs flicker (EGSP).

Common causes

  1. Thermistor circuit shorted - the manuals' own fault definition.
  2. The MQ "E6&E7 tree Inspection" routes E7 to an NTC-circuit inspection tree (check the NTC circuit/wiring; reconnect or replace on failure) - technician-level.

Safe checks, in order

  1. Power-cycle the machine once; if E7 clears, it may have been a transient read.
  2. If E7 persists after power-cycle, the thermistor circuit or PCB is suspect - call a qualified technician (per the manuals).

The steps above are the manuals' own routing. This page does not invent resistance values or probe steps - the Bush DWFS126W thread's ~7 k-ohm figure is a different brand and is not used here.

When to call a technician

  • E7 persists after one power-cycle - the thermistor circuit or PCB needs service.

More guidance: when an appliance error requires professional service.

Safety first

E7 involves the sensor circuit in a mains-powered dishwasher: never open the machine or probe the thermistor circuit yourself - that is qualified-technician work.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does E7 mean on a Daewoo dishwasher?

E7 = short-circuit failure of the thermistor (NTC temperature sensor). It is verified verbatim in two named Daewoo DW manuals: DDW-MQ1214S (pp.28-30) and EGSP-130E/13E/90E/9E (second error block, manualslib p.50).

Is E7 a heater failure?

No - that is repairserviceuae.com's conflation ("failed heating element"). E7 is the thermistor short itself; prolonged-heat failure is E3, a different code.

What is the difference between E6 and E7?

Same sensor, opposite failure: E6 = open circuit, E7 = short circuit. Both route to the MQ manual's "E6&E7 tree Inspection" (p.32).

Can I reset E7?

Power-cycle once; if it returns, the thermistor circuit needs service. No manual reset procedure exists.
