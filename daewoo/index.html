Daewoo Error Codes

Daewoo washing-machine and refrigerator error codes, checked against Daewoo service documentation and user manuals. Daewoo codes are short — IE, OE, UE, LE — and each one maps to a specific sensor or operation fault, so the exact code matters. Daewoo fridge-freezer codes are a sensor alphabet of their own: F for the freezer sensor, r1 for the refrigerator sensor, rt for room temperature, d1 for defrost.

24 verified Daewoo guides — each one names the manual it was checked against. You can also search all error codes across every brand.

Daewoo Washing Machine Error Codes

IE

Daewoo Washing Machine Error IE

Water fill problem: the water level sensor frequency is not changing, or the machine does not fill within the set time.

 E8

Daewoo Washing Machine Error E8

Initial-operation error: the Hall IC / motor connection signal is abnormal and the motor stops.

 H2

Daewoo Washing Machine Error H2

Wash water temperature sensor fault: the sensor circuit is open or short-circuited.

 OE

Daewoo Washing Machine Error OE

Drain fault: the water level did not reach the reset point after drainage started. Some Daewoo families show QE for the same fault (water not draining for more than 15 minutes).

 UE

Daewoo Washing Machine Error UE

Unbalance error: the load is unevenly distributed; the machine tried to rebalance itself twice during spin and gave up, tripping the unbalance switch.

 E9

Daewoo Washing Machine Error E9

E9 = water-level sensor fault: sensor frequency above 30 kHz or below 15 kHz, a sudden >1.44 kHz jump after filling, or the sensor hose disconnected. Daewoo manuals route E9 to the service center.

 LE

Daewoo Washing Machine Error LE

LE = the door was opened while the machine was running (front-loader DWD families). Close the door and the course continues by itself. Not the same as DE (door-lock solenoid fault); top-loaders use E2, not LE.

 E1

Daewoo Washing Machine Error E1

E1 = load imbalance (Daewoo top-loaders). The machine rearranges the load itself; redistribute evenly only if it keeps returning.

 E2

Daewoo Washing Machine Error E2

E2 = the lid is open (Daewoo top-loaders). Open the lid, spread clothes evenly and symmetrically, close the lid, resume.

 E3

Daewoo Washing Machine Error E3

E3 = water sensor abnormal (Daewoo top-loaders). Power-cycle once; if it returns, contact the service department — no user-serviceable fix.

 E4

Daewoo Washing Machine Error E4

E4 = water sensor abnormal (Daewoo top-loaders). Power-cycle once; if it returns, contact the service department — not overload, not leakage.

 E6

Daewoo Washing Machine Error E6

E6 = Child Lock triggered: the lid was opened after Child Lock was set. Keep children away, then close the lid properly.

 E7

Daewoo Washing Machine Error E7

E7 = Direction error: the Hall signal IC reading does not match the predicted drum direction, so the motor stops. Power-cycle once; if E7 returns, a technician must check the Hall IC and its connector.

 H1

Daewoo Washing Machine Error H1

H1 = Drying temperature sensor fault (washer-dryer combos only): the dry thermistor is open or shorted. Do not use drying programs until a technician checks the sensor and its connector.

 H4

Daewoo Washing Machine Error H4

H4 = Wash overheating: the wash temperature sensor reading is over 95 °C. Power off, let it cool, power on once; check the water supply — if H4 returns, a technician must check the wash sensor and heater.

Daewoo Refrigerator Error Codes

F1

Daewoo Refrigerator Error F1

F1 = freezer (F) sensor disconnection or short circuit. Display shows 'Lo' for disconnection, 'Hi' for short. Control runs compressor and freezer fan 25 min on / 25 min off; the code clears automatically once the sensor reads normal.

 r1

Daewoo Refrigerator Error r1

r1 = refrigerator-compartment (R) sensor disconnection or short circuit. Display shows 'Lo' for disconnection, 'Hi' for short. Control falls back to an ambient-temperature work-rate table; the code clears automatically once the sensor reads normal. Not the ambient sensor — that is rt.

 F3

Daewoo Refrigerator Error F3

Daewoo fridge F3 = defrost timed out instead of ending on its sensor — 80 minutes on most models, 50 on FRSU21DFV.

 rt

Daewoo Refrigerator Error rt

Daewoo fridge rt = room-temperature sensor on the main PCB disconnected or shorted — not the compartment sensor (that is r1).

 d1

Daewoo Refrigerator Error d1

Daewoo fridge d1 = defrost sensor disconnected or shorted — not a door code (doors are dr/dF/dH).

 C1

Daewoo Refrigerator Error C1

Daewoo fridge C1 = abnormal cycle: compressor over 3 hours with D-sensor above -5°C — check refrigerant leakage, not the motor.

 dr

Daewoo Refrigerator Error dr

Daewoo fridge dr = refrigerator door sensed open for over 1 hour — check the door first, the switch second.

 dF

Daewoo Refrigerator Error dF

Daewoo fridge dF = freezer door sensed open for over 1 hour — not a defrost or filter code.

 dH

Daewoo Refrigerator Error dH

dH = home-bar door switch defective — the small home-bar door sensed open for an hour or longer. Not dr or dF.
