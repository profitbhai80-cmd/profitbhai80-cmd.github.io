Daewoo Refrigerator Error Code Eu

Quick answer

Error codeEu — Daewoo Refrigerator
What it meansEu on a Daewoo refrigerator means the full-ice switch is in error: the switch that senses whether the ice bin is full has failed. The manual signature behaviour is that when dropping ice, the motor rotates only 90 degrees instead of a full drop cycle. The code ends when the switch returns to normal.
Most common causeThe full-ice switch (the bin-full sensor switch) is faulty, so the control cannot tell whether the ice bin is full.
Safe to check yourself?Limited. Confirm the code is Eu and not Ea, power-cycle once, and check nothing is physically jamming the ice maker. Switch replacement is technician work; do not dismantle the ice maker.
Checked againstDaewoo FRSU21DFV User Manual section 5 (Eu: full-ice switch in error, motor rotates 90 degrees when dropping ice); Daewoo FRS-20 User Manual section 5 (identical Eu entry); Daewoo FRS-2011/2031 Service Manual section 6 (Eu: fully sensor position error, same 90-degree control); Daewoo IWD/KAN58 repair manual section 7.1 (Eu: on/off switch)

Applies to — read this first

Eu is about one switch with one job: telling the machine whether the ice bin is full. When that switch fails, the machine cannot trust its bin-full reading, so it limits the ice-drop motor to a 90-degree rotation. That 90-degree behaviour is the diagnostic clue, and it is what separates Eu from every other ice-maker code.

ManualExact wording for Eu
Daewoo FRSU21DFV User Manual (section 5, item 14)Eu error. Cause: Switch (which senses if the ice is full or not) is in error. Control: When dropping the ice, the motor just rotates 90 degrees. Termination: When the switch is in normal.
Daewoo FRS-20 User Manual (section 5, item 14)Eu in the error table as Full ice switch: error, with the identical detailed item and the same 90-degree control.
Daewoo FRS-2011/2031 Service Manual (section 6, item 15)Eu Error. Cause: Fully sensor position is error. Control: When dropping the ice, the motor just rotates 90 degrees. Termination: Fully sensor is normal. Same fault, same behaviour.
Daewoo IWD / KAN58 repair manual (section 7.1)Eu listed as On/Off switch, with the repair note to test the ice maker and replace the switch. Same fault on that family.
Daewoo refrigerator Ea — do not mix themEa is the ice-drop motor itself malfunctioning. Eu is the full-ice switch failing. A motor that only turns 90 degrees because the switch is in error is Eu, not a dead motor.

No ranking list page carries a Eu row: the code is simply absent from the all-codes lists, so a Eu owner gets nothing usable from them. The 90-degree rotation clue and the bin-full explanation are what this page adds.

What the machine does when Eu fires

The display shows Eu and the ice-drop behaviour changes: when dropping ice, the motor rotates only 90 degrees instead of completing its normal drop cycle. Ice production is therefore limited or wrong, while the refrigerator itself keeps cooling.

Common causes

  1. The full-ice switch has failed, so its bin-full reading cannot be trusted.
  2. The full-ice sensor position is in error, so the switch never reports a normal state.
  3. The switch wiring or sensing path is interrupted, so the control reads the switch as in error.

Safe checks, in order

  1. Confirm the code is Eu, not Ea: Eu is the full-ice switch; Ea is the ice-drop motor. If the motor does not move at all, that points to Ea, not Eu.
  2. Check nothing is physically jamming the ice maker or the bin, and that the bin is seated properly, then power-cycle once and watch one drop cycle.
  3. If Eu returns, or the motor still only rotates 90 degrees, stop. Switch replacement is technician work; do not dismantle the ice maker.

A Eu that clears after reseating the bin and one power-cycle was a sensing glitch or a seating problem. A Eu that stays on with a properly seated bin is a defective switch.

When to call a technician

  • Eu returns after a power-cycle.
  • The ice-drop motor still rotates only 90 degrees, or ice production stays wrong.
  • Any burning smell, damaged wiring, or visible damage near the ice maker — switch off and call a qualified technician immediately.

Safety first

Eu is an ice-maker switch fault, not a home repair: never dismantle the ice maker, never bypass a switch, and never open a control panel. Switch the unit off before any handling and leave switch replacement to a qualified technician.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does Eu mean on a Daewoo refrigerator?

Eu means the full-ice switch is in error: the switch that senses whether the ice bin is full has failed. When dropping ice, the motor rotates only 90 degrees, and the code ends when the switch returns to normal.

What is the full-ice switch?

It is the switch that tells the control whether the ice bin is full, so the machine knows whether to keep making ice. When it fails, the control limits the drop motor to a 90-degree rotation.

Is Eu the same as Ea?

No. Eu is the full-ice switch failing. Ea is the ice-drop motor itself malfunctioning. The 90-degree-only rotation is the Eu signature; a motor that does not move at all points to Ea.

Can I still get ice with Eu showing?

Ice production is limited or wrong while Eu is active, because the drop cycle is restricted to 90 degrees. The refrigerator keeps cooling, but ice making is not normal until the switch is normal again.

Can I fix Eu myself?

Beyond checking the bin seating and one power-cycle, no. Switch replacement inside the ice maker is technician work.
