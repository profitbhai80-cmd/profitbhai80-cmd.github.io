Daewoo Refrigerator Error Code Et

Quick answer

Error codeEt — Daewoo Refrigerator
What it meansEt on a Daewoo refrigerator means the level switch (horizontal switch) is in error: no pulse is sensed from the level switch for some time. The manual control is time control, with the water-supply mode skipped, and the code ends when the switch returns to normal. On FRS-2011/2031 models the same fault is labelled Ft, not Et.
Most common causeThe level switch in the ice maker gives no pulse, so the control cannot tell the ice level and skips the timed water-supply mode.
Safe to check yourself?Limited. There is no home repair for a level-switch fault in the manuals: confirm the code is Et (or Ft on FRS-2011/2031), power-cycle once, and call a technician if it returns. Do not open the ice maker or the control board.
Checked againstDaewoo FRSU21DFV User Manual section 5 (Et: level switch error, no pulse sensed for some time, supply mode skipped, time control); Daewoo FRS-20 User Manual section 5 (identical Et entry); Daewoo FRS-2011/2031 Service Manual section 6 (same fault labelled Ft); Daewoo IWD/KAN58 repair manual section 7.1 (Et: horizontal switch)

Applies to — read this first

Read the label first, because this fault wears two labels. On FRS-20 and FRSU21DFV models the display shows Et. On FRS-2011/2031 models the same fault, with the same control, is labelled Ft. They are one fault, not two, and this page covers both labels so neither family is left searching.

ManualExact wording for Et
Daewoo FRSU21DFV User Manual (section 5, item 16)Et ERROR. Cause: Level switch error (no pulse is sensed for some time). Control: By time (supply mode is skipped). Termination: Normal condition.
Daewoo FRS-20 User Manual (section 5, item 16)Et in the error table as Horizontal switch: error, with the identical detailed item: no pulse for some time, supply mode skipped, time control.
Daewoo FRS-2011/2031 Service Manual (section 6, item 10)The same fault labelled Ft ERROR. Cause: When Level SW is ERROR. Control: Time control (skip water supply mode). Termination: Normal. If your display shows Ft, this page is your page.
Daewoo IWD / KAN58 repair manual (section 7.1)Et listed as Horizontal switch, with the repair note to test the ice maker and replace the switch. Same fault, same switch, different family wording.

No ranking list page carries an Et or Ft row at all: the fault is invisible in the all-codes lists, and the Et-versus-Ft label split only appears when the manuals are compared side by side. That comparison is this page's core value.

What the machine does when Et fires

The display shows Et (or Ft on FRS-2011/2031) and the ice maker stops using its level switch: control falls back to time control and the water-supply mode is skipped, so the machine will not flood the ice maker on a blind timed fill. The refrigerator itself keeps cooling; only the ice-making water supply logic changes.

Common causes

  1. The level switch (horizontal switch) in the ice maker is faulty and gives no pulse.
  2. The level-switch wiring or sensing path is interrupted, so no pulse reaches the control.
  3. The switch is stuck in one state and never pulses, which the control reads as an error.

Safe checks, in order

  1. Confirm the code and the label: Et on FRS-20/FRSU21DFV, Ft on FRS-2011/2031. If your display shows EA instead, that is the level-sensor timing fault, not this one.
  2. Power-cycle once: switch the refrigerator off, wait a few minutes, switch it back on, and see whether Et returns. A transient sensing glitch can clear this way.
  3. If Et returns, stop. The level switch sits inside the ice maker and its replacement is technician work; do not dismantle the ice maker or the control board.

That is the whole home procedure for Et, by design: the manuals give no home test for the level switch beyond its pulse behaviour, and the repair note is to test the ice maker and replace the switch.

When to call a technician

  • Et (or Ft) returns after a power-cycle.
  • The ice maker stops making ice or makes ice inconsistently while Et is showing.
  • Any burning smell, damaged wiring, or visible damage near the ice maker — switch off and call a qualified technician immediately.

Safety first

Et is an ice-maker sensing fault, not a home repair: never dismantle the ice maker, never bypass a switch, and never open a control panel. Switch the unit off before any handling and leave switch replacement to a qualified technician.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does Et mean on a Daewoo refrigerator?

Et means the level switch (horizontal switch) is in error: no pulse is sensed from the level switch for some time. The control falls back to time control and skips the water-supply mode, and the code ends when the switch returns to normal.

My display shows Ft, not Et. Is that the same fault?

Yes. On FRS-2011/2031 models the same fault is labelled Ft: level switch error, time control, water-supply mode skipped. Same fault, same control, different label by family.

Is Et the same as EA?

No. Et is the level switch giving no pulse at all. EA is ice dropping sensed by time three times with a level-sensor switch error, which pauses the ice maker. Related faults, different triggers.

Does Et stop the refrigerator cooling?

No. Et changes the ice-making water-supply logic only: the supply mode is skipped and control runs on time. Cooling itself is not the fault here.

Can I fix Et myself?

Beyond one power-cycle, no. The level switch is inside the ice maker and its replacement is technician work. If Et returns after the power-cycle, call a qualified technician.
