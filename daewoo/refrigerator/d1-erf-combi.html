Daewoo Refrigerator Error Code D1

Quick answer

Error codeD1 — Daewoo Refrigerator
What it meansD1 = D-SENSOR open or short - on Daewoo's Spain-built ERF-364/367 no-frost combi range. Identification: the FREEZER red LED lamp blinks on & off ONE time. While D1 is active the control falls back to a 30-minute limit defrost (timed defrost replaces sensor-terminated defrost). This is NOT the side-by-side-family d1 (digital Lo/Hi display) - a different display system with its own page.
Most common causeThe D-sensor circuit is open or shorted. The manual gives no homeowner reset - the fault clears when the sensor reads normally again; identification is by LED blink.
Safe to check yourself?Limited: the manual's supported diagnostic is LED-blink identification only (no multimeter or board steps for the ERF combi - the CN15/CN14 resistance checks in the old side-by-side specs do not apply). A persistent D1 is service work.
Checked against"ERF-364_367 ALL AR-EU MODELS.pdf" - SERVICE MANUAL NO-FROST COMBI-REFRIGERATOR, DAEWOO ELECTRONICS MANUFACTURING ESPANA S.A., 2003, section 44 PCB control functions (two independent reads)

Applies to — read this first

Read this first, because D1 here is an LED blink, not display text: on Daewoo's Spain-built no-frost combi range (ERF-364/384/394/414 and ERF-367/387/397/417, ..EU and ..AR suffixes) the freezer's red LED blinking on & off ONCE means D1 - the D-sensor is open or short. On 88-segment models the code "D1" itself shows on the display, with error priority R1 > D1 > D2 > RT. This page is ERF-combi-scoped: explicitly disambiguate the side-by-side-family d1 system (digital Lo/Hi display, CN15 resistance checks) - that is a different display context that lives under the side-by-side specs, not the ERF combi manual.

Test the door lock" - the factory manual says D-sensor open/short).

What the machine does when D1 fires

The freezer red LED blinks on & off once, repeating, and the control returns to the limit defrost time (30 min) - timed defrost replaces sensor-terminated defrost while D1 is active.

Common causes

  1. D-sensor open circuit - the manual's own condition.
  2. D-sensor short circuit - the manual's own condition.
  3. The manual names no further sub-cause for the ERF combi.

Safe checks, in order

  1. Locate the control-panel red LEDs - freezer side vs refrigerator side.
  2. Freezer red LED blinking on & off once = D1 (D-sensor open/short). Twice = D2. Refrigerator red LED once = R1, twice = RT.
  3. On 88-segment models the code "D1" shows on the display itself.
  4. There is no manual reset procedure for D1 beyond the fault clearing when the sensor reads normally - do not invent multimeter or board-swap steps (the side-by-side family's CN15/CN14 checks do not apply to the ERF combi).
  5. If D1 persists, call a qualified technician.

The diagnostic the manual supports is LED-blink identification only. The CN15/CN14 resistance checks belong to the side-by-side family - this page does not import them.

When to call a technician

  • D1 persists when the sensor should read normally - the D-sensor circuit or the control board needs service.
  • Other blink codes alongside D1 - 88-segment models show the highest-priority code first (R1 > D1 > D2 > RT).

Safety first

D1 involves mains-powered electronics: never open the control panel or probe the sensor circuit yourself. Identification is by watching the LED - everything past that is qualified-technician work.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does D1 mean on a Daewoo refrigerator?

On the Spain-built ERF-364/367 no-frost combi range, D1 = D-sensor open or short - the freezer red LED blinks on & off once. It is verified verbatim in the 2003 factory service manual (section 44).

Is D1 a door-latch error?

No - one ranking site (forkandspoonkitchen.org) fabricates a "door latch" D1 with light-bulb and door-lock advice. The factory manual says D1 is the D-sensor open/short. Do not follow the spam.

What is the difference between D1 and d1?

Case tells you the family: uppercase D1 is the ERF-combi LED-blink code (this page); lowercase d1 is the side-by-side family's digital Lo/Hi code - a different display system with its own page.

What happens to defrost while D1 is active?

The manual's control row: the unit returns to the limit defrost time of 30 minutes - timed defrost replaces sensor-terminated defrost until the sensor reads normally again.
