Daewoo Refrigerator Error Code F1

Quick answer

Error codeF1 — Daewoo Refrigerator
What it meansF1 on a Daewoo refrigerator (fridge-freezer) means the freezer (F) sensor is disconnected or short-circuited. The display shows 'Lo' for a disconnection and 'Hi' for a short circuit. While the fault is active, the FRS-2011/2031 control runs the compressor and freezer fan 25 minutes on and 25 minutes off, and the code clears automatically once the sensor reads normal — no power-cycle ritual is needed in any manual. This is not Haier F1 (the refrigerator sensor) and it is not a fan failure, whatever two ranking pages claim.
Most common causeThe freezer-compartment sensor (F-sensor) has disconnected or shorted — a broken wire, a loose connector, or a failed sensor.
Safe to check yourself?Partly. The safe home checks are: read Lo versus Hi, check food temperatures, and move food if they are rising. Sensor resistance checks and sensor replacement are technician work.
Checked againstDaewoo FRS-2011/2031 Service Manual (§6, Control Way of Errors) — F1: F-sensor disconnection / short (pull-down); compressor and freezer fan 25 min ON / 25 min OFF; auto-terminates when sensor normal; Daewoo FRSU21DFV User Manual (§5) — F1: F-sensor disconnection or short; check point: measure resistance across both terminals after separating CN15; if disconnected or shorted, change the F-sensor in the freezer compartment; Daewoo FRS20 User Manual (§5) — F1: F-sensor disconnection (Lo) / short (Hi); check CN8 (or CN15); replace the freezer-compartment F-sensor; Daewoo IWD / KAN58 repair manual (§7.1) — F1: freezer compartment sensor; test the control module; replace freezer compartment sensor

Applies to — read this first

Daewoo's fridge-freezer codes are a sensor alphabet, and F1 is its first letter: F is the freezer sensor, r1 is the refrigerator sensor, rt is the room-temperature (ambient) sensor, d1 is the defrost sensor. The page is written from Daewoo manuals only, because the ranking pages mix this system with Haier's — Haier fridge F1 is the refrigerator (R1) sensor, the opposite compartment — and one page calls Daewoo F1 'Fan Failure' outright. Read the code in Daewoo's alphabet, not Haier's.

ManualExact wording for F1
Daewoo FRS-2011/2031 Service Manual (§6)'F1' ERROR Cause: F-sensor disconnection / short (pull-down). Control: compressor and freezer fan ON for 25 min., OFF for 25 min. If the F-sensor is normal, the error is terminated automatically. Neighbours in the same section: r1 = R-sensor, rt = RT-sensor, d1 = D-sensor, F3 = defrosting return by 80-minute time limit.

If the F-sensor is disconnected or shorted, change the F-sensor in the freezer compartment. How to reset: if the F-sensor is normal, the error is terminated automatically.
Daewoo FRS20 User Manual (§5)F1 = F-sensor disconnection ('Lo') / short ('Hi'), check CN8 (or CN15), replace the freezer-compartment F-sensor. Its F3 limit is 80 minutes (FRSU21DFV uses 50 minutes — the only F1/F3 family difference is the F3 time limit, not F1).

Do not borrowHaier refrigerator F1 (refrigerator/R1 sensor) is the opposite compartment. removeandreplace's second list (F1 = open only, plus invented F2 = short, F4 = software defect, F5 = compressor fault) contradicts its own display sequence, which contains no F2, F4 or F5 — that second list is an orphan paste from another system.

The FRSU21DFV manual's own r1 repair line misprints 'F-sensor' once where it means the refrigerator sensor — flagged on the r1 page so readers are not confused by it. On this page the assignment is unambiguous: F1 is the freezer sensor in every Daewoo manual checked.

What the machine does when F1 fires

The display shows F1 — 'Lo' if the F-sensor is disconnected, 'Hi' if it is short-circuited — and the FRS-2011/2031 control falls back to a fixed rhythm: compressor and freezer fan on for 25 minutes, off for 25 minutes, repeating. The fridge is not cooling normally in this state; it is running blind on freezer temperature, on a timer instead of a sensor. The moment the sensor reads normal again, the error terminates automatically — the manuals prescribe no button-press or power-cycle ritual for clearing F1.

Common causes

  1. A disconnected F-sensor — a wire broken or a connector (CN15 on FRSU21DFV, CN8 on FRS20) worked loose in the freezer compartment.
  2. A short-circuited F-sensor — the sensor's internal circuit shorted, shown as 'Hi' on the display.
  3. A failed F-sensor itself, reading neither a valid resistance nor a clean open/short — the sensor must be replaced with the same part.
  4. A control-module fault that misreads a sound sensor — the IWD manual's check step before condemning the sensor.

Safe checks, in order

  1. Read the display exactly: 'Lo' means the F-sensor is disconnected, 'Hi' means it is short-circuited. Note which one — it tells the technician which half of the sensor fault to chase.
  2. Check the actual freezer temperature with a thermometer and the fresh-food compartment too. The machine is running on a 25-minute on/off timer, not on sensor control, so do not trust the set temperatures while F1 is showing.
  3. If temperatures are rising, move perishables and frozen food to another cold store. Food that has thawed above safe temperatures should be discarded, not tasted to check.
  4. Do not hunt for a reset button or a power-cycle ritual: the manuals say the error terminates automatically when the F-sensor reads normal. If F1 stays on, the sensor circuit is still faulty.
  5. If F1 persists, book a technician and tell them the Lo/Hi reading and the connector (CN15 or CN8) for your model family. The technician's checks are the resistance across the sensor terminals after separating the connector, then the control module, then sensor replacement — all technician work.

Work through the checks in order — read Lo/Hi, check temperatures, protect the food — and stop as soon as the code clears on its own. F1 has no home repair step in any manual: the sensor circuit is tested and replaced by a technician, and the code clears automatically when the sensor reads normal.

When to call a technician

  • F1 stays on with the display showing Lo or Hi after any waiting period — the sensor circuit is still open or shorted.
  • Freezer temperature keeps rising on the 25-minute on/off rhythm — the fallback control cannot hold temperature.
  • The sensor's resistance across its terminals is out of range after separating CN15 (or CN8) — sensor replacement.
  • A sound sensor but F1 persists — the control module is suspect.
  • Any burning smell, damaged wiring, or water leaking from electrical parts — unplug immediately and call a qualified technician.

Safety first

F1 involves mains-powered refrigerator electronics: never open the refrigerator's electrical covers or the control-module housing, and never touch sensor terminals or connectors while investigating it. Unplug the refrigerator before any visible check. Resistance checks across sensor terminals and sensor replacement belong to a qualified technician. If temperatures are rising while F1 is showing, protect the food first and call a technician — never attempt refrigerant or high-voltage work without the proper qualifications.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does F1 mean on a Daewoo refrigerator?

F1 means the freezer (F) sensor is disconnected or short-circuited. The display shows 'Lo' for a disconnection and 'Hi' for a short circuit. Three Daewoo manuals agree: the FRS-2011/2031 service manual, the FRSU21DFV user manual and the FRS20 user manual.

Is Daewoo fridge F1 a fan failure?

No. One ranking page calls Daewoo F1 'Fan Failure' and tells readers to replace the fan assembly — that is wrong against every Daewoo manual checked, and the same page drifts into PC-build advice, proving it is not a checked appliance source. F1 is a sensor fault, not a fan fault.

Is Daewoo F1 the same as Haier F1?

No — opposite compartments. Haier refrigerator F1 is the refrigerator (R1) sensor; Daewoo refrigerator F1 is the freezer (F) sensor. The two brands' code alphabets must never be mixed, which is exactly what the mislabelled ranking page does.

How do I clear Daewoo refrigerator F1?

You do not press anything: the manuals say the error terminates automatically once the F-sensor reads normal. If F1 stays on, the sensor circuit is still disconnected or shorted, and a technician must test the resistance across the sensor terminals (CN15 or CN8) and replace the sensor if needed.

What does the fridge do while F1 is showing?

On the FRS-2011/2031 control, the compressor and freezer fan run 25 minutes on and 25 minutes off, repeating — a timer fallback, not sensor control. Temperatures cannot be trusted in this state, so check them with a thermometer and move food if they rise.
