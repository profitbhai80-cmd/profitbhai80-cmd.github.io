Daewoo Refrigerator Error Code RT

Quick answer

Error codeRT — Daewoo Refrigerator
What it meansRT = RT-SENSOR (room-temperature sensor) open or short - on Daewoo's Spain-built ERF-364/367 no-frost combi range. Identification: the REFRIGERATOR red LED lamp blinks on & off TWO times (once on the same LED = R1). Control behavior: the system keeps operating normally, but control by the RT sensor stops working (ambient-temperature input is lost); the error cancels when the RT-sensor reads normally again. On 88-segment models RT ranks lowest in the display-priority order (R1 > D1 > D2 > RT).
Most common causeThe RT-sensor circuit is open or shorted. The manual gives no homeowner reset - the fault clears when the sensor reads normally again; identification is by LED blink.
Safe to check yourself?Limited: the manual's supported diagnostic is LED-blink identification only (no multimeter or board steps for the ERF combi - the CN15/CN14 resistance checks in the old side-by-side specs do not apply). A persistent RT is service work.
Checked against"ERF-364_367 ALL AR-EU MODELS.pdf" - SERVICE MANUAL NO-FROST COMBI-REFRIGERATOR, DAEWOO ELECTRONICS MANUFACTURING ESPANA S.A., 2003, section 44 PCB control functions (two independent reads)

Applies to — read this first

Read this first, because RT here is an LED blink, not display text: on Daewoo's Spain-built no-frost combi range (ERF-364/384/394/414 and ERF-367/387/397/417, ..EU and ..AR suffixes) the refrigerator's red LED blinking on & off TWICE means RT - the RT (room-temperature) sensor is open or short. Once on the same LED = R1 (compartment sensor); twice = RT (room sensor) - the blink count is the whole distinction. On 88-segment models the code "RT" itself shows on the display, ranking lowest in priority (R1 > D1 > D2 > RT). This page is ERF-combi-scoped: explicitly disambiguate the side-by-side-family rt system (digital Lo/Hi display, CN15 resistance checks) - that is a different display context that lives under the side-by-side specs, not the ERF combi manual.

What the machine does when RT fires

The refrigerator red LED blinks on & off twice, repeating; the refrigerator keeps operating normally, but ambient-temperature-based control stops working until the RT-sensor reads normally again.

Common causes

  1. RT-sensor open circuit - the manual's own condition.
  2. RT-sensor short circuit - the manual's own condition.
  3. The manual names no further sub-cause for the ERF combi.

Safe checks, in order

  1. Locate the control-panel red LEDs - freezer side vs refrigerator side.
  2. Refrigerator red LED blinking on & off twice = RT (RT-sensor open/short). Once on the same LED = R1; freezer red LED once = D1, twice = D2.
  3. On 88-segment models the code "RT" shows on the display itself.
  4. There is no manual reset procedure for RT beyond the fault clearing when the sensor reads normally - do not invent multimeter or board-swap steps (the side-by-side family's CN15/CN14 checks do not apply to the ERF combi).
  5. If RT persists, call a qualified technician.

The diagnostic the manual supports is LED-blink identification only. The CN15/CN14 resistance checks belong to the side-by-side family - this page does not import them.

When to call a technician

  • RT persists when the sensor should read normally - the RT-sensor circuit or the control board needs service.
  • Other blink codes alongside RT - 88-segment models show the highest-priority code first (R1 > D1 > D2 > RT), so an active R1, D1 or D2 will hide RT.

Safety first

RT involves mains-powered electronics: never open the control panel or probe the sensor circuit yourself. Identification is by watching the LED - everything past that is qualified-technician work.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does RT mean on a Daewoo refrigerator?

On the Spain-built ERF-364/367 no-frost combi range, RT = RT-sensor (room-temperature sensor) open or short - the refrigerator red LED blinks on & off twice. It is verified verbatim in the 2003 factory service manual (section 44).

How do I tell R1 and RT apart on the same LED?

The blink count: refrigerator red LED once = R1 (compartment sensor); twice = RT (room-temperature sensor). Same LED, different blink count, different sensor.

Does the fridge stop working when RT fires?

No - the manual's control row says the system keeps operating normally, but control by the RT sensor stops working (ambient-temperature input is lost) until the sensor reads normally again.

What is the difference between RT and rt?

Case tells you the family: uppercase RT is the ERF-combi LED-blink code (this page); lowercase rt is the side-by-side family's digital Lo/Hi code - a different display system with its own page.
