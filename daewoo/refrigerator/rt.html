Daewoo Refrigerator Error Code rt

Quick answer

Error codert — Daewoo Refrigerator
What it meansrt on a Daewoo refrigerator means the room/ambient-temperature (RT) sensor on the main PCB is disconnected or shorted. The display shows 'Lo' for a disconnection and 'Hi' for a short. While rt is active the fridge keeps running normally, but it drops every control condition that depends on the room temperature — and the code clears by itself once the sensor reads normal again.
Most common causeThe RT sensor on the main PCB has failed open or shorted, so the control can no longer read the room temperature.
Safe to check yourself?Limited. The manual's own check is a voltage measurement on the main PCB (0.5V–4.5V normal, 0V = short, 5V = disconnected) — that is technician work on a live board. The safe home scope is: confirm the code is rt and not r1, power-cycle once, and call a technician if rt returns.
Checked againstDaewoo FRSU21DFV User Manual §5 (rt: disconnection/short, voltage check at main-PCB point 'A'); Daewoo FRS20 User Manual §5 (identical rt entry); Daewoo FRS-2011/2031 Service Manual §6 (rt: normal operation, RT control conditions deleted); Daewoo FR-530NT/590NT Manual §6 (rt on the LED-bar family); Daewoo IWD/KAN58 repair manual §7.1 (rt: ambient sensor, module-level repair on that family)

Applies to — read this first

Read the sensor assignment first, because Daewoo uses two different sensor codes that the ranking pages mix up. rt is the ROOM/ambient-temperature sensor, and it lives on the main PCB. r1 is the REFRIGERATOR-compartment sensor — a different sensor, a different code, a different repair. If you test the compartment sensor for an rt code, you are testing the wrong part.

ManualExact wording for rt
Daewoo FRSU21DFV User Manual (§5, 'Control way of Error')'rt' error. Cause: RT-sensor disconnection or short (full down). Check point: Measure the voltage of 'A' part on the Main PCB. If the voltage is 0.5V~4.5V, it is normal. If the voltage is 0V (short) or 5V (disconnected), change the RT-sensor on the Main PCB. How to reset: If [RT-]sensor is normal, the error is terminated automatically.
Daewoo FRS20 User Manual (§5)Identical rt entry — disconnection or short (full down); voltage check 0.5V–4.5V normal, 0V = short, 5V = disconnected; replace the RT-sensor on the main PCB; auto-termination when normal.
Daewoo FRS-2011/2031 Service Manual (§6)'rt' ERROR. Cause: RT-sensor disconnection / short (pull-down). Control: Normal operation, deletion of control condition by RT-sensor. If RT-sensor is normal, the error is terminated automatically.
Daewoo FR-530NT/590NT Manual (§6, LED-bar family)'rt' Error. Occurrence: RT-Sensor open / short-circuit. Control: deletion of control-condition by RT-Sensor. Dissolution: if RT-Sensor is in normal state, it is finished by itself. Same meaning on a different display family.
Daewoo IWD / KAN58 repair manual (§7.1) — family note'rt = Ambient temperature sensor — Test the control module — Cannot be changed, replace complete control electronics module.' On the IWD family the RT sensor is part of the control module, so the repair is module-level there — do NOT present 'replace the whole module' as the general fix; the FRS-family manuals' fix is replacing the RT-sensor on the main PCB.
Daewoo refrigerator r1 — do not borrowr1 is the refrigerator-compartment (R) sensor, not the room sensor. The ranking page ukwhitegoods assigns the ambient sensor to BOTH r1 and rt, leaving r1's real meaning unstated. Never carry r1's compartment-sensor diagnosis onto an rt page, or vice versa.

The list pages get rt's label right and then stop: no voltage check, no PCB location, no behaviour, no clearance condition. The voltage check is the whole diagnosis — it is what separates a disconnected sensor (5V) from a shorted one (0V) — and only the manuals give it.

What the machine does when rt fires

The display shows rt ('Lo' for disconnection, 'Hi' for short) and the fridge keeps running normally — but with every RT-dependent control condition deleted. In plain terms: the machine no longer adapts its control to the room temperature while rt is active. It does not shut down, and it does not stop cooling on account of rt alone; the risk is subtler, because the control is now running without its room-temperature input.

Common causes

  1. The RT sensor on the main PCB has failed open (disconnection) — the display shows 'Lo'.
  2. The RT sensor has shorted — the display shows 'Hi'.
  3. A fault in the RT-sensor circuit on the main PCB that reads as a disconnection or a short.

Safe checks, in order

  1. Confirm the code letter: rt is the room/ambient sensor. If your display shows r1, that is the refrigerator-compartment sensor — a different fault with a different page.
  2. Power-cycle the refrigerator once: unplug it, wait a few minutes, plug it back in, and see whether rt returns. A transient reading can clear; a genuine sensor fault returns.
  3. If rt returns, stop: the manual's check is measuring the voltage at point 'A' on the main PCB (0.5V–4.5V normal, 0V = short, 5V = disconnected) and replacing the RT-sensor on the main PCB if it is out of range. That is mains-board technician work — do not open the control cover yourself.
  4. While waiting for the technician, keep the fridge doors closed as much as possible and check food temperatures, since the control is running without its room-temperature input.

Work through the checks in order and stop as soon as the code clears. rt has no deeper home diagnostic in any manual — code check, power-cycle, then the technician's voltage check. Never open the refrigerator's electrical covers or touch main-PCB terminals.

When to call a technician

  • rt returns after a power-cycle.
  • The main-PCB point 'A' voltage reads 0V (short) or 5V (disconnected) instead of 0.5V–4.5V.
  • Any burning smell, damaged wiring, or water near electrical parts — unplug immediately and call a qualified technician.

Safety first

rt involves mains-powered refrigerator electronics: never open the refrigerator's electrical covers or touch main-PCB terminals while investigating it. The voltage check in the manual is a technician measurement on a live board. Unplug the refrigerator before any visible check.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does rt mean on a Daewoo refrigerator?

rt means the room/ambient-temperature (RT) sensor on the main PCB is disconnected ('Lo') or shorted ('Hi'). Five Daewoo manuals agree on this meaning, and the FRSU21DFV and FRS20 manuals give the same voltage check: 0.5V–4.5V at main-PCB point 'A' is normal, 0V is a short, 5V is a disconnection.

Is Daewoo rt the same as r1?

No. rt is the room/ambient sensor on the main PCB; r1 is the refrigerator-compartment sensor. The ranking page ukwhitegoods calls r1 an 'ambient temperature sensor' — that is rt's job — so a reader trusting that row would test the wrong sensor.

Does the fridge stop working when rt shows?

No. The service manual says control is 'normal operation' with the RT control conditions deleted: the fridge keeps running, but it no longer adapts to room temperature. The code clears automatically once the sensor reads normal.

Can I check the RT sensor myself?

Not safely. The manual's check is a voltage measurement on the main PCB, which is technician work on a live board. The home scope is confirming the code, one power-cycle, and then a technician if rt returns.

Why do some pages say to replace the whole control module for rt?

On the IWD/KAN58 family the RT sensor is part of the control module, so that family's repair is module-level. On the FRS families the manuals' fix is replacing the RT-sensor on the main PCB. The family matters — do not carry one family's repair onto another.
