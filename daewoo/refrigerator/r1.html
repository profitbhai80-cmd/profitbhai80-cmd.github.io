Daewoo Refrigerator Error Code r1

Quick answer

Error coder1 — Daewoo Refrigerator
What it meansr1 on a Daewoo refrigerator (fridge-freezer) means the refrigerator-compartment (R) sensor is disconnected or short-circuited. The display shows 'Lo' for a disconnection and 'Hi' for a short circuit. While r1 is active, control falls back to an ambient-temperature work-rate table, and the code clears automatically once the sensor reads normal. It is not the ambient sensor — that is the separate 'rt' code, which one ranking page wrongly assigns to r1. Daewoo writes the code with a lowercase r; the underlying sensor is the refrigerator-compartment sensor in every manual checked.
Most common causeThe refrigerator-compartment sensor (R-sensor) has disconnected or shorted — a broken wire, a loose connector, or a failed sensor.
Safe to check yourself?Partly. The safe home checks are: read Lo versus Hi, check food temperatures, and move food if they are rising. Sensor resistance checks and sensor replacement are technician work.
Checked againstDaewoo FRS-2011/2031 Service Manual (§6) — r1: R-sensor disconnection / short (pull-down); control falls back to the ambient-temperature work-rate table; auto-terminates when sensor normal; Daewoo FRSU21DFV User Manual (§5) — R1: R-sensor disconnection or short; check point: measure resistance across both terminals after separating CN14; if disconnected or shorted, change the sensor in the refrigerator compartment; Daewoo FRS20 User Manual (§5) — r1: R-sensor disconnection (Lo) / short (Hi); check CN7 (or CN14); refrigerator-compartment sensor; Daewoo IWD / KAN58 repair manual (§7.1) — r1: refrigerator compartment sensor; test the control module; replace refrigerator compartment sensor

Applies to — read this first

In Daewoo's fridge-freezer alphabet, r1 is the refrigerator compartment's letter the way F1 is the freezer's: F = freezer sensor, r1 = refrigerator sensor, rt = room-temperature (ambient) sensor, d1 = defrost sensor. The lowercase r is how Daewoo writes it, and the page keeps that case in the title and code chip so searchers recognise their own display. The trap on this code is a ranking page that calls r1 the ambient sensor — that job belongs to rt, a code the same page also lists, so its r1 row duplicates rt and tests the wrong sensor.

Do not borrowukwhitegoods' r1 = 'ambient temperature sensor malfunction' is wrong: the ambient/RT sensor is the separate 'rt' code. Haier's 'R1' label is a different brand's code system — this page is written from Daewoo manuals only.

The FRSU21DFV manual's one-word misprint — 'F-sensor' in the r1 repair line — is flagged here deliberately: the compartment named in that same line is the refrigerator compartment, and CN14 is the R-sensor connector, not the F-sensor's CN15. A reader who follows the misprint would test the freezer sensor for a refrigerator fault.

What the machine does when r1 fires

The display shows r1 — 'Lo' if the R-sensor is disconnected, 'Hi' if it is short-circuited — and control falls back to the service manual's ambient-temperature work-rate table: the compressor runs on fixed ON/OFF rates chosen by the room temperature band instead of by the refrigerator compartment's actual temperature. The fridge is therefore cooling on a guess, not a measurement, and the refrigerator compartment's temperature cannot be trusted while r1 is active. The moment the sensor reads normal again, the error terminates automatically.

Common causes

  1. A disconnected R-sensor — a wire broken or a connector (CN14 on FRSU21DFV, CN7 on FRS20) worked loose in the refrigerator compartment.
  2. A short-circuited R-sensor — the sensor's internal circuit shorted, shown as 'Hi' on the display.
  3. A failed R-sensor itself, reading neither a valid resistance nor a clean open/short — the sensor must be replaced with the same part.
  4. A control-module fault that misreads a sound sensor — the IWD manual's check step before condemning the sensor.

Safe checks, in order

  1. Read the display exactly: 'Lo' means the R-sensor is disconnected, 'Hi' means it is short-circuited. Note which one — it tells the technician which half of the sensor fault to chase, and it separates r1 from rt (the ambient sensor, a different code).
  2. Check the actual refrigerator-compartment temperature with a thermometer. The machine is running on the ambient work-rate table, not on compartment measurement, so do not trust the set temperature while r1 is showing.
  3. If the compartment temperature is rising, move perishables to another cold store. Food that has warmed above safe temperatures should be discarded, not tasted to check.
  4. Do not hunt for a reset button or a power-cycle ritual: the manuals say the error terminates automatically when the R-sensor reads normal. If r1 stays on, the sensor circuit is still faulty.
  5. If r1 persists, book a technician and tell them the Lo/Hi reading and the connector (CN14 or CN7) for your model family. The technician's checks are the resistance across the sensor terminals after separating the connector, then the control module, then sensor replacement — all technician work.

Work through the checks in order — read Lo/Hi, check temperatures, protect the food — and stop as soon as the code clears on its own. r1 has no home repair step in any manual: the sensor circuit is tested and replaced by a technician, and the code clears automatically when the sensor reads normal.

When to call a technician

  • r1 stays on with the display showing Lo or Hi after any waiting period — the sensor circuit is still open or shorted.
  • Refrigerator-compartment temperature keeps rising on the work-rate fallback — the guesswork control cannot hold temperature.
  • The sensor's resistance across its terminals is out of range after separating CN14 (or CN7) — sensor replacement.
  • A sound sensor but r1 persists — the control module is suspect.
  • Any burning smell, damaged wiring, or water leaking from electrical parts — unplug immediately and call a qualified technician.

Safety first

r1 involves mains-powered refrigerator electronics: never open the refrigerator's electrical covers or the control-module housing, and never touch sensor terminals or connectors while investigating it. Unplug the refrigerator before any visible check. Resistance checks across sensor terminals and sensor replacement belong to a qualified technician. If temperatures are rising while r1 is showing, protect the food first and call a technician — never attempt refrigerant or high-voltage work without the proper qualifications.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does r1 mean on a Daewoo refrigerator?

r1 means the refrigerator-compartment (R) sensor is disconnected or short-circuited. The display shows 'Lo' for a disconnection and 'Hi' for a short circuit. Three Daewoo manuals agree: the FRS-2011/2031 service manual, the FRSU21DFV user manual and the FRS20 user manual.

Why is the code written with a lowercase r?

That is how Daewoo writes it in its manuals and on its displays: F1 for the freezer sensor, r1 for the refrigerator sensor, rt for the room-temperature sensor, d1 for the defrost sensor. The case is part of the code — search for 'r1' and you will find this page, not a Haier page.

Is r1 the ambient temperature sensor?

No. The ambient (room-temperature) sensor is the separate 'rt' code. One ranking page calls r1 the ambient sensor while also listing rt, so its r1 row duplicates rt's job and would send you to test the wrong sensor. Test the refrigerator-compartment sensor (CN14/CN7), not the RT sensor.

How do I clear Daewoo refrigerator r1?

You do not press anything: the manuals say the error terminates automatically once the R-sensor reads normal. If r1 stays on, the sensor circuit is still disconnected or shorted, and a technician must test the resistance across the sensor terminals (CN14 or CN7) and replace the sensor if needed.

What does the fridge do while r1 is showing?

Control falls back to the service manual's ambient-temperature work-rate table: the compressor runs on fixed ON/OFF rates chosen by the room-temperature band, instead of by the compartment's actual temperature. It is cooling on a guess, so check the compartment with a thermometer and move food if it rises.
