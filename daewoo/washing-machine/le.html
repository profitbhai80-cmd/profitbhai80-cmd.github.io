Daewoo Washing Machine Error Code LE

Quick answer

Error codeLE — Daewoo Washing Machine
What it meansLE means the door was opened while the washing machine was running. The Daewoo service document's handling is simple: close the door, the lock turns on, and the course continues by itself. Three Daewoo manuals agree. LE is a front-loader (DWD) code — Daewoo top-loader families do not use LE (lid-open is E2 there) — and it is not the same as DE, the door-lock solenoid fault.
Most common causeThe door was opened mid-cycle, or the door was not closed tightly enough for the lock to engage.
Safe to check yourself?Yes — closing the door (or the open-close + restart sequence) is the manual's own fix. No tools needed.
Checked againstDaewoo Washing Machine Error Codes service document (Daewoo service material); Daewoo DWD-M301WP Wall-Mounted Front Load Washer user manual; Daewoo DWD-M221MB Wall-Mounted Front Load Washer user manual

Applies to — read this first

LE belongs to Daewoo's front-loader DWD families — the service document and two DWD wall-mounted mini manuals all define it the same way. Two distinctions the competitors miss: LE is NOT DE (DE is the door-lock solenoid failing after more than 10 operations — a mechanism fault, not an opened door), and LE does not exist on Daewoo top-loader families (the DWF-9001Q/1401Q/1801Q/2001Q manual maps lid-open to E2 and has no LE at all).

ManualExact wording for LE
Daewoo Washing Machine Error Codes service document"LE — This error indicates that the door opens while the washing machine is running. The procedure for handling this error: Close the door, then the lock will turn on, and the course will continue." (Same document: DE = door lock solenoid fault after more than 10 operations.)
Daewoo DWD-M301WP user manual"Washer is not operating. (LE) | Is the door open? Is the door closed tightly?" Note: "If an 'LE' error is displayed, open and close the door. If the error persists, turn off and restart the washer."
Daewoo DWD-M221MB user manualSame LE wording: open and close the door; if LE continues, turn off and restart the washer.

Top-loader scope warning: the Daewoo DWF-9001Q/1401Q/1801Q/2001Q user manual's alarm table lists E2 for 'the lid is open' and contains no LE — a DWF owner reading LE advice is being mis-served. AI-generated pages have applied LE to DWF top-loaders; the manuals do not.

What the machine does when LE fires

The machine stops and shows LE when the door opens mid-cycle. Close the door and the lock turns on and the course continues — the service document describes this auto-continue explicitly; the cycle does not need to be restarted from scratch.

Common causes

  1. The door was opened during the cycle.
  2. The door was not latched tightly when the cycle started.
  3. Laundry is caught in the door seal or latch area, preventing the lock from engaging.
  4. On the mini models, the door sensor needs the open-close cycle to re-register.

Safe checks, in order

  1. Open the door fully, check no laundry is caught in the seal or latch area, then close it firmly until the lock clicks.
  2. Wait a few seconds — per the service document the lock turns on and the course continues by itself.
  3. If LE stays on (DWD-M301WP/M221MB note): open and close the door once more; if it still persists, turn the washer off and restart it.
  4. If LE appears on every cycle even with the door firmly closed, the door lock/interlock itself may be faulty — that is DE territory and needs a technician.

Work through the checks in order and stop as soon as the code clears. LE is the gentlest Daewoo fault — it clears by closing the door; do not let any page talk you into replacing the door-lock assembly before the manual's own steps are tried. If a check needs the door lock removed or wiring tested, it is no longer a safe home check — skip to the technician section.

When to call a technician

  • LE on every cycle with a firmly closed, unobstructed door.
  • The door will not lock at all (click but no lock, or no click).
  • The machine shows DE instead of, or in addition to, LE — DE is the lock-solenoid fault and needs a technician.
  • Visible damage to the door latch or hinge.

Safety first

Never force a locked washing-machine door open mid-cycle — wait for the lock to release after the machine stops; forcing it can break the interlock and flood the floor. If the machine is full of water, keep it switched on until the programme ends or use the manual's drain procedure before opening.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does LE mean on a Daewoo washing machine?

LE means the door was opened while the machine was running. The Daewoo service document says: close the door, the lock will turn on, and the course will continue. It is a front-loader (DWD) code.

How do I clear Daewoo LE?

Close the door firmly — the course continues by itself. The DWD-M301WP/M221MB manuals add: if LE persists, open and close the door, then turn the washer off and restart it.

Is Daewoo LE the same as DE?

No. LE = the door was opened (user action, clears by closing the door). DE = the door-lock solenoid failed after more than 10 operations (a mechanism fault). Every competitor we checked conflates them; the Daewoo service document lists them as separate codes.

My Daewoo top-loader shows a lid error — is that LE?

No. Daewoo top-loader families (e.g. DWF-9001Q series) do not use LE at all — lid-open is E2 there. LE advice applies to DWD front-loader families only.
