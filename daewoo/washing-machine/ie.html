Daewoo Washing Machine Error Code IE

Quick answer

Error codeIE — Daewoo Washing Machine
What it meansWater fill fault: the water level sensor's frequency is not changing, or the machine does not fill within the set time.
Most common causeNo water supply (tap off), a clogged inlet filter, a kinked inlet hose — or a faulty inlet valve or level sensor.
Safe to check yourself?Yes — for the supply, hose and filter checks below.
Checked againstDaewoo washing machine service error code list

Applies to — read this first

Per Daewoo's service code list, IE is raised when the level sensor frequency does not change as expected during filling — in practice the machine is not getting water, or the sensor is not seeing it.

Find your model number on the rating label if you are not sure which family your machine belongs to — see how to find your model number.

Common causes

  1. The water tap is closed or the supply is cut off.
  2. The mesh filter in the inlet hose/valve connection is clogged with grit.
  3. The inlet hose is kinked or squashed.
  4. The inlet valve has failed, or the level (pressure) sensor or its air hose is faulty.

Safe checks, in order

  1. Switch off and unplug the machine, then close the water tap.
  2. Confirm the tap itself works: open it into a bucket — you should get a strong flow.
  3. Unscrew the inlet hose at the machine end and rinse the small mesh filter inside the valve connection.
  4. Straighten the inlet hose along its run and reconnect everything firmly.
  5. Reconnect power, start a wash, and listen: water should start entering within the first minute or two.

Work through the checks in order and stop as soon as the code clears. If a check needs a panel removed, a part tested, or a wire touched, it is no longer a safe home check — skip to the technician section.

When to call a technician

  • IE returns with a proven water supply and a clean filter — the inlet valve or level sensor needs testing.
  • Water enters but the machine still reports IE (the sensor is not registering the level).
  • Water keeps entering and does not stop — switch off at the tap immediately and call a technician.

More guidance: when an appliance error requires professional service.

Safety first

Close the tap and unplug before disconnecting any hose. Never open the machine's top or back panels to reach the valve or sensor — those are internal, mains-connected parts.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does IE mean on a Daewoo washing machine?

Per the Daewoo service code list, IE means the water level sensor frequency is not changing, or filling took too long — the machine is not filling as expected.

Is IE a water inlet problem?

Yes — it is the fill-side fault: supply, inlet filter/hose, inlet valve, or the level sensor that watches the fill.

My tap works fine. Why IE?

Then check the inlet mesh filter, and after that suspect the inlet valve or level sensor — both need a technician's test equipment to confirm.

Can low water pressure cause IE?

Yes. If filling takes longer than the set time because pressure is very low, the machine raises IE.
