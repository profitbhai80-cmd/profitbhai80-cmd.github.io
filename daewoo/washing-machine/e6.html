Daewoo Washing Machine Error Code E6

Quick answer

Error codeE6 — Daewoo Washing Machine
What it meansE6 on a Daewoo DWF top-loader means Child Protection: the lid was opened after the Child Lock function was set. Close the lid properly (first making sure any child is a safe distance away) and the warning clears. This is not a motor fault — the EMG/motor-current E6 belongs to Daewoo front-loaders only.
Most common causeThe lid was opened (or is not fully closed) after Child Lock was set — close the lid properly.
Safe to check yourself?Fully. E6 is cleared without tools: keep children away from the machine, then close the lid (cover) properly. No panels, wiring, or parts are involved.
Checked againstDaewoo DWF-9001Q / DWF-1401Q / DWF-1801Q / DWF-2001Q Washing Machine User Manual (Daewoo Electronics Sales & Services (M) Sdn Bhd) — Auto Alarm table; Daewoo DWF-7002FL Washing Machine User Manual (Daewoo Electronics Sales & Services (M) Sdn Bhd) — Error Digital Display Information; Daewoo Washing Machine Service Manual, DWD platform (front-loader contrast for E6 EMG); Daewoo Washing Machine Error Codes PDF, DD front-loader platform (front-loader contrast: E6 EMG at 20 A)

Applies to — read this first

Good news for diagnosis: on Daewoo DWF top-loaders, E6 is consistent — it is always the Child Lock / lid-open warning, never a motor fault. What you must NOT do is borrow the meaning from Daewoo front-loaders: on DWD/DWC front-loader and washer-dryer platforms E6 is an EMG (motor-current) fault — the current detected at the EMG port reaching 20 A or higher — and that meaning does not apply to any DWF top-loader.

The DWF-9001Q series user manual documents the Child Lock engage sequence (Water Level + Reset pressed together during running). Neither DWF user manual documents an 'unset' sequence for Child Lock — if E6 stays on with the lid fully closed, the manual's remedy is the service center, not a button combination.

What the machine does when E6 fires

The display shows E6 and the machine holds the cycle until the lid is closed properly — it is an interlock response to the lid being opened while Child Lock is set, not a second fault. Closing the lid properly is the manual's stated tactic.

Common causes

  1. The lid (cover) was opened after the Child Lock function was set — the trigger both DWF user manuals state. The machine flags E6 until the lid is closed properly.
  2. Child Lock engages when the Water Level and Reset buttons are pressed together during running (DWF-9001Q series manual) — it is easy to set it accidentally mid-cycle.
  3. The lid was not closed fully or latched after loading — the same E6 appears because the interlock reads the lid as open.
  4. If the lid IS fully closed and E6 stays on, the lid switch may not be registering closure — both manuals route this to the service center; the machine must not be disassembled by the user.

Safe checks, in order

  1. Make sure any child is a safe distance from the machine — the DWF-7002FL manual's own first instruction.
  2. Close the lid (cover) properly and firmly — the tactic both DWF user manuals prescribe. E6 clears once the lid interlock reads closed.
  3. If E6 remains with the lid fully closed, power the machine off and on once. If the code is still displayed, stop: the DWF-9001Q manual's troubleshooting says 'If the error flag is still displayed, contact commercial agent of service center,' and the DWF-7002FL manual's remarks say the customer must not assemble or disassemble — this is now a service-center matter (likely the lid switch).
  4. To avoid repeat E6: remember that Child Lock engages when the Water Level and Reset buttons are pressed together during running (DWF-9001Q manual) — avoid opening the lid mid-cycle while it is set.

Work through the checks in order and stop as soon as the code clears. E6 needs no tools and no panels removed — if closing the lid does not clear it, the manual's remedy is the service center, not further home diagnosis.

When to call a technician

  • E6 stays on with the lid fully closed and latched — the lid switch may not be registering closure.
  • E6 appears even though Child Lock was never knowingly set — a control or switch issue for service.
  • Any burning smell, smoke, sparking, or water near electrical parts — switch off immediately and call a qualified technician.

Safety first

E6 itself needs no electrical work — never remove covers or touch internal parts; both DWF manuals state the customer must not assemble or disassemble the machine. Keep children supervised and away from the washer (the manual's own precaution: do not permit children to go near the machine). If E6 remains with the lid fully closed, or if you notice a burning smell, smoke, or water near electrics, switch the machine off and call a qualified technician.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does E6 mean on a Daewoo top-load washing machine?

On DWF top-loaders E6 is the Child Lock warning: the lid was opened after the Child Lock function was set. Both Daewoo DWF user manuals define it this way — it is a user-correctable lid condition, not a parts failure.

How do I clear the E6 code on my Daewoo washer?

Make sure any child is a safe distance from the machine, then close the lid (cover) properly — those are the manual's own words, and E6 clears. If E6 stays on with the lid fully closed, stop and contact the service center; the manuals forbid user disassembly.

Is Daewoo washer E6 a motor fault?

No — not on top-loaders. E6 = EMG (motor current of 20 A or higher at the EMG port) applies only to Daewoo DWD/DWC front-loader and washer-dryer platforms. On DWF top-loaders E6 is Child Protection. Never borrow the meaning across platforms.

How do I turn Child Lock on or off?

The DWF-9001Q series manual says Child Lock is engaged by pressing the Water Level and Reset buttons together during running. Neither manual documents an 'unset' button sequence — closing the lid clears the E6 warning; a stuck E6 with the lid closed is a service-center matter.
