Daewoo Washing Machine Error Code H1

Quick answer

Error codeH1 — Daewoo Washing Machine
What it meansH1 on a Daewoo washer-dryer combo means the drying temperature sensor has failed: the manuals define it as 'Thermistor Dry OPEN/SHORT'. The DWC-ED1213 service manual's causes are a broken drying temperature sensor (change the sensor temp.) or a connector problem (check the contact of the connector). H1 is a drying-system code only — wash-only machines and top-loaders cannot display it.
Most common causeDrying temperature sensor fault — the dry thermistor is open or shorted, or its connector is faulty.
Safe to check yourself?No internal work. The only safe user actions are switching the machine off and on once to see whether H1 returns, and not using drying programs until the fault is fixed. Replacing the dry thermistor and checking its connector are technician repairs inside a mains-powered machine with a heated drying duct.
Checked againstDaewoo DWC-ED1213 Drum Washing Machine Service Manual (Dec 2005) — H1 sensor temp. dry disorder troubleshooting table; ERROR MODE table; dry-system troubleshooting; Daewoo DWD-E1211R / DWD-E1211W Drum Washing Machine Service Manual — ERROR MODE table: H1 Thermistor Dry OPEN/SHORT

Applies to — read this first

H1 exists only on Daewoo washer-dryer combos — the drum machines with a drying system (the R/DRY variants). The DWC-ED1213 service manual's parts list marks E1211R variants DRY and E1211W variants WASH, and H1 is the dry thermistor's code. What you must NOT do is apply H1 to a wash-only front-loader or a DWF top-loader: a wash-only machine has no dry thermistor, so it cannot display H1, and no top-loader manual lists any H code.

The wash-only DD front-loader error-code document lists H2, H4, H5, H6 and H8 but no H1 — consistent with H1 being dry-system only. The DWC-ED1213 manual's dry-system troubleshooting confirms the same boundary: its H1/H3 entries sit in the dry-system section, and its 'PCB shows H1 or H3' entry is a drying fault (thermistor broken, short or cut-off). If H1 appears on a machine with no drying function, check the model documentation first — this page's meaning may not apply.

What the machine does when H1 fires

The PCB shows 'H1' and the drying temperature control is lost, because the control can no longer read the drying temperature sensor. The service manuals state no alarm pattern or display-clear behaviour for H1, so do not promise that a power cycle clears it — if H1 returns after one restart, the sensor or its connector needs attention.

Common causes

  1. The dry thermistor is open or shorted — the ERROR MODE definition in both service manuals: 'H1: Thermistor Dry OPEN/SHORT'.
  2. The drying temperature sensor (sensor temp.) is broken — the DWC-ED1213 troubleshooting table's first H1 cause, remedied by changing the sensor temp.
  3. A connector problem on the dry thermistor circuit — the DWC-ED1213 troubleshooting table's second H1 cause: 'The contact of the Connector.'

Safe checks, in order

  1. Switch the machine off. Do not start or continue a drying program while H1 is showing — the control cannot read drying temperature without its sensor.
  2. Switch the machine back on once and check whether H1 returns. The manuals state no display-clear behaviour for H1, so treat a single restart as a check, not a fix.
  3. If H1 returns, stop using the drying function and call a qualified technician. Per the DWC-ED1213 manual the remedies are to check the contact of the dry thermistor connector and, if the sensor temp. is broken, to change the sensor temp. (replace the thermistor).
  4. When you call for service, give the full model number — including whether it is a DRY (R) or WASH (W) variant — and the exact display (H1). The manuals' diagnosis depends on the exact model and platform.

There is no documented user-serviceable fix for H1: both manual remedies (sensor replacement, connector check) are internal repairs. Do not open the duct or touch the thermistor, and do not keep running drying cycles in the hope the code clears.

When to call a technician

  • H1 returns after a single power off/on — the dry thermistor or its connector needs testing.
  • H1 appears together with H3 (dry overheating) — the drying thermal system needs technician diagnosis as a whole.
  • Any burning smell, smoke, or scorching near the machine — switch off immediately and call a qualified technician.

Safety first

H1 sits in the drying system, where a heater, a fan and mains power meet. Never remove duct covers, touch the thermistor or heater, or probe connectors. If you notice a burning smell, smoke, or scorching around the machine, switch it off and call a qualified technician. Do not run drying programs with H1 showing — the control cannot regulate drying temperature without its sensor.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does H1 mean on a Daewoo washing machine?

On Daewoo DWC/DWD washer-dryer combos H1 means the drying temperature sensor has failed: the manuals define it as 'Thermistor Dry OPEN/SHORT'. The DWC-ED1213 service manual's causes are a broken drying temperature sensor (change the sensor temp.) or a connector problem (check the contact of the connector).

Is H1 the same as H2?

No. H1 is the DRY thermistor (drying temperature sensor); H2 is the WASH thermistor (washing temperature sensor). The manuals list them as separate ERROR MODE entries, and they point to different sensors — do not swap their fixes.

Can a wash-only Daewoo washer show H1?

No. H1 is a drying-system code. Wash-only machines have no dry thermistor — the wash-only DD front-loader document lists H2, H4, H5, H6 and H8 but no H1, and no DWF top-loader manual lists any H code. H1 belongs to washer-dryer combos (the R/DRY variants) only.

What will a technician do for H1?

Per the DWC-ED1213 service manual: check the contact of the dry thermistor connector, and if the sensor temp. is broken, change the sensor temp. The manual's dry-system troubleshooting also lists replacing the thermistor when it is shorted or cut off. Both are internal repairs — not user work.
