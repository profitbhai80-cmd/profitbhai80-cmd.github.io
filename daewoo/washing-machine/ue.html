Daewoo Washing Machine Error Code UE

Quick answer

Error codeUE — Daewoo Washing Machine
What it meansUnbalance error — the load is unevenly distributed and the machine cannot spin safely. Daewoo's service document says UE appears when the unbalance switch is activated for the third time, after the machine already tried to rebalance the load twice during the spin stage.
Most common causeA single heavy item (one towel, one bedsheet) or tangled clothes sitting on one side of the drum.
Safe to check yourself?Yes — this is one of the safest codes to handle: pause, redistribute the load, restart.
Checked againstDaewoo washing machine service error-code document (UE trigger definition); Daewoo D-MU123 user manual, troubleshooting table (UE = UNBALANCE ERROR)

What the manual actually says

The Daewoo service error-code document is unusually specific: UE occurs when the unbalance switch is activated for the third time after the machine performed the unbalance operation (water pouring and flushing) twice during the spin stage. In plain language: the machine tried to fix the balance itself twice, failed both times, and gave up to protect itself. That matters, because it means UE is almost never a sensor fault — it is a genuinely unbalanced load.

The Daewoo D-MU123 user manual gives the exact reset procedure in its troubleshooting table: open the door, evenly distribute the load and close the door — then the error clears and rotation restarts.

Common causes

  1. A single heavy item — one towel, one bedsheet, a pair of jeans — that cannot balance itself in the drum.
  2. Clothes tangled into a ball on one side of the drum (common with mixed loads and sheets).
  3. A tiny load: with only two or three items, there is nothing to distribute around the drum.
  4. The machine is not level — even a small tilt makes every spin unbalance.
  5. On a new installation: the shipping/transit bolts were never removed, so the drum cannot move at all.

Safe checks, in order

  1. Pause the machine and wait for the door lock to release.
  2. Open the door and spread the clothes out evenly around the drum — untangle anything balled up.
  3. If the load is tiny or a single heavy item, add a few more items of similar weight so the drum can balance.
  4. Close the door firmly and run the spin cycle again.
  5. If UE keeps coming back: rock the machine gently — if it wobbles, adjust the feet until it sits solid and level.
  6. On a brand-new machine, check the back for shipping/transit bolts and remove them according to the installation manual.

Work through the checks in order and stop as soon as the code clears. If a check needs a panel removed, a part tested, or a wire touched, it is no longer a safe home check — skip to the technician section.

When to call a technician

  • UE appears on every cycle even with well-distributed, normal-sized loads and a level machine.
  • The machine shakes violently, "walks" across the floor, or makes loud banging during spin.
  • The drum feels loose or drops when you press it down — the suspension or shock absorbers may be worn.

Safety first

Always wait for the door lock to release before opening the door — forcing a locked door can break the lock and flood the floor. Switch off and unplug before adjusting the feet or moving the machine.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does UE mean on a Daewoo washing machine?

UE is an unbalance error: the load inside the drum is unevenly distributed, so the machine cannot spin safely. The Daewoo service error-code document says it appears when the unbalance switch is activated for the third time after the machine tried correcting the balance twice during the spin stage. The Daewoo D-MU123 user manual lists UE as "UNBALANCE ERROR" in its display error table.

How do I fix Daewoo washing machine error UE?

Pause the machine, open the door and spread the clothes out evenly around the drum, then close the door and run the spin cycle again. The manual's own instruction is exactly this: open the door, evenly distribute the load, close the door — the error clears and rotation restarts.

Why does UE happen on every spin cycle?

Recurring UE usually means one of three things: you keep washing single heavy items (one towel, one bedsheet) that cannot balance; the machine is not level; or the shipping/transit bolts were never removed on a new installation. Fix the root cause rather than redistributing each time.

Is UE dangerous? Can the machine break?

The UE protection itself prevents damage — it stops the spin instead of letting the machine shake itself apart. But ignoring repeated unbalance and forcing runs can wear the suspension and bearings over time, so fix it properly.
