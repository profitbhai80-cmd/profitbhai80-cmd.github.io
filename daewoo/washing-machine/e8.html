Daewoo Washing Machine Error Code E8

Quick answer

Error codeE8 — Daewoo Washing Machine
What it meansInitial-operation error: the Hall IC (motor speed/position sensor) connection signal is abnormal and the motor stops.
Most common causeA motor or Hall sensor connection problem, or a failed Hall sensor / motor — an internal fault.
Safe to check yourself?No — beyond noting the symptom and power-cycling once, this needs a technician.
Checked againstDaewoo washing machine service error code list

Applies to — read this first

Warning: some thin websites list Daewoo E8 as a “load sensor” problem. Daewoo's own service code list says E8 is the initial-operation error for the Hall IC / motor connection — trust the service list over copied blog lists.

Find your model number on the rating label if you are not sure which family your machine belongs to — see how to find your model number.

Common causes

  1. A loose or damaged connection between the motor's Hall sensor and the control board.
  2. A failed Hall IC sensor on the motor.
  3. A motor fault (winding or drive problem).

Safe checks, in order

  1. Switch the machine off and unplug it. Do not open any panels.
  2. Note exactly when E8 appears (at start-up, when the drum should first turn) — this helps the technician.
  3. Reconnect power once and try a short cycle. If the drum does not turn and E8 returns, stop — repeated restarts will not fix a sensor/motor fault.
  4. Book a technician and tell them the code, the model number, and when in the cycle it appears.

Work through the checks in order and stop as soon as the code clears. If a check needs a panel removed, a part tested, or a wire touched, it is no longer a safe home check — skip to the technician section.

When to call a technician

  • E8 appears at all — after one power-cycle retry, this code is itself the sign to call a technician.
  • The drum never turns, or turns jerkily, before the code appears.
  • Any unusual noise, smell or vibration from the motor area.

More guidance: when an appliance error requires professional service.

Safety first

The motor and its drive circuit carry mains voltage and stored charge. Never open the machine to inspect the motor or Hall sensor yourself.

Never open an appliance that is connected to power, never bypass a safety device, and never attempt gas, refrigerant or high-voltage work without the proper qualifications. If anything feels beyond a basic external check, stop and call a qualified technician.

Frequently asked questions

What does E8 mean on a Daewoo washing machine?

Per the Daewoo service code list, E8 is an initial-operation error: the Hall IC (motor sensor) connection signal is abnormal and the motor stops.

Is E8 a load sensor error?

No — that claim circulates on copied lists. The service list ties E8 to the motor's Hall IC connection, not a load sensor.

Can I fix E8 myself?

Realistically no. It involves internal motor wiring and sensors. One power-cycle retry is reasonable; after that it is a technician job.

Will the machine work if I keep restarting it?

Unlikely, and forcing repeated starts on a motor fault can make the damage worse. Note the symptom and book a repair.
